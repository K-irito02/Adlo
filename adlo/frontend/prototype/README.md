# Browser DnD Prototype（临时）

> 这是用于挑交互方案的 throwaway 原型，不是生产代码，也不会进入 production 构建。
> 选定方案已折进正式实现；原型与切换器保留在当前工作分支供追溯，不随主分支发布。

## 跑起来

```powershell
pnpm --dir adlo/frontend exec vite --port 5174 --strictPort
```

打开：

```text
http://127.0.0.1:5174/prototype/browser-dnd.html
```

页面底部浮动条切换 A/B/C/D，也可用键盘 `←` / `→`；URL 带 `?variant=A|B|C|D`，可分享/刷新保持。

## 四套方案

| 方案       | 放置区                                              | 反馈                                                        |
| ---------- | --------------------------------------------------- | ----------------------------------------------------------- |
| A 行三分区 | 目录行上/下 20% 排序，中间 60% 放入                 | 插入线 + 行高亮                                             |
| B 行间缝隙 | 目录行上下各约 10px（或行高 34%）排序，中间区域放入 | 插入线 + 行高亮 + 末端投放带                                |
| C 意图延迟 | 快速划过只排序，停留 500ms 升级为放入               | 插入线 → 行高亮                                             |
| D 幽灵占位 | 采用 A 的分区                                       | 排序：覆盖式幽灵行（不透明） / 放入：虚线幽灵子行（半透明） |

## 已实现的规则

- 书签目录 / 书签列表不出现活标签；活标签只在「已打开标签页」列表。
- 同一容器内书签与目录混合排序；无手动顺序时默认目录在前。
- 顺序写入「容器 → 子项 key 数组」状态，可在右侧状态面板实时查看。
- 跨分类移动：文件夹 ↔ 任意文件夹 / 工作区根节点；书签 → 文件夹 / 工作区根节点。
- 自建目录标题行 / 空白区：文件夹松手变成顶级目录；书签禁止。
- 工作区根节点不可拖，但可作为放置目标；不能变成新顶级目录。
- 历史目录只读。
- 放入折叠目录保持折叠；顶部开关可启用「悬停 600ms 临时展开」。
- 已打开标签页：pinned 固定在前的分组，只在组内排序；边界对两类都合法。
- 非法拖拽恢复原状并给短 toast。

## 已知边界

- 静态 mock 数据、内存态；刷新/重置回到初始。不写 localStorage，不调后端。
- 只演示单条拖拽，没有撤销/重做/键盘排序/多选。
- 行高、字体、间距是原型近似，不是生产组件像素级还原。
- 使用 HTML5 drag & drop；桌面 WebView2 与浏览器若有差异，以实际手感为准。

## 拖拽反馈样式原型（视觉，独立页面）

```text
http://127.0.0.1:5174/prototype/browser-dnd-feedback.html
```

用户已选定 **B（渐隐线）**，最终采用 **B2 标准**；当前页面保留三档中性深浅用于对照：

| 强度    | 放入背景                | 插入线                                   |
| ------- | ----------------------- | ---------------------------------------- |
| B1 轻   | 暗：12% 白 / 亮：9% 黑  | 暗：62% 白 / 亮：55% 黑，光晕 12% / 8%   |
| B2 标准 | 暗：16% 白 / 亮：12% 黑 | 暗：84% 白 / 亮：78% 黑，光晕 20% / 12%  |
| B3 强   | 暗：22% 白 / 亮：17% 黑 | 暗：100% 白 / 亮：92% 黑，光晕 30% / 18% |

- 放入沿用“整行淡色背景”，**不加**描边或外发光；插入为两端渐隐的 2px 线。
- 颜色不跟随强调色：暗色主题用白，亮色主题用黑。
- URL 参数：`?variant=B1|B2|B3&theme=light|dark`；键盘 `←` / `→` 切换强度。
- 左侧树可真实拖动查看反馈；右侧同时给出静态规格、颜色值与实现要点。只比较视觉，不改变顺序。

## 抬起副本样式原型（视觉，独立页面）

```text
http://127.0.0.1:5174/prototype/browser-dnd-ghost.html
```

原行保持原位，副本按原行 1:1 克隆跟随光标；四个变体只改抬升处理。**已选 B（纸张 · 厚阴影）**，并保留近直角（`--radius-sm` = 2px），不做更圆的卡片：

| 变体            | 抬升处理                                       |
| --------------- | ---------------------------------------------- |
| A 现状 · 轻浮   | 1px 边框 + 8/24 双层阴影 + 2% 放大             |
| B 纸张 · 厚阴影 | 无边框 + 2/12/28 三层阴影 + 上浮 2px + 3% 放大 |
| C 玻璃 · 模糊   | 半透明 + 12px backdrop blur + 内高光描边       |
| D 拿起 · 微倾   | 深阴影 + 上浮 3px + 3.5% 放大 + -0.8° 微倾     |

- 亮暗主题各自定义阴影与边框强度；副本内容、尺寸与原行一致。
- URL 参数：`?ghost=A|B|C|D&theme=light|dark`；键盘 `←` / `→` 切换。
- 左侧可真实拖动；右侧提供“原行 / 抬起副本”静态对照与实现要点。
