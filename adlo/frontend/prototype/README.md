# 一次性设计原型

本目录存放**不参与打包**的设计原型（单文件 HTML，双击即可打开）。它们用于在实现前对比方案，
选择结果已落到产品代码；保留在这里作为决策的原始参考。

| 目录                  | 主题                            | 选择结果                       |
| --------------------- | ------------------------------- | ------------------------------ |
| `landing-cards/`      | 着陆页快捷站点/端口卡片的透明化 | C 图标悬浮                     |
| `audio-controls/`     | 弹窗与右下角音量控件            | 弹窗 B 胶囊；右下角 D 常驻竖条 |
| `audio-corner-glass/` | 右下角玻璃/无边框方案           | G1 磨砂双色                    |
| `audio-capsule-wrap/` | 胶囊向上包裹图标 + 5 种滑杆样式 | S1 细轨圆点                    |

约定：原型可以随时删除或重写，不写测试、不接真实数据；不要从产品代码引用这里的文件。
