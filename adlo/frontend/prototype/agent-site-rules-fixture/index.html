Adlo · Agent Site Rules · Fixture

拦截规则测试页

用 Adlo 内置浏览器打开本页，并把它加入「Agent 网址白名单」。逐项点击，核对右侧面板是否按预期打开文件 / 网址；负向用例应保持浏览器原生行为。

准备：设置 → 打开方式 → 开启「Agent 链接拦截」→ 白名单加入 http://127.0.0.1:5200 → 在「拦截规则」里确认全局规则已启用。本页由 pnpm run prototype:serve 提供；直接双击打开时 origin 是 file://，白名单不匹配。
本地文件目标：本页同目录的 sample.md / sample.txt / sample.json，以及 Windows 自带的音频 / 壁纸。
应由拦截规则接管 应保持原生行为 / 不拦截

1. 网站链接 http(s)

普通网站链接 https://example.com/ 按「链接打开方式」打开 远程视频 URL https://www.w3schools.com/html/mov_bbb.mp4 按下载 / 链接打开方式处理 文档链接 https://example.com/docs/guide.md 按「链接打开方式」打开

2. 本地文件 / 媒体 file:// 与本地路径

本地 markdown file:///.../sample.md 应由拦截规则以「打开文件」接管 本地文本 file:///.../sample.txt 应由拦截规则以「打开文件」接管 本地音频 file:///C:/Windows/Media/Alarm01.wav 应由拦截规则以「打开文件」接管 本地图片 file:///C:/Windows/Web/Wallpaper/Windows/img19.jpg 应由拦截规则以「打开文件」接管 本地视频（不存在的负向样本） file:///C:/no-such-folder/sample-video.mp4 应尝试打开并给出错误，不得静默无响应

3. 属性规则 title / aria-label / data-* / 正则

4. 原生行为 不应被拦截

mailto mailto:test@example.com 交给系统邮件客户端 页内锚点 #section-anchor 页面内滚动，不新建标签

5. 媒体元素 直接播放，不经点击拦截

本地音频播放 WebView2 可能因安全策略禁止 http 页面直接加载 file:// 媒体（属预期）；点击用例才是拦截路径
远程视频播放 用于确认媒体渲染未被拦截逻辑影响
