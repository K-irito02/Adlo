# 用户偏好只由用户操作写入

## 适用范围

设置面板中属于「用户显式选择」的配置：来源偏好（自动检测 / 系统安装 / 宿主托管 / 指定路径）、代理模式、下载源、版本来源。运行时事实（当前是否运行、某来源下有没有可用版本）不属于偏好。

## 规则

1. 后台 effect、定时任务、轮询与兜底逻辑**只能读取**偏好，不得写回配置。
2. 偏好写入必须由用户操作触发（下拉变更、按钮点击、恢复默认）；写入失败要提示并回滚界面。
3. 需要「自愈」时改变运行时行为（如代理不可达时本次直连），不得改写偏好值。
4. 业务确需自动纠偏时，先与用户确认并把决定记入 ADR，不得由实现自行决定。

## 正例 / 反例

- 正例：代理模式为「自动检测」且端点不可达 → 本次请求直连，下拉仍显示「自动检测」（ADR-0006）。
- 反例：版本来源为「自动检测」且无可用版本时，effect 自动写回「宿主托管」（2026-10-30 已移除）。

## 检查清单

- [ ] 新增 effect / 定时器是否写配置？改为只读。
- [ ] 每处写入是否都有用户操作入口？
- [ ] 「自愈」是否只改变运行时行为？
