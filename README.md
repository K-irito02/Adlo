# digitalLife

AI数字生命项目 - 现代化AI编程软件实现规划

## 项目概述

本项目旨在构建一个真正的"AI数字生命"——一个能够自动操作电脑上任何内容的智能体。

### 当前阶段

目前聚焦于现代化AI编程能力的实现，这是AI数字生命的基石：
- AI编程助手（MVP）
- 文件管理能力
- 浏览器操作能力
- 应用控制能力
- 完整AI数字生命

## 目录结构

- `digitalLife/aiFunction/expectedFunctionality/` - 功能规格文档

## 技术栈

- TypeScript 5.3+
- Electron 28+
- Vite + electron-builder
- Zustand (状态管理)
- pnpm (包管理)
