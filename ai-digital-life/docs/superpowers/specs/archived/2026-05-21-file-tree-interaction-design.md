# 文件树与文件列表交互背景效果设计

## 一、设计目标

为"文件"功能（文件树）和"变更"功能（文件树、文件列表）设计清晰、直观的三种鼠标交互背景效果：左键选中、右键菜单激活、鼠标悬停，同时考虑各种边缘情况，确保交互体验健壮且一致。

## 二、核心设计原则

1. **视觉优先级明确**：选中状态 > 右键菜单激活状态 > 悬停状态 > 无状态
2. **反馈即时性**：所有状态变化响应迅速，无明显延迟
3. **上下文一致性**：同一状态在不同面板（文件/变更）和不同视图（树/列表）下表现一致
4. **状态互斥与叠加规则清晰**：明确各状态的叠加关系和优先级

## 三、状态定义与优先级

### 3.1 状态优先级（从高到低）

| 优先级 | 状态名称 | 触发方式 | 视觉表现 | 持续时间 |
|--------|----------|----------|----------|----------|
| 1（最高） | 多选选中（含主选中项） | Ctrl+点击、Shift+点击、拖拽选择 | 常驻灰色背景 | 直到手动取消或切换面板 |
| 2 | 左键单选选中 | 鼠标左键点击（无修饰键） | 常驻灰色背景 | 直到其他项被选中或手动取消 |
| 3 | 右键菜单激活 | 鼠标右键点击 | 常驻灰色背景 | 直到菜单（含子菜单）完全关闭 |
| 4 | 鼠标悬停 | 鼠标移入 | 灰色背景 | 鼠标移出即消失 |
| 5（默认） | 无状态 | - | 透明背景 | - |

### 3.2 状态叠加规则

- 若某一项同时处于**选中状态**（单选或多选）和**右键菜单激活**状态：仅显示选中状态（选中状态优先级最高）
- 若某一项同时处于**选中状态**（单选或多选）和**鼠标悬停**状态：仅显示选中状态
- 若某一项同时处于**右键菜单激活**和**鼠标悬停**状态：仅显示右键菜单激活状态
- 若某一项仅处于一种状态：显示该状态
- 若某一项无任何状态：无背景

## 四、详细交互设计

### 4.1 鼠标左键点击（选中状态 - 单选与多选）

**单选模式交互规则**：
- 无修饰键左键点击任意文件或文件夹项：
  - 若当前无多选状态：该项进入左键单选选中状态，显示常驻灰色背景
  - 若当前有多选状态：清除所有多选，该项进入左键单选选中状态
- 同一时刻，**文件面板**和**变更面板**各自**独立**维护选中状态
- 在同一面板内，点击新项时：原选中项取消选中，新项进入选中状态
- 点击已选中项：保持选中状态不变
- 按 Esc 键：取消当前面板的所有选中状态

**多选模式交互规则**：
- **Ctrl+左键点击**：
  - 若点击的项未被选中：将其加入多选集合
  - 若点击的项已被选中：将其从多选集合移除
  - 首次 Ctrl+点击时，被点击项成为**主选中项**（Primary Selection）
- **Shift+左键点击**：
  - 必须已有至少一个选中项才能触发
  - 选中主选中项与当前点击项之间的所有连续项（按列表顺序）
  - 保持原主选中项不变
- **鼠标拖拽选择**：
  - 在空白区域按住左键开始拖拽
  - 拖拽过程中，被矩形框覆盖的所有项被加入多选集合
  - 拖拽结束时，最后一个被覆盖的项成为主选中项
- **Ctrl+A**：选中当前面板中所有可见项
- 多选状态下，所有被选中项显示相同的选中背景

**视觉表现**：
- 所有选中项（单选和多选）背景色使用项目现有设计系统中的选中态颜色
- 背景色与主题适配（浅色/深色模式自动切换）
- 文字颜色保持不变
- 图标颜色保持不变
- 主选中项与其他多选项视觉上无区别（保持一致性）

### 4.2 鼠标右键菜单（右键菜单激活状态）

**交互规则**：
- 右键点击任意文件或文件夹项：
  - 若该项未被选中：临时将其加入选中集合（作为主选中项），**保持原有的选中项不变**，显示右键菜单激活背景
  - 若该项已被选中：保持选中状态不变，显示右键菜单激活背景
  - 若当前有多选状态：右键点击的项成为主选中项，所有多选项保持选中状态
- 右键菜单（含子菜单，如"重命名"子卡片）打开期间：
  - 主选中项保持激活状态（若有多选，其他多选项保持选中状态）
- 右键菜单完全关闭（包括所有子菜单）时：
  - 右键菜单激活状态立即消失
  - 若右键点击前该项未被选中：**清除临时添加的该项，保持其他原有选中项不变**
  - 若右键点击前该项已被选中：保持选中状态不变
  - 多选状态继续保持（不受右键菜单关闭影响）
- 右键菜单打开期间，鼠标悬停到菜单项上：菜单项有自己的悬停效果，不影响触发菜单项的状态
- 右键菜单选项根据选中项数量和类型动态调整：
  - **剪切（Cut）**：始终可用（单选/多选），将选中项标记为待剪切状态
  - **复制（Copy）**：始终可用（单选/多选），复制选中项路径到剪贴板
  - **粘贴（Paste）**：当前目录无选中项或仅右键菜单激活项时可用
  - **重命名（Rename）**：仅单选时可用，多选时禁用或仅对主选中项生效
  - **删除（Delete）**：始终可用（单选/多选），删除所有选中项
  - **其他单文件操作**（如"打开方式"）：仅单选时可用

**视觉表现**：
- 右键菜单激活项背景色使用与悬停状态相同的颜色（`--surface-hover`）
- 与主题适配
- 文字和图标颜色保持不变
- 背景状态变化即时响应，无过渡延迟

### 4.3 鼠标悬停（悬停状态）

**交互规则**：
- 鼠标移入任意文件或文件夹项，该项立即进入悬停状态，显示灰色背景
- 鼠标移出该项，背景立即消失
- 若该项已处于左键选中或右键菜单激活状态：不显示悬停效果
- 悬停效果在所有可交互项上一致，无论是否有子项

**视觉表现**：
- 背景色使用项目现有设计系统中的悬停态颜色
- 与主题适配
- 文字和图标颜色保持不变
- 背景色变化即时响应，无过渡延迟

## 五、边缘情况处理

### 5.1 多面板状态独立性

**场景**：用户在文件面板选中了文件 A（或多选了 A、B、C），然后切换到变更面板右键点击了文件 D

**处理**：
- 文件面板：保持原有选中状态（文件 A 或多选 A、B、C）
- 变更面板：文件 D 进入右键菜单激活状态
- 两个面板的状态完全独立，互不影响

### 5.2 右键菜单期间的交互

**场景**：右键点击文件 A（单选或多选状态下的主选中项）打开菜单后，用户将鼠标移到文件 B 上悬停

**处理**：
- 文件 A：保持右键菜单激活状态（若有多选，其他多选项保持选中状态）
- 文件 B：显示悬停效果

### 5.3 文件夹展开/折叠

**场景**：用户选中文件夹 A（或多选包含文件夹 A）后，展开或折叠它

**处理**：
- 文件夹 A 保持选中状态
- 展开/折叠操作不影响选中状态
- 折叠后，子项不再可见，但选中状态仍然保留；展开后恢复显示

### 5.4 文件列表滚动

**场景**：用户选中文件 A（或多选包含文件 A）后，滚动列表使文件 A 离开可视区域，再滚动回来

**处理**：
- 文件 A 重新可见时，保持选中状态
- 选中状态与滚动位置无关

### 5.5 多选操作中的边缘情况

**场景 1：Shift+点击无前置选中项**
- 用户未选中任何项时直接 Shift+点击
- **处理**：等同于普通左键点击，进入单选选中状态

**场景 2：Shift+点击跨层级**
- 用户选中文件夹 A 下的文件 A1，然后 Shift+点击文件夹 B 下的文件 B1
- **处理**：选中文件夹 A 到文件夹 B 之间按树结构顺序排列的所有可见项

**场景 3：拖拽选择跨越折叠文件夹**
- 用户拖拽选择时，矩形框覆盖了折叠的文件夹
- **处理**：将整个折叠文件夹加入多选集合

**场景 4：多选状态下的右键操作**
- 用户多选了文件 A、B、C，右键点击文件 B
- **处理**：文件 B 成为主选中项，所有多选项保持选中状态，右键菜单显示适用于多选的操作选项

**场景 5：多选状态下打开子菜单**
- 用户多选后打开右键菜单，再打开"重命名"子菜单
- **处理**：选中状态保持不变，子菜单关闭后选中状态继续保持

### 5.6 剪切/复制状态与选中状态的交互

**场景 1：剪切状态下的选中**
- 用户对文件 A 执行剪切操作，然后选中文件 B
- **处理**：文件 A 保持剪切标记（如图标变化），文件 B 进入选中状态

**场景 2：多选剪切**
- 用户多选文件 A、B、C，执行剪切操作
- **处理**：所有选中项都标记为剪切状态，选中状态保持不变

**场景 3：剪切后右键菜单**
- 用户剪切文件 A 后右键点击它
- **处理**：右键菜单中"粘贴"选项可能根据上下文变化，但选中状态正常显示

## 六、设计规范与颜色选择

保持与项目现有设计系统一致，不做任何改变。

### 6.1 颜色规范

使用项目现有设计系统中的 tokens：

| 状态 | 背景色 Token | 说明 |
|------|--------------|------|
| 左键选中 | 项目现有选中态颜色 | - |
| 右键菜单激活 | 与选中状态相同颜色 | - |
| 鼠标悬停 | 项目现有悬停态颜色 | - |
| 无状态 | 透明 | - |

### 6.2 过渡动画

- 所有状态变化（悬停、选中、右键菜单激活）：**无过渡延迟**，即时响应
- 使用 `transition: none` 确保背景状态立即变化

### 6.3 圆角与边距

- **圆角**：直角（无圆角），背景效果为矩形填充
- **边距**：无左右边距，背景效果左右两边贴合对应项的左右边缘线

## 七、应用范围

本设计适用于：
1. **文件面板**：文件树视图
2. **变更面板**：
   - 文件树视图
   - 文件列表视图

两个面板的交互行为完全一致。

## 九、实现状态

### 9.1 已完成功能

1. ✅ **三种交互状态背景效果**
   - 左键选中状态（单选）
   - 右键菜单激活状态
   - 鼠标悬停状态

2. ✅ **状态优先级正确**
   - 选中状态 > 右键菜单激活状态 > 悬停状态

3. ✅ **即时响应**
   - 使用 `flushSync` 确保状态同步更新
   - CSS `transition: none` 禁用过渡动画

4. ✅ **外部状态同步**
   - FileTree 组件内部状态与外部 `selectedFilePath` 同步
   - 右键菜单不影响原有选中项

### 9.2 待完成功能

1. ⏳ **多选功能**
   - Ctrl+点击、Shift+点击、拖拽选择尚未实现
   - 需要在后续迭代中完成

2. ⏳ **左键选中背景颜色**
   - 当前左键选中状态使用 `--surface-hover` 颜色
   - 需要修改为使用 `--surface-active` 加深颜色
   - 这是当前已知的问题，正在排查中

### 9.3 技术债务

1. **状态管理复杂性**
   - 当前实现同时使用内部状态和外部状态
   - 可能需要简化状态管理逻辑

2. **性能优化**
   - `areFileTreeNodePropsEqual` 自定义比较函数需要验证
   - 可能需要调整 memo 的使用策略
