# Minimap 右键菜单重新设计

## 设计决策

| 项目 | 决策 |
|------|------|
| 风格 | 方案 C · 极简线条风 |
| 分段控件 | 下划线标签式，「缩略图 / 标准」 |
| 选中指示 | 底色高亮 + `::before` 左侧纯直线（无边框弯曲） |
| 选中标记 | 底色高亮代替勾选（移除 `√` checkmark） |
| 密度 | 适中（`padding: 6px 12px`） |
| 背景 | 纯直角（`border-radius: 0`） |
| 缓存 | Visual Companion 服务器已添加 `Cache-Control: no-cache` |

## 深色主题颜色体系

| 状态 | 背景色 | 竖线色 |
|------|--------|--------|
| 默认 | `#181818` | 透明 |
| 悬停（选择状态） | `#282828`（较淡） | `#888` |
| 选中（激活状态） | `#242424`（较深） | `#d8d8d8`（与分段下划线统一） |

## 浅色主题颜色体系

| 状态 | 背景色 | 竖线色 |
|------|--------|--------|
| 默认 | `transparent` | 透明 |
| 悬停 | `#f5f5f5` | `#c0c0c0` |
| 选中 | `#ebebeb` | `#222` |

## 菜单结构

- 分段控件：缩略图 / 标准
- 分组标题：显示
  - 渲染字符
- 分组标题：缩放
  - 50% / 100% / 150% / 200%
- 分组标题：宽度（仅在缩略图模式显示）
  - 60px / 80px / 100px / 120px
- 分组标题：滑块突出
  - 明显 / 正常
- 分组标题：设置
  - 全局 / 独立
