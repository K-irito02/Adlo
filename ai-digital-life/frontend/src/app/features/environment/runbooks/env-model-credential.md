# 模型凭据（env-model-credential）

## 症状

- dsh 界面能正常打开，但发送消息后没有回复，或提示未配置模型、鉴权失败。
- 「环境」设置组的模型行没有状态灯，只展示中性的引导文本；即使出现「凭据存储可用」，也与模型配置无关。

## 检测命令

宿主侧没有模型可用性的检测信号：`/env/status` 不包含模型状态；
`ciTokenConfigured` 只表示本机是否存在 CI / GitHub token，既不代表凭据存储整体可用，
也不代表模型已配置成功。因此以 dsh 界面自身的提示为准，不要根据设置组的行状态判断模型是否就绪。

## 安装步骤

本项不是本地安装，而是在 dsh 侧完成配置：

1. 打开 dsh 的配置入口（设置中的模型 / 凭据项，具体名称随 dsh 版本变化）。
2. 按当前模型提供方的要求录入 API Key，占位示例：`<你的 Key>`。
3. 只在该配置界面录入；不要把 Key 写进项目文件、日志、截图或本 runbook。

## 装后回填

回到 dsh 发送一条测试消息，能正常收到回复即配置成功。
随后可在「环境」设置组点「重新检测」，刷新宿主侧状态。

## 回滚

在 dsh 的同一配置入口删除或清空该 Key；如之前有可用配置，恢复上一份模型设置。
移除后记得再发一条测试消息，确认已回到预期状态。
