Tooltip 过渡动画预览 — A / B / C / D / E / F

把鼠标悬停在按钮上看出现动画，移开看消失动画。tooltip 外观统一为中性样式，只比较动效本身。
小提示：消失动画只有约 100ms，一眨眼就没了——如果看不清，可以把鼠标快速"划过"按钮边缘，让 tooltip 反复触发/消失来感受。

A — 现状（上浮淡入）当前线上

透明度 + 上浮 4px，中规中矩的悬浮感。

进入 opacity 450ms + 上浮 4px / 退出 300ms（演示放慢，实战会收紧）
悬停我A：上浮淡入 tooltip 再试一次多试几次感受节奏

B — 缩放浮现

从触发点"长"出来，带一点回弹，活泼，按钮感呼应最强。

进入 opacity + scale(.9→1) 550ms（轻微 overshoot）/ 退出 350ms（演示放慢）
悬停我B：缩放浮现 tooltip 再试一次多试几次感受节奏

C — 滑入

位移最大（10px），有明确的"飞过来"方向感，存在感最强。

进入 opacity + 滑行 10px 600ms / 退出 350ms（演示放慢）
悬停我C：滑入 tooltip 再试一次多试几次感受节奏

D — 纯淡入淡出

无任何位移，原地显隐，最稳、最不打扰，适合高频悬停场景。

仅 opacity 450ms / 退出 300ms（演示放慢）
悬停我D：纯淡入淡出 tooltip 再试一次多试几次感受节奏

E — 纯滑入已选定

只有滑入位移，无缩放，形状与线上实现一致（线上为实战速度 300/100ms）。

进入 opacity + 滑入 8px 500ms / 退出 300ms（演示放慢）
悬停我E：组合 tooltip 再试一次多试几次感受节奏

F — 模糊浮现

由虚到实聚焦，现代感强；注意低端机大面积模糊会有轻微性能开销（tooltip 很小，影响可忽略）。

进入 opacity + blur(3px→0) + 微浮 2px 550ms / 退出 350ms（演示放慢）
悬停我F：模糊浮现 tooltip 再试一次多试几次感受节奏
挑选方式：直接回复 A / B / C / D / E / F，或混搭（例如"E 的进入 + D 的退出""B 但去掉回弹"）。
