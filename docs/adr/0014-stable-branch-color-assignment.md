# 分支配色优先保持稳定，超过色板容量时允许复用

分支图谱要求分支标签、泳道与提交节点使用同一颜色，并且用户新增或删除分支时，已有分支的颜色不得顺移。另一方面，色板槽位数量固定，分支数超过容量时无法让每个分支都独占一种颜色。

决定：**以「名称 → 槽位」的持久化映射为真源，合法已存槽位无条件保留（包括重复槽位）；只有没有记录的新分支才消费空闲槽位。** 分支暂时缺席时保留其历史（历史条目有上限，当前分支永不淘汰）；分支数超过色板容量时复用颜色，而不是重新分配已有分支。色板槽位按色相分离排序，使相邻槽位尽量可区分。

**Considered Options**: 仅按分支名哈希取色（每个名字永久稳定，但相近名字可能撞到相似色，无法保证当前分支可区分）；按当前分支集合排序分配槽位（当前集合最可区分，但增删分支会让后续分支整体顺移）；超过容量或分支删除后重新去重以恢复唯一色（颜色更整齐，但会移动已有分支，违背用户要求）。

**Consequences**: 超过色板容量的分支会出现重复颜色，这是容量上限的必然结果；持久化映射中已存在的重复槽位不会被自动清理，避免因「修复重复」而移动既有分支。映射落盘在 `adl-git-vis:branch-colors`，属于用户可见颜色的持久契约，修改分配策略时必须同时考虑该键的重置或迁移。
