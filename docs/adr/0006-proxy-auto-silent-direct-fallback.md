# 自动检测代理不可达时静默改走直连，自定义代理不回退

代理软件退出后，进程环境变量与 Windows 系统代理常常残留（用户实测 2026-10-30：`ALL_PROXY` 指向已停止监听的本地端口），「自动检测」如实跟随会让下载、版本目录与环境检测整体失败。因此约定：自动检测在建立连接前探测代理端点（结果缓存 5 秒），不可达即本次请求改走直连；不修改配置、不改写下拉显示，真实状态由设置项下方的解析提示与 `proxyEffective` 说明。自定义模式是用户显式填写的地址，失败必须如实报错，绝不静默绕过。代理选择与 reqwest 同源（scheme 环境变量 → Windows 注册表系统代理 → `ALL_PROXY`），否则健康检查与真实请求会对不上。

**Considered Options**: 一律失败并报错——代理残留时应用完全不可用；自动把模式改成「关闭」——破坏用户选择，且代理恢复后不会自愈；只读环境变量——在「只开系统代理」这一常见 Windows 配置下永远看不到代理。

**Consequences**: 自动模式存在「有意使用代理却被悄悄绕过」的窗口（端点不可达时），靠解析提示与 5 秒健康缓存自愈补偿；手动模式保持诚实但不自愈；PAC 自动配置脚本不解析（与 hyper-util 一致）。
