# 宿主托管 CLI 通过终端 PATH 注入生效，而非全局安装

终端会话创建时，若某个 harness 的版本来源解析为宿主托管且该版本已安装，就把其可执行目录前置到该会话的 PATH；来源为系统安装时不注入。不写系统或用户环境变量、不执行 `npm -g`，因此不污染用户机器，也不与应用内多版本切换冲突。只影响新会话（已开会话保持旧 PATH），并提供「在终端中可用」开关（默认开）。OpenCode 另需注入独立的会话数据库路径，见 [ADR-0010](./0010-hosted-opencode-database-isolation.md)。

**Considered Options**: `npm -g` 安装（需管理员权限、污染全局、无法按版本切换）；改系统 PATH（不可逆、影响其它程序）；只给绝对路径说明（用户无法直接敲 `opencode`）。
