# 0017 · 书签导入导出与书签身份独立化

**状态**：已采纳
**日期**：2026-11-09

## 背景

浏览器书签最初借用「标签页 id」当自己的身份（`BookmarkTabItem.tabId`）。只要书签对应的标签页
不再打开——「仅保存」创建的书签、关掉的标签页、从外部文件导入的条目——这层借用就会让一批
动作静默失效：`在当前标签打开`、`显示在中心`、`全部在新标签打开` 都会在找不到活标签页时直接返回。

同时，用户需要与 Edge / Chrome / Firefox / Safari 互通书签，而外部文件携带 `ADD_DATE`、
`LAST_MODIFIED`、`ICON` 三个属性——现有模型一个都存不下。

## 决定

1. **书签是独立实体**：`BookmarkEntry { id, url, title, addedAt, lastModifiedAt, sourceTabId? }`，
   身份与标签页完全解耦；`sourceTabId` 只是可选弱引用，用于「取消收藏仍打开的标签页时同步移除它带来的那份收藏」。
2. **删除 `browserBookmarkTabIdUrlMap`**：它唯一的作用是「条目 URL 为空时反查」，`url` 必填后彻底冗余。
   连带删除 `buildBrowserTabUrlMap` 复合水合器与登记条目。
3. **持久化键改名**：`adl:browser.tabFolders` → `adl:browser.bookmarkFolders`。未发布阶段不写迁移，
   旧键数据直接丢弃。
4. **文件格式只做 Netscape bookmarks HTML**，不做 JSON 私有格式——JSON 其它浏览器读不了，
   只会多一条只有本应用能用的维护路径。
5. ~~**导出写全三个属性**；`ICON` 在导出时按 URL 从站点元数据缓存取 `favicon_data_uri`，**不落书签**：
   一条 data URI 可达数十 KB，而书签存在 localStorage 里、每次修改都要整体序列化。~~
   → **2026-11-12 修订**：`ICON` 仍随文件导入/导出，但**导入时写入书签条目**的
   `iconUri`（跨会话唯一来源）；导出优先用条目自带快照，缺失时回退站点元数据缓存。
   已知代价：导入文件里的图标快照会进 localStorage，受导入文件 10MB 上限约束；若后续遇到
   配额问题，再评估按目录/大小裁剪。展示侧不直接读 `iconUri`，而是启动/导入时播种进共享
   站点元数据镜像（见 [ADR-0020](./0020-site-icon-mirror-and-bookmark-snapshot.md)）。
6. ~~导入判重按 `(url, title)`，只在目标容器内比较~~ → **2026-11-10 修订**：导入判重仍按
   `(url, title)` 元组，但范围扩大为**目标树整体**（`folder`/`self-root`/`workspace` 三类目标，
   含目标子树全部嵌套后代；`new-folder`/`child-folder` 新建目标保持空种子），「跳过重复项 /
   允许重复」的选择从 UI 移除，**永远跳过**。用户 2026-11-09 已决定「永远默认跳过重复项」；
   空树不落位、同名同父复用、空子树不导入，一并以「重复项一律跳过」为不更改口径。
7. **图标/时间戳随文件保留**：从 Chrome 导出再导回 Chrome，收藏时间不变。

## 备选方案与取舍

- **把图标存进书签条目**：会被否决。1000 条书签 × 6KB ≈ 6MB，逼近 localStorage 配额，
  且每次收藏都要序列化几 MB。
- **判重范围扩到全应用**：会被否决（2026-11-10 修订后依然成立）。新建目标保持空种子（无既有子树可判），
  「导入到新文件夹」不会变成"全部跳过"；用户显式重导（目标树判重）不会产生重复；清除重复是另一个功能。
- **复用 `clipboard_save_to_file` 落盘**：会被否决。书签导出调「剪贴板保存」会误导后来人，
  因此把「另存为」提升为与域无关的 `fileSave` 能力（见提交 ③）。

## 后果

- 书签与标签页的动作分界变清晰：需要活标签页的动作（关闭、显示在中心移动）只对真标签页出现；
  按 URL 的动作（打开、导出、在新标签打开）对书签同样有效。
- 删除书签不再连带关闭标签页；只有删除工作区节点才会关闭该工作区的面板标签。
- 浏览器模式下没有系统「另存为」对话框，导出改用 `Blob` + `<a download>`；
  行为差异（无法选择保存路径）由平台能力决定，功能结果一致。
