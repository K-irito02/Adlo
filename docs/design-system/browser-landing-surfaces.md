# 着陆页表面与音量控件（2026-11）

> 适用于「新建标签页 / 着陆页」的卡片表面与视频音量控件；选择记录见
> `docs/root-cause-to-close/2026-11/progress-2026-11-25-204116.md`。

## 卡片表面：图标悬浮（C）

- 快捷站点与本地端口卡片**不占底色**（`background: transparent`）、无常态边框；
  悬停时给 `--bg-hover` 淡底 + `--border-subtle` 边线作为命中反馈。
- 图标保持形状（快捷站点 32px 圆形、端口状态点 8px）；快捷站点图标用主题对应的 2px 描边 + 投影保证在任意
  用户背景上可辨，端口状态点用实色（成功/危险）表达状态、不额外描边。卡片名称与端口地址使用 `--text-primary`、
  端口标签使用 `--text-secondary`，均带主题对应文字投影。
- 分区标题（快捷站点 / 本地端口）同样加一层柔和文字投影。
- 拖拽悬停态仍使用 `--accent` 边线与 `--accent-soft` 光圈（内部拖拽反馈，不属于按钮语义）。

## 音量控件

两处控件共用同一套原子与交互：

| 原子 | 契约 |
| --- | --- |
| `HorizontalVolumeSlider` / `VerticalVolumeSlider` | 自绘 S1「细轨 + 圆点」；支持点击、拖拽（window 级 pointer 事件）、滚轮、方向键 / PageUp / Home / End。 |
| `VolumePercent` | 百分比数值；悬停/键盘聚焦显示 `--bg-hover` 底（2px 圆角）；双击进入输入，输入框固定 14px 高、2px 圆角，Enter/失焦提交，Esc 取消且不关闭父弹窗。外层固定宽度槽位保证编辑前后滑杆长度不变。 |
| 音量图标 | 点击切换静音；悬停背景为**圆形**。 |

### 弹窗（自定义背景）— B 胶囊

- 音量区位于「背景填充」上方，标题与控件同一行。
- 控件容器为胶囊（`border-radius: 999px`、`padding: 3px 9px`、`--bg-elevated`），
  内部顺序：音量图标 → 横向 S1 滑杆 → 百分比。
- 百分比悬停背景 2px 圆角；输入框 14px 高。

### 着陆页右下角 — 音量胶囊（G1 磨砂双色）

- 常态：**只有图标，无背景**；图标恒为灰白色（亮暗主题一致），带轻投影保证浅色背景可见。
- 悬停/聚焦：胶囊向上生长（44×170），把图标包在底部；上方依次是百分比与竖向 S1 滑杆。
- 玻璃：半透明中性色 + `backdrop-filter: blur(18px) saturate(1.1~1.15)`；图标圆底比胶囊浅一档；
  **不使用边框线**。亮色主题胶囊 `rgba(255,255,255,.62)`，暗色 `rgba(20,22,26,.66)`。
- 展开条件为 `:hover`、`:has(:focus-visible)`、`:has(input:focus)`；鼠标操作后移出即收拢，
  键盘 Tab 仍保持展开。
- 图标悬停圆底 22px；百分比悬停底色 2px 圆角。
