OpenCode 深度分析（四）：UI 架构分析

源码参考路径：references/opencode/packages/tui/、app/、desktop/

1. 三端 UI 总览

@opencode-ai/tui    → 终端 UI (opentui + SolidJS)
@opencode-ai/app    → Web UI (SolidJS + Tailwind)
@opencode-ai/desktop → Electron 桌面壳
     ↓ 共享
@opencode-ai/sdk    → API 客户端
@opencode-ai/core   → 核心逻辑
@opencode-ai/schema → 类型定义

2. TUI 终端 UI (packages/tui/)

2.1 Provider 层级（~20 层 Context）

ExitProvider → ErrorBoundary → TuiPathsProvider
  → ClipboardProvider → OpencodeKeymapProvider
    → KVProvider → RouteProvider → TuiConfigProvider
      → PluginRuntimeProvider → SDKProvider (API连接)
        → PermissionProvider → SyncProvider (中央数据)
          → ThemeProvider (34套主题) → LocalProvider
            → DialogProvider → LocationProvider → App

2.2 组件层次

App
├─ StartupLoading                  # 启动动画
├─ Home (routes/home.tsx)          # 首页
│   ├─ Logo + Prompt
│   └─ Plugin Slots
├─ Session (routes/session/)       # 会话页
│   ├─ Sidebar                     # 文件树等
│   ├─ MessageTimeline (ScrollBox)
│   │   ├─ UserMessage
│   │   ├─ AssistantMessage
│   │   │   ├─ ReasoningPart (思考折叠)
│   │   │   ├─ TextPart (Markdown)
│   │   │   └─ ToolPart (Shell/Edit/Read...)
│   │   └─ RevertBar
│   ├─ PermissionPrompt / QuestionPrompt
│   └─ Prompt Slot
├─ DialogStack (20+ Modal)
└─ CommandPaletteDialog / Toast

2.3 状态管理：SyncProvider

集中式 SolidJS createStore + reconcile + produce：

const [store, setStore] = createStore({
  sessions: {}, messages: {}, parts: {},
  agents: {}, providers: {}, permissions: {},
})
setStore("session", reconcile(newData))

数据流：SSE → batch → reconcile → SolidJS 细粒度更新

2.4 键盘映射与主题

  • Keymap：基于 @opentui/keymap，模态键位 + Leader 键（2000ms 超时）+ 50+ 注册命令
  • 主题：34 套内置终端配色方案，日/夜自动切换

4. Desktop (packages/desktop/)

Sidecar 架构

Electron Main Process
├─ 启动 Sidecar 服务器（随机端口 + 密码认证）
├─ 管理 WSL Sidecar（Windows）
├─ IPC 通道（44 handler）
│   ├─ 服务器/文件/剪贴板/窗口管理
│   ├─ 自动更新 / WSL / 调试
│   └─ DeepLink
└─ Renderer Process
    ├─ 加载 Web UI
    ├─ contextBridge (window.api)
    └─ HTTP 连接 Sidecar/WSL/SSH

服务器连接类型

类型场景
Sidecar (base)本地桌面
Sidecar (wsl)Windows WSL 后端
SSH远程 SSH 连接
HTTP直接 HTTP 远程

5. TUI vs Web vs Desktop 对比

维度TUIWebDesktop
运行时Node.js 终端浏览器Electron
渲染引擎opentui 字符级DOM + Tailwind同 Web
输入键盘(Keymap+Leader)鼠标+触摸同Web+原生菜单

主题34套终端配色CSS变量同Web+原生标题栏
i18n英文18种语言同 Web
终端本身就是终端ghostty-web 嵌入同 Web
