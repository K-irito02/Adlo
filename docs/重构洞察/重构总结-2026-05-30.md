## 本轮重构要点

### 1. **Rust Crate 职责边界重构**（P0）

#### 问题诊断
- `terminal` crate 和 `pty` crate 存在严重代码重复
- `terminal` crate 仅做重新导出，自身代码实际未使用
- 两个 crate 功能完全重叠

#### 解决方案
- **删除 `terminal` crate**（原位置：`crates/terminal/`）
- **统一使用 `pty` crate** 和 `command` crate
- 更新所有相关文件的 import

#### 修改文件列表
| 文件 | 变更 |
|------|------|
| `E:\Programs\Obsidian\notes\ai-digital-life\Cargo.toml` | workspace.members 添加 "src-tauri"，移除 "crates/terminal" |
| `E:\Programs\Obsidian\notes\ai-digital-life\src-tauri\Cargo.toml` | 依赖从 adl-terminal 改为 adl-pty + adl-command |
| `src-tauri/src/setup.rs` | use adl_terminal::session_manager → use adl_pty::SessionManager |
| `src-tauri/src/state.rs` | use adl_terminal::session_manager → use adl_pty::SessionManager |
| `src-tauri/src/commands/pty_commands.rs` | use adl_terminal::session_manager → use adl_pty::PtySessionInfo |
| `src-tauri/src/terminal.rs` | use adl_terminal::session_manager → use adl_pty::PtyEventEmitter |
| `src-tauri/src/commands/command.rs` | 添加 use adl_command::{build_request, run_command, run_approved_command, validation_command} |
| `src-tauri/src/commands/patch.rs` | 添加 use adl_command::{run_command, validation_command} |

### 2. **前端代码清理与性能优化**（P0）

#### MessageBlocks React.memo
- 为 `MessageBlocks.tsx` 组件添加 `React.memo`
- 优化 props 传递，避免不必要重渲染

#### MessageStream 虚拟滚动
- 完善 `MessageStream.tsx` 组件
- 集成 `react-window` 实现虚拟滚动
- 正确处理消息高度和滚动行为

#### ui-store.ts 清理
- 删除所有标记 `@deprecated` 的代码
- 保留仍在使用的导出（如类型）

#### CenterPane 简化
- 使用重构后的 `MessageStream` 组件
- 清理内联消息渲染逻辑
