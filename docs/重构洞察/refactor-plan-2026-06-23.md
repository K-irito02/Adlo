## 执行原则

1. **先小后大**：优先执行单文件、低风险变更，积累信心后再推进大范围变更
2. **每步验证**：每完成一项变更，立即运行类型检查 + 相关测试
3. **不破坏现有功能**：所有修改不得改变 UI/UX 行为
4. **失败即停**：任一步骤失败，停止后续执行，分析原因后决策
