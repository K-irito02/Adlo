# 窗口控制

> 标题栏右侧的窗口控制按钮组，用于最小化、最大化/还原和关闭窗口。

## 双端差异

| 模式 | 行为 |
|------|------|
| Tauri 桌面 | 显示窗口控制按钮，可实际执行最小化/最大化/关闭操作 |
| 浏览器模式 | 显示窗口控制按钮，但点击无实际操作效果（浏览器有原生窗口控制，不支持自定义窗口操作） |

> 窗口控制按钮在所有模式下均渲染，但 Tauri 模式下通过桥接层执行实际窗口操作，浏览器模式下为无操作 UI。该设计旨在保持双端 UI 一致性。

## 按钮列表

| 按钮 | 说明 | 文档 |
|------|------|------|
| 最小化 | 将窗口最小化到任务栏 | [最小化](#最小化) |
| 最大化/还原 | 切换窗口最大化状态 | [最大化/还原](#最大化还原) |
| 关闭 | 关闭应用窗口 | [关闭](#关闭) |

## 容器选择器

| 选择器 | 说明 |
|--------|------|
| `.adl-titlebar__window-group` | 窗口控制按钮组容器 |
| `.adl-iconstrip` | 按钮条容器 |

## 最小化

> 将窗口最小化到任务栏

### 定位选择器

| 优先级 | 类型 | 选择器 |
|--------|------|--------|
| 1 | aria-label | `button[aria-label="最小化"]` |
| 2 | CSS | `.adl-window-btn` (第一个，减号图标) |

### 前置条件

- [x] 无特殊条件

### 操作

```javascript
await page.click('button[aria-label="最小化"]');
```

### 状态变化

- 窗口最小化到任务栏
- 页面不可见

### 预期结果

- 窗口从屏幕消失
- 应用仍在运行（任务栏可见图标）

### 注意

- 最小化后无法通过页面操作恢复
- 测试需要使用系统级操作恢复窗口

## 最大化/还原

> 切换窗口的最大化状态

### 定位选择器

| 优先级 | 类型 | 选择器 |
|--------|------|--------|
| 1 | aria-label | `button[aria-label="最大化"]` 或 `button[aria-label="还原"]` |
| 2 | CSS | `.adl-window-btn` (第二个，方形/双矩形图标) |

### 前置条件

- [x] 无特殊条件

### 操作

```javascript
// 点击最大化/还原按钮
const btn = await page.waitForSelector('button[aria-label="最大化"], button[aria-label="还原"]');
await btn.click();
```

### 状态变化

| 当前状态 | 切换后状态 | aria-label 变化 | 图标变化 |
|----------|------------|-----------------|----------|
| 正常 | 最大化 | "最大化" → "还原" | 方形 → 双矩形 |
| 最大化 | 正常 | "还原" → "最大化" | 双矩形 → 方形 |

### 预期结果

- 窗口大小变化
- 按钮图标和 aria-label 更新

### 等待条件

```javascript
// 等待最大化状态变化
await page.waitForFunction(() => {
  const btn = document.querySelector('button[aria-label="还原"], button[aria-label="最大化"]');
  return btn !== null;
});
```

### 验证状态

```javascript
const isMaximized = await page.evaluate(() => {
  const btn = document.querySelector('button[aria-label="还原"]');
  return btn !== null;
});
```

### 图标说明

| 状态 | 图标 | CSS 类名 |
|------|------|----------|
| 正常 | 方形 (`IconSquare`) | - |
| 最大化 | 双矩形 (`IconCopy`) | - |

## 关闭

> 关闭应用窗口

### 定位选择器

| 优先级 | 类型 | 选择器 |
|--------|------|--------|
| 1 | aria-label | `button[aria-label="关闭"]` |
| 2 | CSS | `.adl-window-btn--close` |

### 前置条件

- [x] 无特殊条件

### 操作

```javascript
await page.click('button[aria-label="关闭"]');
```

### 状态变化

- 应用窗口关闭
- 应用进程退出

### 预期结果

- 窗口关闭
- 应用退出

### 注意

- 关闭后应用完全退出
- 测试需要重新启动应用

## 按钮样式

### 普通状态

| 按钮 | 背景色 | 图标颜色 |
|------|--------|----------|
| 最小化 | 透明 | 当前颜色 |
| 最大化/还原 | 透明 | 当前颜色 |
| 关闭 | 透明 | 当前颜色 |

### 悬停状态

| 按钮 | 背景色 | 图标颜色 |
|------|--------|----------|
| 最小化 | 浅灰 | 当前颜色 |
| 最大化/还原 | 浅灰 | 当前颜色 |
| 关闭 | 红色 | 白色 |

### CSS 类名

```css
.adl-window-btn          /* 窗口按钮基础样式 */
.adl-window-btn--close   /* 关闭按钮特殊样式 */
```

| Tooltip | `.tooltip__content` | 悬停按钮时显示的提示 |
