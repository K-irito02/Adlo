# 汉堡菜单

> 标题栏左侧的汉堡菜单，点击展开一级菜单，悬停展开二级子菜单。

## 菜单结构

```
┌─────────────────────────────────────────────────────────────┐
│ [☰]  ← 点击展开                                            │
│     ↓                                                       │
│     ┌──────────────┐                                        │
│     │ 文件        → │ ─── 悬停展开子菜单                     │
│     │ 视图        → │ ─── 悬停展开子菜单                     │
│     │ 帮助        → │ ─── 悬停展开子菜单                     │
│     └──────────────┘                                        │
│                    ┌──────────────┐                          │
│                    │ 新建工作空间    Ctrl+N │                  │
│                    │ 打开文件夹      Ctrl+O │                  │
│                    │ ...            │                         │
│                    └──────────────┘                          │
└─────────────────────────────────────────────────────────────┘
```

## 交互行为

### 点击汉堡图标
- 打开/关闭一级菜单
- 一级菜单包含：文件、视图、帮助（均为悬停展开子菜单的分类，无直接触发项）

### 悬停文件/视图/帮助
- 向右展开对应的二级子菜单
- 子菜单与父级保持 8px 间距
- 鼠标在父级和子菜单之间移动时保持两者都打开（120ms 延迟）

### 键盘操作子菜单
- `ArrowDown/Up` 在一级分类间移动；`ArrowRight` 打开子菜单并聚焦首项
- 子菜单内 `ArrowDown/Up` 移动，`Enter` 触发，`ArrowLeft`/`Escape` 返回/关闭

### 关闭菜单
- 点击菜单外部区域
- 按 Escape 键
- 点击菜单项后自动关闭

## 快捷键

> 菜单右侧显示的快捷键文本由各命令的当前绑定派生（设置 → 快捷键可改）；
> 下表为默认值。`退出 Alt+F4`（macOS `⌘Q`）为系统级展示，不可自定义。

| 快捷键 | 功能 | 所属子菜单 |
|--------|------|-----------|
| `Ctrl+N` | 新建工作空间 | 文件 |
| `Ctrl+O` | 打开文件夹 | 文件 |
| `Ctrl+Shift+E/G/B/\`` | 打开文件/变更/浏览器/终端面板 | 视图 |
| `Ctrl+Shift+Plus` | 放大 | 视图 |
| `Ctrl+-` | 缩小 | 视图 |
| `Ctrl+0` | 重置缩放 | 视图 |
| `Ctrl+Shift+Comma` | 设置 | 视图 |
| （未分配） | 键盘快捷键 | 帮助 |
| `Alt+F4` | 退出 | 文件 |

## 状态

### 触发按钮状态

| 状态 | CSS 类名 | aria 属性 | 说明 |
|------|----------|-----------|------|
| 关闭 | - | `aria-expanded="false"` | 默认状态 |
| 打开 | `.is-open` | `aria-expanded="true"` | 下拉菜单可见 |

### 一级菜单项状态

| 状态 | CSS 类名 | aria 属性 | 说明 |
|------|----------|-----------|------|
| 普通 | - | `role="menuitem"` | 无子菜单 |
| 有子菜单 | - | `role="menuitem" aria-haspopup="true"` | 悬停展开子菜单 |
| 悬停 | `.is-hovered` | `aria-expanded="true"` | 子菜单已展开 |

## 注意事项

1. **单菜单模式**：同一时间只能打开一个汉堡菜单
2. **悬停延迟**：鼠标在菜单项和子菜单之间移动有 120ms 延迟，防止闪烁
3. **Escape 关闭**：按 Escape 键可关闭所有菜单
4. **无障碍**：所有菜单项都有 `role="menuitem"`，支持屏幕阅读器
