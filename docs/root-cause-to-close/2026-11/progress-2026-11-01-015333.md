## 需求与最终实现

### 1. 刷新图标（DSH / OpenCode CLI / 网络 / 环境）

- **行级刷新**：E · 悬停显现。
  - 版本组：版本来源、当前版本、正式版本、预发布版本；检查更新行不提供。
  - 网络：下载源 / 代理模式，仅「自动检测」时显示。
  - 环境：Node.js / Git / Bash / WebView2 / adlserver。
  - 悬停槽 `width: 0 → 22px`，不占常驻宽度；触屏常显；`title` 统一「刷新」，`aria-label` 带对象名。
- **块级刷新**：DSH / OpenCode 版本管理块头、环境基础依赖 / 系统组件块头；版本卡通过 `HarnessVersionCardHandle.refreshAll` 重载整卡。
- **网络 auto 行语义**：重新检测并写回（下载源写 `npm_registry`；代理无持久端点，`force` 清 5s 健康缓存后重探解析结果）。
- **环境独立性**：`/env/recheck` 接受 `{ deps?: string[] }`，只探测请求依赖并与缓存合并；两个块互不联动。

### 2. 直连名单（网络 · 代理模式 = 自定义）

- **最终形态 A · 单行翻页**：
  - 输入框一次显示一条；右侧 `n/total` 与上下箭头只在悬停/聚焦时出现。
  - Enter / Shift+Enter 在当前条目后新增空条目（本地草稿保留，保存值过滤空行），不打开弹层。
  - 三个输入框同宽 200px；展开按钮绝对定位在输入框与卡片内边距之间，不挤占输入框。
  - 展开弹层：多行文本域、原生垂直滚动条、图标关闭、底部单行提示「每行一个地址，无需分隔符，修改会自动保存。」；标题栏可拖拽，限制在设置内容区内，位置不持久化。
  - 兼容历史逗号分隔，编辑后按换行写回；后端 `no_proxy_matches` 同时接受逗号与换行。

### 3. 用户反馈修复记录

1. 点一行刷新导致其它按钮变淡/禁用 → 按行 `Set` + 内部串行，移除跨行 `refreshBusy`。
2. 胶囊骨架出现时行高/卡片跳动 → 原控件 `visibility: hidden`，胶囊绝对覆盖。
3. 代理自定义分隔线过多 → 手动模式卡片内行分隔线移除。
4. HTTP/HTTPS/直连名单缺少提示小字 → 新增 zh/en 描述。
5. 直连名单编辑器 → 先出 A–D 原型，用户选 A 后落地并细化（计数隐藏、按钮进沟槽、图标关闭、自动保存提示、拖拽、原生滚动条）。
6. 版本选择器被改到右侧 → 通道行控件区左对齐。
7. 操作按钮跟着左移 → 通道行控件内容撑满宽度，选择器 `margin-right:auto` 把操作推到最右。
8. 输入框/展开按钮垂直不居中 → 控件盒 flex 居中 + 末行补齐对称下内边距。
9. 弹层双滚动条 → 移除项目 `RevealScrollbar`，仅保留原生垂直滚动条。
