## [x] 事项 3：蓝色来源行显示「运行中」与文案整理

- 状态：已完成（2026-11-04 07:1x 用户桌面实测通过并批准收尾） | 类型：优化/调整 | 流程：本技能 P0–P6
- 根因（已定位）：`crates/server/src/handlers/dsh.rs:1004 running_payload` 对非本次会话拉起的进程恒填 `source="external"`；前端 `DshVersionSourceNote.tsx` 在 `effective==='running'` 时优先取 `running.source`（external → 「运行中」），而同一行的显隐依据是 `resolvedByMode`（忽略 running），两者口径不一致，于是「管理项按系统安装隐藏了，蓝色行却说运行中」。
- 修复：
  - 标签口径：运行中且来源已知 → 取进程自身来源；其余 `resolvedSource === 'system'` 一律报「系统安装」；外部进程 + 非系统偏好 → 仍「运行中」。

  - OpenCode：蓝色行只在 `auto && (system|host)` 显示（不再把 `none` 当来源）。
  - 文案：`dshSystemManagedNote` / `opencodeSystemManagedNote` 改为来源口径的一句话（不再断言「正在用的就是系统安装」），删除与切换对话框重复的「立即生效/下次启动生效」bullets（zh-CN + en-US）；两份来源提示拆成两组判据（管理三行 vs 当前版本/终端开关），并写明同源不重复。

- 验证（真实浏览器，`dev:preview` 中 patch `getSettingsSnapshot`/`getSourceStatus`）：
  - auto→system + external running：蓝色行 = `当前实际使用：系统安装`（原为「运行中」）；警告行 = 新一句文案。
  - 钉住 system（真实生效）：蓝色行消失，仅一句警告。
