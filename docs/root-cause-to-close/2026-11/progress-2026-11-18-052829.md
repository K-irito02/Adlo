## 二、设计决策（grilling 三轮 + 用户后续追加）

| 决策项 | 结论 |
| ------ | ---- |
| 投递机制 | 官方 `tauri-plugin-updater`；下载与安装分离；失败退化为关于页手动下载 |
| 发布来源 | GitHub + Gitee 双源；Gitee 清单落仓库文件 `release/latest.json`，GitHub 用 `releases/latest/download/latest.json` |
| 安装包 | 只发 NSIS、按当前用户安装；MSI / 绿色包不参与自动更新 |
| 版本约定 | tag `vX.Y.Z` 与 `tauri.conf.json` 严格一致；仅稳定通道；说明取 Release 正文首段纯文本 |
| 通知落点 | 通知面板卡片 + 关于页入口；手动检查不弹浮层（`silent`）；不设安装前确认弹窗 |
| 检查策略 | 启动 45s 一次 → 每 24h；手动可随时；自动失败静默；「跳过此版本」按版本记忆 |
| 浏览器模式 | 入口保留但禁用，文案说明「随宿主构建更新」 |
| 签名密钥 | 用户本地生成（`%USERPROFILE%\.tauri\adlo.key`），公钥写入 `plugins.updater.pubkey`；私钥不外传 |
| SmartScreen | 不购证书；下载页说明 + SHA-256 核对 |

ADR：[0026](../adr/0026-app-update-via-official-updater-dual-source.md)、[0027](../adr/0027-update-install-without-confirmation-dialog.md)。
