## 逐项结论

### 1 端口详情闪窗

- 根因：`port_scan.rs` 的 Windows 分支裸拉 `netstat`/`tasklist`，无 `CREATE_NO_WINDOW`，GUI 宿主为其新开控制台。
- 修复：`hidden_command()`（`CREATE_NO_WINDOW`）；netstat/tasklist 全部改走它。同类先例：`dsh.rs::hidden_command`、`adl_server.rs`。
- 验证：Rust 单测 13 项（含 open/closed port 详情）；用户桌面实测「查看详细」不再闪窗。

### 2 聚焦线中性色

- 根因：`PortConfigDialog.css` 用 `--accent`（蓝）；全局 `--focus-ring` 亦为蓝。
- 修复：新增 `--focus-border`（暗 `#fff` / 亮 `#000`），`input/textarea/select` 与端口输入框统一使用；输入框聚焦只用边框（`center.css` 全局禁用输入 ring 的既有策略保持不变）。规范指向 `docs/design-system/foundations/tokens.md`。
- 验证：`getComputedStyle` 实测亮 `rgb(0,0,0)`、暗 `rgb(255,255,255)`。

### 3 卡片透明（C 图标悬浮）

- 根因：卡片 `background: var(--bg-card)` 不透明。
- 修复：快捷站点/端口卡透明、无边框，悬停淡底；图标 2px 描边 + 投影，名称/地址/标签加主题对应投影；分区标题同步投影。
- 验证：`getComputedStyle` 卡片/端口背景 `rgba(0,0,0,0)`；原型 `adlo/frontend/prototype/landing-cards/index.html` 选型 C。

### 4 图片/视频独立文件槽

- 根因：单一 `filePath/fileName`，切模式后预览为空、上传区被隐藏。
- 修复：`drafts.image` / `drafts.video` 双草稿，各自预览与上传区；切换模式互不覆盖。
- 验证：浏览器实测切视频出现视频自己的上传区，切回图片仍保留预览；组件用例覆盖。

### 5 拖拽无效

- 根因链：① 上传区无 HTML5 `onDragOver/onDrop`；② Tauri 拦截外部拖放，`tauri://drag-drop` 的 JS `listen` 被 ACL 拒绝（`plugin:event|listen not allowed by ACL`）；③ wry 的 `with_drag_drop_handler` 回调未触发（日志无 `[ADL-DROP]`）；④ `WM_DROPFILES` 也被 WebView2 先吞。
- 修复：`capabilities/default.json` 显式补 `core:event:default`；`app/hooks/fileDropRouter.ts` 统一路由（覆盖层优先、未消费才打开工作区）；`drop_target.rs` 在 WebView2 子窗口注册自有 OLE `IDropTarget`（独立 STA 线程 + 消息泵 + 子窗口枚举重试），落点写入 `file_drop` 队列（3s 过期）并广播 `adl:file-drop`；`useDragDropWorkspace` 只订阅该事件（其它平台由 `main.rs` 的 `RunEvent::WindowEvent::DragDrop` 桥接成同名事件），弹窗打开时另以 300ms 轮询 `browser_take_pending_drop` 兜底并排空历史落点；事件/轮询重复投递用 1.5s 去重；浏览器模式走 HTML5 drop。
- 验证：用户桌面实测拖拽生效；日志出现 `[ADL-DROP] ole drop targets registered` / `drop (ole target)`。

### 6/7 灰字与重置

- 根因：首个 section 渲染当前模式名；`handleReset` 末尾 `onClose()`。
- 修复：删除该行；重置只清草稿并回默认，不关弹窗、不落库。
- 验证：实测弹窗初始无 label；重置后弹窗仍开、模式为默认。

### 8 预览慢 / 加载 / 应用

- 根因：`FileReader.readAsDataURL` 整文件转 base64 塞进 `background-image`/`<video>`，同一巨串写 localStorage；系统对话框打开期间就进入 importing。
- 修复：弃用 data URL；桌面 Rust 复制到 `%APPDATA%/<id>/adl-backgrounds` + asset 协议流式读取，浏览器 IndexedDB Blob + object URL；`browser_pick_background_file` 只返回路径，选完才 importing；上传/预览用 Spinner，应用按钮应用期只显示 Spinner（尺寸不变）；移除 64MB 上限；素材清理延迟 4s 且以当前配置为准。
- 验证：浏览器预览即时（object URL）；实测 `matrix(1.6…)` 与刷新后恢复；用户在桌面确认大视频可用。

### 9 自由调整并入三种填充

- 根因：原有 `custom` 第四档 + 缩放滑杆，且 transform 作用于媒体元素本身导致溢出。
- 修复：删除 `custom` 档（旧值按 cover 读入）；三种模式统一支持拖拽平移 + 滚轮缩放 + 右上角复位图标；预览改「外层裁剪容器 + 内层媒体 transform」，不再遮挡其它元素；预览区独立底色；切换填充模式复位 adjust；点击已显示背景不再触发更换文件。
- 平铺：图片 `background-size: 33% auto` 重复；视频只保留铺满/适应（单 video 无法真实平铺）。
- 验证：实测滚轮 `scale(1.43)`、拖拽 `translate(12.3%,11.8%)`、复位回零；切换填充复位；媒体不越界。

### 10 终端标签悬停按钮

- 根因：标签栏只渲染关闭按钮。
- 修复：关闭左侧加 `IconArrowUpLeft` + `t.centerTabShowInCenter`，操作区绝对定位（`adl-tool-list__item-actions`），卷帘遮挡宽度同步调整；点击调用 `centerShowTerminalTab`。
- 验证：悬停两按钮 `opacity=1`，顺序为「在中间区显示」→「关闭」，点击后中心标签栏出现 PowerShell。

### 11 视频音量

- 根因：`<video>` 固定 muted；无音量状态。
- 修复：`BackgroundConfig.volume/muted` 持久化；弹窗胶囊（B）+ 新建标签页右下角胶囊（G1 玻璃）共用 `HorizontalVolumeSlider`/`VerticalVolumeSlider`（S1 细轨圆点）+ `VolumePercent`（双击输入、`title=双击输入`、hover 2px 底色）；默认静音起步，交互后解除；`muted` 随配置保存，切面板回来保持。
- 验证：实测音量 0.25→0.93 时主视频/配置/百分比/滑块一致；百分比输入框 34×14；切换填充不改变滑杆长度。

### 12 后台播放与单解码/单音频（canvas 镜像）

- 根因：`useBackgroundVideoPlayback` 只在 `[videoRef]` 上绑定，媒体 URL 异步解析后 `<video>` 才挂载 → 播放控制从未绑定；切回面板带声 autoplay 被拒后永久暂停；多 surface 各自解码导致进度/音频不一致。
- 修复：`backgroundVideoStage.ts` 模块级常驻隐藏 `<video>`（单解码/单音频/单时钟），每个新建标签页只画 `<canvas>`（rAF 约 30fps）；`key` 指纹（assetPath/assetId）避免弹窗预览重复换源；隐藏时继续播放并静音，可见面恢复音量；`registerVideoSurface` 注销时重新判定音频；弹窗已应用视频用同源 canvas 镜像并实时同步音量。
- 验证：浏览器实测两处 canvas + 一个 master；切「文件」工具 `muted=true`、`paused=false`、`currentTime` 继续；切回 `muted=false` 且进度连续；弹窗 canvas 镜像 + 音量双向同步。
