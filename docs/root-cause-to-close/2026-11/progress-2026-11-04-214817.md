## [x] 事项 14：首次运行准备「超时后任务占用」缺陷
- 状态：待用户确认 | 类型：解决 | 流程：本技能 P0–P6
- 根因：`FirstRunProvisioningWizard.waitEnvTask` 是**总时长**硬上限（240 × 500ms = 120s）；Node 下载超过 2 分钟后前端判「安装超时」并立刻重试，但后端 `env_task` 仍被 Node 占用，`try_begin_env_task` 返回 `another env task is already running`（`crates/server/src/handlers/env.rs:667`）。该竞争被当作一次失败尝试计数，4 次机会在 ~2 分 12 秒内耗尽。诊断单证明 Node 后端任务最终成功（宿主托管 26.13.0）——失败是前端放弃，不是安装失败
- 级联：Git 的 4 次尝试全部撞上同一占用 → 从未启动；Bash 要求 `bash.effective === 'host'`，Git 未装 → 报「宿主 Git 包未包含 bash」
- 修复：(A) `MAX_WAIT_POLLS = 1200`（10 分钟上限，替代 240）；(B) 新增 `isEnvTaskBusy`，`install` 返回占用时先 `waitEnvTask` 等占用方收尾，就绪即判 done，不再计为失败；(C) `verifyBash` 区分「Git 未就绪」与「Git 包无 bash」，新增 i18n 键 `firstRunGitNotReady`（zh/en）

## [x] 事项 17：来源切换后界面延迟 2–3 秒才更新
