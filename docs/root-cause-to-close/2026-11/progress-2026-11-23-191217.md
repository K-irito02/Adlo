  - 结论：**主因分层 = 不可控网络/IP 风控 + 可控的冷 profile + 可控的自家指纹（全站原生 API 改写/点击接管）+ 嵌入式认证流程**；UA、深链形状、搜索 URL 构建均不是原因。未证实项：Google 搜索是否读取 `isTauri`/`chrome.webview`、各因素定量权重、Bing 挑战规则。

  3. `Cargo.toml` 增加 `Win32_System_JobObjects` feature。
