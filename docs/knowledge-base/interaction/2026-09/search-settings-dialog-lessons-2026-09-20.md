# 检索设置弹窗经验（2026-09-20）

本轮 27 事项 + Phase 4 三轮审查：检索设置弹窗（忽略树 + 限制 + 保存语义 + 虚拟化）与前后端 gitignore 镜像。

## 1. 复用带 full-bleed 假设的行类进弹窗前，先读它的 width/margin

`adl-filetree__row` 是 `width: calc(100% + offset)` + 负 margin 的 full-bleed 设计，
专为无边框面板准备（靠面板裁剪）。搬进有边框弹窗即左右溢出，且 `rowOffset`
随深度放大使越深越歪。教训：复用行级 chrome 时区分"视觉 token"与"布局假设"；
布局假设（bleed/负 margin/容器裁剪）必须在目标容器里重验，截图是最快的证据。

## 2. 虚拟化占位公式必须覆盖容器的 gap

行高 28px + 容器 `gap: 1px` = 真实行距 29px，占位按 28px 算随行数累积错位。
教训：固定行高虚拟化时，行距 = 行高 + 容器 gap + 边框；三者任一变化都要同步改
常量。做法：容器 `gap: 0`（分隔改行内实现）+ CSS 与 `ROW_HEIGHT` 互锁注释 +
单测断言 `gap: 0`，三保险。

## 3. zustand `getState()` 快照不能做"写后检查"

`set` 同步产生新 state，旧快照引用永不更新。保存逻辑里"先 set 再读旧快照做
不变量检查"恒读旧值。教训：落盘前本地先算好钳制 + 收敛再一次性写入；
需要"写后读"时重新 `getState()`。审查时见到"set 后读同一快照"即标 high。

## 4. 规则"不作用于自身目录"是 gitignore 链最易漏的语义

`sub/.gitignore` 的 `*` 会把 `sub` 自身判为忽略，祖先短路直接返回 true，
同文件的 `!` 永无加回机会。教训：`rel === ''`（路径 == 规则目录自身）必须跳过；
该用例（`*\n!keep`）要在双侧单测同时钉住，否则"同文件取反"测试全绿也覆盖不到。

## 5. 探针先行再定性能方案

3 万行渲染探针：折叠挂载 248ms、展开 8.6s，一次测量即排除"memo  Suffice"的
侥幸（memo 只能优化更新，不能减少首次创建）。教训：卡顿类问题先写一次性探针
量化（挂载/展开/单操作三段计时），数据决定做虚拟化还是只加 memo；探针用后即删，
转为确定性断言（DOM 行数有界 + 占位折算总数）留存。
