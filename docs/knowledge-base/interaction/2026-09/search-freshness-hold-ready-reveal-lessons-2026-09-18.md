# 检索跳转"就绪才呈现"与结果新鲜度经验（2026-09-18）

本轮事项 39–46：内容检索片段点击主区跳转，从"有时不跳"经 8 轮失败迭代收敛到"就绪才原子呈现"。

## 1. 中间态必须显式建模，而不是用"行数一致"推断新鲜
`openFile` 先切路径后到内容；`modelFresh = |lineCount − expected| ≤ 1` 在"路径新＋内容旧"时恒通过。
教训：凡跨越"路径切换 × 内容到达"两阶段的逻辑，必须携带点击时刻快照（path＋content＋mtime）显式识别中间态；
行数/长度等派生量只能做廉价短路，不能做新鲜证明。

## 2. 视口漂移：静止 200ms 不等于正确
新挂载未量测视图上 `scrollIntoView` 按估算高度解析，大行号把像素误差放大成整屏漂移；
异步布局（字体/语言扩展）在"稳定"判定之后仍可改变行高。
做法：帘子（`visibility:hidden` 保布局可量测）保持到目标像素 top 连续不变＋字体就绪；
漂移期间在帘后追踪重发，上限兜底显现，计时器全部跟踪 ID 并在卸载/新跳转时显式取消。

## 3. overflow 语义必须两端同契约
后端"总量超预算即 overflow"若仍附带截断载荷，而前端 overflow 路径丢弃载荷走全量重搜，
则残缺增量造成双算与 IPC 浪费。约定：overflow 即载荷置空，前端见 overflow 必整轮重搜；
游标淘汰（`since ≤ oldest − 2`，注意不是 `< oldest`）同样强制 overflow。

## 4. 折叠/去重键必须带命名空间
`collapsedDirs` 用裸 path 导致跨工作区联动；collapse-all 收集用裸 path 而 toggle 用
`wsId:path` 导致整功能空操作。凡按"工作区＋路径"寻址的状态，键一律 `workspaceId:path`；
去重键用结构化序列化，避免三段拼接的边界串扰。

## 5. 审查快照滞后是第一大误报源
`git diff` 按文件拆快照后，工作树继续改动会导致子代理基于过期快照判"未修复"。
每轮修复后必须重生成快照（rev 递增）＋复审全量重看；主代理对"快照不可见"类结论必须回源码实证。
