# 多工作区变更面板统计信息修复 — 经验教训

> 来源: `2026-05-25-multi-workspace-changes-stats-fix.md`
> 问题: 变更面板统计数字只显示当前工作区，而非所有可见工作区的合计

## 教训

### 1. 多工作区改造的完整性
在进行多工作区架构改造时，需全面梳理所有界面组件：统计数字计算源、筛选/过滤逻辑的范围、显示内容的数据源。

### 2. 渐进式改造的延续性
渐进式改造易遗留部分未覆盖区域。应建立完整的检查清单：功能完整性、用户界面一致性、数据流完整性。

### 3. 向后兼容性设计
新增 `totalChangesStats` 作为优先数据源，保留原有 `snapshot` 作为回退方案，确保不同调用场景下都能正常工作。

### 4. 测试覆盖度
此类显示问题需要专门的 UI 测试验证，特别是多工作区场景下的统计显示正确性。
