# 层级树布局对齐优化 — 经验教训

> 来源: `2026-05-25-tree-layout-alignment.md`
> 问题: 文件树和文档大纲的层级连接竖线与图标对齐；文件树优化后误伤文档大纲样式

## 教训

### 1. 模块化 CSS
不同功能模块应有独立的样式文件或明确的类名前缀，避免共享组件样式耦合。

### 2. 样式隔离
建议使用 CSS Modules 或明确的作用域限定，防止文件树与大纲树样式相互影响。

### 3. 版本回滚
重要样式变更前应记录当前状态，便于快速回滚。本次通过分离 `.adl-outline-tree__*` 和 `.adl-filetree__*` 类名实现隔离。

### 4. 双端验证
同时检查 Tauri 桌面和浏览器模式，确保样式变更在两端效果一致。
