## 经验教训

1. **代码清理的重要性**：定期清理 deprecated 代码和重复实现，能保持代码库的健康状态
2. **工具函数统一**：将常用工具函数统一管理，能减少重复代码，提高可维护性
3. **性能优化的持续性**：即使已有虚拟滚动，还可以通过 useCallback/useMemo 进一步优化
4. **缓存的价值**：在 Rust 后端添加文件缓存，能显著减少磁盘 I/O 次数
5. **测试的重要性**：所有重构完成后必须运行完整的测试套件，确保没有引入回归
