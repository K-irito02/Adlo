## 归档约定

- 文件名前缀 `yyyy-MM-dd-` 表示文档对应的工作日期
- 同一日期的 `plans/` 与 `specs/` 文件可能对应同一功能的不同阶段
- 子目录形式的 spec（含 `spec.md` + `checklist.md` + `tasks.md`）为完整式规格文档
- 单文件形式的 spec 为摘要式设计文档
