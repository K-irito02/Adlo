## [x] 事项 1：DragOverlayPortal 替换 @dnd-kit DragOverlay（消除首帧测量延迟闪现）
- 状态：已完成
- 描述：设置面板工作区拖拽浮层首帧闪现，因 @dnd-kit DragOverlay 的 useRect 在首帧返回 null
- 根因：@dnd-kit 的 activeNodeRect 由 useRect（layout effect）测量，首帧返回 null → PositionedOverlay 不渲染 → 第二帧 translate 已非零 → 闪现
- 修复：
  1. 用 DragOverlayPortal（portal + fixed 定位）替换 @dnd-kit DragOverlay
  2. 使用 tracked cursorPosition + grabOffset 直接计算 overlay 位置
  3. 删除 snapToCenter.ts 和 @dnd-kit/modifiers 依赖
- 验证：用户确认无闪现

## [x] 事项 2：拖拽浮层尺寸与源项不一致
- 状态：已完成
- 描述：替换 DragOverlayPortal 后，浮层尺寸与源工作区项不一致
- 根因：DragOverlayPortal 内 div 无显式宽度/高度，adl-sortable-label 的 flex: 1 在绝对定位下无容器宽度参考
- 修复：
  1. useWorkspaceDnd 在 handleDragStart 中通过 getBoundingClientRect 记录 sourceRect（width/height）
  2. DragOverlayPortal 接受可选 width/height 参数
  3. 浮层内 div 应用 width/height 样式
- 验证：用户确认尺寸正确

## [x] 事项 3：拖拽标签无法放置到列表最后一个位置
- 状态：已完成
- 描述：拖拽标签到任意列表末尾时，总是被放到倒数第二的位置
- 根因：computeMove 总是将拖拽项插入到 overId 之前（insertBefore），当 overId 为最后一个元素时，目标项变为倒数第二
- 修复：
  1. computeMove 接受可选 insertAfter 参数
  2. computeInsertAfter 检查 cursorPosition.y 是否超过 over 元素垂直中点
  3. handleDragOver / handleDragEnd 传入 insertAfter 结果
  4. 逻辑：上半部分 → insertBefore（原行为）；下半部分 → insertAfter（新行为）
- 验证：用户确认 2026-07-21
