- 验证：需用户确认 commit message 现在显示完整

## [x] 事项 4：作者像素头像重复问题
- 状态：已完成（无需代码修改）
- 根因分析：头像由 `md5(email)` 哈希 + Gravatar `d=retro` 参数生成。相同 email = 相同头像（跨 commit 一致），不同 email = MD5 碰撞概率可忽略。
- 结论：已满足"尽量不重复"的要求。

## [x] 事项 5：滚动加载过多提交后悬停效果延迟、缓慢
- 状态：已完成
- 根因：`SvgLanes` 中 `columnLines` 和 `connections` 在每次 `hoveredId` 变化时被完全重新计算，尽管它们不依赖 `hoveredId`
- 修复：将 `columnLines`、`connections`、`nodes` 包裹在 `useMemo` 中，各自声明依赖。`columnLines` 和 `connections` 不再因 hover 变化而重算。
- 验证：821/821 tests ✅

## [x] 事项 6：无节点区域泳道线显示不及时
- 状态：已完成
- 根因：`SvgLanes` 的 `columnLines` 从 `visibleRows` 计算 `yPositions`，某列无可见节点时 `yPositions` 为空，线不渲染
- 修复：泳道线始终从 `y=0` 画到 `y=totalHeight`，不依赖 `visibleRows`
- 验证：821/821 tests ✅
