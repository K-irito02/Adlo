## [x] 事项 2：主题切换时「代码行演变」按钮背景色滞后闪烁
- 状态：已完成（用户于 2026-08-01 确认解决）
- 现象：
  - 主题切换时，主图右侧的「新增、删除、净变化」三个按钮背景色存在滞后变化（暗→亮：黑→白；亮→暗：白→黑），视觉上像在闪烁。
  - 上次修复（事项 1）将「开」状态背景设为 `var(--bg)`，怀疑是 CSS 变量过渡或 `transition` 配置导致。
- 根因（Phase 0 已确认）：
  - `.adl-git-vis__series-toggle-btn` 与 `.adl-git-vis__series-toggle-dot` 使用 `transition: var(--theme-transition)`。
  - `--theme-transition` 包含 `background-color 200ms`（见 `tokens.css:126-132`）。
  - 按钮默认 `background: var(--bg-card)`，"开"状态 `background: var(--bg)`，两者在主题切换时值发生剧烈变化（light: `#f8f8f8`/`#fbfbfb` ↔ dark: `#141414`/`#1a1a1a`）。
  - 200ms 过渡动画使这种近黑↔近白的变化可见，产生"闪烁"。
  - 对比：同文件 `.adl-git-vis__refresh-btn` 不闪烁，因其默认 `background: transparent`（非主题相关），主题切换不触发 `background-color` 过渡。
- 修复方案（Phase 2A）：
  - `git-visualization.css:1329-1345`：将 `.adl-git-vis__series-toggle-btn` 的 `transition: var(--theme-transition)` 最终替换为 `transition: opacity var(--duration-150) var(--ease-default);`
    - 保留 `opacity` 过渡（`aria-pressed` 切换动画仍平滑）
    - 移除 `color` 过渡（主题切换时文字色 `var(--text-secondary)`/`var(--text-primary)` 也会变化，产生 150ms 过渡闪烁）
    - 移除 `background-color` 过渡（主题切换时背景即时更新，消除闪烁）
    - hover 时背景与文字色均即时变化（与 refresh-btn 等小型按钮一致）
  - `git-visualization.css:1367-1375`：将 `.adl-git-vis__series-toggle-dot` 的 `transition: var(--theme-transition)` 替换为 `transition: none;`
    - 圆点 `background` 由 inline style 设置为 `var(--chart-line-primary)` 等，主题切换时也会变化，移除过渡避免微小闪烁
    - `filter: grayscale(1)` 切换本就即时（`--theme-transition` 不含 `filter`），移除后行为不变
- 迭代记录：
  - 第 1 次：仅移除 `background-color` 过渡，保留 `color` 过渡 → 用户反馈"按钮的文字还是有变化效果"
  - 第 2 次：进一步移除 `color` 过渡，只保留 `opacity` 过渡 → 待用户验证
