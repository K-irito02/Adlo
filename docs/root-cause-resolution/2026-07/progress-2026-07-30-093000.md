## [x] 事项 2：作者列显示"头像缺失"图片而非兜底像素头像
- 状态：已修复
- 现象：表格的作者属性列有时显示"头像缺失图片"，获取真实头像失败后未使用兜底的像素风格头像
- 根因：
  - `AuthorAvatar` 组件（`BranchGraph.tsx:41-78`）的 `onError` 降级链耗尽后无更深层兜底
  - 当邮箱不是 GitHub noreply 格式时，`src`（来自 `resolveAvatarUrl`）与 `gravatarSrc`（组件内构造）是**同一个 URL**，切换无意义
  - 当 Gravatar 不可达（离线/网络问题/CSP 拦截）时，`d=retro` 参数无法返回像素头像，`<img>` 维持 broken 状态
  - `commitTooltipUtils.ts:152` 注释承诺的 "initials fallback" **未实现**
  - `currentSrc` 为空时返回 `null`（line 77），无占位
  - 关键误解：用户认为"像素头像"是本地的，实际由 Gravatar 服务端 `d=retro` 生成，仍需网络
- 修复：
  - 新增 `generatePixelAvatar(email, size)` 函数（`commitTooltipUtils.ts:168-215`）
    - 纯本地生成 5x5 对称网格 SVG identicon（基于 email MD5 hash）
    - 返回 data URI，零网络依赖，零延迟
    - 颜色从 hash 派生（HSL），确保视觉区分度
  - 重构 `AuthorAvatar` 组件（`BranchGraph.tsx:40-94`）：
    - 去掉 `src` prop（不再需要外部传入 URL）
    - 初始 `src` 设为本地像素头像（同步、零延迟）
    - `useEffect` 异步加载真实头像（`resolveAvatarUrl` 结果）
    - 真实头像 `onload` 成功 → 替换 src
    - 真实头像 `onerror` 失败 → 保持像素头像（永不显示 broken image）
    - 移除旧的 `onError` 降级链和 `useGravatar` 状态
  - 更新两处调用方去掉 `src` prop
- 验证：
  - 新增 9 个 `generatePixelAvatar` 单元测试 ✓
  - 更新测试 `renders author avatars with local pixel avatar as initial src` ✓
  - 全部 125 个测试通过 ✓

## [x] 事项 3：Tooltip 中兜底像素头像出现有延迟
- 状态：已修复
- 现象：鼠标悬停在表格的"信息"按钮上时，出现的 Tooltip 卡片中兜底像素风格头像出现有延迟
- 根因：
  - `CommitTooltipCard`（`BranchGraph.tsx:90-138`）使用 `resolveAvatarUrl(authorEmail, 32)` 渲染头像
  - 预加载 effect（line 896-909）确实预加载了 size=32 的头像
  - **但预加载依赖网络**：首次打开图表预加载未完成时 hover，需等网络请求
  - 像素头像由 Gravatar 服务端生成，**非本地生成**，必然有网络延迟
  - 与事项2同源：像素头像不是本地的
- 修复：
  - 与事项2同源修复：`AuthorAvatar` 现在优先显示本地像素头像（data URI），Tooltip 挂载时立即显示
  - 真实头像异步加载完成后替换，无延迟感知
  - 预加载 effect 保留（提前发起网络请求，进一步减少替换延迟）
- 验证：
  - Tooltip 测试 `renders tooltip card content on row hover` 仍通过 ✓
  - 全部 125 个测试通过 ✓
