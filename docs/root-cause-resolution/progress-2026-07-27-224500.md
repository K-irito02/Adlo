## [x] 事项 1：多个 origin/main 标签问题
- 状态：已完成（2026-07-27 22:35）
- 根因：back-end 的 `branch` 字段反向传播将 `origin/main` 传给祖先节点。这些祖先节点因拓扑分叉（多子提交）被 Gitamine 算法分配到不同列，导致每列 topmost 都带有 `origin/main` 值
- 修复：标签推导时不再仅用 topmost commit 的 `branch`，改为**收集每列所有提交的 branch 值**，优先选本地分支名（无 `origin/` 前缀）
- 验证：日志确认 col3/4/5 的 local 分支名优先，`origin/main` 不再出现

## [x] 事项 2：本地分支未显示在标签栏
- 状态：已完成（2026-07-27 22:35）
- 根因：标签栏仅显示列派生标签，未使用 back-end `branches` 数组
- 修复：合并 `adapted.allBranches` 中的额外分支名作为标签（延续已有列标签之后），使用 `getBranchColor` 分配颜色
- 效果：所有本地和远程分支名都在标签栏出现，可点击过滤
