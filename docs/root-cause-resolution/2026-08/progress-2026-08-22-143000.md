## [x] 事项 1：Favicon 持久化后重启/切换面板不显示真实图标
- 状态：已完成
- 问题描述：有网络时，favicon 持久化（data-URI 存入 SQLite）后，重启应用或切换面板时，书签/历史/标签列表仍显示兜底字母而非真实 favicon
- 期望行为：有网络时真实 favicon 持久化后，重启/无网络/切换面板时仍显示真实 favicon
- 根因分析（Phase 0 完成）：
  - **根因确认**：reqwest 的 `system-proxy` 功能被 `default-features = false` 禁用，导致无法使用 Windows 系统代理
  - **日志证据**：`download_favicon_data_uri: request send failed (network/timeout/TLS)`
  - **对比**：WebView2 可以正常访问 YouTube（自动使用系统代理），但 reqwest 无法访问
  - **影响范围**：所有需要通过代理才能访问的 favicon 都会下载失败
- 修复方案（Phase 2A 完成）：
  - 在 `Cargo.toml` 中为 reqwest 添加 `system-proxy` 功能
  - reqwest 会自动从 Windows 注册表读取系统代理配置
- 验证结果：
  - 61 Rust 测试通过
  - 37 前端测试通过
  - 用户测试确认：点击"刷新网站图标与标题"按钮后所有地方都显示真实 favicon
  - 用户接受此行为（主动请求才更新，减少不必要的查询/轮询）
