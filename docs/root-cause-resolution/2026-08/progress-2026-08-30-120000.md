#### 发现 1（已修复）：Non-Range Pause 竞态条件
- 下载 #6 (`QISHUIl_setbp_X643637.zip`, non-resumable)
- 服务器探测: 403 → `resumable=false` ✓
- 用户暂停 → non-Range 路径正确取消原生下载 ✓
- 原生取消触发 `finished(false)` → **`download_handler` 将 `NonResumablePaused` 覆盖为 `failed`** ✗
- 用户尝试恢复 → "Download is already failed and cannot be resumed" ✗
- **根因**：`handle_download_finished` 的伪中断检测只检查 `interrupt_reason="UserPaused"`，未识别 `"NonResumablePaused"`
- **修复**：扩展伪中断检测，匹配 `UserPaused | NonResumablePaused | CosmeticPaused`
- **修复文件**：`download_handler.rs:174-183`

#### 发现 2（已知差距）：Native Resume 成功但下载随即失败

- Native `Resume()` 返回成功
- 下载在 ~86ms 后立即失败
- 未触发 Range 回退（因为 `Resume()` 未抛错）
- **评估**：设计差距 — 仅在 `ResumeResult::Failed` 时回退，未处理恢复后快速失败
- **建议**：未来迭代添加恢复后健康检查（2-3 秒监控）
