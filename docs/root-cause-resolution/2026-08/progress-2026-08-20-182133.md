## [x] 事项 1：一次点击产生多条历史记录（Tauri 浏览器面板，抖音"我的"）
- 状态：已完成（根因确认 + 修复 + 用户复测通过）
- 类型：解决/优化/调整
- 现象：抖音首页点击"我的"跳转 `https://www.douyin.com/user/self` 后，历史记录一次性出现多条（4 条），标题混杂"douyin.com"与"空占位显示"。

### 根因（日志证实，2026-08-20 18:35 分析 `.adl-logs/debug-logs.txt`）
- 抖音 SPA 一次导航（点击"我的"）在毫秒级内连续触发多次 HistoryChanged，产生同一页面 `user/self` 的多个**仅来源/导航参数不同**的 URL 变体：
  1. `https://www.douyin.com/user/self?from_nav=1`
  2. `https://www.douyin.com/user/self?from_tab_name=main&showTab=like`
  3. `https://www.douyin.com/user/self?enter_from=discover&enter_method=left_entrance&from_tab_name=main&showTab=like`
  4. `https://www.douyin.com/user/self`（裸 URL，最终态）
- 这些参数（`from_nav`/`from_tab_name`/`showTab`/`enter_from`/`enter_method`）不在 `TRACKING_PARAM_PATTERN` 剥离名单 → `historyDedupKey` 各异（各变体成不同 key）→ 前端 `browserAddToHistory` 的"同日同 dedupKey 去重"拦不住；Rust `should_emit_history_changed` 仅对 500ms 内**完全相同** URL 去重，同样拦不住 → 每个变体各落一条历史。
- 标题混杂原因：以 URL 为 title 的条目，meta 已结算但无真实标题→回退主机名"douyin.com"（`resolveSiteTitle`）；meta 未结算→空占位""。仅 `?from_tab_name=main&showTab=like` 变体结算到真实标题"泥瓶巷一棵草的抖音 - 抖音"。
- 日志证据（第 86 行 `[browser-history] add`）：写入裸 `user/self` 前，历史快照已含 3 个 `user/self` 变体 + 1 个 `jingxuan`；第 83 行 `[browser-url-change] onUrlChanged` seq:8（仅剩该条在 1000 条日志缓冲内，seq 1-7 更早发生被挤出）→ 印证"一次导航多次事件"。第 138 行 `updateTitle` 显示裸 `user/self` 随后被真实标题覆盖。
- **调研对照**：Chrome/Edge 历史库对同一 URL 同日内去重、对同文档 SPA 导航合并为一条（session history 与历史库分离）；SPA 路由对"未真正改变位置"的导航应用 replaceState 而非 pushState 是重复条目根因（ADL `init_script.js` C1 包装仅对归一化后相等 URL 做 push→replace）。

### 修复（2026-08-20 18:42，通用所有站点，不针对抖音特化）
- **方案：同一文档导航突发合并（Chrome/Edge 同文档合并语义）**
  - 新增 `browserDisplayUtils.historyDocumentKey(url)`：`hostname + pathname + 身份参数值`。身份参数 = `IDENTITY_PARAM_PATTERN`（`modal_id`/`v`/`bvid`/`q`，跨站点通用）：值不同视为不同内容，不合并；`from_*`/`enter_*`/`showTab` 等来源/导航参数不参与。
  - `browserHistorySlice.browserAddToHistory`：新增合并分支——当最新历史条目 `visitedAt` 在 `HISTORY_COALESCE_WINDOW_MS`（2000ms）内且 `historyDocumentKey` 相同，则**合并**该变体（保留最新 URL + 更优非占位标题，`isPlaceholderTitle` 判定），不再插入新条目；同时输出 `[browser-history] merge` 调试日志。
  - 安全性：YouTube `v=AAA→BBB`、不同 `modal_id`、不同 `q` 的 documentKey 不同 → 不合并（各自成条，Chrome 语义）；`suppressBase` 视频脚手架抑制逻辑与 `historyContainerKey` 视频去重不受影响（不同 documentKey）。
