## [x] 事项 2：欢迎页子菜单与父卡片间距重叠
- 状态：已完成（用户确认已解决）
- 根因：多层叠加
  1. `position-anchor` 不被 WebView2 支持（`anchorSupport=false`），`@supports` 块修改无效
  2. 欢迎页卡片 `min-width: 300px` 无显式 `width`，shrink-to-fit 模式导致 split button 未填满内容区
  3. 欢迎页卡片 padding（12px）比状态栏（8px）大 4px，相同的 11px offset 在欢迎页产生 5px 重叠
  4. menu 和 settings 的定位上下文不同：menu 在 `.adl-split-btn`（有 1px border），settings 在 `.adl-split-btn__input-area`（无 border），导致 1px 差异
  5. settings 卡片内部左 padding（12px）比 menu 菜单项左 padding（10px）大 2px，产生视觉间距差异
- 修复（多轮迭代）：
  - `composer-input.css`：
    - `.adl-split-btn` 添加 `width: 100%`（填满父卡片内容区）
    - `.adl-split-btn__menu` offset: `calc(100% + 11px)`（视觉间距 2px）
    - `.adl-split-btn__settings` offset: `calc(100% + 10px)`（补偿 1px border 差异，视觉间距 2px）
    - `.adl-split-btn__settings` padding: `12px 12px 12px 10px`（左 padding 与 menu 菜单项一致）
  - `statusbar-menu.css`：
    - `.adl-statusbar__submenu` offset: `calc(100% + 11px)`（统一视觉间距 2px）
  - `center.css`：
    - `.adl-welcome__action-card` 改 `min-width: 300px` 为 `width: 300px`（固定宽度）
    - `.adl-welcome__action-card .adl-split-btn__menu` offset: `calc(100% + 15px)`（12px padding + 1px border + 2px 间距）
    - `.adl-welcome__action-card .adl-split-btn__settings` offset: `calc(100% + 14px)`（补偿 1px border 差异）
- 修改文件：
  - `frontend/src/styles/regions/composer-input.css`
  - `frontend/src/styles/regions/statusbar-menu.css`
  - `frontend/src/styles/regions/center.css`
