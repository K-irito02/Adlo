## [x] 事项 5：自定义搜索引擎 favicon 离线不可用（2026-08-23 13:00）
- 状态：已完成
- 根因：
  1. 保存时使用 Google Favicon 服务 URL 作为 faviconUrl
  2. 该 URL 需要网络访问，离线时无法加载
  3. `failedFaviconUrls` 是内存 Set，每次重新打开面板都会重新加载
- 修复：
  1. 后台获取页面元数据时，优先使用 `faviconDataUri`（base64 data URI，离线可用）
  2. 如果没有 data URI，fallback 到 `favicon` URL
  3. 更新 favicon 和标题在单次后台请求中完成
- 修改文件：`frontend/src/app/features/browser/SearchEnginePopover.tsx`
- 验证：用户测试通过 ✅
