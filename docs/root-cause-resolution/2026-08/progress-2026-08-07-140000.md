## [ ] 事项 2：中间区域选择工作区后，同一工作区在侧栏重复出现（仅重复出现的那行可展开/收起）
- 状态：进行中
- 根因：
  - 前端 `sidebarViewModel.ts` 仅在 id 不匹配时 unshift currentWorkspace，未按 path 去重。
  - 后端 `workspace_sidebar.rs`（`upsert_sidebar_after_open` / `load_sidebar_with_meta_with_db`）全部按 id 匹配/去重。当同一路径的历史 sidebar 条目 id 与新 open 的 meta id 不一致（id 不稳定/路径归一化差异/历史迁移）时，追加新条目 → 同一路径两条不同 id 的条目 → 侧栏与"最近工作区"列表重复。
- 修复：
  - 后端 `workspace_sidebar.rs`：新增 `path_dedup_key` + `dedup_entries_by_path`（按归一化路径去重，优先保留 id 与 DB 一致者）；`upsert_sidebar_after_open` 按 id 或 path 匹配并就地更新（统一 id）；`load_sidebar_with_meta_with_db` 加载时对历史重复条目一次性清理 + 追加时按 path 去重。
  - 前端 `sidebarViewModel.ts`：unshift 判定改为 id 或 path 都算命中。
- 验证：新增 Rust 4 个测试（path_dedup_key 归一化、同路径不同 id 去重、无 DB 匹配保留首个、不同路径保留）通过；前端新增 sidebarViewModel path 去重测试通过。
