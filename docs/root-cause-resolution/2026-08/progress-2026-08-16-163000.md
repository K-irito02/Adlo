- 根因：
  - `dev:tauri` → `run-project-surface.mjs` → `cargo tauri dev` → tauri-cli 内部执行 `cargo run --no-default-features`
  - Windows 下：上一 dev 会话的 `ai-digital-life.exe` 进程残留（终端被强制关闭等），独占锁住 `target/debug/ai-digital-life.exe`

- 修复（`ai-digital-life/scripts/run-project-surface.mjs`）：
  1. 新增 `killProcessesByName(imageName, exePath)` 导出函数：win32 按可执行文件路径精确匹配（`Get-Process` + `$_.Path` 过滤）清理残留实例，避免误伤 release/installed 构建；其余平台用 `pkill -x <name>`
  2. `main()` 中 `tauri`/`both` 模式在 vite 就绪、`cargo tauri dev` 前，先 `isExeLocked(appDevExePath)` 探测锁，仅锁定时才 kill，随后 `waitForUnlock` 确认锁释放（未释放则醒目警告）
