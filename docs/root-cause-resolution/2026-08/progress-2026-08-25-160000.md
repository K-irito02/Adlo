## [x] 事项 6（UI 修复第 2 轮）：下载方式开关无反应 + 搜索图标位置
- 状态：完成
- 1. 下载方式开关点击无反应、滑块一直靠左、一直"每次询问"状态：
  - 根因：`download_types.rs` 中 `DownloadMode` / `DownloadStatus` 枚举 serde 默认按变体名序列化（PascalCase：`"Auto"`/`"InProgress"`），而前端类型期望小写（`"auto"`/`"in_progress"`）。`downloadSettings.mode === 'auto'` 恒为 `false`，开关永远显示"每次询问"，点击切换后 `fetchDownloadSettings` 重新取到的仍是 `"Auto"`，对照依旧失败。
  - 修复：为 `DownloadMode` / `DownloadStatus` 加 `#[serde(rename_all = "snake_case")]`，并新增 3 个序列化/反序列化测试守卫回归。
  - 验证：`cargo test -p adl-browser` 56/56 通过；前端 typecheck、lint 通过。
- 2. 搜索图标位置：希望在输入框内部左侧，显示"搜索图标：搜索下载记录"：
  - 修复：`BrowserDownloadMenu.css` 将 `__search-icon` 移至左侧 `left`，输入框加 `padding-left`，JSX 图标置于 input 前。
  - 验证：前端 typecheck、lint 通过。
