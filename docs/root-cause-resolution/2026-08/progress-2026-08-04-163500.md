## [ ] 事项 1：装载动画统一为扫视动画
- 状态：进行中（待用户观察确认）
- 根因（已确认）：
  - `--foreground` / `--muted-foreground` CSS 变量在 ADL 未定义（仅 `--chart-foreground`、`--text-primary` 等），但 bklit-ui 移植的装载组件直接引用 `var(--foreground)`（line-chart-loading.tsx、loading-sweep.tsx、chart-loading-label.tsx、grid.tsx、shimmering-text.tsx）→ 无效值 → 骨架线条 fallback 纯黑、文字无闪光色、Grid shimmer 无效。
  - 分支图谱/文件热点骨架为静态 CSS 渐变（sweep keyframes 已被 0769ad80 删除），无扫视动画。
  - CodeLineEvo/CommitTimeline 折线用默认 `pulse`（行进脉冲）而非 `sweep`（对角扫视）。
- 修复（已完成）：
  - 将装载组件中 `var(--foreground)` → `var(--chart-foreground)`、`var(--muted-foreground)` → `var(--chart-foreground-muted)`（ADL 有效变量），shimmering-text/chart-loading-label 用 `var(--chart-foreground-muted,var(--muted-foreground))` 兜底兼容。
  - CodeLineEvo/CommitTimeline 折线装载改为 `loadingStyle="sweep"`。
  - 分支图/文件热点骨架恢复 CSS sweep keyframes（`adl-git-vis-sweep`）+ reduced-motion 保护。

## [ ] 事项 2：CodeLineEvo 折线骨架颜色与多线错开
- 状态：进行中（待用户观察确认）
- 根因（已确认）：
  - LineChartLoading 默认 stroke=`var(--foreground)`（未定义 → 纯黑色），应参考 bklit-ui 官方灰白（官方 `--foreground` 亮色 = oklch(0.1479…) 近黑 + strokeOpacity 0.5 → 视觉浅灰；ADL 应用 `var(--chart-foreground)` + opacity 0.5 对齐）。
  - CodeLineEvo 有 3 条线（added/deleted/net）且可单独开关（visible + localStorage），装载时需按当前开启线数/位置渲染对应数量骨架线，多条线动画错开（不同步）。
- 修复（已完成）：
  - 颜色改为 `var(--chart-foreground)` + strokeOpacity 0.5 对齐官方灰白。
  - LineChartLoading 新增 `series` prop（多骨架线：dataKey/stroke/strokeOpacity/phaseOffset），默认多线时 `loadingStyle="sweep"`，各线 sweep 相位按 index 错开（`phaseOffset = i / count`）。
  - LineLoadingSweep / LoadingSweepMask 新增 `phaseOffset`，sweep 起始 x 按相位偏移（多线不同步）。
  - Line 组件新增 `loadingSweepPhaseOffset` 透传。
  - CodeLineEvo 装载按 `visible` 过滤渲染 1~3 条骨架线。
- 验证（已完成）：新增 line-chart-loading.test.tsx（4 测试：默认单线 pulse、多线 sweep 数量、phaseOffset 错开）+ CodeLineEvo 测试增强（3 测试：三线/单线数量、非 var(--foreground)），全部通过。
