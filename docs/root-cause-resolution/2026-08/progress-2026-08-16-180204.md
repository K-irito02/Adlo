## [x] 事项 3：展开/收起按钮点击时图标文字有"伸缩感、挤压感、跳动感"

- 类型：解决/优化/调整（事项 1 的 Phase 3 验证发现）
- 根因：ToastCard 的 motion.div 使用 `layout`（全量）—— 展开/收起时 detail 行数变化导致卡片高度突变，framer-motion 对**整个卡片**做 FLIP scale 投影，图标和文字被整体 scaleY 压缩/拉伸 → 伸缩感/挤压感
- 修复（已完成）：
  1. `ToastCard.tsx` — `layout` 改为 `layout="position"`：去掉卡片级尺寸缩放投影，仅保留进出场时其余卡片的位置补位动画
  2. `toast-card.css` — detail 改用 `max-height` 过渡（收起 1.5em / 展开 60em），正文区域平滑展开/收起，图标与标题（flex-start 定位）保持原位
- 验证：20 项测试通过；tsc 干净（待用户实测）

## [x] 事项 4：收起时卡片"晃动感、跳动感太强"
- 状态：已完成（2026-08-16 用户确认全部解决）
- 类型：解决/优化/调整（事项 3 的 Phase 3 验证发现）
- 根因（收起动画的两个跳变源）：
  1. `max-height` 60em→1.5em 的过渡伪影：可视内容约 4.5em，前 ~190ms 内容完全可见无变化，接近末尾才瞬间收缩 → "延迟后猛缩"
  2. 收起瞬间切换 `white-space: nowrap`：文本从多行瞬间重排为单行 → 文本内容跳变
  3. 卡片级 `layout="position"` 在连续 CSS 高度变化期间与兄弟卡片位置动画互相干扰
- 修复（已完成）：
  1. `ToastCard.tsx` — 移除 motion.div 的 `layout="position"`（消除 framer 对连续 CSS 高度变化的干扰，进出场自带动画保留）
  2. detail 高度实测：`useLayoutEffect` 读 `scrollHeight`（state `detailHeight`），展开时内联 `max-height: <实测px>`（代替 60em，消除"延迟后猛缩"伪影）
  3. 两阶段收起：`collapsedSettled` state + `onTransitionEnd`（`propertyName === 'max-height'`）—— 动画期间保持 `pre-wrap` 逐行裁剪平滑收缩，过渡结束后才加 `is-collapsed-settled`（`nowrap` + `text-overflow: ellipsis`）；切换收起/展开时重置 `collapsedSettled`
  4. `toast-card.css` — `.toast-card.is-collapsed .toast-card__detail` 的 max-height/nowrap/ellipsis 规则迁移为 `.toast-card__detail.is-collapsed-settled`（仅 nowrap + ellipsis，max-height 改由内联控制）
