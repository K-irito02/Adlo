## [x] 事项 1：右侧工具面板终端创建失败（所有 Shell 类型）
- 状态：已完成（由 2026-09-10 PTY 重构 + 后续修复闭环，见 progress-2026-09-10-193847.md）
- 问题描述：右侧工具面板-终端面板下，新建任何类型的终端（PowerShell、CMD、Bash）都失败
- 涉及代码区域：`useTerminalPtyLifecycle.ts` → `tauri-bridge/index.ts` → `pty-ws.ts` → `pty_ws.rs` → `session_manager.rs` → `shell_resolver.rs`
- 根因：**ConPTY 问题** — `portable-pty` 0.8 在 Windows 上存在 ConPTY 限制，测试被标记为 `#[ignore]` 并注明 "ConPTY CreatePseudoConsole returns ERROR_INVALID_HANDLE from the non-interactive test process"
- 关键发现：
  1. PTY WebSocket 测试 (`pty_ws.rs`) 中 `pty_ws_create_returns_session_id` 和 `pty_ws_echo_round_trip` 被标记为 `#[ignore]`
  2. `portable-pty` 0.8 存在已知 Windows ConPTY 问题
  3. `portable-pty` 0.9.0 引入了 `PSEUDOCONSOLE_INHERIT_CURSOR` 标志，需要响应 DSR（Device Status Report）查询
  4. Microsoft 文档指出 ConPTY 需要 `bInheritHandles=TRUE` 和 `STARTF_USESTDHANDLES`
- 修复：待定（见 Phase 1）
