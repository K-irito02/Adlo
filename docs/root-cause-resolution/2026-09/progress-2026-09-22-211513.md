## [x] 事项 15：下拉滚动条时有时无（日志定位根因 → 已完成 2026-09-22 23:52）
- 状态：已完成
- 根因（初判，错）：hovered 门控。用户复测仍现 → 返回 Phase 0。
- 根因（深挖，错）：测量时序（菜单挂载晚一拍）。用户复测仍现 + 同意埋点 → 日志分析。
- 根因（日志，确定）：无限渲染循环。Tauri 实测日志（.adl-logs/debug-logs.txt，界面字体 9 选项）：
  open 与 scroll 以约 5ms 间隔交替刷屏、scrollTop 被钉死在 75（scrollHeight 305 > clientHeight 230，内容确实溢出，控制器 scrollable:true/visible:true 也正确）。
  链条：useRevealScrollbar 每次渲染返回新对象 → 依赖它的 effect 每轮重跑 → scrollIntoView 回写 scrollTop → 触发 scroll → measure → setState → 重渲染 → 新对象 → 循环。
  这同时解释三个症状：滑块看似随机（循环中反复挂载）、拖拽跳动闪烁（逐帧重渲染）、滚轮近乎无用（scrollTop 被钉死）。
- 修复：下游 effect 禁止依赖 scrollbar 对象本身，只依赖稳定 listRef；scrollable/visible 经 scrollStateRef（mutable ref，渲染期同步）读取；scrollIntoView 加 keyboardNavRef 门控——仅键盘上下键导航滚入高亮项，鼠标悬停不抢滚动。
- 验证：144 通过；tsc/eslint 干净

  wheel deltaY:100 → scrollTop 单调递增 0→75（305-230=75 即最大值，末尾 3 次 wheel 无 scroll 系已触底，正常非 bug）；
  measured 恒 scrollable:true。结论：滚动链路正常，无残留问题 → 删埋点收尾。
