# 进度 — 2026-09-08 15:00:00

## [x] 事项 1：右侧浏览器面板 WebView2 与面板左边缘出现背景色间隙
- 状态：已完成
- 根因：`.adl-rightpanel__content` 的 CSS `transform: translateX(var(--panel-content-shift))` 在面板展开时有55ms transition-delay，导致 `getBoundingClientRect()` 在延迟期间返回偏移10px的中间位置，WebView2 bounds 基于错误位置设置
- 修复：
  1. CSS: 添加 `.adl-rightpanel:not(.adl-rightpanel--collapsed) .adl-rightpanel__content { transition-delay: 0ms; }` 移除展开时的transition delay
  2. JS: 在 `useWebViewBounds` 中，当 `isVisible` 变为 true 时立即将 content 的 transform 重置为 `translateX(0)`，确保 bounds 基于最终布局位置
- 验证：用户在 Tauri 桌面应用中确认间隙已消失
