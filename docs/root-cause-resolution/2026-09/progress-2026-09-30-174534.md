### Phase 0 根因调查（已完成 2026-09-30）
**根因**：`.adl-rightpanel__resize-handle` 的 14px 命中带（`left:-8px; width:14px`，相对面板 padding box → border-box 坐标 [-7, +7)）依赖"区域逃逸"前提——向左 8px 是**无 WebView 的主窗口 DOM 区**（`project-design-standard.md:416`）。dsh 打开后该前提被打破：

1. 中心侧 [-7, 0)：`useDshWebViewBounds` 把 dsh WebView2 bounds 镜像到 `#dsh-host-region`（`.adl-app-host { position:absolute; inset:0 }`）容器 rect，右缘正好贴到面板左缘 → OS 级 child HWND 覆盖。
2. 面板侧 [0, +7)：浏览器侧边栏收起后，`.adl-tool-primary--browser`（`primaryRef` 容器）左缘 = 面板内容左缘（仅隔 `border-left:1px`）→ 浏览器 tab WebView2 覆盖。
3. WebView2 是 OS 级渲染表面，鼠标命中测试落在子窗口，主窗口 DOM 永远收不到事件，`z-index` 无效。
4. 仅剩可达区：顶栏 ToolSwitcher 行约 40px 高 × 6px 宽的小块 + 1px 边框线 → "很难触发拖拽"。

**关键事实**：拖拽一旦起手即正常（面板宽度变化 → ResizeObserver → bounds 自动跟随），难点只在第一次抓取。

**关键证据/代码位置**：
- `RightPanel.tsx:220-224`（handle JSX）、`files-panel-core.css:36-44`（left:-8px; width:14px）
- `useDshWebViewBounds.ts:58-71`、`useWebViewBounds.ts:57-71`（bounds = 容器 rect 镜像）
- `dsh.css:232-238`（`.adl-app-host { inset: 0 }`）、`browser-webview.css:109-112`（`.adl-tool-primary--browser`）
- `BrowserContentArea.tsx:37`（primaryRef 容器）
- `useWebViewVisibility.ts:48-65`（既有"移出画面"机制，本方案无需动用）

**同类问题检查（Phase 2A 步骤 3）**：
- `.adl-leftbar__resize-handle`（leftbar.css:52-76）：命中 `::before` 位于 [-3,0)（leftbar 自有 DOM 侧）→ 不受 dsh 影响，无需修。

- 结论：仅 `.adl-rightpanel__resize-handle` 跨越边界，是唯一受影响手柄。

1. 中心侧：`dsh.css` `.adl-app-host` 由 `inset:0` 改为 `top/right/bottom/left:0` 且 **`right: 8px`** → dsh WebView2 右缘内缩 8px，露出 [-8,0) DOM 缝 ⊇ [-7,0)。

### 方案 A 落地设计（2026-09-30）
**原理**：子 WebView2 吃掉命中测试是 OS 窗口层问题 → 在接缝上架一条 6px 宽、全高的**透明子 WebView**（`adl-divider-strip`，与 dsh/浏览器 tab 同 `add_child` 机制、同 Physical 坐标惯例，像素级对齐），天然获得命中权；页面只画 1px 主题分隔线（hover 发光），JS 经 pointer capture 拖拽、只回传 X 增量，主窗口复用现有几何逻辑。
- Tauri 2.12 官方 API 核验：`WebviewBuilder::transparent/focused/initialization_script/on_navigation` 均存在；建窗必须异步（Windows 同步死锁警示）；`unstable` 特性本仓库已启用。
- z-order：重建即最上层；generation（dshUrl|activeTabId|tabCount）变化即销毁重建（覆盖 tab 新建/驱逐恢复等兄弟窗口排序变化）。
- 双端：条仅 Tauri（浏览器模式 DOM 手柄本就可达）；bridge 四端同步（tauri 实现 + preview/mock/http no-op，接口文档注明原因）。
