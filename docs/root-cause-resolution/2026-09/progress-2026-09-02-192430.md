## [x] 事项 3：HintCardTrigger 箭头覆盖 "!" 图标

- 状态：已完成
- 类别：Bug 修复
- 根因：`.adl-bookmark-dir-toolbar__btn-hint`（"!" 图标）有 `position: absolute`，脱离文档流。`measureTrigger` 之前测量的是 wrapper span（`display: inline-flex`）的 `getBoundingClientRect()`，但因为唯一的子元素是绝对定位的，wrapper 的尺寸几乎为零 → 卡片被定位到视口左上角附近 → 覆盖了 "!" 图标。

### 修复

- `HintCardTrigger.tsx`：`measureTrigger` 改为测量 `el.firstElementChild`（即 "!" `<span>` 本身）的 `getBoundingClientRect()`，它返回绝对定位元素的正确视口坐标

### 提交

- `7461fb2c`

## [x] 事项 6：鼠标在提示卡片上移动时卡片自动关闭

- 状态：已完成
- 类别：Bug 修复
- 根因：HintCard 通过 `createPortal` 渲染到 `document.body`，脱离了 wrapper span 的 DOM 树。当鼠标从 "!" 图标移到卡片上时，wrapper span 的 `onMouseLeave` 先触发 `scheduleClose(80ms)`，卡片的 `onMouseEnter` 虽然调用 `cancelClose()`，但存在竞态——timer 可能在 `cancelClose()` 执行前已触发。且 `scheduleClose` 中的 timer callback 无条件调用 `hide()`，未检查鼠标是否已移回卡片区域。

### 修复

- `HintCardTrigger.tsx`：新增 `isMouseOverCardRef` 跟踪鼠标是否在卡片上；`scheduleClose` 的 timer callback 中检查 `isMouseOverCardRef.current`，仅在鼠标不在卡片上时才关闭
- `useHintCard.ts`：同步修改，新增 `isMouseOverCardRef`，`scheduleHide` 的 timer callback 中检查后再关闭

### 提交
