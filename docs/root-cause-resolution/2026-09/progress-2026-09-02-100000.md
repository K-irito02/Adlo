## [x] 事项 2：自定义背景对话框蓝色提示色优化
- 状态：已完成
- 问题描述：在 Tauri 桌面应用右侧面板浏览器面板的空标签引导页中，点击"自定义背景"按钮后，选择项（默认/图片/视频）和文件拖拽放置时显示的蓝色提示色过于鲜艳，希望使用更柔和的颜色。
- 测试环境：Tauri 桌面应用
- 根因：
  1. CSS 中使用了 `var(--accent)` 和 `var(--accent-soft)` 变量，这些变量定义在 `themes.css` 中
  2. 亮色主题：`--accent: #2563eb`（较深的蓝色）
  3. 暗色主题：`--accent: #60a5fa`（较浅的蓝色）
  4. 自定义背景对话框没有专门的颜色方案，直接使用了全局的 accent 颜色
- 修复方案：
  1. 为自定义背景对话框改用黑白灰色配色方案
  2. 使用项目原有的 CSS 变量，自动适配亮/暗主题切换
  3. 配色规则：
     - 默认状态：透明背景、默认边框
     - 悬停状态：`var(--bg-hover)`
     - 选中/激活状态：`var(--bg-card)` 背景 + `var(--text-primary)` 边框
     - 上传区域悬停：`var(--text-secondary)` 边框
- 修改的文件：
  - `BackgroundSettingsDialog.css` - 更新所有颜色相关的样式
- 验证结果：
  - 选择项按钮默认状态保持原样，选中时显示灰色背景和深色边框
  - 文件拖拽区域默认保持原样，悬停时边框变深
  - 填充模式按钮默认状态保持原样，选中时显示灰色背景
  - 颜色方案自动适配亮/暗主题切换
