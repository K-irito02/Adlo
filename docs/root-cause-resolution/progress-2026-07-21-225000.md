## [x] 事项 1：拖拽工作区浮层标签时穿透触发底层按钮 tooltip 和悬停效果
- 状态：已完成 (2026-07-21 23:00)
- 根因：DragOverlayPortal 外层容器使用 `pointerEvents: 'none'`（有意为之，允许鼠标事件穿透到 document 层的事件监听），但副作用是浏览器将光标视为直接与底层 DOM 元素交互，从而触发 CSS `:hover` 效果和 tooltip 显示。
- 修复：在 DragOverlayPortal (`frontend/src/app/components/drag/DragOverlayPortal.tsx`) 中添加全屏透明阻挡层 `<div>`，z-index: 9998（介于内容层 `< 90` 与拖拽浮层 `9999` 之间）。阻挡层捕获所有指针事件，阻止 tooltip/hover 穿透，同时 mousemove/mouseup 通过事件冒泡继续传到 document 层监听器（拖拽系统只使用 `e.clientX/Y`，不依赖 `e.target`）。
- 验证：pnpm lint（0 errors）+ pnpm test（105 test files, 719 tests 全部通过）

## [x] 事项 2：拖拽时预放置位置显示半透明 ghost 标签而非不透明标签
- 状态：已完成 (2026-07-21 23:05)
- 根因：`drag.css` 中 `.adl-dragging` 仅添加 outline，预放置位置显示为完整不透明标签。
