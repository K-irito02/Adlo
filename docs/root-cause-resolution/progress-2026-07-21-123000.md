## [ ] 事项 1：拖拽时工作区标签（DragOverlay）出现在鼠标光标以下，与鼠标脱节
- 状态：已完成（待用户确认）
- 根因：@dnd-kit 的 DragOverlay 默认将 overlay 内容的左上角锚定到鼠标指针坐标，
  overlay 内容（有 padding/height）使其视觉上"在光标下方"。即使 @dnd-kit 做了一些居中计算，
  在实际使用中 (v6.3.1) overlay 与鼠标位置存在偏移。
- 修复：
  1. 安装 @dnd-kit/modifiers@9.0.0
  2. 在 WorkspaceSettings.tsx:218 为 <DragOverlay> 添加 modifiers={[snapCenterToCursor]}
     snapCenterToCursor 修饰符强制 overlay 以鼠标指针为中心的定位方式，消除偏移
- 验证：等待用户测试

## [ ] 事项 2：拖拽 overlay 边框仍显示蓝色（而不是相反主题颜色）
- 状态：已完成（待用户确认）
- 根因：之前设置的 --accent-inverse（#60a5fa / #2563eb）仍然是蓝色系。
  用户希望"在深色主题下用浅色边框，在浅色主题下用深色边框"——即中性、非蓝色的边框线。
- 修复（第二轮）：
  1. 从 themes.css 移除 --accent-inverse（亮色/暗色两处）
  2. 在 themes.css 中新增 --adl-drag-overlay-border：亮色主题 #000000，暗色主题 #ffffff
  3. 将 settings.css 的 .adl-drag-overlay border 从 color-mix(...) 改为 var(--adl-drag-overlay-border)
     亮色主题 → 纯黑色边框，暗色主题 → 纯白色边框
- 验证：等待用户测试
