## [x] 事项 3：修复 TagRow 错误显示在其他 UI 元素上层的问题
- 状态：已完成（2026-07-30）
- 根因：`.adl-branch-graph__tag-row--sticky` 使用 `position: sticky; z-index: 10`，而 `.adl-git-vis__chart` 未创建自己的层叠上下文（stacking context），导致 tag row 的 `z-index: 10` 直接作用于根层叠上下文。`.adl-workspace-tab__container` 的 `position: sticky; z-index: 1` 创建了 SC1 层叠上下文，其内部的 dropdown 菜单（如 ChartColorPresetSelector 的 z-index: 50）受限于 SC1 的层叠级别（z-index: 1）。由于 10 > 1，tag row 在根层叠上下文中排在 SC1 之上，导致 tag row 覆盖了 dropdown 菜单。
- 修复：在 `.adl-git-vis__chart` 上添加 `isolation: isolate`，为 chart 创建独立的层叠上下文。这样 tag row 的 `z-index: 10` 被限制在 chart 内部，不再影响外部元素。外部的 dropdown 菜单（通过 SC1 位于 z-index: 1）正确显示在 chart 之上。
- 验证：156 个 git-visualization 测试通过，lint 无报错
