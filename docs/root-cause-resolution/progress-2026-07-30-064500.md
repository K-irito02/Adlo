## [x] 事项 11：缓存命中后快速滚动仍闪烁
- 状态：已完成
- 根因：useEffect 无条件先 `setSrc(pixelAvatar)`，再异步 `getAvatar().then(setSrc)`。即使 L1 缓存已命中，两次 setState 间有一帧渲染间隙显示像素头像
- 修复：新增同步 API `getCachedAvatarUrl(email)` 仅查 L1 内存。useState 初始化时用 `getCachedAvatarUrl(email) ?? pixelAvatar`，命中则初始就是缓存头像；useEffect 中命中则直接 setSrc(cached) 并 return，跳过像素头像阶段
- 验证：152/152 测试通过（含 4 个新增 getCachedAvatarUrl 测试）
