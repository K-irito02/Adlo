历史记录列表闪烁问题

场景：当天再次访问同一 URL，条目标签移动位置时的闪烁

当前问题

当天目录下的标签列表
🔴 旧 之前访问的 URL-A（在旧位置，比如第3位）
⋯ 其他标签 ⋯
⚡ 闪烁 再次访问 URL-A → 树重建 → 整列标签闪烁

三套动画方案

A. FLIP 位置动画

使用 FLIP（First Last Invert Play）技术：记录每个条目标签的旧位置 → 计算新位置偏移 → 执行 transform 动画到目标位置。所有标签平滑移动，新标签从上方渐入。

Pros

  • 最自然的"列表重排"体验
  • 每个标签平滑过渡到新位置

Cons

  • 实现复杂，需 DOM 测量
  • 与虚拟列表兼容性差
  • 虚拟滚动时测量失效

B. 新条目高亮脉冲

新添加的条目标签获得一个短暂的高亮动画（背景色从亮色渐变为正常），持续约 1.5 秒。其它标签不移动，使用 CSS @keyframes pulse。

Pros

  • 实现简单，纯 CSS
  • 不影响现有渲染结构
  • 与虚拟列表兼容

Cons

  • 不解决"位置跳变"视觉
  • 条目仍会瞬间跳到首位

C. 容器级 CSSTransition

对列表容器整体应用 transition: all 0.3s ease，新条目从上方滑入（transform: translateY(-20px) → translateY(0) + opacity: 0 → 1），旧条目 opacity 短暂 0.9 后恢复。

Pros

  • 实现适中
  • 动画平滑，视觉舒适
  • 与虚拟列表基本兼容

Cons

  • 仍需处理 React key
  • 需要防抖避免多次触发
