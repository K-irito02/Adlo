Block 合并策略

相邻的相同类型 diff 行，多久合并为一个块？

A

紧合并

间隔 ≤ 1 行就合并（传统做法），块较大但块数少

B

宽合并

间隔 ≤ 3 行合并，减少过多小块碎片

C

不合并

每行独立显示，不合并。最精确但视觉上可能显得碎片化

Sticky Context Rail 整合

Sticky Context 的 diff rail 也应统一颜色体系。当前已有 rail 样式，是否需要保持一致？

A

统一颜色体系

Sticky Context rail 使用与编辑器相同的 Insert/Delete/Modify 颜色

B

保持独立

Sticky Context 使用自己的微弱的色调体系，不与编辑器完全绑定
