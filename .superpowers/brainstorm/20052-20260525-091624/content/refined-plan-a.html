在方案A的基础上，加上您要求的两种对齐规则

最终效果示意

▶ src/ ← 父节点首字符 "s"
▶ components/ ← ▶ 对齐父 "s"
▶ utils/
TSX Button.tsx ← TSX 徽标与 ▶ 同列
黄底 = 文件 logo（方案改动：从 label 内移到外面，替代 indent 占位符）

改动项一览

1

CSS：竖线位置微调

::before left: 9px → 10px（图标中心点）

2

CSS：子容器缩进调整

children padding-left: 20px → 22px

目的：子节点 toggle/logo 位于 position=0（相对children容器），22px使其对齐父节点首字符（20+2=22）

3

CSS：顶节点竖线显示

移除 .adl-tree-root > .adl-tree-node::before { display: none; }

4

JS/TSX：文件节点结构调整

TreeNodeRow / fileTree.tsx：将文件 logo（badge）从 <label> 内部移到外部，
替代 <indent> 占位符。
文件节点：[badge] [label-text]
文件夹节点：[toggle] [label-text]

目的：文件logo与文件夹toggle处于同一水平列

考虑过的替代方案（不采用的原因）

❌ 不移文件logo：纯靠CSS padding调整

文件logo在label内部，padding再怎么调也无法使其与toggle同一列——因为label的padding同时作用于文件夹节点（无logo）和文件节点（有logo），无法单独控制。除非增加条件类名。

❌ 加条件类名区分文件/文件夹

可以用 .adl-filetree__item--file .adl-tree-node__label 减少一些padding，但会引入CSS hack，且文件logo仍然受label的margin/padding影响，不如直接移出来干净。

不改动的部分

✅ TreeNodeRow 组件接口不变 —— props 不增加、不删减
✅ fileTree.tsx 的递归渲染逻辑不变
✅ OutlineTree.tsx 不变（大纲树无文件logo）
✅ ARIA tree 语义不变
✅ 悬停高亮逻辑不变

需要确认后决定的

⚡ 改动项4 的具体实现方式：

选项4a：在 TreeNodeRow 层处理（推荐）
给 TreeNodeRow 加一个 leading slot（如 iconBefore prop），文件节点传入文件 badge，文件夹节点不传。
内部渲染逻辑：
if (hasChildren) → [toggle]
else if (leading) → [leading]
else → [indent]
优点：TreeNodeRow 承担布局职责；fileTree 只需传 prop 无需改结构

选项4b：在 fileTree 层用条件渲染覆盖
不通过 TreeNodeRow 的 indent/toggle 机制，直接在 fileTree.tsx 的 JSX 中判断。
缺点：破坏 TreeNodeRow 的封装性
