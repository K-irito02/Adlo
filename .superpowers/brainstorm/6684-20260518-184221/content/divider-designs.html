并排 Diff 分隔区域 — 分层感设计方案

目标：左区域在下、右区域在上的分层效果。以下展示了 4 种不同思路，点击可选中偏好的方案。

方案 A: 右侧浮起阴影

右侧编辑器添加左阴影 (box-shadow: -2px 0 8px -2px rgba(0,0,0,0.12))，产生右侧面板"浮在左侧之上"的效果。最轻量的改动。

优点

  • 改动最小，只加一行 CSS
  • 不影响拖拽功能
  • 视觉效果自然

缺点

  • 分层感相对温和

左侧编辑器
- deleted line A
- deleted line B
- deleted line C
右侧编辑器
+ inserted line A
+ inserted line B
+ inserted line C

方案 B: 双线分隔槽

在分隔区域绘制两条竖线（左侧浅色、右侧深色），形成"凹槽"效果。视觉上左区与右区被一道物理分隔槽明确隔开，同时 8px 宽的分隔区提供了拖拽抓手空间。

优点

  • 分隔感强烈
  • 凹槽视觉暗示深度
  • 拖拽区域更大

缺点

  • 占用更多水平空间（8px）

左侧编辑器
- deleted line A
- deleted line B
- deleted line C
右侧编辑器
+ inserted line A
+ inserted line B
+ inserted line C

方案 C: 微渐变过渡

左区域右边缘用 linear-gradient 创建微妙渐变遮罩，仿佛左侧内容自然"退后"。没有硬边界线，强调软过渡的层次感。

优点

  • 柔和的层次过渡
  • 不增加额外宽度
  • 视觉上最优雅

缺点

  • 层次感最弱，可能达不到"明显分层"要求
D
左侧编辑器
background: var(--bg)
- deleted line A
- deleted line B
- deleted line C
无阴影、无修饰
右侧编辑器
background: var(--bg-card), box-shadow + border-radius
+ inserted line A
+ inserted line B
+ inserted line C

方案 D: 卡片叠加（最强分层）

右侧编辑器完全模拟"卡片"形态：白色/卡片背景、左侧圆角、深阴影，仿佛一张卡片叠放在左侧内容之上。左侧保持无修饰背景，形成"左低右高"的强烈对比。

优点

  • 分层感最强烈最明显
  • "左区域在下、右区域在上"效果突出
  • 视觉上最精致

缺点

  • 改动最大
  • 右侧背景变化可能影响 diff 颜色感知

我的建议

推荐方案 A — 最轻量，只加一行 box-shadow，对现有布局零影响。分层感恰到好处，右侧浮起的阴影自然传达了"左低右高"的关系。如果预览后觉得分层不够明显，可以升级到方案 D。
