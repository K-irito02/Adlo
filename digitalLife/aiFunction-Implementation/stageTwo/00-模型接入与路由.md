# 模型接入与路由实施计划

## 模块概述

**包名**: `@ai-digital-life/model-gateway`

**优先级**: P0 - 所有 AI 功能的基石

**目标**: 统一管理多种大语言模型的接入、请求分发与响应处理，屏蔽不同模型提供商的 API 差异，向上层提供一致的调用接口，同时根据任务特征智能选择最优模型。

## 设计原则

- **统一接口优先**: 上层模块只依赖 ModelRouter 统一入口，不直接感知底层模型差异
- **流式默认**: 所有模型交互默认流式，非流式作为降级选项
- **故障隔离**: 单个模型提供商故障不影响整体服务
- **安全存储**: API Key 等凭据通过系统凭据存储，不落盘明文
- **可观测**: 每次请求的路由决策、Token 用量、延迟和错误都可追踪

## Phase 1 职责边界

### 必须交付

- 至少接入 2 个模型提供商（OpenAI + Claude 或 OpenAI + Ollama）
- 统一 chat 接口，支持流式和非流式
- 手动指定模型路由
- 基于任务类型的自动路由
- 故障转移与熔断
- 流式响应的增量回调与中途取消
- 单次请求 Token 用量统计
- 累计用量追踪（按模型/按日/按会话）

### 只做骨架

- 智能负载均衡（竞速模式）
- 本地模型 GPU 调度
- 模型微调接口
- 多模态支持
- A/B 测试框架

```typescript
export abstract class BaseProvider implements ModelProvider {
  abstract readonly id: string;
  abstract readonly name: string;
  abstract readonly models: ModelInfo[];

  constructor(
    protected readonly config: ProviderConfig,
    protected readonly logger: Logger
  ) {}

  abstract chat(request: ChatRequest): Promise<ChatResponse>;
  abstract chatStream(request: ChatRequest): AsyncIterable<StreamChunk>;
  abstract estimateTokens(text: string): number;

  async isAvailable(): Promise<boolean> {
    try {
      const response = await this.chat({
        messages: [{ role: 'user', content: 'ping' }],
        maxTokens: 5,
      });
      return response.content.length > 0;
    } catch {
      return false;
    }
  }

  protected validateRequest(request: ChatRequest): Result<void> {
    if (!request.messages.length) {
      return Result.err(new ValidationError('Messages cannot be empty'));
    }
    return Result.ok(undefined as void);
  }
}
```

### 任务4: 模型路由 (5天)

```typescript
export type RouteStrategy = 'task' | 'cost' | 'latency' | 'manual' | 'fallback';

export interface RouteDecision {
  providerId: string;
  modelId: string;
  strategy: RouteStrategy;
  reason: string;
  fallbackChain: Array<{ providerId: string; modelId: string }>;
}

export class ModelRouter {
  private strategies: Map<RouteStrategy, RoutingStrategy>;

  constructor(
    private readonly registry: ProviderRegistry,
    private readonly config: RouterConfig
  ) {
    this.strategies = new Map([
      ['task', new TaskRoutingStrategy()],
      ['cost', new CostRoutingStrategy()],
      ['latency', new LatencyRoutingStrategy()],
      ['manual', new ManualRoutingStrategy()],
      ['fallback', new FallbackRoutingStrategy()],
    ]);
  }

  async route(request: ChatRequest): Promise<RouteDecision> {
    const strategy = this.resolveStrategy(request);
    const decision = await strategy.decide(request, this.registry);

    if (!decision) {
      throw new NoAvailableModelError('No model available for this request');
    }

    return decision;
  }

  private resolveStrategy(request: ChatRequest): RoutingStrategy {
    if (request.model) {
      return this.strategies.get('manual')!;
    }
    if (request.metadata?.intent) {
      return this.strategies.get('task')!;
    }
    return this.strategies.get(this.config.defaultStrategy || 'task')!;
  }
}
```

```typescript
export type CircuitState = 'closed' | 'open' | 'half-open';

export class CircuitBreaker {
  private state: CircuitState = 'closed';
  private failureCount = 0;
  private lastFailureTime = 0;
  private successCount = 0;

  constructor(
    private readonly config: CircuitBreakerConfig = {
      failureThreshold: 3,
      recoveryTimeout: 30000,
      halfOpenSuccessThreshold: 2,
    }
  ) {}

  async execute<T>(fn: () => Promise<T>): Promise<T> {
    if (this.state === 'open') {
      if (Date.now() - this.lastFailureTime < this.config.recoveryTimeout) {
        throw new CircuitOpenError('Circuit breaker is open');
      }
      this.state = 'half-open';
      this.successCount = 0;
    }

    try {
      const result = await fn();
      this.onSuccess();
      return result;
    } catch (error) {
      this.onFailure();
      throw error;
    }
  }

  private onSuccess(): void {
    if (this.state === 'half-open') {
      this.successCount++;
      if (this.successCount >= this.config.halfOpenSuccessThreshold) {
        this.state = 'closed';
        this.failureCount = 0;
      }
    } else {
      this.failureCount = 0;
    }
  }

  private onFailure(): void {
    this.failureCount++;
    this.lastFailureTime = Date.now();
    if (this.failureCount >= this.config.failureThreshold) {
      this.state = 'open';
    }
  }

  getState(): CircuitState {
    return this.state;
  }
}
```

### 任务6: SSE 流解析 (3天)

```typescript
export class SSEParser {
  parseLine(line: string): SSEEvent | null {
    if (line.startsWith('data: ')) {
      const data = line.slice(6).trim();
      if (data === '[DONE]') {
        return { type: 'done', data: '' };
      }
      try {
        return { type: 'data', data: JSON.parse(data) };
      } catch {
        return { type: 'raw', data };
      }
    }
    if (line.startsWith('event: ')) {
      return { type: 'event', data: line.slice(7).trim() };
    }
    if (line.startsWith('id: ')) {
      return { type: 'id', data: line.slice(4).trim() };
    }
    return null;
  }

  async *parseStream(body: ReadableStream<Uint8Array>): AsyncIterable<SSEEvent> {
    const reader = body.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    try {
      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() || '';

        for (const line of lines) {
          const event = this.parseLine(line.trim());
          if (event) yield event;
        }
      }

      if (buffer.trim()) {
        const event = this.parseLine(buffer.trim());
        if (event) yield event;
      }
    } finally {
      reader.releaseLock();
    }
  }
}

export interface SSEEvent {
  type: 'data' | 'event' | 'id' | 'done' | 'raw';
  data: string;
}
```

```typescript
export class UsageTracker {
  constructor(private readonly storage: Storage) {}

  async recordUsage(entry: UsageEntry): Promise<void> {
    const key = `usage:${entry.providerId}:${entry.modelId}:${this.toDateKey(entry.timestamp)}`;
    const existing = await this.storage.get<UsageAggregate>(key);
    const aggregate = existing || this.createEmptyAggregate(entry);

    aggregate.totalRequests++;
    aggregate.totalPromptTokens += entry.promptTokens;
    aggregate.totalCompletionTokens += entry.completionTokens;
    aggregate.totalTokens += entry.promptTokens + entry.completionTokens;
    aggregate.totalCost +=
      entry.promptTokens * entry.costPerInputToken +
      entry.completionTokens * entry.costPerOutputToken;

    await this.storage.set(key, aggregate);
  }

  async getUsage(query: UsageQuery): Promise<UsageAggregate[]> {
    const pattern = `usage:${query.providerId || '*'}:${query.modelId || '*'}:${query.dateKey || '*'}`;
    return this.storage.query<UsageAggregate>(pattern);
  }

  private toDateKey(timestamp: number): string {
    const date = new Date(timestamp);
    return `${date.getFullYear()}-${String(date.getMonth() + 1).padStart(2, '0')}-${String(date.getDate()).padStart(2, '0')}`;
  }
}

export interface UsageEntry {
  providerId: string;
  modelId: string;
  promptTokens: number;
  completionTokens: number;
  costPerInputToken: number;
  costPerOutputToken: number;
  timestamp: number;
  sessionId?: string;
  taskId?: string;
}

export interface UsageAggregate {
  providerId: string;
  modelId: string;
  dateKey: string;
  totalRequests: number;
  totalPromptTokens: number;
  totalCompletionTokens: number;
  totalTokens: number;
  totalCost: number;
}
```

## 验收标准

- [ ] 至少接入 2 个模型提供商
- [ ] 统一接口可正常发起非流式请求并返回完整响应
- [ ] 流式请求可逐 Token 回调，UI 可实时渲染
- [ ] 手动指定模型路由正常工作
- [ ] 任务路由可根据任务类型自动选择模型
- [ ] 主模型不可用时自动故障转移至备选模型
- [ ] 熔断器在连续失败后正确进入 Open 状态
- [ ] 单次请求 Token 用量统计准确
- [ ] 累计用量可按模型/日期查询
- [ ] 路由决策耗时 < 5ms
- [ ] 流式首 Token 延迟 < 模型原生延迟 + 50ms
- [ ] API Key 无效时返回明确错误信息，不崩溃
- [ ] 流式请求中途取消不导致内存泄漏
