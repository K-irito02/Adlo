# 变更预览与应用实施计划

## 模块概述

**包名**: `@ai-digital-life/change-engine`

**优先级**: P0 - 建立用户信任的关键环节

**目标**: 把 AI 生成的修改转成可审查的 patch/diff，在用户确认后安全地应用到工作区，通过透明的变更展示、分步确认机制和完善的回滚能力，确保用户对 AI 的每一次修改都有完全的控制权。

## 设计原则

- **Patch First**: AI 默认生成变更草案，不直接盲写文件
- **透明可审**: 每次变更都有完整的 diff 展示和风险说明
- **分步确认**: 支持按文件、按块部分接受修改
- **检查点必建**: 应用前自动创建检查点，确保可回滚
- **原子性**: 批量修改要么全部应用，要么全部回滚

## Phase 1 职责边界

### 必须交付

- PatchSet 模型与 FilePatch/Hunk 数据结构
- 单文件 diff 预览与应用
- 多文件 patch 与分块接受
- 检查点机制（创建、恢复、管理）
- 冲突检测（脏文件检测）
- 自动验证（应用后运行验证命令）
- 审计日志

### 只做骨架

- 三方合并
- AI 解释变更
- Git 工作树深度联动
- 变更模板

```typescript
export class PatchSetBuilder {
  private filePatches: FilePatch[] = [];

  addFileChange(
    filePath: string,
    originalContent: string,
    newContent: string,
    operation: FileOperation = 'modify'
  ): PatchSetBuilder {
    const hunks = this.computeHunks(originalContent, newContent);
    const filePatch: FilePatch = {
      id: this.generateId(),
      patchSetId: '',
      filePath,
      operation,
      hunks,
      originalContent,
      newContent,
    };

    this.filePatches.push(filePatch);
    return this;
  }

  addFileCreation(filePath: string, content: string): PatchSetBuilder {
    this.filePatches.push({
      id: this.generateId(),
      patchSetId: '',
      filePath,
      operation: 'create',
      hunks: [],
      originalContent: '',
      newContent: content,
    });
    return this;
  }

  addFileDeletion(filePath: string, originalContent: string): PatchSetBuilder {
    this.filePatches.push({
      id: this.generateId(),
      patchSetId: '',
      filePath,
      operation: 'delete',
      hunks: [],
      originalContent,
      newContent: '',
    });
    return this;
  }

  build(description: string, taskId?: string): PatchSet {
    const riskLevel = this.assessRisk();
    const impactSummary = this.generateImpactSummary();

    const patchSet: PatchSet = {
      id: this.generateId(),
      taskId,
      description,
      filePatches: this.filePatches.map(fp => ({
        ...fp,
        patchSetId: '',
      })),
      riskLevel,
      impactSummary,
      status: 'pending',
      createdAt: Date.now(),
    };

    for (const fp of patchSet.filePatches) {
      fp.patchSetId = patchSet.id;
    }

    this.filePatches = [];
    return patchSet;
  }

  private computeHunks(original: string, modified: string): Hunk[] {
    const diffComputer = new DiffComputer();
    const preview = diffComputer.computeDiff(original, modified, '');
    return preview.hunks.map(h => ({
      id: h.id,
      filePatchId: '',
      oldStart: h.startLineOriginal,
      oldLines: h.endLineOriginal - h.startLineOriginal + 1,
      newStart: h.startLineModified,
      newLines: h.endLineModified - h.startLineModified + 1,
      content: '',
      status: 'pending' as HunkStatus,
    }));
  }

  private assessRisk(): RiskLevel {
    const operations = this.filePatches.map(fp => fp.operation);
    if (operations.includes('delete')) return 'high';
    if (operations.includes('create') && this.filePatches.length > 3) return 'medium';
    if (this.filePatches.length > 5) return 'medium';
    return 'low';
  }

  private generateImpactSummary(): string {
    const counts = {
      create: this.filePatches.filter(fp => fp.operation === 'create').length,
      modify: this.filePatches.filter(fp => fp.operation === 'modify').length,
      delete: this.filePatches.filter(fp => fp.operation === 'delete').length,
    };

    const parts: string[] = [];
    if (counts.create > 0) parts.push(`${counts.create} 个文件创建`);
    if (counts.modify > 0) parts.push(`${counts.modify} 个文件修改`);
    if (counts.delete > 0) parts.push(`${counts.delete} 个文件删除`);

    return `影响 ${this.filePatches.length} 个文件：${parts.join('，')}`;
  }

  private generateId(): string {
    return `id-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`;
  }
}
```

```typescript
export class CheckpointManager {
  private store: CheckpointStore;

  constructor(
    private readonly fsOps: FileService,
    private readonly config: { maxCheckpoints: number },
    private readonly logger: Logger
  ) {
    this.store = new CheckpointStore(config.maxCheckpoints || 50);
  }

  async createCheckpoint(patchSet: PatchSet): Promise<Checkpoint> {
    const fileSnapshots: FileSnapshot[] = [];

    for (const filePatch of patchSet.filePatches) {
      try {
        const contentResult = await this.fsOps.readFile(filePatch.filePath);
        if (Result.isOk(contentResult)) {
          fileSnapshots.push({
            filePath: filePatch.filePath,
            content: contentResult.value,
            hash: this.computeHash(contentResult.value),
          });
        }
      } catch {
        this.logger.warn('Failed to snapshot file', {
          filePath: filePatch.filePath,
        });
      }
    }

    const checkpoint: Checkpoint = {
      id: this.generateId(),
      patchSetId: patchSet.id,
      fileSnapshots,
      description: `Checkpoint for: ${patchSet.description}`,
      createdAt: Date.now(),
    };

    this.store.add(checkpoint);
    this.logger.info('Checkpoint created', {
      checkpointId: checkpoint.id,
      patchSetId: patchSet.id,
      fileCount: fileSnapshots.length,
    });

    return checkpoint;
  }

  async restoreCheckpoint(checkpointId: string): Promise<Result<void>> {
    const checkpoint = this.store.get(checkpointId);
    if (!checkpoint) {
      return Result.err(new CheckpointNotFoundError(checkpointId));
    }

    for (const snapshot of checkpoint.fileSnapshots) {
      const result = await this.fsOps.writeFile(
        snapshot.filePath,
        snapshot.content,
        { overwrite: true }
      );
      if (Result.isErr(result)) {
        this.logger.error('Failed to restore file from checkpoint', {
          filePath: snapshot.filePath,
          checkpointId,
        });
        return result as Result<void>;
      }
    }

    checkpoint.restoredAt = Date.now();
    this.logger.info('Checkpoint restored', {
      checkpointId,
      fileCount: checkpoint.fileSnapshots.length,
    });

    return Result.ok(undefined as void);
  }

  async partialRestore(
    checkpointId: string,
    filePaths: string[]
  ): Promise<Result<void>> {
    const checkpoint = this.store.get(checkpointId);
    if (!checkpoint) {
      return Result.err(new CheckpointNotFoundError(checkpointId));
    }

    const snapshots = checkpoint.fileSnapshots.filter(s =>
      filePaths.includes(s.filePath)
    );

    for (const snapshot of snapshots) {
      const result = await this.fsOps.writeFile(
        snapshot.filePath,
        snapshot.content,
        { overwrite: true }
      );
      if (Result.isErr(result)) return result as Result<void>;
    }

    return Result.ok(undefined as void);
  }

  getCheckpoints(patchSetId?: string): Checkpoint[] {
    if (patchSetId) {
      return this.store.getByPatchSetId(patchSetId);
    }
    return this.store.getAll();
  }

  private computeHash(content: string): string {
    let hash = 0;
    for (let i = 0; i < content.length; i++) {
      const char = content.charCodeAt(i);
      hash = ((hash << 5) - hash) + char;
      hash |= 0;
    }
    return hash.toString(36);
  }

  private generateId(): string {
    return `cp-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`;
  }
}
```

```typescript
export class ConflictDetector {
  constructor(
    private readonly fsOps: FileService,
    private readonly tabManager: TabManager,
    private readonly logger: Logger
  ) {}

  async detectConflicts(patchSet: PatchSet): Promise<ConflictInfo[]> {
    const conflicts: ConflictInfo[] = [];

    for (const filePatch of patchSet.filePatches) {
      const dirtyConflict = this.checkDirtyEditor(filePatch);
      if (dirtyConflict) {
        conflicts.push(dirtyConflict);
        continue;
      }

      const externalConflict = await this.checkExternalModification(filePatch);
      if (externalConflict) {
        conflicts.push(externalConflict);
      }
    }

    return conflicts;
  }

  private checkDirtyEditor(filePatch: FilePatch): ConflictInfo | null {
    const tab = this.tabManager.getAllTabs().find(
      t => t.filePath === filePatch.filePath
    );

    if (tab?.isDirty) {
      return {
        filePath: filePatch.filePath,
        conflictType: 'dirty-editor',
        currentContent: tab.content,
        expectedContent: filePatch.originalContent,
      };
    }

    return null;
  }

  private async checkExternalModification(
    filePatch: FilePatch
  ): Promise<ConflictInfo | null> {
    const contentResult = await this.fsOps.readFile(filePatch.filePath);
    if (Result.isErr(contentResult)) return null;

    const currentContent = contentResult.value;
    if (currentContent !== filePatch.originalContent) {
      return {
        filePath: filePatch.filePath,
        conflictType: 'external-modification',
        currentContent,
        expectedContent: filePatch.originalContent,
      };
    }

    return null;
  }
}
```

```typescript
export class ValidationRunner {
  constructor(
    private readonly terminal: TerminalService,
    private readonly logger: Logger
  ) {}

  async validate(
    patchSet: PatchSet,
    options?: ApplyOptions
  ): Promise<ValidationResult> {
    const command = options?.validateCommand || this.inferCommand(patchSet);
    if (!command) {
      return {
        success: true,
        command: '',
        exitCode: 0,
        output: 'No validation command configured',
        errors: [],
        duration: 0,
      };
    }

    const startTime = Date.now();
    const result = await this.terminal.execute({
      command,
      timeout: options?.timeout || 120000,
      metadata: { source: 'system' },
    });

    const outputParser = new OutputParser();
    const errors = outputParser.parseCompilerErrors(
      result.stdout + '\n' + result.stderr
    );

    const validation: ValidationResult = {
      success: result.exitCode === 0,
      command,
      exitCode: result.exitCode || 0,
      output: result.stdout,
      errors,
      duration: Date.now() - startTime,
    };

    this.logger.info('Validation completed', {
      patchSetId: patchSet.id,
      success: validation.success,
      duration: validation.duration,
    });

    return validation;
  }

  private inferCommand(patchSet: PatchSet): string | null {
    const filePaths = patchSet.filePatches.map(fp => fp.filePath);
    const hasTypeScript = filePaths.some(p => p.endsWith('.ts') || p.endsWith('.tsx'));

    if (hasTypeScript) {
      return 'npm run build 2>&1 || npx tsc --noEmit';
    }

    return null;
  }
}
```

### 任务5: 变更服务（核心编排） (4天)

```typescript
export class ChangeService {
  constructor(
    private readonly patchSetBuilder: PatchSetBuilder,
    private readonly checkpointManager: CheckpointManager,
    private readonly conflictDetector: ConflictDetector,
    private readonly validationRunner: ValidationRunner,
    private readonly auditLogger: AuditLogger,
    private readonly fsOps: FileService,
    private readonly logger: Logger
  ) {}

  async preview(patchSet: PatchSet): Promise<PatchSet> {
    await this.auditLogger.log(patchSet.id, 'previewed', 'PatchSet previewed by user');
    return patchSet;
  }

  async apply(
    patchSet: PatchSet,
    options?: ApplyOptions
  ): Promise<Result<PatchSet>> {
    const conflicts = await this.conflictDetector.detectConflicts(patchSet);
    if (conflicts.length > 0) {
      this.logger.warn('Conflicts detected before apply', {
        patchSetId: patchSet.id,
        conflictCount: conflicts.length,
      });
      return Result.err(new ConflictDetectedError(conflicts));
    }

    const checkpoint = await this.checkpointManager.createCheckpoint(patchSet);
    patchSet.checkpointId = checkpoint.id;

    await this.auditLogger.log(patchSet.id, 'accepted', 'PatchSet accepted by user');

    try {
      await this.applyFilePatches(patchSet);
    } catch (error) {
      this.logger.error('Failed to apply patches, rolling back', {
        patchSetId: patchSet.id,
        error: (error as Error).message,
      });
      await this.checkpointManager.restoreCheckpoint(checkpoint.id);
      patchSet.status = 'rolled-back';
      return Result.err(new PatchApplyError((error as Error).message));
    }

    if (options?.validateCommand) {
      const validation = await this.validationRunner.validate(patchSet, options);
      if (!validation.success && options.autoRollbackOnFailure) {
        this.logger.warn('Validation failed, auto-rolling back', {
          patchSetId: patchSet.id,
          exitCode: validation.exitCode,
        });
        await this.checkpointManager.restoreCheckpoint(checkpoint.id);
        patchSet.status = 'rolled-back';
        await this.auditLogger.log(
          patchSet.id,
          'rolled-back',
          `Auto-rollback: validation failed with exit code ${validation.exitCode}`
        );
        return Result.err(new ValidationError(`Validation failed: ${validation.output}`));
      }
    }

    patchSet.status = 'applied';
    patchSet.appliedAt = Date.now();
    await this.auditLogger.log(patchSet.id, 'applied', 'PatchSet successfully applied');

    return Result.ok(patchSet);
  }

  async rollback(patchSetId: string): Promise<Result<void>> {
    const checkpoints = this.checkpointManager.getCheckpoints(patchSetId);
    const checkpoint = checkpoints[0];
    if (!checkpoint) {
      return Result.err(new CheckpointNotFoundError(patchSetId));
    }

    const result = await this.checkpointManager.restoreCheckpoint(checkpoint.id);
    if (Result.isOk(result)) {
      await this.auditLogger.log(
        patchSetId,
        'rolled-back',
        'PatchSet rolled back by user'
      );
    }
    return result;
  }

  async acceptHunk(
    patchSet: PatchSet,
    filePatchId: string,
    hunkId: string
  ): Promise<PatchSet> {
    return {
      ...patchSet,
      filePatches: patchSet.filePatches.map(fp =>
        fp.id === filePatchId
          ? {
              ...fp,
              hunks: fp.hunks.map(h =>
                h.id === hunkId ? { ...h, status: 'accepted' as HunkStatus } : h
              ),
            }
          : fp
      ),
    };
  }

  async rejectHunk(
    patchSet: PatchSet,
    filePatchId: string,
    hunkId: string
  ): Promise<PatchSet> {
    return {
      ...patchSet,
      filePatches: patchSet.filePatches.map(fp =>
        fp.id === filePatchId
          ? {
              ...fp,
              hunks: fp.hunks.map(h =>
                h.id === hunkId ? { ...h, status: 'rejected' as HunkStatus } : h
              ),
            }
          : fp
      ),
    };
  }

  private async applyFilePatches(patchSet: PatchSet): Promise<void> {
    for (const filePatch of patchSet.filePatches) {
      switch (filePatch.operation) {
        case 'create':
          await this.fsOps.writeFile(
            filePatch.filePath,
            filePatch.newContent,
            { createDir: true }
          );
          break;

        case 'modify': {
          const content = this.applyAcceptedHunks(filePatch);
          await this.fsOps.writeFile(
            filePatch.filePath,
            content,
            { overwrite: true }
          );
          break;
        }

        case 'delete':
          await this.fsOps.deleteFile(filePatch.filePath);
          break;
      }
    }
  }

  private applyAcceptedHunks(filePatch: FilePatch): string {
    const acceptedHunks = filePatch.hunks.filter(h => h.status === 'accepted');
    if (acceptedHunks.length === 0 && filePatch.hunks.some(h => h.status === 'pending')) {
      return filePatch.newContent;
    }

    if (acceptedHunks.length === 0) {
      return filePatch.originalContent;
    }

    return filePatch.newContent;
  }
}
```

```typescript
export class AuditLogger {
  constructor(private readonly storage: Storage) {}

  async log(
    patchSetId: string,
    action: PatchAuditEntry['action'],
    details: string
  ): Promise<void> {
    const entry: PatchAuditEntry = {
      id: `audit-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`,
      patchSetId,
      action,
      details,
      timestamp: Date.now(),
    };

    await this.storage.append(`change:audit:${patchSetId}`, entry);
  }

  async getAuditLog(patchSetId: string): Promise<PatchAuditEntry[]> {
    return this.storage.query<PatchAuditEntry>(`change:audit:${patchSetId}`);
  }

  async getRecentAuditLog(limit = 50): Promise<PatchAuditEntry[]> {
    const all = await this.storage.query<PatchAuditEntry>('change:audit:*');
    return all
      .sort((a, b) => b.timestamp - a.timestamp)
      .slice(0, limit);
  }
}
```

## 验收标准

- [ ] 用户能在应用前看到完整 diff

- [ ] 应用失败时可回滚到应用前状态
