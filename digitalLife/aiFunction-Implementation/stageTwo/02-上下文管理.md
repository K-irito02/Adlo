# 上下文管理实施计划

## 模块概述

**包名**: `@ai-digital-life/context`

**优先级**: P0 - AI 响应质量的核心决定因素

**目标**: 收集、组织、优先级排序和动态裁剪送入模型的信息，确保在有限的 Token 窗口内最大化有效信息的密度，管理多种类型的上下文（对话历史、代码片段、项目结构）。

## 设计原则

- **关键信息不丢失**: System Prompt 和当前用户消息绝不被截断
- **显式引用优先**: 用户 @引用的内容优先级高于自动收集
- **Token 预算硬约束**: 总上下文严格控制在模型窗口内
- **缓存友好**: 避免重复计算，相同内容的 Token 计数结果缓存
- **可观测**: 截断决策可追踪，记录哪些内容被截断及原因

## Phase 1 职责边界

### 必须交付

- Token 计算与预算分配
- 上下文类型管理与优先级排序
- 动态截断（优先级截断 + 滑动窗口 + 代码裁剪）
- 基础上下文缓存（L1 内存缓存）

### 只做骨架

- 自动上下文收集（Phase 1 仅支持手动 @引用）
- L2/L3 文件缓存
- 语义压缩
- 学习型优先级

#### 1.1 统一 Token 计数接口

```typescript
export interface TokenCounter {
  count(text: string): number;
  estimate(text: string): number;
}

export class CompositeTokenCounter implements TokenCounter {
  private primary: TokenCounter | null = null;
  private fallback: TokenCounter;

  constructor(
    private readonly modelId: string,
    private readonly logger: Logger
  ) {
    this.fallback = new ApproximateTokenCounter();
    this.initializePrimary();
  }

  private async initializePrimary(): Promise<void> {
    try {
      this.primary = new TiktokenCounter(this.modelId);
    } catch (error) {
      this.logger.warn('Tiktoken initialization failed, using approximate counter', {
        modelId: this.modelId,
        error: (error as Error).message,
      });
      this.primary = null;
    }
  }

  count(text: string): number {
    if (this.primary) {
      try {
        return this.primary.count(text);
      } catch {
        this.logger.warn('Tiktoken count failed, falling back to approximate');
      }
    }
    return this.fallback.count(text);
  }

  estimate(text: string): number {
    return this.fallback.count(text);
  }
}
```

#### 1.2 近似 Token 计数

```typescript
export class ApproximateTokenCounter implements TokenCounter {
  count(text: string): number {
    const cjkCount = (text.match(/[\u4e00-\u9fff\u3040-\u309f\u30a0-\u30ff]/g) || []).length;
    const otherCount = text.length - cjkCount;
    return Math.ceil(cjkCount / 2 + otherCount / 4);
  }

  estimate(text: string): number {
    return this.count(text);
  }
}
```

### 任务2: 优先级计算 (3天)

```typescript
export interface PriorityFactor {
  name: string;
  weight: number;
  calculate(entry: ContextEntry, context: PriorityContext): number;
}

export interface PriorityContext {
  currentTask?: string;
  currentFile?: string;
  referencedFiles?: string[];
  timestamp: number;
}

export class PriorityCalculator {
  private factors: PriorityFactor[];

  constructor() {
    this.factors = [
      new RelevanceFactor(0.35),
      new RecencyFactor(0.25),
      new ImportanceFactor(0.25),
      new ExplicitnessFactor(0.15),
    ];
  }

  calculate(entry: ContextEntry, context: PriorityContext): number {
    let priority = 0;
    for (const factor of this.factors) {
      priority += factor.calculate(entry, context) * factor.weight;
    }
    return Math.min(1, Math.max(0, priority));
  }

  sort(entries: ContextEntry[], context: PriorityContext): ContextEntry[] {
    return [...entries].sort((a, b) =>
      this.calculate(b, context) - this.calculate(a, context)
    );
  }
}

export class ImportanceFactor implements PriorityFactor {
  name = 'importance';
  constructor(public weight: number) {}

  private static IMPORTANCE_MAP: Record<ContextType, number> = {
    'system-prompt': 1.0,
    'current-message': 0.95,
    'explicit-reference': 0.85,
    'recent-conversation': 0.5,
    'active-code': 0.55,
    'project-structure': 0.3,
    'symbol-index': 0.25,
    'terminal-output': 0.2,
  };

  calculate(entry: ContextEntry): number {
    return ImportanceFactor.IMPORTANCE_MAP[entry.type] ?? 0.3;
  }
}

export class RecencyFactor implements PriorityFactor {
  name = 'recency';
  constructor(public weight: number) {}

  calculate(entry: ContextEntry, context: PriorityContext): number {
    const ageMs = context.timestamp - entry.createdAt;
    const ageHours = ageMs / (1000 * 60 * 60);
    return Math.exp(-0.1 * ageHours);
  }
}

export class ExplicitnessFactor implements PriorityFactor {
  name = 'explicitness';
  constructor(public weight: number) {}

  calculate(entry: ContextEntry): number {
    return entry.type === 'explicit-reference' ? 1.0 : 0.0;
  }
}

export class RelevanceFactor implements PriorityFactor {
  name = 'relevance';
  constructor(public weight: number) {}

  calculate(entry: ContextEntry, context: PriorityContext): number {
    if (!context.currentTask) return 0.5;

    const taskWords = context.currentTask.toLowerCase().split(/\s+/);
    const contentWords = entry.content.toLowerCase().split(/\s+/);
    const overlap = taskWords.filter(w => contentWords.includes(w)).length;
    return Math.min(1, overlap / Math.max(taskWords.length, 1));
  }
}
```

### 任务3: 动态截断 (4天)

```typescript
export class TruncationEngine {
  private strategies: Map<ContextType, TruncationStrategy>;

  constructor(private readonly tokenCounter: TokenCounter) {
    this.strategies = new Map([
      ['recent-conversation', 'sliding-window'],
      ['active-code', 'code-trim'],
      ['project-structure', 'structure-retain'],
    ]);
  }

  truncate(
    entries: ContextEntry[],
    maxTokens: number,
    context: PriorityContext
  ): { entries: ContextEntry[]; log: TruncationLogEntry[] } {
    const log: TruncationLogEntry[] = [];
    let totalTokens = entries.reduce((sum, e) => sum + e.tokenCount, 0);

    if (totalTokens <= maxTokens) {
      return { entries, log };
    }

    const protectedEntries = entries.filter(e =>
      e.type === 'system-prompt' || e.type === 'current-message'
    );
    const truncatableEntries = entries.filter(e =>
      e.type !== 'system-prompt' && e.type !== 'current-message'
    );

    const protectedTokens = protectedEntries.reduce((sum, e) => sum + e.tokenCount, 0);
    const remainingBudget = maxTokens - protectedTokens;

    if (remainingBudget <= 0) {
      return { entries: protectedEntries, log };
    }

    const sorted = [...truncatableEntries].sort((a, b) =>
      new PriorityCalculator().calculate(b, context) -
      new PriorityCalculator().calculate(a, context)
    );

    const result: ContextEntry[] = [...protectedEntries];
    let usedTokens = protectedTokens;

    for (const entry of sorted) {
      if (usedTokens + entry.tokenCount <= remainingBudget + protectedTokens) {
        result.push(entry);
        usedTokens += entry.tokenCount;
      } else {
        const available = maxTokens - usedTokens;
        if (available > 50) {
          const strategy = this.strategies.get(entry.type) || 'priority-based';
          const truncated = this.applyStrategy(entry, available, strategy);
          if (truncated) {
            result.push(truncated);
            usedTokens += truncated.tokenCount;
            log.push({
              entryId: entry.id,
              entryType: entry.type,
              originalTokens: entry.tokenCount,
              remainingTokens: truncated.tokenCount,
              strategy,
              reason: `Token budget exceeded: ${entry.tokenCount} > ${available}`,
            });
          }
        } else {
          log.push({
            entryId: entry.id,
            entryType: entry.type,
            originalTokens: entry.tokenCount,
            remainingTokens: 0,
            strategy: 'priority-based',
            reason: 'Insufficient budget for partial truncation',
          });
        }
      }
    }

    return { entries: result, log };
  }

  private applyStrategy(
    entry: ContextEntry,
    maxTokens: number,
    strategy: TruncationStrategy
  ): ContextEntry | null {
    switch (strategy) {
      case 'code-trim':
        return this.trimCode(entry, maxTokens);
      case 'sliding-window':
        return this.trimConversation(entry, maxTokens);
      case 'structure-retain':
        return this.trimStructure(entry, maxTokens);
      default:
        return this.trimByPriority(entry, maxTokens);
    }
  }

  private trimCode(entry: ContextEntry, maxTokens: number): ContextEntry {
    const lines = entry.content.split('\n');
    const result: string[] = [];
    let tokenCount = 0;

    for (const line of lines) {
      const lineTokens = this.tokenCounter.estimate(line);
      const isSignature = /^(export\s+)?(function|class|interface|type|const|let|var)\s/.test(line.trim());
      const isComment = /^\s*(\/\/|\/\*|\*\s)/.test(line);
      const isImport = /^import\s/.test(line.trim());

      if (isSignature || isComment || isImport) {
        if (tokenCount + lineTokens <= maxTokens) {
          result.push(line);
          tokenCount += lineTokens;
        }
      } else if (tokenCount + 5 <= maxTokens) {
        result.push('  // ... (truncated)');
        tokenCount += 5;
      }
    }

    return {
      ...entry,
      content: result.join('\n'),
      tokenCount,
    };
  }

  private trimConversation(entry: ContextEntry, maxTokens: number): ContextEntry {
    const messages = entry.content.split('\n---\n');
    const recentMessages = messages.slice(-5);
    let content = recentMessages.join('\n---\n');
    let tokenCount = this.tokenCounter.estimate(content);

    while (tokenCount > maxTokens && recentMessages.length > 1) {
      recentMessages.shift();
      content = recentMessages.join('\n---\n');
      tokenCount = this.tokenCounter.estimate(content);
    }

    return { ...entry, content, tokenCount };
  }

  private trimStructure(entry: ContextEntry, maxTokens: number): ContextEntry {
    const lines = entry.content.split('\n');
    const result: string[] = [];
    let tokenCount = 0;

    for (const line of lines) {
      const depth = (line.match(/\s/g) || []).length;
      if (depth <= 2) {
        const lineTokens = this.tokenCounter.estimate(line);
        if (tokenCount + lineTokens <= maxTokens) {
          result.push(line);
          tokenCount += lineTokens;
        }
      }
    }

    return {
      ...entry,
      content: result.join('\n'),
      tokenCount,
    };
  }

  private trimByPriority(entry: ContextEntry, maxTokens: number): ContextEntry {
    const charBudget = maxTokens * 3.5;
    const content = entry.content.slice(0, charBudget);
    return {
      ...entry,
      content: content + '\n... (truncated)',
      tokenCount: this.tokenCounter.estimate(content),
    };
  }
}
```

### 任务4: Token 预算分配 (3天)

```typescript
export class TokenBudgetAllocator {
  constructor(
    private readonly tokenCounter: TokenCounter,
    private readonly config: TokenBudgetConfig = DEFAULT_BUDGET_CONFIG
  ) {}

  allocate(
    modelMaxTokens: number,
    entries: ContextEntry[]
  ): TokenBudget {
    const budget: TokenBudget = {
      systemPrompt: Math.floor(modelMaxTokens * this.config.systemPromptRatio),
      currentMessage: Math.floor(modelMaxTokens * this.config.currentMessageRatio),
      explicitReferences: Math.floor(modelMaxTokens * this.config.explicitReferenceRatio),
      recentConversation: Math.floor(modelMaxTokens * this.config.conversationRatio),
      codeContext: Math.floor(modelMaxTokens * this.config.codeContextRatio),
      outputReserve: Math.floor(modelMaxTokens * this.config.outputReserveRatio),
    };

    const actualSystemPrompt = this.sumTokensByType(entries, 'system-prompt');
    const actualCurrentMessage = this.sumTokensByType(entries, 'current-message');

    if (actualSystemPrompt > budget.systemPrompt) {
      this.redistribute(budget, 'systemPrompt', actualSystemPrompt - budget.systemPrompt);
    }
    budget.systemPrompt = Math.max(budget.systemPrompt, actualSystemPrompt);

    if (actualCurrentMessage > budget.currentMessage) {
      this.redistribute(budget, 'currentMessage', actualCurrentMessage - budget.currentMessage);
    }
    budget.currentMessage = Math.max(budget.currentMessage, actualCurrentMessage);

    return budget;
  }

  private sumTokensByType(entries: ContextEntry[], type: ContextType): number {
    return entries
      .filter(e => e.type === type)
      .reduce((sum, e) => sum + e.tokenCount, 0);
  }

  private redistribute(budget: TokenBudget, from: keyof TokenBudget, excess: number): void {
    const flexibleKeys: (keyof TokenBudget)[] = [
      'recentConversation',
      'codeContext',
      'explicitReferences',
    ];

    let remaining = excess;
    for (const key of flexibleKeys) {
      if (key === from) continue;
      const available = Math.floor(budget[key] * 0.3);
      const take = Math.min(available, remaining);
      budget[key] -= take;
      remaining -= take;
      if (remaining <= 0) break;
    }

    if (remaining > 0) {
      budget.outputReserve = Math.max(
        Math.floor(budget.outputReserve * 0.5),
        budget.outputReserve - remaining
      );
    }
  }
}
```

### 任务5: 上下文组装 (3天)

```typescript
export class ContextAssembler {
  private cache: MemoryCache<ContextEntry[]>;

  constructor(
    private readonly tokenCounter: TokenCounter,
    private readonly priorityCalculator: PriorityCalculator,
    private readonly truncationEngine: TruncationEngine,
    private readonly budgetAllocator: TokenBudgetAllocator,
    private readonly logger: Logger
  ) {
    this.cache = new MemoryCache<ContextEntry[]>({ maxSize: 100, ttlMs: 60000 });
  }

  assemble(
    entries: ContextEntry[],
    modelMaxTokens: number,
    context: PriorityContext
  ): ContextWindow {
    const budget = this.budgetAllocator.allocate(modelMaxTokens, entries);
    const sorted = this.priorityCalculator.sort(entries, context);
    const maxInputTokens = modelMaxTokens - budget.outputReserve;

    const { entries: finalEntries, log } = this.truncationEngine.truncate(
      sorted,
      maxInputTokens,
      context
    );

    const totalTokens = finalEntries.reduce((sum, e) => sum + e.tokenCount, 0);

    if (log.length > 0) {
      this.logger.info('Context truncated', {
        originalEntries: entries.length,
        finalEntries: finalEntries.length,
        truncatedCount: log.length,
        totalTokens,
        maxTokens: maxInputTokens,
      });
    }

    return {
      entries: finalEntries,
      totalTokens,
      maxTokens: modelMaxTokens,
      truncationLog: log,
    };
  }

  toMessages(window: ContextWindow): ModelMessage[] {
    const messages: ModelMessage[] = [];

    const systemEntries = window.entries.filter(e => e.type === 'system-prompt');
    if (systemEntries.length > 0) {
      messages.push({
        role: 'system',
        content: systemEntries.map(e => e.content).join('\n\n'),
      });
    }

    const conversationEntries = window.entries.filter(e =>
      e.type === 'recent-conversation'
    );
    for (const entry of conversationEntries) {
      const parsed = this.parseConversationEntry(entry);
      if (parsed) messages.push(parsed);
    }

    const contextEntries = window.entries.filter(e =>
      e.type !== 'system-prompt' && e.type !== 'recent-conversation' && e.type !== 'current-message'
    );
    if (contextEntries.length > 0) {
      messages.push({
        role: 'user',
        content: this.formatContextBlock(contextEntries),
      });
    }

    const currentMessage = window.entries.find(e => e.type === 'current-message');
    if (currentMessage) {
      messages.push({
        role: 'user',
        content: currentMessage.content,
      });
    }

    return messages;
  }

  private parseConversationEntry(entry: ContextEntry): ModelMessage | null {
    if (entry.metadata.role === 'user' || entry.metadata.role === 'assistant') {
      return { role: entry.metadata.role, content: entry.content };
    }
    return null;
  }

  private formatContextBlock(entries: ContextEntry[]): string {
    return entries
      .map(e => `## ${e.source}\n${e.content}`)
      .join('\n\n');
  }
}
```

## 验收标准

- [ ] 可正确计算文本的 Token 数量（与模型分词器误差 < 5%）
- [ ] Token 预算分配各项比例符合配置
- [ ] 上下文条目按优先级正确排序
- [ ] 超出 Token 预算时自动截断低优先级条目
- [ ] 截断日志记录完整
- [ ] System Prompt 和当前用户消息不被截断
- [ ] @引用内容优先级高于自动收集内容
- [ ] 代码裁剪保留函数签名，移除函数体
- [ ] Token 计算耗时 < 10ms / 1K Token
- [ ] 上下文构建耗时 < 100ms（不含文件读取）
- [ ] 优先级排序耗时 < 20ms（100 条目）
- [ ] Token 计算器初始化失败时降级为近似估算
- [ ] 文件读取失败时跳过该上下文条目，不阻塞构建
