# 代码编辑器集成实施计划

## 模块概述

**包名**: `@ai-digital-life/editor`

**优先级**: P0 - AI 数字生命的核心交互界面

**目标**: 将 Monaco Editor 嵌入 AI 数字生命，提供专业级代码编辑体验，并实现编辑器与对话系统的深度联动，通过行内建议、diff 预览、编辑器-对话联动等特色功能，将 AI 能力无缝融入编码工作流。

## 设计原则

- **编辑器即界面**: Monaco Editor 是 AI 数字生命的核心交互界面之一
- **联动优先**: 编辑器与对话系统双向联动，不是两个独立模块
- **渐进增强**: 先实现基础编辑和 diff 预览，再逐步添加行内建议等高级功能
- **性能敏感**: 编辑器操作延迟必须 < 50ms，不影响编码体验
- **安全边界**: 编辑器内容变更通过受控通道，不直接操作文件系统

## Phase 1 职责边界

### 必须交付

- Monaco Editor 嵌入与基础编辑功能
- 语法高亮（TypeScript/JavaScript/Python）
- 多文件标签页管理
- diff 预览（inline + side-by-side）
- 编辑器-对话基础联动（选中代码发送至对话）

### 只做骨架

- 行内建议（Ghost Text）
- AI 智能补全
- 行内对话（Ctrl+I）
- 代码诊断集成
- 多光标 AI 编辑

```typescript
export class EditorManager {
  private editor: monaco.editor.IStandaloneCodeEditor | null = null;
  private diffEditor: monaco.editor.IStandaloneDiffEditor | null = null;

  constructor(
    private readonly container: HTMLElement,
    private readonly logger: Logger
  ) {}

  initialize(options?: EditorInitOptions): void {
    this.setupMonacoEnvironment();

    this.editor = monaco.editor.create(this.container, {
      value: '',
      language: 'typescript',
      theme: 'ai-digital-life-dark',
      fontSize: 14,
      lineHeight: 20,
      minimap: { enabled: true },
      scrollBeyondLastLine: false,
      automaticLayout: true,
      tabSize: 2,
      wordWrap: 'on',
      formatOnPaste: true,
      ...options,
    });

    this.registerCommands();
    this.registerActions();
  }

  dispose(): void {
    this.editor?.dispose();
    this.diffEditor?.dispose();
  }

  setContent(content: string, language?: string): void {
    if (!this.editor) return;
    const model = this.editor.getModel();
    if (model) {
      model.setValue(content);
      if (language) {
        monaco.editor.setModelLanguage(model, language);
      }
    }
  }

  getContent(): string {
    return this.editor?.getModel()?.getValue() || '';
  }

  setLanguage(language: string): void {
    const model = this.editor?.getModel();
    if (model) {
      monaco.editor.setModelLanguage(model, language);
    }
  }

  getSelection(): Selection | null {
    const selection = this.editor?.getSelection();
    if (!selection) return null;
    return {
      startLineNumber: selection.startLineNumber,
      startColumn: selection.startColumn,
      endLineNumber: selection.endLineNumber,
      endColumn: selection.endColumn,
    };
  }

  getSelectedText(): string {
    const selection = this.editor?.getSelection();
    if (!selection || selection.isEmpty()) return '';
    const model = this.editor?.getModel();
    return model?.getValueInRange(selection) || '';
  }

  revealLine(lineNumber: number): void {
    this.editor?.revealLineInCenter(lineNumber);
  }

  setCursorPosition(position: Position): void {
    this.editor?.setPosition(position);
    this.editor?.focus();
  }

  private setupMonacoEnvironment(): void {
    (self as any).MonacoEnvironment = {
      getWorkerUrl(moduleId: string, label: string) {
        if (label === 'json') return '/workers/json.worker.js';
        if (label === 'css' || label === 'scss' || label === 'less') return '/workers/css.worker.js';
        if (label === 'html' || label === 'handlebars' || label === 'razor') return '/workers/html.worker.js';
        if (label === 'typescript' || label === 'javascript') return '/workers/ts.worker.js';
        return '/workers/editor.worker.js';
      },
    };
  }

  private registerCommands(): void {
    this.editor?.addAction({
      id: 'ai-send-to-chat',
      label: '发送至对话',
      keybindings: [monaco.KeyMod.CtrlCmd | monaco.KeyCode.KeyI],
      run: (editor) => {
        const selection = editor.getSelection();
        if (selection && !selection.isEmpty()) {
          const content = editor.getModel()?.getValueInRange(selection) || '';
          this.emitAction({
            type: 'send-to-chat',
            content,
            filePath: this.getCurrentFilePath(),
            selection: {
              startLineNumber: selection.startLineNumber,
              startColumn: selection.startColumn,
              endLineNumber: selection.endLineNumber,
              endColumn: selection.endColumn,
            },
          });
        }
      },
    });
  }

  private registerActions(): void {
    this.editor?.addAction({
      id: 'ai-accept-suggestion',
      label: '接受 AI 建议',
      keybindings: [monaco.KeyCode.Tab],
      run: () => {
        this.acceptSuggestion();
      },
    });

    this.editor?.addAction({
      id: 'ai-reject-suggestion',
      label: '拒绝 AI 建议',
      keybindings: [monaco.KeyCode.Escape],
      run: () => {
        this.rejectSuggestion();
      },
    });
  }

  private getCurrentFilePath(): string {
    return '';
  }

  private emitAction(action: EditorAction): void {
    // 通过事件系统发出
  }

  private acceptSuggestion(): void {}

  private rejectSuggestion(): void {}
}
```

```typescript
export class TabManager {
  private tabs: Map<string, EditorTab> = new Map();
  private groups: EditorGroup[] = [];
  private activeTabId: string | null = null;

  constructor(
    private readonly fsOps: FileService,
    private readonly logger: Logger
  ) {}

  async openFile(filePath: string, options?: { preview?: boolean }): Promise<EditorTab> {
    const existing = this.findTabByPath(filePath);
    if (existing) {
      this.activateTab(existing.id);
      return existing;
    }

    const contentResult = await this.fsOps.readFile(filePath);
    if (Result.isErr(contentResult)) throw contentResult.error;

    const language = this.detectLanguage(filePath);
    const tab: EditorTab = {
      id: this.generateId(),
      filePath,
      fileName: path.basename(filePath),
      content: contentResult.value,
      language,
      isDirty: false,
      isPreview: options?.preview ?? false,
    };

    this.tabs.set(tab.id, tab);
    this.addToGroup(tab.id);
    this.activateTab(tab.id);

    return tab;
  }

  closeTab(tabId: string): EditorTab | null {
    const tab = this.tabs.get(tabId);
    if (!tab) return null;

    if (tab.isDirty) {
      this.logger.warn('Closing dirty tab', { filePath: tab.filePath });
    }

    this.tabs.delete(tabId);
    this.removeFromGroup(tabId);

    if (this.activeTabId === tabId) {
      this.activateNearestTab();
    }

    return tab;
  }

  async saveTab(tabId: string): Promise<Result<void>> {
    const tab = this.tabs.get(tabId);
    if (!tab) return Result.err(new Error('Tab not found'));

    const result = await this.fsOps.writeFile(tab.filePath, tab.content, { overwrite: true });
    if (Result.isOk(result)) {
      tab.isDirty = false;
    }
    return result;
  }

  updateTabContent(tabId: string, content: string): void {
    const tab = this.tabs.get(tabId);
    if (!tab) return;

    const originalContent = tab.content;
    tab.content = content;
    tab.isDirty = content !== originalContent;
  }

  activateTab(tabId: string): void {
    if (this.tabs.has(tabId)) {
      this.activeTabId = tabId;
    }
  }

  getActiveTab(): EditorTab | null {
    if (!this.activeTabId) return null;
    return this.tabs.get(this.activeTabId) || null;
  }

  getAllTabs(): EditorTab[] {
    return Array.from(this.tabs.values());
  }

  getDirtyTabs(): EditorTab[] {
    return Array.from(this.tabs.values()).filter(t => t.isDirty);
  }

  private findTabByPath(filePath: string): EditorTab | undefined {
    for (const tab of this.tabs.values()) {
      if (tab.filePath === filePath) return tab;
    }
    return undefined;
  }

  private detectLanguage(filePath: string): string {
    const ext = path.extname(filePath).toLowerCase();
    const languageMap: Record<string, string> = {
      '.ts': 'typescript',
      '.tsx': 'typescript',
      '.js': 'javascript',
      '.jsx': 'javascript',
      '.py': 'python',
      '.json': 'json',
      '.css': 'css',
      '.scss': 'scss',
      '.html': 'html',
      '.md': 'markdown',
      '.yaml': 'yaml',
      '.yml': 'yaml',
    };
    return languageMap[ext] || 'plaintext';
  }

  private addToGroup(tabId: string): void {
    if (this.groups.length === 0) {
      this.groups.push({
        id: 'group-1',
        tabIds: [tabId],
        activeTabId: tabId,
      });
    } else {
      this.groups[0].tabIds.push(tabId);
    }
  }

  private removeFromGroup(tabId: string): void {
    for (const group of this.groups) {
      const idx = group.tabIds.indexOf(tabId);
      if (idx >= 0) {
        group.tabIds.splice(idx, 1);
        break;
      }
    }
  }

  private activateNearestTab(): void {
    const group = this.groups[0];
    if (group && group.tabIds.length > 0) {
      this.activeTabId = group.tabIds[group.tabIds.length - 1];
    } else {
      this.activeTabId = null;
    }
  }

  private generateId(): string {
    return `tab-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`;
  }
}
```

### 任务3: diff 预览 (4天)

```typescript
export class DiffComputer {
  computeDiff(
    originalContent: string,
    modifiedContent: string,
    filePath: string
  ): DiffPreview {
    const hunks = this.computeHunks(originalContent, modifiedContent);

    return {
      id: this.generateId(),
      filePath,
      originalContent,
      modifiedContent,
      hunks,
      viewMode: 'inline',
    };
  }

  private computeHunks(original: string, modified: string): DiffHunk[] {
    const originalLines = original.split('\n');
    const modifiedLines = modified.split('\n');
    const hunks: DiffHunk[] = [];

    const diff = this.myersDiff(originalLines, modifiedLines);

    let currentHunk: DiffHunk | null = null;
    let originalLine = 1;
    let modifiedLine = 1;

    for (const change of diff) {
      switch (change.type) {
        case 'equal':
          if (currentHunk) {
            hunks.push(currentHunk);
            currentHunk = null;
          }
          originalLine++;
          modifiedLine++;
          break;

        case 'insert':
          if (!currentHunk) {
            currentHunk = {
              id: `hunk-${hunks.length}`,
              startLineOriginal: originalLine,
              endLineOriginal: originalLine - 1,
              startLineModified: modifiedLine,
              endLineModified: modifiedLine,
              type: 'add',
              status: 'pending',
            };
          }
          currentHunk.endLineModified = modifiedLine;
          modifiedLine++;
          break;

        case 'delete':
          if (!currentHunk) {
            currentHunk = {
              id: `hunk-${hunks.length}`,
              startLineOriginal: originalLine,
              endLineOriginal: originalLine,
              startLineModified: modifiedLine,
              endLineModified: modifiedLine - 1,
              type: 'delete',
              status: 'pending',
            };
          }
          currentHunk.endLineOriginal = originalLine;
          originalLine++;
          break;
      }
    }

    if (currentHunk) {
      hunks.push(currentHunk);
    }

    return hunks;
  }

  private myersDiff(
    a: string[],
    b: string[]
  ): Array<{ type: 'equal' | 'insert' | 'delete'; value: string }> {
    const result: Array<{ type: 'equal' | 'insert' | 'delete'; value: string }> = [];
    let i = 0;
    let j = 0;

    while (i < a.length || j < b.length) {
      if (i < a.length && j < b.length && a[i] === b[j]) {
        result.push({ type: 'equal', value: a[i] });
        i++;
        j++;
      } else if (j < b.length && (i >= a.length || a[i] !== b[j])) {
        if (i < a.length && a[i] !== b[j]) {
          result.push({ type: 'delete', value: a[i] });
          i++;
        }
        result.push({ type: 'insert', value: b[j] });
        j++;
      } else if (i < a.length) {
        result.push({ type: 'delete', value: a[i] });
        i++;
      }
    }

    return result;
  }

  private generateId(): string {
    return `diff-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`;
  }
}

export class HunkManager {
  acceptHunk(preview: DiffPreview, hunkId: string): DiffPreview {
    return {
      ...preview,
      hunks: preview.hunks.map(h =>
        h.id === hunkId ? { ...h, status: 'accepted' as const } : h
      ),
    };
  }

  rejectHunk(preview: DiffPreview, hunkId: string): DiffPreview {
    return {
      ...preview,
      hunks: preview.hunks.map(h =>
        h.id === hunkId ? { ...h, status: 'rejected' as const } : h
      ),
    };
  }

  acceptAll(preview: DiffPreview): DiffPreview {
    return {
      ...preview,
      hunks: preview.hunks.map(h => ({ ...h, status: 'accepted' as const })),
    };
  }

  rejectAll(preview: DiffPreview): DiffPreview {
    return {
      ...preview,
      hunks: preview.hunks.map(h => ({ ...h, status: 'rejected' as const })),
    };
  }

  applyAccepted(preview: DiffPreview): string {
    const originalLines = preview.originalContent.split('\n');
    const modifiedLines = preview.modifiedContent.split('\n');
    const result: string[] = [];

    let originalIdx = 0;
    let modifiedIdx = 0;

    for (const hunk of preview.hunks) {
      while (originalIdx < hunk.startLineOriginal - 1) {
        result.push(originalLines[originalIdx]);
        originalIdx++;
        modifiedIdx++;
      }

      if (hunk.status === 'accepted') {
        while (modifiedIdx < hunk.endLineModified) {
          result.push(modifiedLines[modifiedIdx]);
          modifiedIdx++;
        }
        originalIdx = hunk.endLineOriginal;
      } else {
        while (originalIdx < hunk.endLineOriginal) {
          result.push(originalLines[originalIdx]);
          originalIdx++;
        }
        modifiedIdx = hunk.endLineModified;
      }
    }

    while (originalIdx < originalLines.length) {
      result.push(originalLines[originalIdx]);
      originalIdx++;
    }

    return result.join('\n');
  }
}
```

```typescript
export class ChatIntegration {
  constructor(
    private readonly tabManager: TabManager,
    private readonly messageService: MessageService,
    private readonly diffComputer: DiffComputer,
    private readonly hunkManager: HunkManager,
    private readonly fsOps: FileService,
    private readonly logger: Logger
  ) {}

  async sendSelectionToChat(): Promise<void> {
    const tab = this.tabManager.getActiveTab();
    if (!tab) return;

    const selection = this.getCurrentSelection();
    if (!selection) return;

    const content = this.getSelectedText();
    if (!content) return;

    const message = `请看以下代码（来自 ${tab.filePath}）：\n\`\`\`${tab.language}\n${content}\n\`\`\``;

    await this.messageService.sendMessage(
      this.getCurrentSessionId(),
      message,
      () => {}
    );
  }

  async applyDiffToEditor(
    filePath: string,
    modifiedContent: string
  ): Promise<DiffPreview> {
    const tab = this.tabManager.getAllTabs().find(t => t.filePath === filePath);
    const originalContent = tab?.content || '';

    const preview = this.diffComputer.computeDiff(
      originalContent,
      modifiedContent,
      filePath
    );

    return preview;
  }

  async confirmAndApplyDiff(preview: DiffPreview): Promise<Result<void>> {
    const appliedContent = this.hunkManager.applyAccepted(preview);
    const acceptedHunks = preview.hunks.filter(h => h.status === 'accepted');

    if (acceptedHunks.length === 0) {
      return Result.ok(undefined as void);
    }

    const writeResult = await this.fsOps.writeFile(
      preview.filePath,
      appliedContent,
      { overwrite: true }
    );

    if (Result.isErr(writeResult)) return writeResult as Result<void>;

    const tab = this.tabManager.getAllTabs().find(t => t.filePath === preview.filePath);
    if (tab) {
      this.tabManager.updateTabContent(tab.id, appliedContent);
    }

    this.logger.info('Diff applied', {
      filePath: preview.filePath,
      acceptedHunks: acceptedHunks.length,
      totalHunks: preview.hunks.length,
    });

    return Result.ok(undefined as void);
  }

  private getCurrentSelection(): Selection | null {
    return null;
  }

  private getSelectedText(): string {
    return '';
  }

  private getCurrentSessionId(): string {
    return '';
  }
}
```

## 依赖关系

**内部依赖**:

| 模块 | 依赖方式 | 说明 |
|------|----------|------|
| `@ai-digital-life/kernel` | 强依赖 | Result 类型、常量 |
| `@ai-digital-life/fs-ops` | 强依赖 | 文件内容加载、保存、变更管理 |
| `@ai-digital-life/conversation` | 强依赖 | 编辑器-对话联动 |
| `@ai-digital-life/config` | 中依赖 | 编辑器配置 |
| `@ai-digital-life/events` | 中依赖 | 编辑器事件 |
| `@ai-digital-life/logger` | 中依赖 | 编辑器日志 |

**被依赖关系**:

| 上游模块 | 依赖方式 | 说明 |
|----------|----------|------|
