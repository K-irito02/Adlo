# 对话交互引擎实施计划

## 模块概述

**包名**: `@ai-digital-life/conversation`

**优先级**: P0 - 用户与 AI 数字生命的核心交互层

**目标**: 管理多轮对话生命周期、渲染流式输出、识别用户意图、处理 @引用和斜杠命令，将原始模型响应转化为结构化、可交互的对话内容。

## 设计原则

- **流式优先**: 首 Token 到达即开始渲染，不等待完整响应
- **上下文连贯**: 多轮对话上下文正确传递，模型能引用前文
- **交互丰富**: @引用、斜杠命令降低用户操作成本
- **持久可靠**: 对话历史自动保存，重启后可恢复
- **可扩展**: 斜杠命令和引用类型支持注册扩展

## Phase 1 职责边界

### 必须交付

- 单轮对话 + 流式渲染
- 多轮对话 + 上下文传递
- 对话历史持久化与恢复
- @file 引用解析
- 基础斜杠命令（/help、/clear、/model、/run）
- 意图识别（规则匹配模式）

### 只做骨架

- @symbol、@url、@git 等高级引用
- 对话分支

```typescript
export class SessionManager {
  private sessions: Map<string, ChatSession> = new Map();
  private activeSessionId: string | null = null;

  constructor(
    private readonly store: SessionStore,
    private readonly logger: Logger
  ) {}

  async createSession(workspaceId: string, options?: { modelId?: string }): Promise<ChatSession> {
    const session: ChatSession = {
      id: this.generateId(),
      workspaceId,
      title: '新对话',
      modelId: options?.modelId,
      messages: [],
      createdAt: Date.now(),
      updatedAt: Date.now(),
      metadata: {
        totalMessages: 0,
        totalTokens: 0,
        lastMessagePreview: '',
      },
    };

    this.sessions.set(session.id, session);
    await this.store.save(session);
    return session;
  }

  async getSession(id: string): Promise<ChatSession | undefined> {
    if (this.sessions.has(id)) {
      return this.sessions.get(id);
    }
    const session = await this.store.load(id);
    if (session) {
      this.sessions.set(id, session);
    }
    return session;
  }

  setActiveSession(id: string): void {
    this.activeSessionId = id;
  }

  getActiveSession(): ChatSession | undefined {
    if (!this.activeSessionId) return undefined;
    return this.sessions.get(this.activeSessionId);
  }

  async listSessions(workspaceId: string): Promise<ChatSession[]> {
    const all = await this.store.list(workspaceId);
    return all.sort((a, b) => b.updatedAt - a.updatedAt);
  }

  async deleteSession(id: string): Promise<void> {
    this.sessions.delete(id);
    await this.store.delete(id);
    if (this.activeSessionId === id) {
      this.activeSessionId = null;
    }
  }

  async updateSession(id: string, updates: Partial<ChatSession>): Promise<void> {
    const session = this.sessions.get(id);
    if (!session) return;

    Object.assign(session, updates, { updatedAt: Date.now() });
    await this.store.save(session);
  }

  private generateId(): string {
    return `session-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`;
  }
}

### 任务2: 消息服务与流式处理 (4天)

```typescript
export class MessageService {
  constructor(
    private readonly sessionManager: SessionManager,
    private readonly modelRouter: ModelRouter,
    private readonly contextAssembler: ContextAssembler,
    private readonly promptAssembler: PromptAssembler,
    private readonly logger: Logger
  ) {}

  async sendMessage(
    sessionId: string,
    content: string,
    onChunk: (chunk: StreamChunk) => void
  ): Promise<ChatMessage> {
    const session = this.sessionManager.getActiveSession();
    if (!session) throw new SessionNotFoundError(sessionId);

    const userMessage = this.createUserMessage(sessionId, content);
    session.messages.push(userMessage);

    const context = this.buildContext(session, content);
    const assembledPrompt = await this.promptAssembler.assemble('chat', context.slotValues);
    const contextWindow = this.contextAssembler.assemble(
      this.buildContextEntries(session, assembledPrompt, content),
      context.modelMaxTokens,
      context.priorityContext
    );

    const messages = this.contextAssembler.toMessages(contextWindow);

    const assistantMessage = this.createAssistantMessage(sessionId);
    session.messages.push(assistantMessage);

    try {
      const stream = this.modelRouter.chatStream({
        messages,
        model: session.modelId,
        stream: true,
        metadata: { sessionId, workspaceId: session.workspaceId },
      });

      let fullContent = '';
      for await (const chunk of stream) {
        if (chunk.delta.content) {
          fullContent += chunk.delta.content;
          assistantMessage.content = fullContent;
          assistantMessage.status = 'streaming';
          onChunk(chunk);
        }
      }

      assistantMessage.content = fullContent;
      assistantMessage.status = 'completed';
      assistantMessage.tokenUsage = this.extractUsage(stream);
    } catch (error) {
      assistantMessage.status = 'error';
      assistantMessage.content = `Error: ${(error as Error).message}`;
      this.logger.error('Stream error', { sessionId, error });
    }

    await this.sessionManager.updateSession(sessionId, {
      messages: session.messages,
      metadata: this.updateMetadata(session.metadata, userMessage, assistantMessage),
    });

    return assistantMessage;
  }

  cancelStream(sessionId: string): void {
    this.modelRouter.abortStream(sessionId);
  }

  private createUserMessage(sessionId: string, content: string): ChatMessage {
    return {
      id: `msg-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`,
      sessionId,
      role: 'user',
      content,
      status: 'completed',
      createdAt: Date.now(),
      updatedAt: Date.now(),
    };
  }

  private createAssistantMessage(sessionId: string): ChatMessage {
    return {
      id: `msg-${Date.now()}-${Math.random().toString(36).slice(2, 6)}`,
      sessionId,
      role: 'assistant',
      content: '',
      status: 'pending',
      createdAt: Date.now(),
      updatedAt: Date.now(),
    };
  }

  private updateMetadata(
    metadata: SessionMetadata,
    userMessage: ChatMessage,
    assistantMessage: ChatMessage
  ): SessionMetadata {
    return {
      totalMessages: metadata.totalMessages + 2,
      totalTokens: metadata.totalTokens + (assistantMessage.tokenUsage?.totalTokens || 0),
      lastMessagePreview: assistantMessage.content.slice(0, 100),
    };
  }
}

export class IntentRecognizer {
  private rules: IntentRule[];

  constructor() {
    this.rules = this.buildDefaultRules();
  }

  recognize(input: string): UserIntent {
    const trimmed = input.trim();

    if (trimmed.startsWith('/')) {
      return 'command-execution';
    }

    for (const rule of this.rules) {
      if (rule.pattern.test(trimmed)) {
        return rule.intent;
      }
    }

    return 'chat';
  }

  private buildDefaultRules(): IntentRule[] {
    return [
      { pattern: /^(写|实现|创建|生成|添加)\s.+/, intent: 'code-generation' },
      { pattern: /^(修改|重构|优化|修复|更新)\s.+/, intent: 'code-modification' },
      { pattern: /^(解释|说明|分析|这段代码|这个函数)/, intent: 'code-explanation' },
      { pattern: /^(运行|执行|跑一下)\s.+/, intent: 'command-execution' },
      { pattern: /^(如何|怎么|什么是|为什么|能不能)/, intent: 'question' },
      { pattern: /^(write|implement|create|generate|add)\s/i, intent: 'code-generation' },
      { pattern: /^(modify|refactor|optimize|fix|update)\s/i, intent: 'code-modification' },
      { pattern: /^(explain|describe|analyze|what does)\s/i, intent: 'code-explanation' },
      { pattern: /^(run|execute)\s/i, intent: 'command-execution' },
      { pattern: /^(how|what|why|can you)\s/i, intent: 'question' },
    ];
  }
}

export interface IntentRule {
  pattern: RegExp;
  intent: UserIntent;
}

### 任务4: @引用解析 (3天)

```typescript
export class ReferenceParser {
  private resolvers: Map<string, ReferenceResolver>;

  constructor(
    private readonly fileResolver: FileReferenceResolver,
    private readonly terminalResolver: TerminalReferenceResolver
  ) {
    this.resolvers = new Map([
      ['file', fileResolver],
      ['terminal', terminalResolver],
    ]);
  }

  parse(input: string): ParsedReference[] {
    const references: ParsedReference[] = [];
    const pattern = /@(\w+):([^\s]+)/g;
    let match;

    while ((match = pattern.exec(input)) !== null) {
      references.push({
        type: match[1],
        target: match[2],
        raw: match[0],
        startIndex: match.index,
        endIndex: match.index + match[0].length,
      });
    }

    return references;
  }

  async resolve(references: ParsedReference[]): Promise<MessageReference[]> {
    const resolved: MessageReference[] = [];

    for (const ref of references) {
      const resolver = this.resolvers.get(ref.type);
      if (resolver) {
        try {
          const content = await resolver.resolve(ref.target);
          resolved.push({
            type: ref.type as MessageReference['type'],
            target: ref.target,
            content,
          });
        } catch (error) {
          resolved.push({
            type: ref.type as MessageReference['type'],
            target: ref.target,
            content: `[Error resolving ${ref.raw}: ${(error as Error).message}]`,
          });
        }
      }
    }

    return resolved;
  }

  stripReferences(input: string, references: ParsedReference[]): string {
    let result = input;
    for (const ref of [...references].sort((a, b) => b.startIndex - a.startIndex)) {
      result = result.slice(0, ref.startIndex) + result.slice(ref.endIndex);
    }
    return result.trim();
  }
}

export interface ParsedReference {
  type: string;
  target: string;
  raw: string;
  startIndex: number;
  endIndex: number;
}

export interface ReferenceResolver {
  resolve(target: string): Promise<string>;
}

export class FileReferenceResolver implements ReferenceResolver {
  constructor(private readonly fsOps: FileService) {}

  async resolve(target: string): Promise<string> {
    const result = await this.fsOps.readFile(target);
    if (Result.isErr(result)) throw result.error;
    return result.value;
  }
}

export class CommandRegistry {
  private commands: Map<string, SlashCommand> = new Map();

  constructor() {
    this.registerBuiltins();
  }

  register(command: SlashCommand): void {
    this.commands.set(command.name, command);
  }

  unregister(name: string): void {
    this.commands.delete(name);
  }

  get(name: string): SlashCommand | undefined {
    return this.commands.get(name);
  }

  list(): SlashCommand[] {
    return Array.from(this.commands.values());
  }

  parse(input: string): ParsedCommand | null {
    if (!input.startsWith('/')) return null;

    const parts = input.slice(1).split(/\s+/);
    const name = parts[0];
    const args = parts.slice(1);

    return { name, args };
  }

  private registerBuiltins(): void {
    this.register({
      name: 'help',
      description: '显示可用命令列表',
      execute: async (_, context) => {
        const commands = this.list();
        const content = commands
          .map(c => `/${c.name} - ${c.description}`)
          .join('\n');
        return { content };
      },
    });

    this.register({
      name: 'clear',
      description: '清空当前对话',
      execute: async (_, context) => {
        return { content: '对话已清空', shouldSendToModel: false };
      },
    });

    this.register({
      name: 'model',
      description: '切换模型',
      parameters: [
        { name: 'model', description: '模型名称', required: true },
      ],
      execute: async (args, context) => {
        const modelId = args[0];
        return {
          content: `已切换到模型: ${modelId}`,
          shouldSendToModel: false,
        };
      },
    });

    this.register({
      name: 'run',
      description: '执行命令',
      parameters: [
        { name: 'command', description: '要执行的命令', required: true },
      ],
      execute: async (args, context) => {
        const command = args.join(' ');
        return {
          content: `执行命令: ${command}`,
          shouldSendToModel: false,
        };
      },
    });
  }
}

export interface ParsedCommand {
  name: string;
  args: string[];
}

```typescript
export class MarkdownRenderer {
  private codeBlockRenderers: Map<string, CodeBlockRenderer>;

  constructor() {
    this.codeBlockRenderers = new Map();
  }

  render(content: string): RenderedContent {
    const blocks = this.parseBlocks(content);
    return {
      blocks: blocks.map(block => this.renderBlock(block)),
      rawContent: content,
    };
  }

  private parseBlocks(content: string): ContentBlock[] {
    const blocks: ContentBlock[] = [];
    const lines = content.split('\n');
    let currentBlock: ContentBlock | null = null;
    let codeBlockLang = '';
    let codeBlockContent: string[] = [];

    for (const line of lines) {
      if (line.startsWith('```')) {
        if (currentBlock?.type === 'code') {
          blocks.push({
            type: 'code',
            language: codeBlockLang,
            content: codeBlockContent.join('\n'),
          });
          currentBlock = null;
          codeBlockContent = [];
        } else {
          if (currentBlock) blocks.push(currentBlock);
          codeBlockLang = line.slice(3).trim();
          currentBlock = { type: 'code', language: codeBlockLang, content: '' };
          codeBlockContent = [];
        }
        continue;
      }

      if (currentBlock?.type === 'code') {
        codeBlockContent.push(line);
        continue;
      }

      const blockType = this.detectBlockType(line);
      if (currentBlock && currentBlock.type !== blockType) {
        blocks.push(currentBlock);
        currentBlock = null;
      }

      if (!currentBlock) {
        currentBlock = { type: blockType, content: line };
      } else {
        currentBlock.content += '\n' + line;
      }
    }

    if (currentBlock) blocks.push(currentBlock);
    return blocks;
  }

  private detectBlockType(line: string): ContentBlock['type'] {
    if (line.startsWith('#')) return 'heading';
    if (line.startsWith('- ') || line.startsWith('* ')) return 'list';
    if (line.startsWith('> ')) return 'quote';
    if (line.startsWith('| ')) return 'table';
    return 'paragraph';
  }

  private renderBlock(block: ContentBlock): RenderedBlock {
    switch (block.type) {
      case 'code':
        return {
          type: 'code',
          language: block.language,
          html: this.renderCodeBlock(block.content, block.language),
          source: block.content,
        };
      case 'heading':
        return { type: 'heading', html: this.renderHeading(block.content) };
      default:
        return { type: block.type, html: this.renderInline(block.content) };
    }
  }

  private renderCodeBlock(code: string, language: string): string {
    return `<pre><code class="language-${language}">${this.escapeHtml(code)}</code></pre>`;
  }

  private renderHeading(content: string): string {
    const match = content.match(/^(#{1,6})\s+(.+)/);
    if (!match) return `<p>${content}</p>`;
    const level = match[1].length;
    return `<h${level}>${match[2]}</h${level}>`;
  }

  private renderInline(content: string): string {
    return content
      .replace(/\*\*(.+?)\*\*/g, '<strong>$1</strong>')
      .replace(/\*(.+?)\*/g, '<em>$1</em>')
      .replace(/`(.+?)`/g, '<code>$1</code>')
      .replace(/\[(.+?)\]\((.+?)\)/g, '<a href="$2">$1</a>');
  }

  private escapeHtml(text: string): string {
    return text
      .replace(/&/g, '&amp;')
      .replace(/</g, '&lt;')
      .replace(/>/g, '&gt;');
  }
}

export interface ContentBlock {
  type: 'paragraph' | 'heading' | 'list' | 'code' | 'quote' | 'table';
  language?: string;
  content: string;
}

export interface RenderedContent {
  blocks: RenderedBlock[];
  rawContent: string;
}

export interface RenderedBlock {
  type: string;
  html: string;
  language?: string;
  source?: string;
}

## 依赖关系

**内部依赖**:

| 模块 | 依赖方式 | 说明 |
|------|----------|------|
| `@ai-digital-life/kernel` | 强依赖 | Result 类型、常量 |
| `@ai-digital-life/model-gateway` | 强依赖 | 通过 ModelRouter 发送对话请求 |
| `@ai-digital-life/context` | 强依赖 | 协调上下文窗口分配 |
| `@ai-digital-life/prompt-engine` | 强依赖 | 获取系统提示词 |
| `@ai-digital-life/config` | 中依赖 | 对话配置 |
| `@ai-digital-life/storage` | 中依赖 | 对话历史持久化 |
| `@ai-digital-life/events` | 中依赖 | 对话事件发布 |
| `@ai-digital-life/logger` | 中依赖 | 对话日志 |

**被依赖关系**:

| 上游模块 | 依赖方式 | 说明 |
|----------|----------|------|
| `editor` | 强依赖 | 编辑器-对话联动 |
| `terminal` | 弱依赖 | 斜杠命令 /run 触发终端执行 |
