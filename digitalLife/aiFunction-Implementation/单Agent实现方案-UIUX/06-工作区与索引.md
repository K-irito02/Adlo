# 工作区与索引

## 目标

为后端的工作区管理和索引服务提供可视化展示，让用户了解索引状态和项目结构。

## 索引进度

### StatusBar 中的索引状态

- 索引进行中：显示「索引中…」 + 进度文字（如 128/356 文件）
- 索引完成：显示「已索引」 + 文件总数
- 索引失败：显示「索引异常」 + 点击查看错误

### 索引详情面板

在右侧面板文件视图顶部增加索引状态条：

- 最近索引时间
- 索引覆盖范围（文件数 / 排除数）
- 「重建索引」按钮（确认后触发全量重建）

## 仓库地图

仓库地图仍作为「检索/索引侧的结构化元数据」保留，但当前版本**默认不在界面直接展示**（避免与文件树重复、增加认知负担）。

### 当前呈现方式（默认）

- 仓库地图会在索引/检索快照生成时构建，用于后续模型消费与诊断。
- 相关信息通过**后台日志**输出（如：扫描文件数、top extensions、repo-map 条目数量、以及部分预览条目）。

### 如需恢复 UI 展示（未来可选）

- 可在文件面板中重新引入「仓库地图」视图（建议做成可折叠区块或独立 Tab，而不是默认常驻）。

### 展示内容

- 以树形结构展示项目的模块/目录概览
- 每个节点显示：目录名 + 文件数 + 主要语言标签
- 重要模块（如 src/、tests/、docs/）默认展开一级

### 交互

- 点击目录节点展开/折叠子项
- 点击文件节点打开编辑器
- 支持搜索过滤

### 与已有文件树的关系

- 仓库地图与文件树共用文件面板区域
- 若恢复 UI：建议通过面板内顶部的分段按钮切换：「文件树」/「仓库地图」，或默认折叠避免冗余

## Git 状态集成

在文件面板中为文件树增加 Git 状态展示：

- 修改文件名使用 `--color-warning` 文字色
- 新增文件名使用 `--color-success` 文字色
- 删除文件名使用 `--color-danger` 文字色 + 删除线
- 未跟踪文件名使用 `--text-muted` 文字色

### 底部 Git 摘要

文件面板底部显示一行 Git 摘要：

- 当前分支名
- 修改/新增/删除的文件数

## 工作区切换增强

左侧栏工作区列表增强：

- 当前工作区显示状态标签（已索引 / 索引中 / 未索引）
- 固定工作区支持拖拽排序（已实现）
- 「打开文件夹」按钮样式统一为 ghost 按钮

## 视觉规范

- 索引进度条使用 `--accent` 前景色 + `--bg-muted` 背景轨道
- 仓库地图节点使用 `--text-sm` 字号
- 语言标签使用 `--bg-muted` 背景 + `--radius-full` 圆角
- Git 状态色仅应用于文件名文字，不使用背景色
