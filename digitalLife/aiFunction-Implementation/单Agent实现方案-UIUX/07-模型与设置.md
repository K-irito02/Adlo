# 模型与设置

## 目标

为模型接入和应用配置提供清晰的管理界面。

## 模型管理

### 模型选择

在对话输入区域增加模型选择器：

- 位于输入框左下角，显示当前模型名称
- 点击弹出模型列表
- 每个模型项显示：模型名 + Provider 标签 + 状态指示（在线/离线/受限）
- 在线模型直接可选，离线模型置灰

### 模型健康面板

在右侧面板增加「模型」选项卡（作为 ToolSwitcher 选项）：

- 已配置 Provider 列表
- 每个 Provider 显示：名称 + 状态 + 最近调用延迟
- API Key 配置入口（输入时掩码显示，不在前端存储原文）
- 「刷新状态」按钮

### Token 用量

每次对话后在消息底部显示 Token 统计：

- 输入 Token 数 + 输出 Token 数
- 可折叠，默认仅显示总数
- 使用 `--text-muted` + `--text-xs` 字号

## 设置面板

### 入口

- TitleBar 中的齿轮图标（已有）
- 点击后右侧面板切换到设置视图

### 设置分组


| 分组    | 内容                        |
| ----- | ------------------------- |
| 通用    | 语言、主题模式（浅色/深色/跟随系统）       |
| 模型    | Provider 配置、默认模型、Token 预算 |
| Agent | 自动审批级别、最大步骤数、重试次数         |
| 工作区   | 默认排除规则、索引深度、Git 集成开关      |
| 快捷键   | 常用操作的键盘快捷键列表（只读展示）        |


### 设置项交互

- 开关类设置使用 Toggle 组件
- 选择类设置使用 Select 下拉
- 输入类设置使用 Input 组件 + 失焦保存
- 密钥类设置使用 Password Input + 「测试连接」按钮
- 所有设置变更通过 Tauri Command 持久化到后端

### 设置搜索

设置面板顶部提供搜索输入：

- 实时过滤匹配的设置项
- 匹配关键词在设置项名称中高亮

## 主题切换

- TitleBar 中保留现有的主题循环按钮（system → light → dark）
- 设置面板中提供三选一分段按钮

## 视觉规范

- 设置面板使用双列布局：左侧分组导航（固定宽 160px）+ 右侧内容区
- 分组导航使用 `--text-secondary` 默认色 + `--text-primary` 选中色
- 设置项间距使用 `--space-5`
- 描述文字使用 `--text-muted` + `--text-sm`
- 面板最大宽度 640px，居中显示
