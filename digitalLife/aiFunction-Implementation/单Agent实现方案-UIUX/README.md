# 单 Agent 工作流 — UI/UX 方案

## 定位

本目录为「单Agent实现方案」的前端补充，定义后端能力在界面层的呈现方式。

## 设计原则


| 原则     | 说明                                            |
| ------ | --------------------------------------------- |
| 极简     | 组件无多余装饰，以功能为导向                                |
| 双主题    | 仅深色（#141414 系）与浅色（#F8F8F8 系），不引入彩色主题          |
| 语义色有限  | 仅使用 accent、success、warning、danger 四种语义色，不堆砌颜色 |
| 信息密度适中 | 桌面端优先，保留足够留白，避免信息过载                           |
| 状态可见   | Agent 执行全程状态对用户透明                             |
| 渐进展示   | 默认展示核心信息，详情按需展开                               |


## 当前前端已有能力

已实现的布局与组件：

- 三栏布局：左侧栏（工作区/会话列表）、中间栏（对话）、右侧面板（编辑器/文件/变更/终端）
- TitleBar：应用标题、主题切换、语言切换、设置入口
- 对话系统：多轮消息、流式渲染、消息块（markdown / plan / tool-call / patch-summary / validation-result 等）
- 编辑器：Monaco 编辑器、diff 视图（inline/side-by-side）、诊断标注
- 变更面板：PatchSet 展示、hunk 接受/拒绝、应用/回滚
- 终端面板：命令输入、流式输出、停止控制
- 文件面板：文件树、搜索、outline
- 会话管理：创建/切换/归档/固定/排序/重命名
- 审批：任务中心快照、审批决策
- 模型健康：Provider 状态展示
