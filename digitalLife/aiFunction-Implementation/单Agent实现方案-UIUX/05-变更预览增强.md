# 变更预览增强

## 目标

在已有 PatchSet 展示和 hunk 接受/拒绝基础上，增加检查点管理、冲突处理和验证结果联动。

## 当前能力

已实现：PatchSet 文件列表、hunk 级接受/拒绝、diff 视图（inline/side-by-side）、应用/回滚、验证诊断标注。

## 检查点管理

### 检查点列表

在变更面板顶部增加检查点区域：

- 显示当前 PatchSet 的检查点信息（检查点 ID + 创建时间）
- 如有多个历史检查点，以时间线形式纵向排列
- 当前活跃检查点高亮

### 检查点操作

- 回滚到指定检查点：点击检查点右侧的回滚按钮
- 回滚前弹出确认提示（内联确认，非模态弹窗）
- 回滚后刷新 diff 和文件内容

### 视觉

- 检查点时间线使用竖线 + 圆点样式
- 当前检查点使用 `--accent` 圆点
- 历史检查点使用 `--text-muted` 圆点

## 冲突提示

当 Agent 生成的变更与磁盘文件发生冲突时：

- 在文件列表中对应文件行显示冲突图标
- 编辑器顶部显示黄色提示条：「文件已在外部修改」
- 提供操作：「重新加载」/「保留当前」/「查看差异」

### 已有能力复用

当前已有 `externalFileChange` 检测和提示条，增强为：

- 提示条中增加「查看差异」选项
- 差异以三方 diff 形式展示（原始 → 外部修改 / 原始 → Agent 修改）

## 验证结果联动

变更应用后验证结果的展示增强：

### 验证摘要条

在变更面板文件列表上方显示：

- 通过数 / 警告数 / 错误数（使用对应语义色 + 数字）
- 点击错误数跳转到第一个错误文件和行号

### 文件级标记

- 文件列表中每个文件行后追加诊断计数标签
- 有错误的文件使用 `--color-danger` 标签
- 有警告的文件使用 `--color-warning` 标签
- 无问题的文件不显示额外标签

## 批量操作

文件列表顶部增加批量按钮：

- 「全部接受」：接受所有 hunk
- 「全部拒绝」：拒绝所有 hunk
- 按钮仅在有 pending hunk 时可用

## 视觉规范

- 检查点区域高度固定 48px（折叠时），展开后按内容撑开
- 冲突提示条使用 `--warning-subtle` 背景 + `--color-warning` 文字
- 验证摘要条使用 `--surface-subtle` 背景
- 批量按钮使用 ghost 样式（无背景 + accent 文字）
