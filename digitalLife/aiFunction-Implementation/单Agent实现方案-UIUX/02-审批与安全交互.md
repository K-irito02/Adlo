# 审批与安全交互

## 目标

为高风险操作提供清晰的审批界面，让用户在做出决策前充分了解操作内容和风险。

## 审批卡片

当 Agent 请求审批时，在对话流中插入审批卡片：

### 结构

- 风险等级标签（低/中/高），使用对应语义色
- 操作描述（一到两行）
- 影响范围摘要（涉及的文件数/命令/路径）
- 操作详情（默认折叠，点击展开）
- 操作按钮：批准 / 拒绝

### 风险等级视觉


| 等级  | 标签色               | 边框                    |
| --- | ----------------- | --------------------- |
| 低   | `--color-info`    | `--border-subtle`     |
| 中   | `--color-warning` | `--color-warning` 左侧条 |
| 高   | `--color-danger`  | `--color-danger` 左侧条  |


### 交互

- 批准/拒绝按钮在审批卡片底部，水平排列
- 批准后卡片变为已批准状态（灰化操作按钮，显示决策和时间戳）
- 拒绝后同理，显示拒绝标记
- 卡片不可逆（已决策不可修改）

## 审批等待状态

Agent 等待审批时：

- 对话输入区显示提示文字「Agent 等待审批中」
- StatusBar 显示待审批数量
- 如用户切换会话后切回，审批卡片仍保留在对话位置

## 操作详情展开

点击「查看详情」后展开：

- 命令操作：显示完整命令、工作目录、参数
- 文件操作：显示目标路径、操作类型（写入/删除/移动）
- 终端操作：显示命令行、风险分类依据

## 审计入口

在右侧面板中增加「审计」入口：

- 作为 ToolSwitcher 的一个选项卡
- 展示最近操作的时间线列表
- 每条记录包含：时间戳、操作类型、操作摘要、风险等级、决策结果
- 支持按类型和风险等级筛选

## 视觉规范

- 审批卡片使用左侧色条表示风险等级（4px 宽）
- 批准按钮使用 `--accent` 背景
- 拒绝按钮使用透明背景 + `--color-danger` 文字
- 已决策卡片降低整体透明度至 0.7
