# 终端与命令

## 目标

增强终端面板的结构化展示和与审批系统的集成。

## 当前能力

已实现：命令输入（binary + args）、流式输出、停止控制。

## 需增强部分

### 结构化输出

终端输出区域增加基础的结构化解析：

- stdout 使用 `--text-primary` + 等宽字体
- stderr 使用 `--color-danger` 文字
- 退出码为 0 时，底部提示行使用 `--color-success`
- 退出码非 0 时，底部提示行使用 `--color-danger`
- 超长输出自动截断，显示「展开全部」按钮

### 审批集成

当命令被风险分级系统拦截时：

- 终端面板中显示「需要审批」提示卡片
- 卡片内容：命令摘要 + 风险等级 + 分类原因
- 「前往审批」按钮跳转到对话中对应的审批卡片
- 审批通过后自动开始执行

### 命令历史

终端面板底部增加历史记录下拉：

- 显示最近 20 条命令记录
- 每条包含：命令文本 + 退出码 + 执行时间
- 点击回填到输入框

### 多实例预留

当前为单终端实例，但 UI 结构预留多实例支持：

- 面板顶部预留 Tab 条位置
- 当前仅显示一个「终端 1」标签
- 未来可扩展为多个终端标签页

## 对话中的命令展示

Agent 执行终端命令时，在对话流中以消息块形式展示：

- 命令行（等宽字体，带 `$` 前缀）
- 输出摘要（最多 5 行，超出折叠）
- 退出码标签
- 「查看完整输出」按钮切换到终端面板

## 视觉规范

- 终端区域背景使用 `--bg-strong`
- 命令输入区域使用 `--bg-input` + `--border-default` 边框
- 历史记录下拉使用 `--bg-elevated` + `--shadow-md`
- 退出码标签使用 `--radius-full` 圆角胶囊样式
