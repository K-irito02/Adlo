# Agent 执行面板

## 目标

让用户在对话过程中清晰看到 Agent 当前执行状态、计划进度和每一步的工具调用结果。

## 位置

嵌入中间栏（对话区域），作为对话消息流中的结构化块出现，不独立开辟新面板。

## 计划卡片

当 Agent 生成执行计划后，在对话流中插入计划卡片：

- 显示目标摘要（一行文字）
- 列出步骤清单，每步包含：序号、标题、类型图标、风险标记
- 高风险步骤以 `--color-warning` 图标标记
- 当前执行步骤高亮，已完成步骤显示勾选标记
- 卡片底部显示整体进度（如 3/7）

### 交互

- 点击步骤可展开详情（预期输出、验证命令）
- 默认折叠详情，仅显示标题行

## 步骤执行块

每个步骤执行时在对话中显示一个行内状态块：

- 步骤名称 + 类型标签（analyze / search / read / edit / command / verify）
- 执行中：显示加载指示器（小圆点脉动，不使用旋转动画）
- 完成：显示结果摘要（一行）
- 失败：显示错误摘要 + 重试按钮

### 工具调用摘要

工具调用以紧凑行形式展示：

- 图标 + 工具名 + 输入摘要（截断显示）
- 点击展开完整输入/输出

## 执行总结卡片

Agent 完成后在对话中插入总结卡片：

- 状态标签：成功 / 失败 / 已回滚
- 关键操作列表（修改了哪些文件、执行了哪些命令）
- 如有验证结果，展示通过/失败数
- 如有回滚，说明回滚原因

## 状态指示

在 StatusBar（底部栏）中显示 Agent 当前状态：

- idle：无特殊显示
- planning / executing / verifying：显示状态文字 + 脉动指示器
- waiting-approval：显示审批等待提示 + 待审批数
- failed：显示错误摘要

## 视觉规范

- 卡片背景使用 `--bg-card`，边框使用 `--border-subtle`
- 步骤类型标签使用 `--bg-muted` 背景 + `--text-secondary` 文字
- 风险标记仅用图标 + `--color-warning`，不使用背景色块
- 所有卡片圆角使用 `--radius-lg`
