# 对话增强

## 目标

在已有对话系统基础上，增强引用、命令快捷入口和上下文管理能力。

## 引用系统

### `@` 引用触发

在输入框中键入 `@` 后弹出引用选择面板：

- `@file`：从文件树中选择文件路径
- `@symbol`：搜索当前工作区中的符号（函数/类/变量）
- `@terminal`：引用最近的终端输出
- `@selection`：引用编辑器中当前选中的代码段

### 引用面板

- 紧贴输入框上方弹出，宽度与输入框一致
- 显示搜索输入 + 分类列表
- 键盘导航：上下箭头选择，Enter 确认，Esc 关闭
- 选中后在输入框中显示为内联标签（带图标 + 名称）

### 引用在消息中的显示

- 用户消息中的引用显示为可点击链接
- 点击文件引用跳转到右侧编辑器打开对应文件
- 点击符号引用跳转到对应行

## 斜杠命令

在输入框中键入 `/` 后弹出命令列表：


| 命令         | 说明          |
| ---------- | ----------- |
| `/plan`    | 仅生成计划，不执行   |
| `/edit`    | 指定文件的修改任务   |
| `/fix`     | 修复当前诊断错误    |
| `/explain` | 解释选中代码或指定文件 |
| `/test`    | 为指定代码生成测试   |
| `/review`  | 审查最近的变更     |


- 命令列表与引用面板共享弹出位置和交互模式
- 选中命令后自动在输入框中插入，光标定位到参数位置

## 上下文摘要

在输入框上方显示当前上下文摘要条：

- 当前工作区名称
- 活跃文件数 / 引用的文件数
- 预估 Token 使用量（如：~2.4k tokens）
- 点击展开上下文详情列表，可手动移除条目

### 视觉

- 摘要条高度 28px，背景 `--surface-subtle`
- 使用 `--text-muted` 文字色
- 展开后的列表每项显示：类型图标 + 名称 + Token 占用 + 移除按钮

## 执行总结增强

Agent 完成任务后的总结卡片（已在 01 中描述）在对话中需支持：

- 摘要默认展示，详细步骤可展开
- 失败步骤直接展示错误原因
- 「查看变更」按钮切换右侧面板到变更视图

## 视觉规范

- 引用标签使用 `--bg-muted` 背景 + `--radius-full` 圆角 + `--text-sm` 字号
- 弹出面板使用 `--bg-elevated` + `--shadow-lg`
- 上下文摘要条使用 `--border-subtle` 下边框分隔
