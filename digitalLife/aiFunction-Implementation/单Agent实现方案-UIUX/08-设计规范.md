# 设计规范

## 目标

统一整个应用的视觉语言，确保所有新增组件与现有设计系统一致。

## 颜色使用原则

### 允许的颜色来源

- 背景：`--bg-*`、`--surface-*` 系列
- 文字：`--text-*` 系列
- 边框：`--border-*` 系列
- 强调：`--accent-*` 系列
- 语义：`--color-success`、`--color-warning`、`--color-danger`、`--color-info`

### 禁止

- 硬编码任何 HEX / RGB / HSL 颜色值
- 在语义场景外使用语义色（如用 `--color-danger` 做装饰）
- 引入上述系列之外的新颜色

### 语义色使用场景

| 颜色 | 用途 |
|------|------|
| `--color-success` | 操作成功、测试通过、新增文件 |
| `--color-warning` | 风险提示、冲突警告、修改文件 |
| `--color-danger` | 错误、失败、高风险、删除操作 |
| `--color-info` / `--accent` | 主操作、链接、低风险标记 |

## 组件交互状态

所有可交互组件必须提供完整的状态覆盖：

| 状态 | 视觉表现 |
|------|----------|
| default | 基础样式 |
| hover | 背景使用 `--bg-hover` 或 `--surface-hover` |
| focus-visible | 显示 `--focus-ring` 轮廓 |
| active | 背景使用 `--bg-active` 或 `--surface-active` |
| disabled | 透明度 0.5 + 禁止鼠标指针 |
| loading | 内容替换为加载指示器或叠加半透明遮罩 |

## 间距系统

基于 4px 网格（`--space-*` 系列）：

| 场景 | Token |
|------|-------|
| 组件内部 padding | `--space-2` ~ `--space-4` |
| 卡片内 padding | `--space-4` ~ `--space-5` |
| 列表项间距 | `--space-1` ~ `--space-2` |
| 区域间分隔 | `--space-6` ~ `--space-8` |
| 紧凑行（状态条、标签）| `--space-1` ~ `--space-2` |

## 排版层级

| 层级 | 字号 | 字重 | 色值 |
|------|------|------|------|
| 标题 | `--text-lg` | `--font-semibold` | `--text-primary` |
| 正文 | `--text-sm` | `--font-normal` | `--text-primary` |
| 辅助 | `--text-xs` | `--font-normal` | `--text-secondary` |
| 提示 | `--text-xs` | `--font-normal` | `--text-muted` |
| 代码 | `--text-sm` | `--font-normal` | `--text-primary` + `--font-mono` |

## 圆角规范

| 场景 | Token |
|------|-------|
| 按钮 | `--radius-md` |
| 卡片 | `--radius-lg` |
| 输入框 | `--radius-md` |
| 标签 / 胶囊 | `--radius-full` |
| 弹出面板 | `--radius-xl` |
| 对话消息气泡 | `--radius-lg` |

## 图标规范

- 图标使用 SVG 格式，继承 `currentColor`
- 图标尺寸遵循 `--icon-*` Token 系列
- 工具栏图标使用 `--icon-sm`（16px）
- 面板标题图标使用 `--icon-md`（20px）
- 空状态图标使用 `--icon-xl`（32px）

## 动效规范

- 展开/折叠：`--duration-200` + `--ease-default`
- 弹出/消失：`--duration-150` + `--ease-enter` / `--ease-exit`
- 主题切换：`--theme-transition`（已定义）
- 加载指示器：脉动动画（opacity 0.3 ↔ 1），周期 1.5s
- 禁止使用旋转动画（spinner）

## Tooltip

- 禁止使用原生 HTML `title` 属性
- 统一使用 `TooltipSimple` 组件
- 侧边栏项目 `placement="right"`，其余 `placement="top"`

## 响应式

- 最小窗口宽度 640px
- 当窗口 < 900px 时：左侧栏自动折叠，右侧面板隐藏
- 当窗口 < 1200px 时：右侧面板可手动折叠
- 三栏最小宽度分配：左侧栏 48px（折叠）/ 260px（展开）、中间栏 360px、右侧面板 280px
