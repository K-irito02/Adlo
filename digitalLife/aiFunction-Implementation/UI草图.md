- 可以包含多个"工作空间"标签，每个"工作空间"标签下有各自的会话标签
- 鼠标悬停在"工作空间"标签上时，右边显示收缩/展开按钮（收缩/展开会话标签）、新建会话标签按钮，左边显示置顶/取消置顶按钮
- "工作空间"支持拖拽排序、右键弹出工作空间标签菜单
  - 工作空间标签菜单：置顶/取消置顶、会话标签全部标记为已读、会话标签全部归档、整个工作空间从侧边栏移除

- 每个"工作空间"下面的会话标签支持拖拽排序、双击重命名、右键弹出会话标签菜单、悬停显示菜单按钮和归档按钮
  - 会话标签菜单：重命名、会话标签标记为已读、会话标签归档

- 不管是"工作空间"标签还是"会话标签"，它们的最左侧在某些情况下会有显示指示灯
  - "工作空间"标签指示灯：当该工作空间下的会话标签是收缩状态时显示指示灯；当该工作空间下的会话标签是展开状态时不显示指示灯。若是该工作空间下有正在处理中（淡蓝）、待审核/批准（淡黄）、出现异常（淡红）、已完成（淡绿）、已读（灰色） 的会话标签时，则工作空间标签左侧的指示灯依次按每个会话标签的颜色进行呼吸感的闪烁（已读的灰色会话标签除外）。
  - "会话标签"指示灯：当会话标签是展开状态时，按 正在处理中（淡蓝）、待审核/批准（淡黄）、出现异常（淡红）、已完成（淡绿）、已读（灰色）这些状态颜色进行"长亮"显示。

15. 对应于14区域的每个功能所显示的子功能内容。

- 工作空间文件目录结构按钮下的子功能：收缩/展开文件目录结构侧边栏按钮、搜索按钮、横向文件标签列表暂存显示区域、文件预览按钮、源Markdown格式文件预览按钮、菜单按钮。
  - 菜单：Save File 保存文件选项（保存当前文件的修改）、Discard Changes	放弃更改选项（撤销文件未保存的修改，恢复到上次保存状态）、Copy Relative Path 复制相对路径（复制文件相对于项目根目录的路径）、Copy Absolute Path 复制绝对路径（复制文件相对于磁盘目录的路径）、Diff View 差异视图开关功能（查看文件修改前后的对比差异）、Line Numbers 显示/隐藏行号开关功能（显示 / 隐藏编辑器的行号）、Word Wrap 自动换行开关功能（编辑器内容超过视口宽度时自动换行显示）

- 变更文件目录结构按钮下的子功能：显示所有分支（默认显示当前分支，并且文件目录结构只显示变更的文件）、菜单按钮
  - 菜单：Unified 统一视图（代码差异对比的显示模式，将修改前后的内容合并在同一区域显示）、Split	分栏视图（代码差异对比的另一种模式，将修改前、修改后的内容分左右两栏显示）、Refresh Changes	刷新变更（重新加载并刷新文件的修改差异，常用于外部修改文件后更新视图）

- 浏览器按钮下的子功能：收缩/展开浏览器标签的侧边栏按钮、前进按钮、后退按钮、刷新按钮、收藏按钮、网站输入区域、菜单按钮
  - 菜单：Hard Reload 强制刷新（跳过浏览器缓存，重新从服务器加载页面资源，常用于开发调试）、Copy Current URL 复制当前网址（复制当前页面的 URL 地址）、Clear Browsing History 清除浏览历史（删除浏览器记录的网页访问记录）、Clear Cookies 清除 Cookies（删除网站存储在本地的 Cookies 数据（如登录状态、偏好设置））、Clear Cache	清除缓存（删除浏览器本地存储的静态资源缓存（如图片、样式文件））

- 终端按钮下的子功能：收缩/展开终端标签的侧边栏按钮
