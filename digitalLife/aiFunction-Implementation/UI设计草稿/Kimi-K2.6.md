## 1. 顶部菜单栏（1）

| 菜单 | 选项 |
|------|------|
| **Logo / File** | 新建工作空间 · 打开文件夹 · 新建终端 · 新建浏览器 · 打开编辑器窗口 · 退出 |
| **View** | Diff 查看 · 浏览器查看 · 文件查看 · 终端查看 · Zoom In · Zoom Out · Reset Zoom · Settings |
| **Help** | Command Palette · Keyboard Shortcuts · View License |

## 2. 设置按钮（2）

- 独立设置入口，快速打开应用设置面板

## 3. 侧边栏控制（3）

| 按钮 | 功能 |
|------|------|
| 一键收缩 | 同时收起左侧和右侧边栏 |
| 左箭头 | 单独收起/展开左侧边栏 |
| 右箭头 | 单独收起/展开右侧边栏 |

## 4. 窗口控制（4）

- 最小化 · 最大化 · 关闭

## 5. 技能与快捷操作区（5）

- 预留的 Skills（技能）
- 预留的 MCP
- 新建工作空间

## 6. 会话展示区（6）

### 工作空间标签
- 支持多工作空间，每个工作空间下有独立会话标签
- **悬停交互**：右侧显示「收缩/展开会话标签」和「新建会话」；左侧显示「置顶/取消置顶」
- **拖拽**：支持排序
- **右键菜单**：置顶/取消置顶 · 全部标记为已读 · 全部归档 · 从侧边栏移除

### 会话标签
- **交互**：拖拽排序 · 双击重命名 · 右键菜单 · 悬停显示菜单/归档按钮
- **右键菜单**：重命名 · 标记为已读 · 归档

### 指示灯规则

| 元素 | 状态 | 显示规则 |
|------|------|----------|
| **工作空间标签灯** | 收缩时 | 显示灯（按子会话状态呼吸闪烁：处理中淡蓝、待审核淡黄、异常淡红、完成淡绿；已读灰色不闪） |
| | 展开时 | 隐藏 |
| **会话标签灯** | 展开时 | 长亮显示（处理中淡蓝、待审核淡黄、异常淡红、完成淡绿、已读灰色） |

## 7. 底部控制区（7）

- 语言选择按钮
- 主题选择按钮

## 8. 主内容区（8）

展示 Agent 运行内容：
- 新增/修改文件
- 终端命令执行
- Agent 输出内容
- 待用户审核/批准的操作

## 9. 首次启动引导页（9）

未打开工作区时显示：

| 元素 | 内容 |
|------|------|
| 图标 | `icon-folder-open`（大尺寸） |
| 标题 | "打开工作空间" |
| 描述 | "选择一个项目目录开始" |
| 主按钮 | [打开工作空间] → 调起系统目录选择器 |
| 次要链接 | "最近打开的工作空间" → 展开最近列表 |

## 10. 添加菜单（10）

点击 `+` 号展开：

| 选项 | 说明 |
|------|------|
| Plan | 计划模式 |
| Debug | 解决问题模式 |
| Ask | 问答模式 |
| Image | 添加图片 |
| Models | 模型选择 |
| Skills | 添加技能 |
| MCP Servers | 查看/改变 MCP 服务状态 |

> 提示：Add agents, context, tools...

## 11. 提示词输入区（11）

- 支持文本输入
- 支持拖拽上传：图片、`.md`、`.txt`、`.docx`

## 12. 发送按钮（12）

- 无输入时：显示「语音」图标
- 有输入后：变为「发送」图标

## 13. 状态栏（13）

| 元素 | 说明 |
|------|------|
| Git 状态灯 | 已同步（淡绿 3s 后转灰）· 有未提交（淡黄）· 有未推送（淡黄）· 冲突（淡红）· 非 Git 仓库仅显示目录名 |
| 工作空间名称 | 当前工作空间 |
| Git 分支 | 当前分支名 |
| 模型选择 | 当前使用的模型 |

> **自动机制**：文件变化后自动刷新索引；Agent 完成后统一展示变更，支持手动回滚；切换工作空间/会话/关闭应用时自动保存。

## 14. 功能标签栏（14）

四个可拖拽排序的功能入口：

| 图标 | 功能 |
|------|------|
| 📁 | 工作空间文件目录 |
| 📝 | 变更文件目录 |
| 🌐 | 浏览器 |
| 💻 | 终端 |

## 15. 子功能工具栏（15）

各功能对应的子操作栏：

### 工作空间文件目录
- 收缩/展开侧边栏 · 搜索 · 横向文件标签暂存区 · 文件预览 · Markdown 预览 · 菜单

**菜单选项**：
- Save File（保存当前文件）
- Discard Changes（放弃未保存修改）
- Copy Relative Path（复制相对路径）
- Copy Absolute Path（复制绝对路径）
- Diff View（差异视图开关）
- Line Numbers（行号显示/隐藏）
- Word Wrap（自动换行开关）

### 变更文件目录
- 显示所有分支（默认当前分支，仅展示变更文件）· 菜单

**菜单选项**：
- Unified（统一视图）
- Split（分栏视图）
- Refresh Changes（刷新变更）

### 浏览器
- 收缩/展开侧边栏 · 前进 · 后退 · 刷新 · 收藏 · 网址输入 · 菜单

**菜单选项**：
- Hard Reload（强制刷新，跳过缓存）
- Copy Current URL（复制当前网址）
- Clear Browsing History（清除浏览历史）
- Clear Cookies（清除 Cookies）
- Clear Cache（清除缓存）

### 终端
- 收缩/展开侧边栏

## 16. 侧边栏区域（16）

对应 15 中选中功能的侧边栏内容展示区。

## 17. 内容展示区域（17）

对应 16 中选中项的详细内容展示区（文件内容、Diff 对比、网页内容、终端输出等）。
