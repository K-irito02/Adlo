### 工具面板类型

| 工具 ID | 名称 | 说明 |
|---------|------|------|
| `files` | 文件浏览器 | 工作区文件树、搜索、编辑器 |
| `changes` | 变更预览 | Git 变更、补丁预览与应用 |
| `browser` | 浏览器 | 内嵌浏览器标签页 |
| `terminal` | 终端 | 命令执行与输出流 |
| `audit` | 审计日志 | 操作审计记录 |
| `models` | 模型健康 | 模型网关状态监控 |
| `settings` | 设置 | 应用偏好设置 |

### 布局特性

1. **左侧边栏**：
   - 可折叠/展开
   - 可拖拽调整宽度（最小 180px，最大 360px）
   - 工作区与会话支持拖拽排序
   - 会话状态指示灯（处理中/待审批/异常/已完成/已读）

2. **中心面板**：
   - 消息流自动滚动到底部
   - Composer 支持上下文标签（模式、文件、技能等）
   - 内联状态栏显示当前工作区、模型、Git 分支

3. **右侧面板**：
   - 可折叠/展开
   - 可拖拽调整宽度
   - 支持 overlay 模式（当宽度超过阈值时覆盖中心区域）
   - 工具切换器带徽章（显示未保存文件数、Git 变更数等）
