## 🔧 Region 14: Tool Switcher Bar (工具切换栏)

### 位置
- 右侧面板最顶部，横跨 Region 16 和 Region 17 上方

### 功能
提供文件浏览器、源代码管理、浏览器、终端四个核心工具的快速切换

### 工具选项卡

| 序号 | 工具名称 | 图标 | 快捷键 | 说明 |
|------|----------|------|--------|------|
| 1 | 文件资源管理器 | `Files` | `Ctrl+Shift+E` | 浏览和编辑项目文件 |

- **拖拽排序**: 支持拖拽调整选项卡顺序
- **Badge 徽章**:

## 📑 Region 16: Tool Sidebar (工具侧边栏)

### 位置
- 右侧面板左侧窄条，位于 Region 17 左侧
- **宽度**: 约 48-60px（图标模式）或 180-240px（展开模式）

### 功能概述
根据 Region 15 选择的工具不同，此区域显示对应的辅助控件。

### 通用设计原则
- **图标优先**: 默认只显示图标，节省空间
- **悬停展开**: 鼠标悬停或点击图标显示文字 label
- **分组**: 相关功能用分隔线分组
- **激活状态**: 当前使用的功能项高亮显示
- **Tooltip**: 所有图标必须有 tooltip 说明

## 📄 Region 17: Tool Primary Content View (工具主视图)

### 位置
- 右侧面板的主体区域，位于 Region 16 右侧

### 内容动态切换

#### 17.1 文件编辑器视图
**功能特性：**
- **语法高亮**: 支持 100+ 种编程语言
- **IntelliSense**: 代码补全、参数提示、快速文档
- **迷你地图**: 右侧代码缩略图（可关闭）
- **面包屑导航**: 显示当前符号路径 (Class > Method > Line)
- **多标签编辑**: 支持同时打开多个文件标签
- **分屏编辑**: 并排/上下对比两个文件
- **查找替换**: `Ctrl+F` / `Ctrl+H`，支持正则表达式
- **转到定义**: `F12` 或 `Ctrl+Click`
- **重命名符号**: `F2` 重命名并更新所有引用

**标签栏功能：**
- 显示文件名 + 修改状态指示（● 已修改）
- 分隔符显示路径
- 右键: 关闭、关闭其他、关闭全部、复制路径、在资源管理器中显示
- 拖拽排序
- 支持拖拽文件到此区域打开

#### 17.2 Diff/变更视图
**布局：**
- 顶部: 分支选择器 + 操作按钮栏
- 主体: 文件变更列表（可折叠）
- 详情: 选中的文件 diff 视图

**Diff 视图功能：**
- **Unified 模式**: 上下文合并显示
- **Split 模式**: 左右分栏对比
- **行内差异**: 精确到字符级别的变化高亮
- **忽略空白**: 可选忽略空白字符差异
- **单词差异**: 单词粒度的高亮（更适合文本）
- **操作按钮**: 暂存/取消暂存/放弃/打开文件

#### 17.3 浏览器视图
**功能：**
- **地址栏**: 支持 URL 输入、搜索建议、历史记录
- **标签页**: 多标签浏览，支持拖拽排序、关闭、固定
- **开发者工具**: 内置 DevTools（Elements/Console/Network）
- **控制台日志捕获**: 自动捕获 console.log/error
- **网络请求监控**: 查看请求/响应详情
- **设备模拟**: 移动端响应式测试模式
- **书签管理**: 快速访问常用链接

#### 17.4 终端视图
**功能：**
- **Shell 集成**: PowerShell, CMD, Bash, WSL, Python REPL
- **多会话**: 支持多个并行终端会话（标签切换）
- **分屏**: 水平/垂直分割终端
- **字体定制**: 字体族、字号、行高
- **主题**: 支持多种终端配色方案
- **快捷命令**: 常用命令快捷按钮
- **命令历史**: 上下箭头浏览历史，持久化跨会话
- **搜索**: `Ctrl+F` 在终端输出中搜索
- **链接识别**: 自动识别 URL/文件路径，点击可打开
- **拖拽支持**: 拖拽文件到终端输入路径
