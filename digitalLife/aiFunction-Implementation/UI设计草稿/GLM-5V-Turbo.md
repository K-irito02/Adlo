## 🔝 Region 1: Application Menu (应用菜单栏)

### 位置
- 顶部导航栏左侧，横跨整个左半部分宽度

### 组件构成

#### 1.1 Logo 图标
- **位置**: 菜单栏最左侧
- **样式**: 应用品牌标识，可点击返回首页
- **交互**: 悬停显示应用名称 tooltip

#### 1.2 File 菜单 (文件操作)
**下拉菜单项：**
| 菜单项 | 快捷键 | 功能说明 |
|--------|--------|----------|
| 新建工作空间 | `Ctrl+N` | 创建新的工作空间实例 |
| 打开文件夹 | `Ctrl+O` | 打开系统目录选择器，选择项目目录 |
| 新建终端 | `Ctrl+Shift+\`` | 在当前工作空间新建终端实例 |
| 新建浏览器 | - | 打开内置浏览器标签页 |
| 打开编辑器窗口 | - | 以独立窗口模式打开代码编辑器 |
| 退出 | `Alt+F4` | 关闭应用程序 |

#### 1.3 View 菜单 (视图控制)
**下拉菜单项：**
| 菜单项 | 快捷键 | 功能说明 |
|--------|--------|----------|
| Diff 查看 | - | 切换到差异对比视图模式 |
| 浏览器查看 | - | 显示/隐藏浏览器面板 |
| 文件查看 | - | 显示/隐藏文件资源管理器 |
| 终端查看 | - | 显示/隐藏终端面板 |
| Zoom In 放大 | `Ctrl++` | 增大界面缩放比例 (+10%) |
| Zoom Out 缩小 | `Ctrl+-` | 减小界面缩放比例 (-10%) |
| Reset Zoom 重置缩放 | `Ctrl+0` | 恢复默认 100% 缩放比例 |
| Settings 设置 | `Ctrl+,` | 打开全局设置页面 |

#### 1.4 Help 菜单 (帮助支持)
**下拉菜单项：**
| 菜单项 | 快捷键 | 功能说明 |
|--------|--------|----------|
| Command Palette 命令面板 | `Ctrl+Shift+P` | 打开全局命令搜索面板 |
| Keyboard Shortcuts 键盘快捷键 | `Ctrl+K Ctrl+S` | 显示快捷键映射表 |
| View License 查看许可证 | - | 显示软件许可证信息 |

### 设计规范
- **高度**: 32px（紧凑型）/ 40px（标准型）
- **背景**: 主题色 surface 层级
- **字体**: 系统默认 sans-serif, 13px
- **间距**: 菜单项水平 padding 16px, 垂直 padding 6px

## ⚙️ Region 2: Global Settings Entry (全局设置入口)

### 位置
- 顶部导航栏右侧，Region 3 的左侧

### 组件规格
- **图标**: `Settings` (Lucide SVG Icon)
- **尺寸**: 24×24px (符合标准尺寸规范)
- **状态**:
  - 默认: 使用 `color-muted` 语义色
  - 悬停: 高亮 + 背景 highlight (使用 `bg-surface-hover`)
  - 点击: 打开 Settings 页面（可内嵌面板或新页面）

### 功能范围
打开后应包含以下设置分类：
1. **通用设置**: 语言、主题、字体大小、自动保存间隔
2. **AI 模型配置**: API Key 管理、模型选择、参数调优、Token 限制
3. **工作空间设置**: 默认工作目录、索引策略、文件监听规则
4. **快捷键绑定**: 自定义快捷键映射
5. **隐私与安全**: 数据本地存储策略、遥测开关、敏感数据屏蔽
6. **高级选项**: 代理设置、调试模式、日志级别

## 🔀 Region 3: Panel Controls (面板控制)

### 位置
- 顶部导航栏右侧，Region 2 和 Region 4 之间

### 组件构成

#### 3.1 一键收起全部侧边栏
- **图标**: `PanelLeftClose` + `PanelRightClose` 组合或 `Columns`
- **功能**: 同时收起左侧边栏和右侧面板
- **快捷键**: `Ctrl+B` 或 `Ctrl+J`
- **状态指示**: 
  - 展开时显示"收起"图标
  - 收起时显示"展开"图标

#### 3.2 单独控制左侧边栏
- **图标**: `PanelLeft` / `PanelLeftClose`
- **功能**: 仅切换左侧边栏（Region 5-7）的显示/隐藏
- **独立状态**: 与右侧面板无关

#### 3.3 单独控制右侧面板
- **图标**: `PanelRight` / `PanelRightClose`
- **功能**: 仅切换右侧面板（Region 14-17）的显示/隐藏
- **独立状态**: 与左侧边栏无关

### 交互细节
- **拖拽调整**: 所有面板边界支持拖拽调整宽度
  - 左侧边栏: 默认 260px, 最小 200px, 最大 400px
  - 右侧面板: 默认 30% 视口宽度, 最小 20%, 最大 50%
- **记忆功能**: 用户调整的面板宽度自动持久化到本地存储
- **动画过渡**: 面板展开/收起使用 200ms ease-out 动画

## 🪟 Region 4: Window Management (窗口管理)

### 位置
- 顶部导航栏最右侧（Windows/Linux/macOS 自适应）

### 组件构成

| 按钮 | 图标 | 功能 | 平台适配 |
|------|------|------|----------|
| 最小化 | `Minus` | 窗口最小化到任务栏 | 全平台 |
| 最大化 | `Square` / `Copy` | 窗口最大化/还原 | 全平台 |
| 关闭 | `X` | 关闭窗口/应用 | 全平台 |

### 设计规范
- **Windows**: 按钮在右上角，间距 0px，悬停有背景色
- **macOS**: 交通灯按钮在左上角（红黄绿），需调整整体布局
- **Linux**: 遵循系统主题（GNOME/KDE）

### 特殊行为
- **关闭确认**: 如果有未保存的会话或正在运行的 Agent，弹出确认对话框
- **托盘最小化**: 可选配置为关闭到系统托盘而非完全退出
- **多窗口支持**: 支持打开多个编辑器窗口（从 File 菜单触发）

## 🚀 Region 5: Quick Actions Toolbar (快捷操作区)

### 位置
- 左侧边栏顶部，位于 Region 6 上方

### 组件构成

#### 5.1 技能按钮 (Skills)
- **图标**: `Sparkles` 或自定义技能图标
- **状态**: 
  - 默认: 灰色轮廓
  - 已激活技能: 高亮填充色
  - 徽章: 显示已加载技能数量
- **点击**: 展开/收起技能列表面板
- **拖拽**: 支持将技能拖拽到输入框作为上下文

#### 5.2 MCP 服务按钮 (MCP Servers)
- **图标**: `Plug` 或 `Server`
- **状态指示灯**: 
  - 绿色: 所有 MCP 服务已连接
  - 黄色: 部分服务连接中
  - 红色: 服务连接失败
  - 灰色: 未配置 MCP 服务
- **点击**: 打开 MCP 服务管理面板（查看状态、启停服务、配置新服务）
- **功能范围**: Phase 2+ 能力，Phase 1 显示但标记为"即将推出"

#### 5.3 新建工作空间按钮
- **图标**: `Plus` 或 `FolderPlus`
- **点击**: 
  - 直接创建空白工作空间，或
  - 弹出选项：新建空白 / 从模板创建 / 导入已有项目
- **快捷键**: `Ctrl+N`

### 布局规则
- **排列方式**: 水平排列，图标优先模式
- **间距**: 8px 间隙
- **Tooltip**: 悬停显示完整功能名称 + 快捷键
- **响应式**: 当左侧边栏宽度 < 220px 时，仅显示图标；≥ 220px 时显示图标+文字

## 💬 Region 6: Session Management System (会话管理系统)

### 位置
- 左侧边栏主体部分，位于 Region 5 和 Region 7 之间
- **这是整个界面的核心导航区域**

### 架构层次

```
Region 6 结构：
├── 工作空间标签层 (Workspace Tabs)
│   ├── Workspace A (置顶) [Pin icon]
│   ├── Workspace B 
│   └── Workspace C
│
└── 会话标签层 (Conversation Tabs) [可折叠]
    ├── Session 1 (未读 [Dot])
    ├── Session 2 (处理中 [Dot] 蓝色呼吸)
    ├── Session 3 (已完成 [Check] 绿色)
    └── Session 4 (异常 [X] 红色)
```

### 6.1 工作空间标签 (Workspace Tabs)

#### 基础属性
- **显示格式**: 状态指示灯图标/置顶或取消置顶图标 + 工作空间名称 + 展开/折叠图标 + 新建会话图标 + 更多菜单图标
**状态指示灯图标 与 置顶或取消置顶图标关系**: 仅当工作空间的会话标签处于**折叠状态**时显示指示灯图标。仅当工作空间的会话标签处于**展开状态**时显示置顶或取消置顶图标。

#### 交互行为

| 操作 | 触发方式 | 效果 |
|------|----------|------|
| 悬停 | 鼠标进入 | 显示操作按钮组（展开/折叠图标 + 新建会话图标 + 更多菜单图标） |
| 拖拽排序 | 拖动 | 改变工作空间标签顺序，实时预览位置 |
| 右键菜单 | 右键单击 | 弹出工作空间上下文菜单 |
| 滚动 | 鼠标滚轮 | 当标签数量超出可视区域时滚动 |

#### 右键菜单项
| 菜单项 | 功能 | 图标 |
|--------|------|------|
| 置顶 / 取消置顶 | 固定到列表顶部 / 取消固定 | `Pin` / `PinOff` |
| 全部标记已读 | 将该工作空间下所有会话标记为已读 | `CheckCheck` |
| 全部归档 | 归档该工作空间下所有会话（移至归档区） | `Archive` |
| 从侧边栏移除 | 关闭但不删除工作空间（可在最近列表恢复） | `Trash-2` |
| 在文件管理器中显示 | 打开工作空间目录 | `FolderOpen` |

#### 状态指示灯系统 (Workspace Level)

**显示条件**: 仅当工作空间的会话标签处于**折叠状态**时显示指示灯

**颜色编码与优先级**（按重要性排序，高优先级覆盖低优先级）：

| 优先级 | 状态 | 语义色 | CSS Variable | 动画效果 | 说明 |
|--------|------|--------|--------------|----------|------|
| P1 | 出现异常 | `danger` | `var(--color-danger)` | 呼吸闪烁 (2s 周期) | Agent 执行失败、API 错误 |
| P2 | 待审核/批准 | `warning` | `var(--color-warning)` | 呼吸闪烁 (2s 周期) | 等待用户确认的操作 |
| P3 | 正在处理中 | `info` / `primary` | `var(--color-info)` | 呼吸闪烁 (1.5s 周期) | Agent 正在执行任务 |
| P4 | 已完成 | `success` | `var(--color-success)` | 常亮 (3s 后渐隐至 muted) | 任务执行完毕 |
| P5 | 已读 | `muted` | `var(--color-muted)` | 无动画 | 无待处理事项（不参与闪烁） |

**多重状态处理**: 当同一工作空间下存在多种状态的会话时，指示灯按最高优先级颜色显示，并在 tooltip 中列出各状态数量。

### 6.2 会话标签 (Conversation Tabs)

#### 基础属性
- **层级关系**: 从属于某个工作空间标签下方
- **显示格式**: 状态指示灯图标/置顶或取消置顶图标 + 会话标题 + 日期 + 归档图标 + 更多菜单图标
**状态指示灯图标 与 置顶或取消置顶图标关系**: 当鼠标悬停在会话标签上时，不显示状态指示灯，仅显示置顶或取消置顶图标。当鼠标移出时，仅显示状态指示灯。
**日期与操作按钮显示关系**: 当鼠标悬停在会话标签上时，不显示日期，仅显示操作按钮组（归档图标 + 更多菜单图标）。当鼠标移出时，仅显示日期。
#### 交互行为

| 操作 | 触发方式 | 效果 |
|------|----------|------|
| 切换会话 | 单击 | 加载该会话历史到主内容区 (Region 8) |
| 悬停 | 鼠标进入 | 右侧显示：操作按钮组（归档图标 + 更多菜单图标）; 左侧显示置顶或取消置顶图标 |
| 拖拽排序 | 拖动 | 在同一工作空间内调整会话顺序 |
| 双击重命名 | 双击 | 进入编辑模式修改会话标题 |
| 右键菜单 | 右键单击 | 弹出会话上下文菜单 |

#### 右键菜单项
| 菜单项 | 功能 | 图标 |
|--------|------|------|
| 重命名 | 修改会话标题 | `Pencil` |
| 标记已读 / 未读 | 切换已读状态 | `Check` / `Mail` |
| 归档 | 归档此会话 | `Archive` |
| 复制会话 ID | 复制唯一标识符用于分享/调试 | `Copy` |
| 导出对话 | 导出为 Markdown/PDF 文件 | `Download` |
| 置顶 / 取消置顶 | 固定不被自动归档 | `Pin` / `PinOff` |
| 删除 | 永久删除此会话（不可恢复） | `Trash-2` (危险操作，红色) |

#### 状态指示灯系统 (Session Level)

**显示条件**: 会话标签处于**展开状态**时显示

**状态颜色映射**（使用语义化命名）：

| 状态 | 语义色 | CSS Variable | 显示方式 | 说明 |
|------|--------|--------------|----------|------|
| 正在处理中 | `info` / `primary` | `var(--color-info)` | **长亮** | Agent 正在生成回复或执行命令 |
| 待审核/批准 | `warning` | `var(--color-warning)` | **长亮** | 存在需要用户确认的操作（如文件修改、命令执行） |
| 出现异常 | `danger` | `var(--color-danger)` | **长亮** | 发生错误或异常情况 |
| 已完成 | `success` | `var(--color-success)` | **长亮** | 最后一次交互正常完成 |
| 已读 | `muted` | `var(--color-muted)` | **长亮** | 用户已查看最新内容，无待处理事项 |

### 6.3 特殊场景处理

#### 空状态（无工作空间时）
- 显示引导提示："点击上方 + 号创建工作空间"
- 虚线边框卡片样式
- 点击直接触发新建流程

#### 大量会话时的性能优化
- **虚拟滚动**: 仅渲染可视区域的会话标签（> 50 条时启用）
- **搜索过滤**: 顶部出现搜索框，实时过滤会话
- **分组**: 按时间（今天/本周/更早）或状态分组显示

#### 归档区域
- 位于活跃会话列表底部，可折叠
- 显示归档数量徽章
- 点击展开查看历史归档会话
- 支持从归档恢复会话

## 🎨 Region 7: Environment Controls (环境控制区)

### 位置
- 左侧边栏底部，固定位置

### 组件构成

#### 7.1 语言选择按钮
- **图标**: `Globe` + 当前语言代码 (如 "中文", "EN")
- **点击**: 弹出语言选择下拉菜单
- **支持语言**: 中文简体、English、日本語、한국어（可扩展）
- **效果**: 即时切换界面语言，无需重启
- **持久化**: 选择保存到用户偏好设置

#### 7.2 主题选择按钮
- **图标**: `Sun` (亮色) / `Moon` (暗色) / `Monitor` (跟随系统)
- **点击**: 循环切换主题 或 弹出主题选择器
- **可选主题**:
  - Light (浅色)
  - Dark (暗色)
  - System (跟随操作系统)
  - High Contrast (高对比度，辅助功能)
- **过渡动画**: 300ms 渐变过渡，避免突兀切换
- **影响范围**: 全局界面色彩方案

### 布局规范
- **排列**: 水平排列，居中对齐
- **间距**: 12px 间隔
- **分隔线**: 与上方 Region 6 之间有 1px 分隔线
- **固定定位**: 不随 Region 6 内容滚动

## 📋 Region 8: Task Execution Display (任务展示区)

### 位置
- 主内容区域的核心部分，占据大部分视口空间

### 功能概述
这是用户与 AI 交互的主要展示区域，负责呈现：
- 多轮对话历史
- Agent 实时执行过程（流式输出）
- 代码块、文件变更、终端输出
- 图片、文档等多模态内容
- 待审核/批准的操作卡片

### 8.1 消息类型与渲染

#### 用户消息 (User Message)
- **布局**: 右对齐（或根据 RTL 设置）
- **样式**: 用户头像 + 消息气泡 + 时间戳
- **内容支持**:
  - 纯文本（Markdown 渲染）
  - 图片（支持预览、放大、下载）
  - 文件附件（显示文件名、大小、类型图标）
  - 代码片段（语法高亮）
- **操作**: 编辑（发送后 2 分钟内）、复制、重新生成

#### AI 助手消息 (Assistant Message)
- **布局**: 左对齐
- **样式**: AI 头像/Logo + 消息内容 + 操作栏
- **内容支持**:
  - Markdown 富文本（GFM 标准）
  - 代码块（带语言标识、行号、复制按钮）
  - 表格、列表、引用块
  - Mermaid 流程图（可选）
  - 数学公式（KaTeX，可选）
- **特殊组件**:

##### 8.1.1 代码块增强功能
每个代码块顶部显示工具栏：
| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 复制代码 | 复制到剪贴板 | - |
| 插入到编辑器 | 将代码插入到光标位置 | - |
| 应用更改 | 直接写入文件（需确认） | - |
| Diff 预览 | 查看与原文件的差异 | - |
| 新建文件 | 创建新文件并填入代码 | - |

##### 8.1.2 文件变更卡片 (File Change Card)
当 Agent 修改文件时显示的结构化卡片：
```
┌─ [FileText] src/components/Button.tsx ────────┐
│ [Modified] +12 lines -3 lines             │
│                                            │
│ ┌─ Diff Preview ────────────────────────┐ │
│ │ + const handleClick = () => {         │ │
│ │ +   setLoading(true);                 │ │
│ │ -   console.log('clicked');           │ │
│ }                                        │ │
│ └────────────────────────────────────────┘ │
│                                            │
│ [Check Accept] [X Reject] [Eye Preview]    │
└────────────────────────────────────────────┘
```

##### 8.1.3 终端输出块 (Terminal Output Block)
```bash
$ npm run build

> @ai-digital-life/app@1.0.0 build

[Copy 输出] [Terminal 在终端中运行] [Square 停止]
```

##### 8.1.4 待批准操作卡 (Approval Required Card)
当 Agent 需要执行敏感操作时：
```
[AlertTriangle] Agent 请求权限执行以下操作：

[Package] 安装依赖: lodash@4.17.21
[MapPin] 工作目录: /project/root
[Zap] 影响: 将修改 package.json 和 lock 文件

[Check 批准] [X 拒绝] [Pencil 编辑命令] [Settings 详细信息]
```

### 8.2 Agent 执行状态可视化

#### 流式输出指示器
- **打字动画**: 光标闪烁 + 逐字/逐块显示
- **思考过程**: 可选显示 Chain-of-Thought 推理步骤（折叠/展开）
- **进度条**: 对于长时间任务（如重构），显示预估进度百分比

#### Agent 状态指示
| 状态 | SVG 图标 (Lucide) | 语义色 | 动画 | 说明 |
|------|-------------------|--------|------|------|
| 空闲 | `Minus` | `muted` | 无 | 等待用户输入 |
| 思考中 | `Brain` / `Loader2` | `info` / `primary` | 脉冲 | 正在分析用户请求 |
| 生成中 | `PenTool` | `info` / `primary` | 打字光标 | 正在生成回复 |
| 执行命令 | `Play` | `warning` | 进度条 | 正在运行终端命令 |
| 修改文件 | `Pencil` | `purple` (自定义) | 旋转 | 正在读写文件 |
| 等待审批 | `Pause` | `warning` | 呼吸 | 等待用户确认 |
| 完成 | `CheckCircle` | `success` | 淡出 | 任务成功完成 |
| 错误 | `XCircle` | `danger` | 震动 | 出现错误或被拒绝 |

### 8.3 Token 使用监控
在每条 AI 回复底部显示（可配置显示/隐藏）：
```
[Coins] Tokens: 1,234 input | 567 output | Cost: $0.0023
```

### 8.4 交互功能
- **滚动加载**: 自动滚动到最新消息，用户向上滚动查看历史时锁定
- **消息搜索**: `Ctrl+F` 在当前会话中搜索关键词
- **消息引用**: 悬停消息显示引用按钮，可在输入框中引用该消息
- **书签**: 重要消息可添加书签，快速跳转
- **导出**: 导出会话为 Markdown/JSON/PDF
- **分支对话**: 从某条消息开始新的分支（类似 Git 分支概念）

## ✍️ Region 11: Prompt Input Interface (提示词输入区)

### 位置
- 底部输入栏中央，Region 10 和 Region 12 之间
- **这是用户与 AI 交互的核心入口**

### 外观规格
- **容器**: 圆角矩形输入框，自适应高度（最小 48px，最大 200px）
- **占位符**: "向 AI 助手提问..." / "描述你想要完成的任务..."
- **字体**: 14px, monospace for code snippets
- **背景**: 主题色 input background
- **边框**: 1px solid, focus 时高亮 + shadow

### 输入功能支持

#### 11.1 文本输入
- **多行支持**: 自动扩展高度，`Shift+Enter` 换行，`Enter` 发送
- **Markdown 预览**: 可选开启实时 Markdown 预览
- **语法检测**: 自动识别代码块（```language）并提供高亮
- **字数统计**: 右下角显示字符数 / Token 估算值

**支持的文件类型：**

| 类型 | 格式 | 最大大小 | 处理方式 |
|------|------|----------|----------|

| 文档 | MD, TXT, PDF, DOCX | 25MB | 文本提取 + 解析 |
| 代码 | JS, TS, PY, JSON, YAML 等 | 1MB | 语法高亮 + 分析 |
| 数据 | CSV, XLSX | 5MB | 表格解析 |

**上传方式：**
1. **拖拽**: 直接拖拽文件到输入框区域
2. **粘贴**: `Ctrl+V` 粘贴截图或文件
3. **点击**: 点击上传按钮选择文件（从 Region 10 触发）
4. **@引用**: 通过 @File 引用工作空间中的文件

**上传后的显示：**

│ 请帮我分析这个代码的问题...                    │

│                                                │
│                                              ↑ │
│                              [Send] [Mic]     │
└────────────────────────────────────────────────┘
```

#### 11.3 语音输入（可选）
- **按钮**: 麦克风图标 `Mic` (Lucide SVG, 20×20px)
- **功能**: 点击开始录音，再次点击结束并转换为文本
- **状态**: 录音时显示波形动画
- **支持**: 离线语音识别（首选）或在线 API

### 11.4 上下文标签 (Context Chips)
当通过 Region 10 添加了上下文引用后，输入框上方显示标签：

```

- 每个 tag 可单独关闭（×）
- 悬停显示完整路径/名称
- 不同类型用不同颜色区分

## 🚀 Region 12: Action Button (操作按钮)

### 位置
- 底部输入栏最右侧，紧邻 Region 11

### 状态机设计

```
┌─────────────────────────────────────────┐
│                                         │
│  [空闲状态]          →  [ArrowUp/Send] │
│  [有输入内容]        →  [ArrowUp 高亮]  │
│  [Agent 生成中]      →  [Square/Stop]   │
│  [网络错误]          →  [RefreshCw]     │
│  [队列等待]          →  [Loader2]       │
│                                         │
└─────────────────────────────────────────┘
```

### 各状态详细说明

#### 12.1 发送状态 (Send)
- **图标**: `ArrowUp` 或 `Send`
- **外观**: Primary button style（主题色填充）
- **条件**: 输入框非空 或 有上下文标签
- **禁用**: 输入框完全为空且无上下文
- **点击**: 触发消息发送 → 按钮变为 Stop 状态

#### 12.2 停止状态 (Stop)
- **图标**: `Square` 或 `StopCircle`
- **外观**: Danger/Warning style（红色或橙色）
- **条件**: Agent 正在生成回复或执行任务
- **点击**: 中断当前生成 → 按钮恢复为 Send 状态
- **效果**: 保留已生成的内容，显示"已停止"标记

#### 12.3 重试状态 (Retry)
- **图标**: `RefreshCw`（带旋转动画）
- **外观**: Warning style
- **条件**: 上一次请求失败（网络错误、超时、API 错误）
- **点击**: 重新发送上一次的消息
- **自动重试**: 可配置自动重试次数（默认 0 次，手动触发）

#### 12.4 等待状态 (Waiting)
- **图标**: `Loader2`（旋转动画）或 `Hourglass`
- **外观**: Disabled/Neutral style
- **条件**: 消息已发送但尚未开始处理（排队中）
- **显示**: 可能显示预计等待时间

### 尺寸与样式
- **尺寸**: 36×36px（圆形）或 36×48px（圆角矩形）
- **与输入框间距**: 8px
- **动画**: 状态转换使用 150ms ease-out 过渡
- **触觉反馈**: 移动端支持 Haptic Feedback

## ♿ Accessibility & Performance Requirements (无障碍与性能要求)

### 无障碍性 (Accessibility - WCAG 2.1 AA)

#### 视觉辅助
- **对比度**: 正文文本 ≥ 4.5:1，大文本 ≥ 3:1
- **焦点指示**: 所有交互元素有清晰的焦点环（2-4px outline）
- **屏幕阅读器**: 完整的 ARIA label 和 role 支持
- **语义化 HTML**: 使用正确的 heading hierarchy (h1→h6)
- **颜色独立性**: 不仅依靠颜色传达信息（配合图标/文字）

#### 键盘导航
- **Tab 顺序**: 符合视觉阅读顺序的逻辑 Tab 流
- **Skip Links**: 提供"跳转到主要内容"的隐藏链接
- **快捷键提示**: 所有按钮悬停显示快捷键
- **模态焦点陷阱**: 对话框/面板打开时焦点限制在其内部

#### 运动与动画
- **减少动画**: 尊重 `prefers-reduced-motion` 系统设置
- **闪烁限制**: 不存在频率 > 3Hz 的闪烁内容
- **时长控制**: 动画时长 150-300ms，可禁用

#### 辅助功能模式
- **高对比度**: 专用主题，增强对比度至 7:1+
- **大字号**: 支持 125%/150%/200% 缩放不破坏布局
- **键盘-only**: 所有功能可通过纯键盘操作完成
- **朗读模式**: AI 回复支持 TTS 朗读

### 性能要求 (Performance Budgets)

#### 启动性能
| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 冷启动时间 | < 3s | 从双击图标到可交互 |
| 热启动时间 | < 1s | 从系统托盘恢复 |
| 首屏渲染 | < 1.5s | 主内容区首次绘制 |
| 可交互时间 (TTI) | < 2s | 所有核心功能可用 |

#### 运行时性能
| 指标 | 目标值 |
|------|--------|
| UI 响应延迟 | < 100ms (用户感知即时) |
| 帧率 | 稳定 60fps (动画流畅) |
| 内存占用 | < 500MB (空闲状态) |
| CPU 占用 | < 5% (空闲), < 30% (活跃任务) |
| 文件索引速度 | < 5s (1000 文件的项目) |

#### 资源加载
| 资源类型 | 策略 |
|----------|------|
| 图标/字体 | 预加载关键资源，懒加载次要资源 |

### 3. 简约设计原则

**✅ 已遵循**: 组件数量有限，保持界面简洁；避免复杂布局和动画

**具体实践：**

| 原则 | 本文档体现 |
|------|-----------|
| **组件精简** | 17 个区域清晰划分职责，避免功能重叠 |
| **布局简洁** | 三栏布局符合用户心智模型，无嵌套混乱 |
| **视觉一致** | 统一使用圆角、间距(8px grid)、阴影层级 |
| **动画克制** | 仅在必要时使用过渡动画（200ms ease-out），避免装饰性动画 |
| **信息层次** | 通过字号(12/14/16/20/24px)、字重(regular/medium/semibold/bold)、颜色深浅建立清晰层次 |

**动画使用限制：**
- ✅ 允许: 面板展开/收起(200ms)、按钮悬停(150ms)、主题切换(300ms)
- ⚠️ 谨用: 状态指示灯呼吸动画(1.5-2s)、进度条
- ❌ 禁止: 页面载入复杂动画、元素入场特效、背景粒子效果

### 4. 设计令牌 (Design Tokens)

**间距系统 (8px Grid):**

| Token | 值 | 用途 |
|-------|-----|------|
| `space-1` | 4px | 元素内部紧凑间距 |
| `space-2` | 8px | 相关元素间基础间距 |
| `space-3` | 12px | 区块间中等间距 |
| `space-4` | 16px | 区块间标准间距 |
| `space-6` | 24px | 区域间大间距 |
| `space-8` | 32px | 主要分区间距 |

**字号系统:**

| Token | 值 | 用途 |
|-------|-----|------|
| `text-xs` | 12px | 状态栏、辅助信息 |
| `text-sm` | 14px | 正文、输入框、列表项 |
| `text-base` | 16px | 子标题、重要正文 |
| `text-lg` | 18px | 小标题 |
| `text-xl` | 20px | 中标题 |
| `text-2xl` | 24px | 主标题、页面标题 |

**圆角系统:**

| Token | 值 | 用途 |
|-------|-----|------|
| `radius-sm` | 4px | 小按钮、Tag、Badge |
| `radius-md` | 8px | 输入框、卡片、下拉菜单 |
| `radius-lg` | 12px | 对话框、面板 |
| `radius-xl` | 16px | 模态窗口、大卡片 |
| `radius-full` | 9999px | 圆形按钮、Avatar |
