# 存储与恢复

## 目标

提供可靠的本地持久化、配置管理、结构化日志、错误恢复和版本迁移能力。

## 存储分层


| 数据类型         | 介质               | 说明           |
| ------------ | ---------------- | ------------ |
| 工作区、会话、任务、审批 | SQLite（rusqlite） | 核心业务元数据      |
| 索引元数据        | SQLite           | 校验和恢复增量索引    |
| 检查点内容        | 文件目录             | 独立存储，便于清理    |
| 缓存（文件树、搜索结果） | 文件/内存            | 可重建，删除不影响正确性 |
| 凭据与密钥        | 系统凭据存储           | 不进入普通配置或日志   |


## 本地目录约定

```
{app_data}/
├─ app.db            # SQLite 主数据库
├─ config.toml       # 用户配置
├─ cache/            # 可重建缓存
├─ checkpoints/      # 检查点快照
├─ logs/             # 结构化日志文件
└─ backups/          # 迁移前备份
```

## 配置管理

- 支持全局配置与工作区级配置
- 配置变更通过事件通知
- 配置校验失败时使用默认值，不崩溃
- API Key 等敏感配置不落盘到配置文件

## 日志系统

- 使用 `tracing` 实现结构化日志
- 支持 DEBUG/INFO/WARN/ERROR 级别
- 日志文件按大小轮转
- 日志写入不阻塞主线程
- 敏感信息自动脱敏

## 错误处理

- 错误按类别分类：系统、网络、AI、用户
- 可恢复错误支持自动重试（指数退避）
- 关键服务使用熔断器模式
- 错误边界隔离，单模块错误不影响全局

## 事件系统

- 使用 tokio broadcast/mpsc 实现模块间通信
- 事件类型化，编译期校验
- 支持优先级与一次性订阅
- 全局唯一事件总线，避免多总线不互通

## 数据迁移

- 启动时自动检测版本变更
- 迁移脚本幂等可重试
- 迁移前自动备份
- 失败自动回滚到迁移前状态

## 验收标准

- 重启后能恢复工作区与会话状态
- 缓存删除后不影响正确性
- 敏感数据不以明文落盘
- 日志按级别正确输出并轮转
- 版本升级时数据自动迁移
