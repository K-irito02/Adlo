# 工作区与索引

## 目标

管理工作区边界、会话恢复和代码库索引，为 Agent 提供稳定的项目上下文。

## 工作区管理

### 核心职责

- 识别项目根目录（支持从子目录向上查找）
- 维护最近工作区列表
- 工作区打开、关闭、切换
- 会话状态恢复

### 会话模型

每个工作区可绑定一个活跃会话，会话记录：

- 最近任务摘要
- 审批模式
- 最近检查点引用
- 最近索引版本

### Git 状态

工作区模块维护 Git 快照：

- 当前分支与 HEAD
- staged / unstaged / untracked / conflicts
- 脏工作树保护：有冲突时阻止高风险操作

## 索引服务

### 必须实现

- 文件树索引：遍历工作区，记录文件路径、大小、修改时间
- 仓库地图：提取入口文件、主目录、关键模块、配置文件摘要
- 索引状态管理：idle / indexing / ready / error

### 设计约束

- 索引任务在后台线程执行，不阻塞 UI
- 索引状态对前端可见（进度、错误）
- 索引中断后可从上次状态恢复
- 忽略 `.gitignore` 匹配的文件和二进制文件
- 文件大小上限可配置

### 增量更新

- 文件新增：补充索引
- 文件修改：更新该文件索引
- 文件删除：移除索引记录
- 避免每次全量重建

### 延后实现

- 符号级索引（AST 解析）
- 向量检索
- 复杂调用图分析

## 验收标准

- 能正确识别项目根目录
- 重启后恢复最近工作区与会话
- 中型仓库可在合理时间内完成首次索引
- 索引状态对 UI 可见
- 文件变更后增量更新
