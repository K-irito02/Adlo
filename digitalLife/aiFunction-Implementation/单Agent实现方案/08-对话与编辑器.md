# 对话与编辑器

## 目标

对话界面作为 Agent 工作流的主入口与观测面，编辑器作为变更预览与代码操作面，两者双向联动。

## 对话界面

### 消息类型

不只是文本消息，还包括结构化执行块：

- 普通文本（markdown）
- 执行计划
- 工具调用摘要
- 审批提示
- 补丁摘要
- 验证结果
- 最终执行总结

### 引用系统

支持在输入中引用上下文：

- `@file:path` — 引用文件
- `@symbol:name` — 引用符号（基于 outline）
- `@terminal:last` — 引用最近终端输出

引用失败时给出明确提示，不阻塞对话。

### 交互命令

保留少量结构化命令入口：

- `/plan` — 要求 Agent 先生成计划
- `/apply` — 应用当前补丁
- `/rollback` — 回滚到最近检查点
- `/model` — 切换模型
- `/clear` — 清除当前对话

### 执行状态可视化

对话中实时展示：

- 当前计划与步骤进度
- 正在调用的工具
- 审批等待原因
- 验证结果摘要
- 最终总结

### 会话管理

- 多轮对话持久化
- 重启后恢复最近会话
- 恢复未处理的审批请求

## 编辑器

### 核心能力

- 代码查看与基础编辑
- 多标签页
- inline / side-by-side diff 切换
- 按文件或按 hunk 接受/拒绝补丁
- 基础诊断标注（文件、行号、严重级别）

### 与对话联动

- 选区发送至对话（附带文件路径、语言、选区范围）
- 对话生成补丁后在编辑器打开 diff
- 验证失败时跳转到错误位置
- 失败上下文可一键再发回 Agent

### 外部修改处理

编辑器需处理三类状态：

- 内存中未保存的修改
- Agent 已应用的补丁
- 外部程序修改的文件

冲突时不静默覆盖，给出明确提示。

### 多 Agent 扩展点

消息块类型可扩展，未来可展示多 Agent 协作状态（如子 Agent 进度、Agent 间消息）。

## 延后实现

- AI Ghost Text 补全
- 多光标 AI 编辑
- 行内对话浮层
- 多模态输入
- 团队协作对话

## 验收标准

- 多轮对话稳定，流式内容与结构化块共同渲染
- 引用系统可用
- 对话展示计划、工具、审批、验证和总结
- 编辑器 diff 预览可用，支持逐块接受
- 选区可发送到对话
- 验证错误可跳转定位
