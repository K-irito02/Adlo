# 上下文与 Prompt

## 目标

为 Agent 在有限 Token 窗口内构建高质量上下文，并通过规则栈保证行为一致性。

## 上下文管理

### 上下文条目类型

- 系统规则
- 用户消息
- 显式引用（`@file`、`@symbol`）
- 当前执行计划
- 活跃文件与选区
- 最近工具输出
- 最近验证结果
- 工作区摘要
- 对话历史摘要

### 优先级排序

固定优先级（高到低）：系统规则 > 用户消息 > 显式引用 > 执行计划 > 活跃代码 > 工具输出 > 对话摘要 > 工作区摘要

### Token 预算

将可用输入窗口按比例分配：


| 类别        | 占比   |
| --------- | ---- |
| 规则与约束     | ~10% |
| 用户消息      | ~10% |
| 显式引用      | ~20% |
| 计划与当前步骤   | ~10% |
| 活跃代码与诊断   | ~20% |
| 对话摘要与工具输出 | ~15% |
| 输出预留      | ~15% |


### 智能裁剪

按内容类型裁剪，不做简单字符截断：

- 代码：保留签名、注释、诊断附近片段
- 终端输出：保留错误块与尾部上下文
- 对话：保留最近轮次 + 历史摘要

### 缓存

- 会话内内存缓存
- 工作区级摘要缓存
- 文件变动或会话变动时精确失效

## Prompt 规则栈

### 组装层级

固定顺序，高层不可覆盖安全基线：

1. **平台级**：安全边界、Patch First 约束、审批要求
2. **项目级**：技术栈、目录边界、代码风格、测试约束
3. **会话级**：用户偏好、执行模式
4. **阶段指令**：plan / edit / verify 的具体行为要求
5. **工具契约**：可用工具列表与调用格式
6. **输出契约**：期望的输出结构

### 场景模板


| 场景     | 核心要求          |
| ------ | ------------- |
| plan   | 输出结构化步骤与风险标记  |
| edit   | 优先生成补丁，不输出整文件 |
| verify | 根据命令输出进行结构化归因 |
| chat   | 简洁回答，必要时引用代码  |


### 注入安全

所有外部内容（文件、终端输出、网页）包装为"参考材料"，不进入高优先级规则层。

### 效果追踪

记录：Prompt 版本、使用场景、补丁接受率、验证通过率、用户重试率。

## 延后实现

- 自动 Prompt 优化
- 向量检索增强
- 长期记忆学习
- 跨 Agent 共享记忆（多 Agent 扩展点）

## 验收标准

- 能为不同执行阶段构建差异化上下文
- 显式引用优先于自动收集
- 超长内容被摘要而不是粗暴截断
- Prompt 可按场景版本化管理
- 外部内容注入不破坏安全基线
