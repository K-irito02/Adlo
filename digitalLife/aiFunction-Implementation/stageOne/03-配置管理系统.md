# 配置管理系统实施计划

## 模块概述

**包名**: `@ai-digital-life/config`

**优先级**: P0 - 核心基础设施，几乎所有模块均依赖配置系统

**目标**: 提供多层级、类型安全的配置管理能力，支持全局配置、工作区配置、项目配置和文件级配置的继承与合并。

## 设计原则

- **多层级继承**: 全局→工作区→项目→文件，低优先级配置被高优先级覆盖
- **类型安全**: 所有配置项均有TypeScript类型定义与JSON Schema约束
- **热更新**: 配置文件变更后自动生效，无需重启应用
- **可观测**: 配置变更触发事件通知，支持变更审计

## 修订说明

第一阶段建议先稳定落地 `global -> workspace -> project` 三级配置。

`file` 级配置可以保留类型定义，但不应成为 Phase 0 的必做项，否则很容易把配置系统做重。

另外，配置系统不应自行创建独立事件总线，而应注入共享 `EventEmitter`，避免系统内部出现多个互不互通的事件中心。

```typescript
import yaml from 'js-yaml';
import fs from 'fs/promises';

export class YamlLoader {
  async load<T>(filePath: string): Promise<T> {
    const content = await fs.readFile(filePath, 'utf-8');
    return yaml.load(content) as T;
  }

  async save<T>(filePath: string, data: T): Promise<void> {
    const content = yaml.dump(data, {
      indent: 2,
      lineWidth: -1,
      noRefs: true,
    });
    await fs.writeFile(filePath, content, 'utf-8');
  }
}
```

```typescript
// src/loader/index.ts

import { YamlLoader } from './yaml-loader';
import { JsonLoader } from './json-loader';
import type { ConfigLevel } from '../types';

export interface ConfigLoader {
  load<T>(filePath: string): Promise<T>;
  save<T>(filePath: string, data: T): Promise<void>;
}

export function createLoader(filePath: string): ConfigLoader {
  const ext = filePath.toLowerCase();
  
  if (ext.endsWith('.yaml') || ext.endsWith('.yml')) {
    return new YamlLoader();
  }
  
  if (ext.endsWith('.json')) {
    return new JsonLoader();
  }
  
  throw new Error(`Unsupported config file format: ${filePath}`);
}

export function getConfigPath(level: ConfigLevel, basePath?: string): string {
  const configDir = '.ai-digital-life';
  
  switch (level) {
    case 'global':
      return `${process.env.HOME || process.env.USERPROFILE}/${configDir}/config.yaml`;
    case 'workspace':
      return `${basePath}/${configDir}/config.yaml`;
    case 'project':
      return `${basePath}/${configDir}/project.yaml`;
    case 'file':
      return `${basePath}.ai-digital-life.yaml`;
    default:
      throw new Error(`Unknown config level: ${level}`);
  }
}
```

### 任务3: 配置合并器 (1天)

```typescript
// src/merger.ts

import { deepMerge, getValueByPath } from '@ai-digital-life/kernel';
import type { GlobalConfig, WorkspaceConfig, ProjectConfig, FileConfig } from './types';

type AnyConfig = GlobalConfig | WorkspaceConfig | ProjectConfig | FileConfig;

export type MergeStrategy = 'override' | 'deep-merge' | 'array-replace';

export interface MergeOptions {
  strategies?: Record<string, MergeStrategy>;
}

const DEFAULT_STRATEGIES: Record<string, MergeStrategy> = {
  'model.apiKey': 'override',
  'workspace.excludePatterns': 'array-replace',
};

export class ConfigMerger {
  private strategies: Record<string, MergeStrategy>;

  constructor(options: MergeOptions = {}) {
    this.strategies = { ...DEFAULT_STRATEGIES, ...options.strategies };
  }

  merge<T extends AnyConfig>(base: T, override: Partial<T>): T {
    const result = { ...base } as T;

    for (const key in override) {
      if (override[key] !== undefined) {
        const strategy = this.strategies[key] ?? 'deep-merge';
        result[key] = this.mergeValue(
          base[key],
          override[key],
          strategy
        ) as T[Extract<keyof T, string>];
      }
    }

    return result;
  }

  private mergeValue(
    baseValue: unknown,
    overrideValue: unknown,
    strategy: MergeStrategy
  ): unknown {
    if (overrideValue === null) {
      return undefined;
    }

    if (strategy === 'override') {
      return overrideValue;
    }

    if (strategy === 'array-replace' && Array.isArray(overrideValue)) {
      return overrideValue;
    }

    if (
      typeof baseValue === 'object' &&
      baseValue !== null &&
      typeof overrideValue === 'object' &&
      overrideValue !== null &&
      !Array.isArray(baseValue) &&
      !Array.isArray(overrideValue)
    ) {
      return deepMerge(
        baseValue as Record<string, unknown>,
        overrideValue as Record<string, unknown>
      );
    }

    return overrideValue;
  }

  mergeAll<T extends AnyConfig>(
    configs: Array<{ config: Partial<T>; priority: number }>
  ): T {
    const sorted = [...configs].sort((a, b) => a.priority - b.priority);
    
    return sorted.reduce(
      (acc, { config }) => this.merge(acc, config),
      {} as T
    );
  }
}
```

### 任务4: 配置验证器 (1天)

```typescript
// src/validator.ts

import Ajv from 'ajv';
import type { AnySchema } from 'ajv';

export interface ValidationResult {
  valid: boolean;
  errors: Array<{
    path: string;
    message: string;
  }>;
}

export class ConfigValidator {
  private ajv: Ajv;
  private schemas = new Map<string, AnySchema>();

  constructor() {
    this.ajv = new Ajv({
      allErrors: true,
      useDefaults: true,
      strict: false,
    });
  }

  registerSchema(name: string, schema: AnySchema): void {
    this.schemas.set(name, schema);
    this.ajv.addSchema(schema, name);
  }

  validate<T>(schemaName: string, data: T): ValidationResult {
    const validate = this.ajv.getSchema(schemaName);
    
    if (!validate) {
      return {
        valid: false,
        errors: [{ path: '', message: `Schema not found: ${schemaName}` }],
      };
    }

    const valid = validate(data);

    if (valid) {
      return { valid: true, errors: [] };
    }

    return {
      valid: false,
      errors: (validate.errors ?? []).map(err => ({
        path: err.instancePath,
        message: err.message ?? 'Unknown error',
      })),
    };
  }

  validateOrThrow<T>(schemaName: string, data: T): T {
    const result = this.validate(schemaName, data);
    
    if (!result.valid) {
      const messages = result.errors
        .map(e => `${e.path}: ${e.message}`)
        .join('\n');
      throw new Error(`Config validation failed:\n${messages}`);
    }
    
    return data;
  }
}
```

### 任务5: 配置管理器 (2天)

```typescript
// src/manager.ts

import { EventEmitter } from '@ai-digital-life/events';
import { createLoader, getConfigPath } from './loader';
import { ConfigMerger } from './merger';
import { ConfigValidator } from './validator';
import type { GlobalConfig, WorkspaceConfig, ProjectConfig, FileConfig, ConfigLevel, ConfigSource } from './types';

export interface ConfigManagerOptions {
  watchForChanges?: boolean;
  emitter: EventEmitter;
}

export class ConfigManager {
  private emitter: EventEmitter;
  private merger = new ConfigMerger();
  private validator = new ConfigValidator();
  
  private globalConfig: GlobalConfig | null = null;
  private workspaceConfigs = new Map<string, WorkspaceConfig>();
  private projectConfigs = new Map<string, ProjectConfig>();
  private fileConfigs = new Map<string, FileConfig>();
  
  private sources = new Map<string, ConfigSource>();

  constructor(options: ConfigManagerOptions) {
    this.emitter = options.emitter;
  }

  async initialize(): Promise<void> {
    await this.loadGlobalConfig();
  }

  private async loadGlobalConfig(): Promise<void> {
    const path = getConfigPath('global');
    const loader = createLoader(path);
    
    try {
      this.globalConfig = await loader.load<GlobalConfig>(path);
      this.sources.set('global', {
        level: 'global',
        path,
        exists: true,
      });
    } catch {
      this.globalConfig = this.getDefaultGlobalConfig();
      this.sources.set('global', {
        level: 'global',
        path,
        exists: false,
      });
    }
  }

  async loadWorkspaceConfig(workspacePath: string): Promise<WorkspaceConfig> {
    const path = getConfigPath('workspace', workspacePath);
    const loader = createLoader(path);
    
    let config: Partial<WorkspaceConfig> = {};
    
    try {
      config = await loader.load<Partial<WorkspaceConfig>>(path);
      this.sources.set(`workspace:${workspacePath}`, {
        level: 'workspace',
        path,
        exists: true,
      });
    } catch {
      this.sources.set(`workspace:${workspacePath}`, {
        level: 'workspace',
        path,
        exists: false,
      });
    }

    const merged = this.merger.merge(this.globalConfig!, {
      ...config,
      path: workspacePath,
    } as WorkspaceConfig);
    
    this.workspaceConfigs.set(workspacePath, merged);
    return merged;
  }

  get<T>(path: string, workspacePath?: string): T | undefined {
    let config: Record<string, unknown> | null = null;
    
    if (workspacePath) {
      config = this.workspaceConfigs.get(workspacePath) ?? null;
    }
    
    config = config ?? this.globalConfig;
    
    if (!config) return undefined;
    
    return getValueByPath(config, path) as T | undefined;
  }

  async set(
    path: string,
    value: unknown,
    level: ConfigLevel,
    workspacePath?: string
  ): Promise<void> {
    const configPath = getConfigPath(level, workspacePath);
    const loader = createLoader(configPath);
    
    let config: Record<string, unknown> = {};
    
    try {
      config = await loader.load(configPath);
    } catch {
      // File doesn't exist, start fresh
    }
    
    const keys = path.split('.');
    let current = config;
    
    for (let i = 0; i < keys.length - 1; i++) {
      const key = keys[i];
      if (!(key in current)) {
        current[key] = {};
      }
      current = current[key] as Record<string, unknown>;
    }
    
    current[keys[keys.length - 1]] = value;
    
    await loader.save(configPath, config);
    
    await this.emitter.emit({
      type: 'config.changed',
      timestamp: Date.now(),
      payload: { key: path, oldValue: undefined, newValue: value },
    });
  }

  private getDefaultGlobalConfig(): GlobalConfig {
    return {
      version: '0.1.0',
      app: {
        name: 'AI Digital Life',
        logLevel: 'info',
        language: 'zh-CN',
        theme: 'system',
      },
      model: {
        defaultProvider: 'openai',
        defaultModel: 'gpt-4',
        apiKey: '',
        timeout: 30000,
        maxRetries: 3,
      },
      workspace: {
        autoSave: true,
        autoSaveDelay: 1000,
        maxRecentWorkspaces: 10,
      },
      security: {
        approvalMode: 'semi-auto',
        riskThresholds: {
          low: 1,
          medium: 5,
          high: 10,
        },
      },
    };
  }

  onConfigChange(
    handler: (event: { key: string; oldValue: unknown; newValue: unknown }) => void
  ): string {
    return this.emitter.on('config.changed', event => {
      handler(event.payload);
    });
  }

  off(subscriptionId: string): void {
    this.emitter.off(subscriptionId);
  }
}
```

```typescript
// tests/merger.test.ts

import { describe, it, expect } from 'vitest';
import { ConfigMerger } from '../src/merger';

describe('ConfigMerger', () => {
  const merger = new ConfigMerger();

  describe('merge', () => {
    it('should merge objects deeply', () => {
      const base = { a: { b: 1, c: 2 } };
      const override = { a: { b: 3 } };
      const result = merger.merge(base, override);
      expect(result).toEqual({ a: { b: 3, c: 2 } });
    });

    it('should handle null as deletion', () => {
      const base = { a: 1, b: 2 };
      const override = { a: null };
      const result = merger.merge(base, override);
      expect(result).toEqual({ b: 2 });
    });
  });
});
```

## 验收标准

- [ ] 支持全局/工作区/项目/文件四级配置，层级继承正确
- [ ] 深度合并策略正确：对象递归合并、数组整体替换、null删除
- [ ] 配置文件修改后1s内自动热更新生效
- [ ] 配置验证失败时不影响当前运行配置，并输出清晰错误信息
- [ ] 支持通过点号路径访问嵌套配置（如`ai.model.name`）
- [ ] 配置变更触发事件通知
