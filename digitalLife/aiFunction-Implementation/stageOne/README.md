# 第一阶段：可运行架构底座（Phase 0）

## 阶段定位

第一阶段不再只定义“基础设施模块”，而是定义一个 **可启动、可恢复、可扩展、可治理** 的桌面应用底座。

Phase 0 的目标不是提前实现完整 AI 编程能力，而是建立后续能力赖以成立的系统基础：

`启动应用 → 打开工作区 → 恢复状态 → 构建索引 → 展示日志/健康状态/审批壳层 → 安全退出与恢复`

只要这条底座路径稳定，Phase 1 的模型接入、Patch 应用、命令执行和验证闭环才有可靠承载面。

## 核心原则

- 桌面优先：充分利用本地数据与系统能力，但必须明确权限边界
- 工作区优先：一切后续 AI 行为都围绕工作区上下文展开
- 任务优先：系统未来要面向任务执行，而不是停留在对话问答
- 安全默认开启：高风险动作必须经过审批、审计和恢复机制
- 简洁精炼：第一阶段只做能支撑后续迭代的最小必要集合
- 可恢复、可观测：日志、状态、迁移、健康检查默认存在

## 第一阶段范围重定义

### Phase 0 必须完成

- 桌面应用能启动并展示基础页面
- 可以打开工作区并恢复最近工作区
- 可以持久化工作区、会话、任务、审批和日志元数据
- 可以后台构建索引并回传状态
- 可以显示健康状态、日志摘要和审批壳层
- 可以在异常退出后恢复必要状态

### Phase 0 只做骨架

- 模型接入与路由
- Prompt 工程
- 终端执行
- 文件改写与 Patch 引擎
- 智能体规划与执行控制

这些能力属于后续阶段，但第一阶段必须为它们预留稳定接口与清晰边界。

## 技术选型

### 核心技术栈

| 决策项 | 选型 | 理由 |
|--------|------|------|
| 开发语言 | TypeScript 5.3+ | 类型安全、适合多包协作 |
| 统一运行时 | Node.js LTS | Electron 生态一致，稳定性优先 |
| 应用框架 | Electron 28+ | 桌面能力成熟，安全边界明确 |
| 构建工具 | Vite + electron-builder | 开发效率和打包成熟度平衡 |
| 状态管理 | Zustand | 简洁、轻量、适合桌面 UI |
| 数据库 | SQLite + better-sqlite3 | 本地嵌入式、事务强、易恢复 |
| 日志框架 | pino | 结构化日志性能好 |
| 文件监听 | chokidar | 桌面场景可靠 |
| 密钥存储 | keytar 或系统凭据存储 | 比 `localStorage` 更合理 |

### 开发工具链

| 决策项 | 选型 | 理由 |
|--------|------|------|
| 包管理 | pnpm | 依赖隔离、Monorepo 友好 |
| Monorepo | pnpm workspace | 足够轻量，避免额外复杂度 |
| 单元测试 | Vitest | 与 TypeScript / Vite 集成顺畅 |
| E2E 测试 | Playwright | 可覆盖桌面壳层关键路径 |
| 类型检查 | tsc | 基本质量门槛 |
| 静态检查 | ESLint | 统一工程规范 |
| 代码格式化 | Prettier | 降低协作摩擦 |

## 总体验收标准

### 架构与工程

- [ ] 模块边界清晰，无循环依赖
- [ ] 进程边界清晰，Renderer 不具备高危系统能力
- [ ] IPC 通道类型化且最小化暴露
- [ ] 工程骨架能承载后续包扩展

### 运行与恢复

- [ ] 应用可启动、可关闭、可恢复最近工作区
- [ ] 初始化失败时有可读错误反馈
- [ ] 崩溃或异常退出后可恢复必要元数据
- [ ] Worker 异常可被感知和处理

### 基础设施

- [ ] 配置、日志、错误恢复、存储可用
- [ ] 工作区、会话、索引、任务与审批链路可运行
- [ ] 敏感数据不会以明文落盘
- [ ] 数据 Schema 和迁移策略明确

### 测试与质量

- [ ] 核心基础设施模块有单元测试
- [ ] IPC、启动恢复、工作区打开、索引启动有集成测试
- [ ] 影响安全与恢复的能力有端到端验证

## 进入 Phase 1 的门槛

只有当以下条件满足时，才应该进入交互式 MVP：

1. 桌面壳层稳定。
2. 工作区和会话恢复稳定。
3. 索引服务可在后台可靠运行。
4. 审批、日志、存储、错误恢复链路稳定。
5. 关键基础数据结构和迁移策略已经固定。

## 结论

第一阶段的正确目标不是“先把一些基础模块列出来”，而是 **建立一个真正能跑起来、能恢复、能扩展、能守住安全边界的桌面应用地基**。这是后续 AI 数字生命所有功能的承重墙。
