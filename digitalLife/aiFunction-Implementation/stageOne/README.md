## 技术选型

| 决策项 | 选型 | 理由 |
|--------|------|------|
| 开发语言 | TypeScript 5.3+ | 类型安全、IDE友好 |
| 应用框架 | Electron 28+ | 成熟的跨平台桌面应用方案 |
| 构建工具 | Vite + electron-builder | Vite极速HMR，electron-builder成熟打包 |
| 状态管理 | Zustand | 轻量、TypeScript友好、无模板代码 |
| 包管理 | pnpm | 严格依赖隔离，monorepo友好 |
| 日志框架 | pino | Node.js生态性能最优的结构化日志库 |
| 配置格式 | YAML（主）+ JSON（兼容） | YAML可读性好支持注释，JSON兼容性广 |
| 数据库 | SQLite | 查询灵活、事务支持、嵌入式 |

## 验收标准

### 架构阶段总体验收

- [ ] 模块边界明确，无循环依赖
- [ ] 配置、日志、恢复、检查点可用
- [ ] 所有核心模块有单元测试
- [ ] 影响执行安全的模块有集成测试

### 功能验收清单

1. **基础工具类库**
   - [ ] Result/Option类型可用
   - [ ] 防抖、节流、重试工具函数可用
   - [ ] 路径处理工具函数可用

2. **事件系统**
   - [ ] 发布/订阅模式正常工作
   - [ ] 优先级排序正确
   - [ ] 单事件分发延迟 < 0.1ms

3. **配置管理**
   - [ ] 四级配置层级继承正确
   - [ ] 配置文件修改后1s内自动热更新
   - [ ] 配置验证失败时不影响当前运行配置

4. **持久化与缓存**
   - [ ] 重启后能恢复必要工作区与会话状态
   - [ ] 缓存失效不会导致错误结果长期存在
   - [ ] 敏感数据不会以明文形式落盘

5. **日志系统**
   - [ ] 日志按级别正确输出
   - [ ] 日志文件按策略轮转
   - [ ] 日志写入不阻塞主线程

6. **错误处理**
   - [ ] 四类错误分类正确
   - [ ] 错误边界隔离有效
   - [ ] 重试策略按配置执行

7. **工作区管理**
   - [ ] 能正确识别项目根目录并绑定配置
   - [ ] 重启应用后可恢复最近工作区与会话摘要
   - [ ] patch应用前后能创建和切换检查点

8. **索引与检索**
   - [ ] 中型仓库可在可接受时间内完成首次索引
   - [ ] 文件修改后索引可增量更新
   - [ ] 能生成适合模型消费的仓库地图摘要

9. **任务与审批**
   - [ ] 任务创建后状态正确流转
   - [ ] 高风险操作正确触发审批流程
   - [ ] 任务执行失败可回滚

10. **数据迁移**
    - [ ] 可自动检测新版本并提示用户
    - [ ] 升级前自动备份用户数据
    - [ ] 迁移失败时可自动回滚

## 工程基线

- 所有核心模块必须有单元测试
- 影响执行安全的模块必须有集成测试
- 任何新增自动执行能力都必须补审计与回滚设计
- 任何新能力进入MVP前，都要明确"失败时如何停下并恢复"
