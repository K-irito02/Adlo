# 设置与配置页面 UI 元素

> 对应模块: [03-配置管理系统](../stageOne/03-配置管理系统.md)
>
> 配置层级: Global → Workspace → Project
>
> IPC 通道: `config.get` / `config.set` / `config.listSources`

## 1. 设置页布局

### 1.1 页面结构

```
┌──────────────────────────────────────────────────────┐
│  设置                                                │
├──────────┬───────────────────────────────────────────┤
│          │                                           │
│ 设置分类  │           配置内容区                       │
│ 侧边栏   │          (Config Content)                 │
│ (Tabs)   │                                           │
│          │                                           │
│ · 通用    │                                           │
│ · 外观    │                                           │
│ · 工作区  │                                           │
│ · 模型    │                                           │
│ · 安全    │                                           │
│ · 索引    │                                           │
│ · 高级    │                                           │
│ · 关于    │                                           │
│          │                                           │
├──────────┴───────────────────────────────────────────┤
│  [重置为默认]                        [保存更改]       │
└──────────────────────────────────────────────────────┘
```

## 2. 通用设置

### 2.1 语言与区域

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 界面语言 | Select | zh-CN / en-US / ja-JP 等 | `app.language` |

### 2.2 日志配置

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 日志级别 | Select | DEBUG / INFO / WARN / ERROR / SILENT | `app.logLevel` |
| 日志目录 | Text (Readonly) + [浏览] | 日志文件存储路径 | Logger 初始化参数 |
| 最大日志文件大小 | Input (Number) + Unit | 单个日志文件上限（默认 10MB） | FileTransport.maxSize |
| 最大日志文件数 | Input (Number) | 保留的日志文件数量（默认 30） | FileTransport.maxFiles |
| 压缩旧日志 | Toggle | 是否 gzip 压缩历史日志 | FileTransport.compress |

## 3. 外观设置

### 3.1 主题

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 主题模式 | RadioGroup / CardGroup | 选择界面主题 | `app.theme` |
| └ 浅色主题 | RadioCard | 浅色背景，深色文字 | value: "light" |
| └ 深色主题 | RadioCard | 深色背景，浅色文字 | value: "dark" |
| └ 跟随系统 | RadioCard | 自动匹配操作系统主题 | value: "system" |
| 主题预览 | PreviewPanel | 实时预览当前主题效果 | - |

### 3.2 字体与显示（基础）

> Phase 0 仅提供最小字体设置，复杂排版延后

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 界面字体大小 | Slider + Label | 基础字号调节（Small / Medium / Large） | 预留 |
| 代码字体 | Select | 代码块使用的等宽字体族 | 预留 |

## 4. 工作区设置

### 4.1 通用工作区行为

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 自动保存 | Toggle | 工作区状态自动保存开关 | `workspace.autoSave` |
| 自动保存延迟 | Input (Number) + Unit(ms) | 状态变更后多久自动保存 | `workspace.autoSaveDelay` |
| 最近工作区上限 | Input (Number) | 保留的最近工作区记录数 | `workspace.maxRecentWorkspaces` |
| 启动时恢复上次工作区 | Toggle | 应用启动时是否自动打开上次工作区 | 预留 |

### 4.2 当前工作区配置

**注意**: 以下配置属于 workspace 级别，仅在打开工作区时可编辑

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 工作区名称 | Input | 自定义工作区显示名 | `WorkspaceConfig.name` |
| Git 集成 | Toggle | 启用/禁用 Git 状态检测 | `WorkspaceConfig.git.enabled` |
| Git 自动提交 | Toggle | 自动 git commit（Phase 1 实现） | `WorkspaceConfig.git.autoCommit` |
| 提交消息模板 | Input (Text, Placeholder) | 默认 commit message 格式 | `WorkspaceConfig.git.commitMessage` |

## 5. 模型配置（预留入口）

> Phase 0 不接入模型，但需要预留配置 UI 为 Phase 1 准备

### 5.1 模型提供商设置

| 元素 | 类型 | 说明 | 配置路径 | 条件 |
|------|------|------|----------|------|
| 模型配置区标题 | Text (Muted) | "模型配置（即将推出）" | - | - |
| 默认提供商 | Select | OpenAI / Anthropic / 本地模型 等 | `model.defaultProvider` | Phase 1 可用 |
| 默认模型 | Select | gpt-4 / claude-3 等 | `model.defaultModel` | Phase 1 可用 |
| API Key 输入 | Input (Password) | API 密钥输入框（掩码显示） | `model.apiKey` | Phase 1 可用 |
| API Key 显示/隐藏 | IconButton (👁️) | 切换密钥明文/掩码 | - | 有输入时 |
| Base URL | Input (URL, Optional) | 自定义 API 端点 | `model.baseUrl` | Phase 1 可用 |
| 请求超时 | Input (Number) + Unit(ms) | API 请求超时时间 | `model.timeout` | Phase 1 可用 |
| 最大重试次数 | Input (Number) | 失败后的重试次数 | `model.maxRetries` | Phase 1 可用 |
| **[测试连接]** 按钮 | Button (Secondary) | 验证 API Key 和连接有效性 | - | Phase 1 可用 |

**Phase 0 表现**: 模型配置区以 **置灰/禁用** 状态展示，附带提示 "此功能将在 Phase 1 中启用"

## 6. 安全设置

### 6.1 审批模式

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 审批模式标题 | Heading | "审批模式" | - |
| 模式说明 | DescriptionText | 解释每种模式的行为差异 | - |
| 模式选择器 | SegmentedControl | auto / semi-auto / manual | `security.approvalMode` |
| └ 自动模式 | Option | 低风险操作自动通过 | value: "auto" |
| └ 半自动模式 | Option | 所有操作弹窗提示可一键批准 | value: "semi-auto" |
| └ 手动模式 | Option | 所有操作必须用户逐一确认 | value: "manual" |

### 6.2 风险阈值

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 阈值标题 | Heading | "风险等级阈值" | - |
| 阈值说明 | DescriptionText | 数值越高表示风险容忍度越高 | - |
| 低风险阈值 | Slider + NumberInput | 触发低风险警告的操作分值下限 | `security.riskThresholds.low` |
| 中风险阈值 | Slider + NumberInput | 触发中风险警告的操作分值下限 | `security.riskThresholds.medium` |
| 高风险阈值 | Slider + NumberInput | 触发高风险强制审批的分值下限 | `security.riskThresholds.high` |
| 阈值预览条 | VisualBar | 三段颜色编码的可视化阈值条 | - |
| **[恢复默认阈值]** 按钮 | Button (Ghost) | 重置为系统默认值 | - |

### 6.3 数据安全

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 敏感数据存储位置 | InfoCard | 显示密钥存储方式（keytar / safeStorage / 系统） | 只读信息 |
| 数据目录位置 | Text (Monospace) + [打开] | 应用数据存储目录路径 | - |
| **[打开数据目录]** 按钮 | Button (Ghost) | 在文件管理器中打开 | - |
| **[导出全部配置]** 按钮 | Button (Secondary) | 导出所有配置为 YAML 文件（敏感值脱敏） | - |
| **[导入配置]** 按钮 | Button (Secondary) | 从 YAML 文件导入配置 | - |

## 7. 索引设置

### 7.1 索引行为

| 元素 | 类型 | 说明 | 配置路径 |
|------|------|------|----------|
| 启用索引 | Toggle | 打开工作区后是否自动构建索引 | `WorkspaceConfig.indexing.enabled` |
| 排除规则 | TagInput | 忽略的文件/目录模式列表 | `WorkspaceConfig.indexing.excludePatterns` |
| 包含规则 | TagInput | 显式包含的文件模式（覆盖排除） | `WorkspaceConfig.indexing.includePatterns` |
| 最大文件大小 | Input (Number) + Unit(KB/MB) | 超过此大小的文件不索引 | `WorkspaceConfig.indexing.maxFileSize` |
| **[编辑排除规则]** 按钮 | Button (Ghost) | 打开 .ai-digital-life 的 ignore 配置 | - |
| 预设排除模板 | ButtonGroup | 快速应用常见排除规则: node_modules / .git / dist / *.min.* | - |

## 10. 设置页通用元素

### 10.1 配置层级指示

| 元素 | 类型 | 说明 |
|------|------|------|
| 层级标签 | Breadcrumb / Tab | 全局配置 / 工作区配置 / 项目配置 |
| 层级说明 | HintText | "全局配置对所有工作区生效" / "仅对当前工作区生效" |
| 配置来源指示 | SourceTag | 标注每个配置项的实际来源层级 |
| 覆盖提示 | OverrideHint | 当低层级配置被高层级覆盖时的提示 |

### 10.2 配置变更状态

| 元素 | 类型 | 说明 |
|------|------|------|
| 未保存提示 | Badge | "有未保存的更改" |
| **[保存更改]** 按钮 | Button (Primary, Fixed Bottom) | 保存所有修改的配置项 |
| **[放弃更改]** 按钮 | Button (Ghost) | 放弃未保存的修改 |
| **[重置为默认]** 按钮 | Button (Danger, Ghost) | 将当前分类的所有配置恢复为默认值 |
| 保存成功提示 | Toast | "配置已保存" |
| 保存失败提示 | Toast (Error) | "配置保存失败: {错误原因}" |

### 10.3 配置校验反馈

| 元素 | 类型 | 说明 |
|------|------|------|
| 字段级错误 | InlineError | 输入框下方红色错误文本 |
| 字件级警告 | InlineWarning | 输入框下方黄色警告文本 |
| 校验通过标记 | CheckIcon (Green) | 字段右侧绿色勾选 |
| 实时校验 | Validation | 失焦或输入时即时校验 |
