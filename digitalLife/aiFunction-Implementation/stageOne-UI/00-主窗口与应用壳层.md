## 2. 启动与欢迎流程

### 2.1 欢迎页 / 工作区选择页

**场景**: 应用启动后无活跃工作区时展示

| 元素 | 类型 | 说明 | 行为 |
|------|------|------|------|
| 应用 Logo | Image | 大尺寸品牌标识 | 静态展示 |
| 欢迎标题 | Text | "欢迎使用 AI Digital Life" | 静态展示 |
| 副标题 | Text | "选择或创建一个工作区开始" | 静态展示 |
| **[打开工作区...] 按钮** | Button (Primary) | 触发原生目录选择对话框 | 调用 `workspace.open` IPC |
| **[新建工作区...] 按钮** | Button (Secondary) | 创建新项目目录（延后） | 置灰/隐藏（Phase 0 不实现） |
| 最近工作区区域 | Card List | 展示最近打开的工作区卡片 | 点击调用 `workspace.open` |
| └ 工作区卡片 | Card | 包含: 路径、名称、上次打开时间、Git分支、状态标签 | 可点击打开 |
| └ └ 卡片删除按钮 | IconButton (X) | 从最近列表移除 | 仅移除记录，不删文件 |
| └ └ 状态标签 | Badge | ready / indexing / error / degraded | 颜色编码状态 |

### 2.2 启动恢复检测

**场景**: 检测到上次异常退出

| 元素 | 类型 | 说明 | 行为 |
|------|------|------|------|
| 恢复提示横幅 | Alert/Banner | "检测到上次异常退出，是否恢复工作区状态？" | 顶部固定提示 |
| **[恢复上次状态]** 按钮 | Button (Primary) | 恢复最近会话和工作区 | 执行恢复流程 |
| **[忽略并继续]** 按钮 | Button (Secondary) | 以干净状态启动 | 清除崩溃标记 |
| 崩溃详情展开按钮 | Toggle | 显示崩溃原因摘要 | 展开/收起详情文本 |

## 3. 主布局结构

### 3.1 整体布局

```
┌──────────────────────────────────────────────────────┐
│  标题栏 (Title Bar)                                   │
├──────────┬───────────────────────────────────────────┤
│          │                                           │
│ 侧边栏   │           主内容区                         │
│ (Sidebar)│          (Content Area)                    │
│          │                                           │
│          │                                           │
├──────────┴───────────────────────────────────────────┤
│  状态栏 (Status Bar)                                  │
└──────────────────────────────────────────────────────┘
```

### 3.2 侧边导航栏

| 元素 | 类型 | 图标 | 说明 | 目标页面 |
|------|------|------|------|----------|
| 导航 Logo | Image | - | 折叠态显示小图标 | - |
| **首页/概览** | NavItem | 🏠 House | 工作区总览 + 健康仪表盘 | DashboardPage |
| **工作区** | NavItem | 📁 Folder | 工作区信息与会话管理 | WorkspacePage |
| **检索状态** | NavItem | 🔍 Search | 索引进度与仓库地图 | RetrievalPage |
| **任务中心** | NavItem | ✅ TaskList | 任务列表与审批队列 | TaskPage |
| **日志查看器** | NavItem | 📋 FileText | 结构化日志查看 | LogViewerPage |
| **设置** | NavItem | ⚙️ Settings | 全局配置与管理 | SettingsPage |
| 分隔线 | Separator | - | 导航分组 | - |
| 侧边栏折叠按钮 | Toggle | ◀► | 展开/折叠侧边栏 | - |

### 3.3 状态栏

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 工作区名称 | Text | 当前工作区名（可点击） | `workspace.current` |
| Git 分支 | Badge | 当前 Git 分支名 | `workspace.gitSnapshot.branch` |
| 索引状态 | StatusDot+Text | idle/indexing/ready/error | `index.getStatus` |
| Worker 状态 | StatusDot+Text | 运行中/已停止/异常 | `app.getHealth` |
| 内存占用 | Text | 格式化内存使用量 | `performanceMonitor.getMemoryUsage` |
| 版本号 | Text | `v0.1.0`（悬停显示完整版本） | `app.getInfo` |

## 4. 页面容器

### 4.1 通用页面骨架

每个内容页面的公共元素：

| 元素 | 类型 | 说明 |
|------|------|------|
| 页面标题 | Heading | 当前页面名称 |
| 页面操作栏 | Toolbar | 页面级别的操作按钮组 |
| 内容滚动区 | ScrollArea | 支持滚动的主体内容 |
| 页面级加载态 | Skeleton/Spinner | 数据加载中的占位 |
| 页面级空状态 | EmptyState | 无数据时的引导提示 |
| 页面级错误态 | ErrorFallback | 出错时的重试入口 |

## 5. 全局弹窗与对话框

### 5.1 关于对话框

| 元素 | 类型 | 说明 |
|------|------|------|
| 应用名称 | Text (Large) | "AI Digital Life" |
| 版本号 | Text | "v0.1.0 (Phase 0)" |
| Electron 版本 | Text | 底层运行时版本 |
| Node.js 版本 | Text | Node.js LTS 版本 |
| 许可证链接 | Link | 开源许可证信息 |
| **[确定]** 按钮 | Button | 关闭对话框 |

### 5.2 确认对话框（通用）

| 元素 | 类型 | 说明 |
|------|------|------|
| 图标 | Icon | warning / danger / info 三种类型 |
| 标题 | Text | 操作确认标题 |
| 描述文本 | Text | 详细说明操作后果 |
| 危险操作确认输入框 | Input | 高危操作需手动输入确认文字（如 "DELETE"） |
| **[取消]** 按钮 | Button (Secondary) | 取消操作 |
| **[确认]** 按钮 | Button (Primary/Danger) | 执行操作 |

### 5.3 更新提示对话框

| 元素 | 类型 | 说明 |
|------|------|------|
| 新版本号 | Text | "发现新版本 v0.2.0" |
| 更新内容列表 | List | 变更日志摘要 |
| **[稍后提醒]** 按钮 | Button (Secondary) | 跳过本次更新 |
| **[立即更新]** 按钮 | Button (Primary) | 下载并安装更新 |

## 6. 安全边界相关 UI 表现

### 6.1 权限不足提示

当 Renderer 尝试访问未授权能力时：

| 元素 | 类型 | 说明 |
|------|------|------|
| 权限错误提示 | Toast/Alert | "此操作需要更高权限级别" |
| 申请权限按钮 | Button (可选) | 向用户申请提升权限（如审批模式切换） |

### 6.2 安全模式指示

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 安全模式角标 | Banner | "当前运行在受限模式" | 检测到沙箱异常或权限降级时 |
