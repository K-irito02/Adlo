# 日志与监控面板 UI 元素

> 对应模块: [05-日志与监控系统](../stageOne/05-日志与监控系统.md)
>
> IPC 通道: `log.tail` / `log.search` / `app.getHealth`

## 1. 日志查看器

### 1.1 页面布局

```
┌──────────────────────────────────────────────────────┐
│  日志查看器          [级别筛选] [模块筛选] [搜索] [实时] │
├──────────────────────────────────────────────────────┤
│  ┌─ 工具栏 ──────────────────────────────────────┐   │
│  │ 日志级别 | 模块过滤 | 时间范围 | 搜索 | 导出    │   │
│  └────────────────────────────────────────────────┘   │
│                                                      │
│  ┌─ 日志列表区域 ─────────────────────────────────┐   │
│  │ [2024-01-15 10:23:45] INFO  [workspace] ...   │   │
│  │ [2024-01-15 10:23:46] DEBUG [retrieval] ...    │   │
│  │ [2024-01-15 10:23:47] ERROR [task]     ...     │   │
│  │ [2024-01-15 10:23:48] WARN  [config]   ...     │   │
│  │ ...                                            │   │
│  └────────────────────────────────────────────────┘   │
│                                                      │
│  ┌─ 详情面板（可折叠）────────────────────────────┐   │
│  │ 选中日志条目的完整 JSON 详情                     │   │
│  └────────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
```

### 1.2 日志工具栏

| 元素 | 类型 | 说明 |
|------|------|------|
| **实时跟踪开关** | Toggle (Switch) | 开启后自动滚动到最新日志，新日志实时流入 |
| 自动滚动锁定 | Button (Icon) | 当用户向上查看历史时暂停自动滚动，点击恢复 |
| **[清空显示]** 按钮 | Button (Ghost) | 清空当前视图中的日志（不清除文件） |
| **[导出日志]** 按钮 | Button (Secondary) | 将当前过滤结果导出为文件 |

#### 级别过滤器

| 元素 | 类型 | 说明 |
|------|------|------|
| 级别选择组 | CheckboxGroup / TagGroup | 多选过滤 |
| └ DEBUG | ToggleTag | 调试信息（灰色） |
| └ INFO | ToggleTag | 一般信息（绿色） |
| └ WARN | ToggleTag | 警告（黄色） |
| └ ERROR | ToggleTag | 错误（红色） |
| 快捷按钮: 仅错误 | Button | 一键只显示 ERROR 级别 |
| 快捷按钮: 全部 | Button | 一键选择所有级别 |

#### 模块过滤器

| 元素 | 类型 | 说明 |
|------|------|------|
| 模块下拉选择 | MultiSelect / Combobox | 选择一个或多个模块来源 |
| 预设模块选项 | Option | app / workspace / retrieval / task / config / storage / migration / indexer / error-boundary / main / worker |
| 自定义模块输入 | Input | 输入自定义模块名进行模糊匹配 |

#### 时间范围过滤

| 元素 | 类型 | 说明 |
|------|------|------|
| 时间范围选择 | SegmentedControl / Select | 最近 15分钟 / 1小时 / 6小时 / 24小时 / 自定义范围 |
| 开始时间 | DateTimePicker | 自定义起始时间 |
| 结束时间 | DateTimePicker | 自定义结束时间 |

#### 搜索

| 元素 | 类型 | 说明 |
|------|------|------|
| 搜索输入框 | Input | 支持关键词搜索日志消息内容 |
| 正则开关 | Toggle | 切换普通搜索 / 正则表达式搜索 |
| 搜索高亮 | HighlightText | 在日志内容中高亮匹配文本 |
| 匹配计数 | Text | "找到 N 条匹配" |

### 1.3 日志条目列表

每条日志条目的展示元素:

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 时间戳 | Text (Monospace) | ISO 格式时间 | `LogEntry.timestamp` |
| 级别标签 | Badge | DEBUG(灰) / INFO(绿) / WARN(黄) / ERROR(红) | `LogEntry.levelName` |
| 模块名 | Text (Monospace) | 来源模块标识 | `LogEntry.module` |
| 消息内容 | Text | 日志主要消息 | `LogEntry.message` |
| 展开箭头 | Chevron | 点击展开详情 | - |
| 上下文数据预览 | Text (Muted, Small) | 关键 context 字段的摘要 | `LogEntry.context` |
| 耗时标签 | Badge (Optional) | 操作耗时 | `LogEntry.duration` |

**行颜色编码**: 根据日志级别使用微妙的背景色区分

**ERROR 行特殊展示**:
- 默认展开状态
- 显示错误名称和堆栈预览
- 更醒目的背景色

### 1.4 日志详情面板

**触发**: 点击日志条目展开

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 完整时间戳 | Text | 含毫秒的完整时间 | `LogEntry.timestamp` |
| 级别 | Badge | 大尺寸级别标签 | `LogEntry.levelName` |
| 模块 | Text | 完整模块路径 | `LogEntry.module` |
| 消息 | Text (Pre) | 完整消息文本 | `LogEntry.message` |
| 上下文数据 | JSONView (Collapsible) | 结构化的上下文对象 | `LogEntry.context` |
| 错误信息面板 | Panel (Conditional) | 仅 ERROR 级别显示 | `LogEntry.error` |
| └ 错误名称 | Text | Error 类名 | `LogEntry.error.name` |
| └ 错误消息 | Text | 错误描述 | `LogEntry.error.message` |
| └ 堆栈跟踪 | CodeBlock | 完整堆栈（可复制） | `LogEntry.error.stack` |
| 耗时 | Text | 执行耗时毫秒数 | `LogEntry.duration` |
| **[复制 JSON]** 按钮 | Button (Ghost) | 复制该条日志的完整 JSON 到剪贴板 |
| **[复制堆栈]** 按钮 | Button (Ghost) | 仅复制错误堆栈 | 有错误信息时 |

### 1.5 日志分页与加载

| 元素 | 类型 | 说明 |
|------|------|------|
| 加载更多触发区 | ScrollTrigger | 滚动到底部自动加载更早的日志 |
| 加载中指示 | Spinner | 正在加载更多日志 |
| 已到达最底提示 | Text | "已显示全部日志" |
| 总条数统计 | Text | "当前显示 N / 共 M 条" |

## 2. 系统健康仪表盘

### 2.1 健康状态总览卡片

**位置**: 可作为独立页面 或 首页/Dashboard 的核心区域

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 整体健康评分 | HealthScore | 0~100 分的圆形/线性指标 | 综合计算 |
| 健康状态文字 | StatusText | "健康" / "警告" / "异常" / "严重" | 根据评分分段 |
| 上次检查时间 | Text | "最后更新: 2秒前" | 自动刷新间隔 |

**健康评分分段:**

| 分数段 | 状态 | 颜色 | 说明 |
|--------|------|------|------|
| 90~100 | 健康 | 🟢 绿色 | 所有系统正常运行 |
| 70~89 | 警告 | 🟡 黄色 | 存在非关键性问题 |
| 50~69 | 异常 | 🟠 橙色 | 部分功能受损 |
| 0~49 | 严重 | 🔴 红色 | 关键组件故障 |

### 2.2 子系统健康状态网格

| 元素 | 类型 | 图标 | 说明 | 数据来源 |
|------|------|------|------|----------|
| 应用进程 | HealthCard | ⚙️ | Main 进程运行状态 | 进程存活检测 |
| 渲染进程 | HealthCard | 🖥️ | Renderer 进程状态 | 心跳检测 |
| Worker 进程 | HealthCard | 🔧 | 后台 Worker 状态 | Worker 心跳 |
| 数据库连接 | HealthCard | 💾 | SQLite 连接健康度 | 连接池状态 |
| 文件系统 | HealthCard | 📁 | 数据目录可读写性 | 磁盘空间 + 权限 |
| 工作区连接 | HealthCard | 📂 | 当前工作区可达性 | 路径有效性 |
| 索引服务 | HealthCard | 🔍 | 索引服务状态 | IndexStatus |
| 配置系统 | HealthCard | ⚙️ | 配置加载与校验状态 | ConfigManager |

每个 HealthCard 包含:

| 子元素 | 类型 | 说明 |
|--------|------|------|
| 组件名称 | Text | 子系统名称 |
| 状态指示灯 | StatusDot | 🟢正常 / 🟡降级 / 🔴异常 |
| 状态描述 | Text | 一句话状态说明 |
| 最后检查时间 | Text | 相对时间 |
| **[详情]** 按钮 | Ghost | 展开该子系统的详细诊断信息 |

### 2.3 性能监控面板

#### 资源使用情况

| 元素 | 类型 | 图标 | 说明 | 数据来源 |
|------|------|------|------|----------|
| 内存使用量 | MetricCard | 💾 | 当前内存占用 | `performanceMonitor.getMemoryUsage()` |
| └ RSS 数值 | Text | 常驻内存集大小 | `memoryUsage.rss` |
| └ Heap 数值 | Text | V8 堆内存使用 | `memoryUsage.heapUsed / heapTotal` |
| └ 堆使用率 | ProgressBar | heapUsed / heapTotal 百分比 | 计算值 |
| └ External 数值 | Text | C++ 绑定对象内存 | `memoryUsage.external` |
| CPU 使用率 | MetricChart | 📊 | 实时 CPU 占用率折线图 | `performanceMonitor.getCpuUsage()` |
| 事件循环延迟 | MetricChart | ⏱️ | Event Loop 延迟趋势图 | 性能钩子采集 |
| 活跃句柄数 | StatCard | 🔗 | 当前活跃 Handle 数量 | `process.getActiveResourcesInfo()` |

#### 性能指标历史

| 元素 | 类型 | 说明 |
|------|------|------|
| 时间范围选择 | SegmentedControl | 最近 5分钟 / 15分钟 / 1小时 |
| 图表类型切换 | Tab | 折线图 / 面积图 |
| 刷新频率 | Text | "每 5 秒刷新" |
| **[暂停刷新]** 按钮 | Button (Ghost) | 暂停实时数据更新 |

### 2.4 自定义性能指标

> Phase 0 基础版仅提供内置指标，此为扩展预留

| 元素 | 类型 | 说明 |
|------|------|------|
| 自定义指标列表 | Table | 用户注册的自定义性能指标 |
| 添加指标按钮 | Button | 注册新的性能观察点（预留） |

## 3. 通知与告警中心

### 3.1 系统通知列表

| 元素 | 类型 | 说明 |
|------|------|------|
| 通知铃铛图标 | IconButton (Header) | 全局通知入口，带未读数角标 |
| 通知列表 | NotificationList | 所有系统通知的时间线 |

#### 通知项

| 元素 | 类型 | 说明 |
|------|------|------|
| 通知图标 | Icon | info / warning / error / success |
| 通知标题 | Text | 通知标题 |
| 通知正文 | Text | 通知详细内容 |
| 通知时间 | Text (Relative) | 发出时间 |
| 已读/未读状态 | UnreadIndicator | 未读项高亮显示 |
| 操作按钮 | ButtonGroup | 查看 / 忽略 / 关联跳转 |
| **[全部已读]** 按钮 | Button (Ghost) | 一键标记所有通知为已读 |
| **[清空]** 按钮 | Button (Ghost) | 清除所有已读通知 |

### 3.2 告警规则（预留）

Phase 0 不实现复杂告警引擎，但应预留 UI 入口:

| 元素 | 类型 | 说明 |
|------|------|------|
| 告警设置入口 | SettingsLink | "告警配置 →" 跳转至设置页 |
| 当前活跃告警 | AlertBanner | 内存超限 / CPU 过高 / 磁盘不足 等即时警告 |

## 4. 日志文件管理

### 4.1 日志文件信息

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 当前日志文件 | Text | 活跃日志文件名 | FileTransport |
| 日志文件大小 | Text | 当前文件大小 | 文件 stat |
| 日志目录 | Text (Link) | 日志存储目录路径 | Logger 配置 |
| **[打开日志目录]** 按钮 | Button (Ghost) | 在系统文件管理器中打开日志目录 | 调用 shell.showItemInFolder |
| 日志轮转历史 | List | 已归档的历史日志文件列表 | 目录扫描 |
| └ 文件名 | Text | 归档文件名（含时间戳） |
| └ 文件大小 | Text | 文件大小 |
| └ 创建时间 | Text | 归档时间 |
| └ **[下载]** 按钮 | Button (Ghost) | 下载单个日志文件 |
| └ **[删除]** 按钮 | Button (Danger, Ghost) | 删除归档文件（需确认） |
