# 错误处理与恢复 UI 元素

> 对应模块: [06-错误处理与恢复机制](../stageOne/06-错误处理与恢复机制.md)
>
> 错误分类: System / Network / AI / User

## 1. 错误通知系统

### 1.1 Toast 通知（瞬时错误）

**适用场景**: 非阻塞、可自动消失的轻量级错误提示

| 元素 | 类型 | 说明 |
|------|------|------|
| 通知容器 | ToastContainer | 屏幕右上角（或底部）固定区域 |
| 通知卡片 | Toast | 单条通知 |

#### 通知卡片元素

| 子元素 | 类型 | 说明 |
|--------|------|------|
| 图标 | Icon | ✅ success / ❌ error / ⚠️ warning / ℹ️ info |
| 标题 | Text | 错误简短标题（一行） |
| 描述 | Text (Optional) | 可选的详细描述（最多两行） |
| 关闭按钮 | IconButton (X) | 手动关闭通知 |
| 操作按钮 | Button (Optional, Ghost) | 如 "重试" / "查看详情" |
| 进度条 | ProgressBar | 自动关闭倒计时指示器 |
| 进入/退出动画 | Animation | 滑入滑出效果 |

**Toast 级别样式:**

| 级别 | 背景色 | 图标 | 自动关闭时间 | 示例场景 |
|------|--------|------|--------------|----------|
| Success | 绿色 | ✅ | 3s | 操作成功完成 |
| Info | 蓝色 | ℹ️ | 4s | 一般信息提示 |
| Warning | 黄色 | ⚠️ | 5s | 非关键性警告 |
| Error | 红色 | ❌ | 不自动关闭 | 操作失败需关注 |

### 1.2 全局错误横幅（持续性错误）

**适用场景**: 影响全局或当前页面功能的持续性错误

| 元素 | 类型 | 说明 |
|------|------|------|
| 横幅容器 | Banner | 页面顶部固定区域 |
| 横幅图标 | Icon | ⚠️ / ❌ / 🔒 |
| 横幅标题 | Text | 错误类型标题 |
| 横幅描述 | Text | 错误影响说明 |
| **[查看详情]** 按钮 | Button (Ghost) | 打开错误详情对话框 |
| **[忽略]** 按钮 | Button (Ghost) | 关闭横幅（本次会话不再显示） |
| **[修复]** 按钮 | Button (Primary) | 触发修复操作（如有） |
| 关闭按钮 | IconButton (X) | 关闭横幅 |

## 2. 错误详情对话框

### 2.1 标准错误报告视图

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 对话框标题 | Text | "错误详情" |
| 报告 ID | Text (Monospace, Small) | 唯一错误标识 | `ErrorReport.id` |
| 错误时间 | DateTimeText | 错误发生时间 | `ErrorReport.timestamp` |

#### 错误基本信息

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 错误名称 | Badge (Large) | 错误类名 | `ErrorReport.error.name` |
| 错误代码 | Badge (Monospace) | 错误码如 E1001 / E2001 | `ErrorInfo.code` |
| 错误类别 | Badge | system / network / ai / user | `ErrorInfo.category` |
| 严重程度 | Badge | low / medium / high / critical | `ErrorInfo.severity` |
| 错误消息 | Text (Pre) | 完整错误消息 | `ErrorReport.error.message` |
| 堆栈跟踪 | CodeBlock (Collapsible) | 可展开的错误堆栈 | `ErrorReport.error.stack` |

#### 错误上下文

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 触发模块 | Text | 发生错误的模块 | `ErrorReport.context.module` |
| 触发操作 | Text | 正在执行的操作 | `ErrorReport.context.operation` |
| 附加上下文 | JSONView (Collapsible) | 结构化附加信息 | `ErrorReport.context` |

#### 系统环境快照

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 操作系统 | Text | platform 信息 | `ErrorReport.system.platform` |
| Node 版本 | Text | Node.js 版本 | `ErrorReport.system.version` |
| 内存快照 | Text | 错误时的内存使用量 | `ErrorReport.system.memory` |

#### 用户反馈区

| 元素 | 类型 | 说明 |
|------|------|------|
| 用户备注输入框 | TextArea | 用户可补充错误发生时的操作步骤 |
| **[复制报告]** 按钮 | Button (Secondary) | 复制完整 JSON 报告到剪贴板 |
| **[导出报告]** 按钮 | Button (Secondary) | 导出为 .json 文件 |
| **[发送反馈]** 按钮 | Button (Primary) | 提交错误报告（预留，Phase 0 仅本地存储） |
| **[关闭]** 按钮 | Button (Secondary) | 关闭对话框 |

### 2.2 分类错误专用视图

#### 系统错误 (SystemError)

额外展示:

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 文件系统错误路径 | Text (Monospace) | 涉及的文件路径 | code = E1001 |
| 进程信息 | Text | 相关进程 PID 等 | code = E1002 |
| 内存状态 | MetricBar | 当前内存占用比例 | code = E1003 |
| 配置项位置 | Text | 有问题的配置文件和行号 | code = E1004 |
| **[检查磁盘空间]** 按钮 | Button (Ghost) | 文件系统相关错误的快捷诊断 | - |
| **[重启应用]** 按钮 | Button (Warning) | 进程或内存错误的恢复选项 | - |

#### 网络错误 (NetworkError)

额外展示:

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 目标 URL | Text (Link) | 请求的目标地址 | 所有网络错误 |
| 连接超时设置 | Text | 当前超时配置值 | code = E2002 |
| DNS 信息 | Text | 解析失败的域名 | code = E2003 |
| SSL 详情 | Text | 证书相关信息 | code = E2004 |
| **[测试网络连接]** 按钮 | Button (Ghost) | 网络连通性快速检测 | - |
| **[更改代理设置]** 按钮 | Button (Ghost) | 跳转到代理配置（预留） | - |
| **[重试请求]** 按钮 | Button (Primary) | 重新发起失败的网络请求 | retryable=true 时 |

#### AI 错误 (AIError)

额外展示:

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 模型名称 | Text | 加载/推理失败的模型 | code = E3001/E3002 |
| Token 用量 | Text | 已用/上限 token 数 | code = E3003 |
| 服务商名称 | Text | 配额耗尽的提供商 | code = E3004 |
| **[切换模型]** 按钮 | Button (Ghost) | 切换到备用模型（预留） | - |
| **[检查 API Key]** 按钮 | Button (Ghost) | 跳转到模型配置页 | - |
| **[重试推理]** 按钮 | Button (Primary) | 重试 AI 推理请求 | retryable=true 时 |

#### 用户错误 (UserError)

额外展示:

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 校验字段名 | Text | 未通过校验的字段 | code = E4001 |
| 校验规则 | Text | 未满足的校验规则 | code = E4001 |
| 取消的操作 | Text | 被用户取消的操作名 | code = E4002 |
| 缺少的权限 | Text | 所需权限与当前权限对比 | code = E4003 |
| **[修正输入]** 按钮 | Button (Primary) | 跳转到对应输入框聚焦 | code = E4001 |
| **[撤销操作]** 按钮 | Button (Warning) | 撤销上一步用户操作 | code = E4002 时可用 |

## 3. 错误边界 UI 表现

### 3.1 组件级错误降级

当某个 UI 组件渲染出错时:

| 元素 | 类型 | 说明 |
|------|------|------|
| 降级占位容器 | FallbackContainer | 替代出错组件的区域 |
| 降级图标 | Image | 友好的错误插图 |
| 降级标题 | Text | "此部分暂时无法显示" |
| 降级描述 | Text | "组件加载时出现问题" |
| **[重新加载]** 按钮 | Button (Primary) | 尝试重新渲染该组件 |
| **[报告问题]** 按钮 | Button (Ghost) | 打开错误报告对话框 |
| 错误详情折叠面板 | CollapsiblePanel | 展开查看技术细节（面向开发者） |

### 3.2 页面级错误回退

当整个页面无法加载时:

| 元素 | 类型 | 说明 |
|------|------|------|
| 错误页面容器 | ErrorPage | 占据整个内容区的错误展示 |
| 错误代码大字 | Text (Large) | "500" 或 "Something went wrong" |
| 错误标题 | Heading | "页面加载失败" |
| 错误建议列表 | List | 可能的原因和解决建议:
- 检查网络连接
- 重启应用
- 清除缓存
- 查看日志 |
| **[返回首页]** 按钮 | Button (Primary) | 导航到首页/Dashboard |
| **[刷新页面]** 按钮 | Button (Secondary) | 重新加载当前页面路由 |
| **[查看日志]** 按钮 | Button (Ghost) | 跳转到日志查看器 |

## 4. 崩溃恢复界面

### 4.1 启动崩溃检测

**触发**: 应用启动时检测到上次异常退出标记

| 元素 | 类型 | 说明 |
|------|------|------|
| 恢复模式标识 | Banner (Full Width) | "检测到上次非正常退出" |
| 崩溃摘要面板 | Card | 崩溃基本信息 |
| └ 崩溃时间 | DateTimeText | 上次崩溃的时间 |
| └ 运行时长 | Text | 崩溃前运行了多久 |
| └ 崩溃类型 | Badge | uncaughtException / unhandledRejection / OOM / SIGSEGV |
| └ 崩溃次数 | Text | 近期连续崩溃次数（防崩溃循环） |
| 崩溃详情展开 | Accordion | 详细堆栈和上下文 |
| **[安全模式启动]** 按钮 | Button (Primary) | 以最小功能集启动，跳过 Worker 和索引 |
| **[正常启动]** 按钮 | Button (Secondary) | 尝试正常启动（忽略崩溃标记） |
| **[查看崩溃日志]** 按钮 | Button (Ghost) | 打开崩溃日志文件 |
| **[重置应用数据]** 按钮 | Button (Danger) | 清除所有本地数据从头开始（最后手段） |

### 4.2 安全模式指示

**条件**: 以安全模式运行时

| 元素 | 类型 | 说明 |
|------|------|------|
| 安全模式横幅 | Banner (Persistent, Top) | "🔒 当前运行在安全模式（受限功能）" |
| 功能禁用列表 | List | 当前不可用的功能:
- 后台索引
- Worker 任务
- 自动保存
- Git 集成 |
| **[退出安全模式]** 按钮 | Button (Warning) | 尝试以完整模式重启 |
| **[诊断问题]** 按钮 | Button (Primary) | 打开诊断工具收集更多信息 |

### 4.3 Worker 崩溃恢复

**触发**: 后台 Worker 异常退出

| 元素 | 类型 | 说明 |
|------|------|------|
| Worker 崩溃通知 | Toast (Persistent) | "后台服务进程已停止" |
| Worker 状态面板 | InlineAlert | 在受影响的页面内嵌提示 |
| Worker 崩溃原因 | Text | OOM / 超时 / 未捕获异常 / 被系统杀死 |
| 受影响功能列表 | TagList | 依赖此 Worker 的功能标签 |
| **[自动重启]** 按钮 | Button (Primary) | Main 进程拉起新 Worker 实例 |
| **[手动重启]** 按钮 | Button (Secondary) | 用户确认后重启 |
| 重启计数 | Text | "已自动重启 N 次" | 防止无限重启循环 |
| **[禁用该 Worker]** 按钮 | Button (Danger) | 禁用该 Worker（功能降级） | 重启超过阈值后出现 |

## 5. 断路器状态 UI

### 5.1 断路器打开提示

**触发**: 某个外部服务调用连续失败达到阈值，断路器打开

| 元素 | 类型 | 说明 |
|------|------|------|
| 断路器警告横幅 | Banner (Warning) | "服务已临时断开以防止进一步故障" |
| 服务名称 | Text | 受影响的服务/API 名称 |
| 失败次数 | Text | 连续失败 N 次 |
| 冷却倒计时 | Countdown | 距离下次尝试的剩余时间 |
| 断路器状态图示 | StateDiagram | Closed → Open → Half-Open 的可视化 |
| **[立即重试]** 按钮 | Button (Warning) | 强制尝试一次请求（Half-Open） |
| **[查看历史]** 按钮 | Button (Ghost) | 查看最近的失败记录 |

### 5.2 断路器半开状态

| 元素 | 类型 | 说明 |
|------|------|------|
| 半开状态指示 | StatusBadge | "正在试探性恢复..." |
| 探测进度 | IndeterminateProgress | 等待探测结果 |
| 成功后提示 | Toast (Success) | "服务已恢复正常" |
| 失败后提示 | Toast (Error) | "服务仍未恢复，继续等待..." |

## 6. 重试与降级 UI 反馈

### 6.1 操作中重试指示

**场景**: 网络请求等可重试操作的实时反馈

| 元素 | 类型 | 说明 |
|------|------|------|
| 重试状态容器 | InlineStatus | 内联在操作区域的反馈 |
| 重试计数 | Text | "第 2/3 次尝试..." |
| 退避计时 | Text | "下次重试: 3秒后..." |
| 取消按钮 | Button (Ghost, Small) | 取消正在进行的重试序列 |
| 最终失败提示 | ErrorInline | 所有重试耗尽后的最终错误 |

### 6.2 降级体验提示

**场景**: 核心功能不可用时启用降级方案

| 元素 | 类型 | 说明 |
|------|------|------|
| 降级提示条 | InfoBanner | "部分功能已切换为简化模式" |
| 降级功能说明 | Text | 解释哪些功能被降级了 |
| 降级原因 | Text (Muted) | "因 AI 服务暂不可用，搜索功能已降级为基础文本匹配" |
| **[了解详情]** 按钮 | Button (Ghost) | 展开降级的详细说明 |
| 恢复提示 | Toast (Success) | 当主功能恢复时的通知 |
