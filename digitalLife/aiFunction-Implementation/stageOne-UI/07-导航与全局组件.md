## 1. 全局快捷键

### 1.1 快捷键列表

| 快捷键 | 功能 | 目标位置 | 条件 |
|--------|------|----------|------|

## 5. 全局确认对话框体系

### 5.1 危险等级分级

| 等级 | 图标颜色 | 按钮样式 | 二次确认要求 | 适用场景 |
|------|----------|----------|--------------|----------|
| Info | 蓝色信息图标 | 普通主按钮 | 无 | 一般确认（如保存成功提示） |
| Warning | 黄色警告图标 | 黄色主按钮 | 无 | 可逆操作的确认（如关闭未保存） |
| Danger | 红色危险图标 | 红色主按钮 | 勾选确认框 | 不可逆操作（如删除数据） |
| Critical | 红色闪烁图标 | 红色主按钮 | 手动输入确认文字 | 极高危操作（如清空数据库） |

### 5.2 危险操作二次确认机制

**Level 1 - Checkbox 确认:**

| 元素 | 类型 | 说明 |
|------|------|------|
| 确认提示文本 | Text | "此操作不可撤销，请确认:" |
| 复选框 | Checkbox | "我理解并确认要执行此操作" |
| 影响范围摘要 | AlertBox | 列出受影响的项目数量和类型 |
| 确认按钮 | Button (Danger, Disabled→Enabled) | 勾选后才可点击 |

**Level 2 - 文字输入确认:**

| 元素 | 类型 | 说明 |
|------|------|------|
| 危险提示横幅 | Banner (Danger) | "⚠️ 此操作将永久删除数据" |
| 确认指令文本 | Text | '请在下方输入 "{CONFIRM_TEXT}" 以确认' |
| 确认输入框 | Input (Text) | 用户必须手动输入指定文字 |
| 输入验证 | ValidationIcon | 输入正确时变绿 ✅ |
| 确认按钮 | Button (Danger, Disabled→Enabled) | 输入匹配后才可点击 |
| 倒计时 | Countdown | 冷却期（如 5 秒后才允许确认） | 极高危操作 |

## 9. 工具提示 (Tooltip) 系统

### 9.1 触发方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| Hover | 鼠标悬停显示（延迟 500ms） | 按钮、图标的辅助说明 |
| Focus | 键盘聚焦时显示 | 无障碍访问 |
| Click | 点击触发显示/隐藏 | 信息密度高的紧凑区域 |

### 9.2 工具提示类型

| 类型 | 样式 | 说明 |
|------|------|------|
| 简短提示 | Single Line | 单行纯文字，如 "保存" |
| 格式化提示 | Rich Text | 支持加粗、代码等格式 |
| 包含操作 | Actionable | 底部带操作按钮，如 "按 Ctrl+S 保存" |
| 方向自适应 | Auto Position | 自动选择上下左右最佳位置，避免溢出 |

## 11. 无障碍访问 (A11y) 支持

### 11.1 键盘导航

| 元素 | 类型 | 说明 |
|------|------|------|
| Focus Ring | Visual Indicator | 键盘焦点可见的环形轮廓（非鼠标 focus 时隐藏） |
| Focus Trap | Behavior | 模态对话框内 Tab 循环不逃逸 |
| Skip Link | Hidden Link | "跳转到主要内容"（屏幕阅读器首选项） |
| 跳转顺序 | Logical Order | 符合视觉阅读顺序的 Tab 序列 |

### 11.2 屏幕阅读器支持

| 元素 | ARIA 属性 | 说明 |
|------|-----------|------|
| 区域地标 | role="main" / nav / aside | 页面结构语义化 |
| 实时区域 | aria-live="polite" / assertive | 动态内容变更通知 |
| 状态描述 | aria-current / aria-pressed / aria-expanded | 组件状态表达 |
| 加载状态 | aria-busy="true" | 正在加载的指示 |
| 错误关联 | aria-describedby → error message | 表单错误绑定 |
| 图标替代 | aria-label / sr-only text | 纯图标按钮的文字描述 |
