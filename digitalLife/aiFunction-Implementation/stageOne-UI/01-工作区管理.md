# 工作区管理 UI 元素

> 对应模块: [07-工作区与会话管理](../stageOne/07-工作区与会话管理.md)
>
> IPC 通道: `workspace.open` / `workspace.listRecent` / `workspace.getInfo`

## 1. 工作区选择与打开

### 1.1 目录选择器

**触发方式**: 点击"打开工作区"按钮或欢迎页卡片

| 元素 | 类型 | 说明 | 行为 |
|------|------|------|------|
| 路径输入框 | Input (Readonly) | 显示当前选中路径 | 用户通过系统对话框选择 |
| **[浏览...] 按钮** | Button | 打开原生目录选择对话框 | 调用 `dialog.showOpenDialog` |
| 路径验证状态 | ValidationIcon | ✅ 有效路径 / ⚠️ 非项目根 / ❌ 无权限 | 实时校验反馈 |
| 项目类型检测标签 | Badge | node / python / java / go / rust / unknown | 自动检测后展示 |
| **[确认打开]** 按钮 | Button (Primary) | 确认选择并加载工作区 | 调用 `workspace.open` IPC |
| **[取消]** 按钮 | Button (Secondary) | 关闭选择器 | 返回上一页 |

### 1.2 工作区信息面板

**位置**: 工作区页面主区域

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 工作区名称 | Text (Heading) | 工作区显示名称 | `WorkspaceMeta.name` |
| 工作区路径 | Text (Monospace) | 绝对路径（可复制） | `WorkspaceMeta.rootPath` |
| 项目类型图标+文字 | Badge | 语言/框架标识 | `WorkspaceMeta.type` |
| 状态指示灯+文字 | StatusIndicator | initializing / ready / indexing / degraded / error / closed | `WorkspaceMeta.status` |
| 创建时间 | Text | 格式化时间戳 | `WorkspaceMeta.createdAt` |
| 最后打开时间 | Text | 相对时间描述（如 "2小时前"） | `WorkspaceMeta.lastOpenedAt` |

## 2. Git 状态面板

### 2.1 Git 快照摘要

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| Git 仓库标识 | Badge | "Git Repository" 或 "非 Git 项目" | `GitSnapshot.isRepo` |
| 当前分支 | Select/Text | 分支名（可切换分支的预留入口） | `GitSnapshot.branch` |
| HEAD 提交 | Text (Truncated) | 短 Hash + 前7位 | `GitSnapshot.head` |
| Ahead 指标 | Badge (+N) | 领先远程 N 个提交 | `GitSnapshot.ahead` |
| Behind 指标 | Badge (-N) | 落后远程 N 个提交 | `GitSnapshot.behind` |

### 2.2 文件变更统计

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 已暂存文件数 | StatCard | 绿色数字 + "Staged" | `GitSnapshot.staged.length` |
| 未暂存文件数 | StatCard | 黄色数字 + "Unstaged" | `GitSnapshot.unstaged.length` |
| 未跟踪文件数 | StatCard | 灰色数字 + "Untracked" | `GitSnapshot.untracked.length` |
| 冲突文件数 | StatCard (Alert) | 红色数字 + "Conflicts" | `GitSnapshot.conflicts.length` |
| **[查看详情]** 按钮 | Button (Ghost) | 展开完整变更列表 | 展开折叠面板 |
| 最后快照时间 | Text | Git 状态采集时间 | `GitSnapshot.capturedAt` |

### 2.3 变更文件列表（可展开）

| 元素 | 类型 | 说明 |
|------|------|------|
| 文件路径 | Text (Relative) | 相对于工作区根的路径 |
| 变更类型标签 | Badge | A(新增) / M(修改) / D(删除) / U(冲突) |
| 文件路径复制按钮 | IconButton | 复制完整路径到剪贴板 |

## 3. 会话管理

### 3.1 当前会话信息

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 会话 ID | Text (Monospace, Small) | 当前会话标识 | `SessionMeta.id` |
| 会话状态 | Badge | active / paused / completed / archived | `SessionMeta.status` |
| 审批模式 | SegmentedControl | auto / semi-auto / manual 切换 | `SessionMeta.approvalMode` |
| 创建时间 | Text | 会话创建时间 | `SessionMeta.createdAt` |
| 更新时间 | Text | 最后活动时间 | `SessionMeta.updatedAt` |

### 3.2 会话摘要恢复

**场景**: 重启应用后恢复上次会话上下文

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 上次用户意图 | Text | 最近一次用户操作意图摘要 | `SessionSummary.lastUserIntent` |
| 索引版本 | Text | 最后使用的索引版本号 | `SessionSummary.lastIndexVersion` |
| 最近检查点 | Text | 检查点 ID（可点击查看详情） | `SessionSummary.lastCheckpointId` |
| 最近任务 | Text | 任务 ID（可点击跳转任务详情） | `SessionSummary.lastTaskId` |
| 会话备注 | TextArea (Readonly) | 用户或系统记录的笔记 | `SessionSummary.notes` |
| **[继续此会话]** 按钮 | Button (Primary) | 基于摘要恢复会话上下文 | 执行恢复流程 |
| **[开始新会话]** 按钮 | Button (Secondary) | 放弃旧会话，创建新的 | 重置会话状态 |

## 4. 脏工作树保护提示

### 4.1 保护警告横幅

**触发条件**: 检测到 Git 冲突、大量未提交改动等

| 元素 | 类型 | 说明 |
|------|------|------|
| 警告图标 | Icon | ⚠️ warning |
| 警告标题 | Text | "检测到工作区存在风险状态" |
| 警告详情 | Text | 具体问题描述（如 "存在 3 个冲突文件"） |
| **[查看详情]** 按钮 | Button | 展开 Git 状态详情 |
| **[忽略并继续]** 按钮 | Button (Ghost/Danger) | 用户确认忽略风险（需二次确认） |
| **[暂存所有更改]** 按钮 | Button (Secondary) | 执行 git add -A（预留，Phase 1 实现） |

### 4.2 外部修改检测提示

**触发条件**: 检测到外部工具修改了工作区文件

| 元素 | 类型 | 说明 |
|------|------|------|
| 外部修改通知 | Toast/Banner | "检测到工作区文件被外部修改" |
| **[刷新索引]** 按钮 | Button | 触发增量索引更新 |
| **[稍后处理]** 按钮 | Button (Ghost) | 暂时关闭提示 |

## 5. 检查点引用管理

### 5.1 检查点列表

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 检查点 ID | Text (Monospace) | 唯一标识 | `Checkpoint.id` |
| 检查点类型 | Badge | manual / pre-task / post-approval / auto | `Checkpoint.type` |
| 检查点描述 | Text | 检查点说明 | `Checkpoint.description` |
| 创建时间 | Text | 时间戳 | `Checkpoint.createdAt` |
| 关联会话 ID | Text (Link) | 可点击跳转会话 | `Checkpoint.sessionId` |
| **[恢复到此检查点]** 按钮 | Button (Warning) | 恢复到该检查点状态（需确认） | 调用恢复逻辑 |

## 6. 工作区操作按钮组

### 6.1 页面级操作栏

| 元素 | 类型 | 图标 | 说明 | 快捷键 | 条件 |
|------|------|------|------|--------|------|
| **[切换工作区]** 按钮 | Button | 📂 | 打开新工作区 | Ctrl+Shift+O | 始终可用 |
| **[刷新状态]** 按钮 | Button | 🔄 | 刷新工作区和 Git 状态 | F5 | 有活跃工作区时 |
| **[创建检查点]** 按钮 | Button | 💾 | 手动创建当前状态检查点 | Ctrl+S | 有活跃工作区时 |
| **[关闭工作区]** 按钮 | Button (Ghost) | ✖ | 关闭当前工作区返回欢迎页 | - | 有活跃工作区时 |
