# 索引与检索状态 UI 元素

> 对应模块: [08-索引与检索服务](../stageOne/08-索引与检索服务.md)
>
> IPC 通道: `index.start` / `index.getStatus` / `index.getProgress`
>
> 执行位置: 后台 Worker（Renderer 仅展示）

## 1. 索引状态总览面板

### 1.1 状态卡片区域

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 整体状态指示 | StatusHero | 大型状态图标 + 文字描述 | `IndexStatus.phase` |
| 状态描述文本 | Text | "索引就绪" / "正在构建索引..." / "索引异常" | 根据 phase 动态切换 |

**Phase 状态映射:**

| Phase 值 | 显示文案 | 图标颜色 | 可执行操作 |
|----------|----------|----------|------------|
| idle | 等待开始索引 | 灰色 | [开始索引] |
| initializing | 正在初始化... | 蓝色 | - |
| indexing | 正在构建索引 (N/M) | 蓝色(动画) | [暂停] / [取消] |
| ready | 索引就绪 | 绿色 | [重新索引] |
| error | 索引出错 | 红色 | [重试] / [查看错误] |

### 1.2 统计数据卡片组

| 元素 | 类型 | 图标 | 说明 | 数据来源 |
|------|------|------|------|----------|
| 已索引文件数 | StatCard | 📄 | 索引文件总数 | `IndexStatus.fileCount` |
| 符号总数 | StatCard | 🔣 | 提取的符号数量 | `IndexStatus.symbolCount` |
| 索引版本 | StatCard | 🏷️ | 当前索引版本号 | `IndexContext.version` |
| 最后更新时间 | StatCard | 🕐 | 最后完成/更新的时间 | `IndexStatus.updatedAt` |
| 工作区根路径 | StatCard | 📂 | 索引的目标目录 | `IndexContext.rootPath` |

## 2. 索引进度展示

### 2.1 进度条组件

**场景**: 首次扫描或全量重建时展示

| 元素 | 类型 | 说明 |

| 百分比文字 | Text | "已完成 67%" |

| 预估剩余时间 | Text | "预计剩余 01:15" |

### 2.2 分阶段进度（可选增强）

| 元素 | 类型 | 说明 |
|------|------|------|
| 阶段步骤列表 | StepList | 文件发现 → 文件树构建 → 内容提取 → 符号分析 → 完成 |
| 当前阶段高亮 | ActiveStep | 正在执行的阶段高亮显示 |
| 已完成阶段勾选 | CompletedStep | 已完成的阶段带 ✅ 标记 |

## 3. 索引控制操作

### 3.1 操作按钮组

| 元素 | 类型 | 说明 | 条件 | IPC 通道 |
|------|------|------|------|-----------|
| **[开始索引]** 按钮 | Button (Primary) | 启动首次或重新索引 | phase = idle 或 error | `index.start` |
| **[暂停索引]** 按钮 | Button (Warning) | 暂停当前索引任务 | phase = indexing | `index.pause` |
| **[继续索引]** 按钮 | Button (Primary) | 恢复暂停的索引 | phase = paused | `index.resume` |
| **[取消索引]** 按钮 | Button (Danger) | 取消当前索引任务 | phase = indexing | `index.cancel` |
| **[重新索引]** 按钮 | Button (Secondary) | 清除并重建全部索引 | phase = ready | `index.rebuild` |
| **[增量更新]** 按钮 | Button (Ghost) | 基于变更文件的增量索引 | 有未提交变更时 | `index.incremental` |

### 3.2 高级操作下拉菜单

| 元素 | 类型 | 说明 |
|------|------|------|
| 清除缓存 | MenuItem | 删除所有可重建的缓存数据 |
| 导出索引报告 | MenuItem | 导出当前索引统计信息为 JSON |
| 索引配置 | MenuItem | 跳转到设置中的索引配置项 |

## 6. 文件搜索（Phase 0 基础版）
