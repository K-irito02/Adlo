# 响应式设计规范 (Responsive Design)

> 确保桌面应用在不同窗口尺寸和分辨率下的适配性

## 1. 断点系统

### 1.1 断点定义

| 令牌名 | 最小宽度 | 典型设备/场景 | 布局行为 |
|--------|----------|---------------|----------|
| `bp-xs` | 0px | 极窄窗口（< 640px） | 单列堆叠，侧边栏隐藏 |
| `bp-sm` | 640px | 小窗口 / 分屏一半 | 单列 + 紧凑间距 |
| `bp-md` | 768px | 平板竖屏 / 小笔记本 | 双列开始出现 |
| `bp-lg` | 1024px | 平板横屏 / 标准笔记本 | 标准双列布局 |
| `bp-xl` | 1280px | HD 显示器 | 完整三列布局 |
| `bp-2xl` | 1536px | Full HD+ 大显示器 | 宽松布局 |
| `bp-max` | 1920px+ | 2K/4K 显示器 | 最大内容宽度限制 |

### 1.2 桌面应用特殊断点说明

与 Web 应用不同，桌面应用的窗口尺寸由用户控制：

| 考量因素 | 说明 |
|----------|------|
| 最小支持宽度 | **768px** — 低于此宽度显示水平滚动条或提示用户放大窗口 |
| 最佳体验宽度 | **1280px ~ 1536px** — 设计的主要目标分辨率 |
| 最大内容宽度 | **1440px** — 内容区最大宽度，超出后居中留白 |
| 高度适应性 | 内容区高度 = 窗口高度 - 标题栏 - 状态栏，使用 `100vh` 或 `dvh` |

## 2. 布局响应策略

### 2.1 主布局结构响应

```
┌─ ≥1280px (Desktop Standard) ────────────────────────┐
│ [Sidebar 240px] [Content flex-1 max-w-1440px] [Status] │
└────────────────────────────────────────────────────┘

┌─ 1024~1279px (Compact Desktop) ─────────────────────┐
│ [Sidebar 200px(icon+text)] [Content] [Status]        │
└────────────────────────────────────────────────────┘

┌─ 768~1023px (Narrow Window) ────────────────────────┐
│ [≡ Sidebar(collapsed, icons only)] [Content] [Status] │
└────────────────────────────────────────────────────┘

┌─ <768px (Too Narrow) ───────────────────────────────┐
│ ⚠ 提示: "窗口过小，建议放大至 768px 以上"             │
│ [Full-width Content with horizontal scroll if needed] │
└────────────────────────────────────────────────────┘
```

### 2.2 侧边栏响应

| 窗口宽度 | 侧边栏状态 | 宽度 | 内容展示 |
|----------|-----------|------|----------|
| ≥ 1280px | Expanded (完整) | 240px | 图标 + 文字标签 |
| 1024~1279px | Compact | 200px | 图标 + 截断文字 |
| 768~1023px | Collapsed (Icon-only) | 56~64px | 仅图标，Tooltip 展开文字 |
| < 768px | Hidden (Overlay) | 0px (默认) | 点击按钮以 Overlay 弹出 |

### 2.3 内容区响应

| 组件类型 | ≥1280px | 1024~1279px | 768~1023px |
|----------|---------|-------------|------------|
| Dashboard 卡片网格 | 4 列 | 3 列 | 2 列 |
| 任务列表表格 | 全部列可见 | 隐藏次要列 | 隐藏更多列 + 横向滚动 |
| 日志查看器 | 左右分栏(列表+详情) | 左右分栏(较窄) | 仅列表，详情覆盖层 |
| 设置页 | 左导航 + 右内容 | 同上（更紧凑） | 导航变为顶部 Tabs |
| Modal 对话框 | 居中，max-w-lg | 居中，max-w-md | 接近全屏 |
| 表单 | 双列布局 | 双列（较窄） | 单列堆叠 |

### 2.4 数据表格响应策略

| 策略 | 说明 | 适用场景 |
|------|------|----------|
| **列优先级隐藏** | 低优先级列在窄屏下隐藏，通过"显示更多列"展开 | 任务列表、文件列表 |
| **横向滚动** | 表格容器 `overflow-x: auto`，保留所有列 | 日志数据、Git 变更详情 |
| **卡片化转换** | 将表格行转为卡片列表（每行一张 Card） | 移动端适配（Phase 0 可选） |
| **关键列固定** | 操作列始终可见，其余可滚动 | 含操作按钮的表格 |

**列优先级示例（任务列表）：**

| 优先级 | 列名 | ≥1024px | 768~1023px | <768px |
|--------|------|---------|-------------|--------|
| P0 | 任务描述 | ✅ | ✅ | ✅ |
| P0 | 状态 Badge | ✅ | ✅ | ✅ |
| P0 | 操作按钮 | ✅ | ✅ | ✅ |
| P1 | 优先级 | ✅ | ✅ (图标) | ❌ |
| P1 | 类型 | ✅ | ❌ | ❌ |
| P2 | 创建时间 | ✅ | ❌ | ❌ |
| P2 | 关联工作区 | ✅ | ❌ | ❌ |
| P3 | ID | ❌ (Tooltip) | ❌ | ❌ |

## 3. 字体与间距的响应调整

### 3.1 字体大小微调

| 元素 | ≥1280px | 768~1279px |
|------|---------|-------------|
| 页面标题 (H1) | text-3xl (30px) | text-2xl (24px) |
| Section 标题 (H2) | text-xl (20px) | text-lg (18px) |
| 正文 | text-base (16px) | text-base (16px)（不变） |
| 辅助文字 | text-sm (14px) | text-sm (14px)（不变） |
| Caption | text-xs (12px) | text-xs (12px)（不变） |

### 3.2 间距压缩

| 区域 | ≥1280px | 768~1279px |
|------|---------|-------------|
| 页面左右 padding | space-8 (32px) | space-5 (20px) |
| Card 内 padding | space-5 (20px) | space-4 (16px) |
| Section 间距 | space-8 (32px) | space-6 (24px) |
| 列表项间距 | space-3 (12px) | space-2 (8px) |
| 表单字段间距 | space-6 (24px) | space-4 (16px) |

## 4. 触摸与点击目标适配

虽然主要面向桌面端，但仍需考虑以下场景：

| 场景 | 适配要求 |
|------|----------|
| 触摸屏笔记本 | 所有可点击元素最小 44×44px hit area |
| 高 DPI 屏幕 (Retina/4K) | 使用 `devicePixelRatio` 缩放 SVG 和 Canvas |
| 窗口缩放 | 支持系统级别的 UI 缩放（125%/150%/200%） |
| 外接触控显示器 | 按钮间距不小于 8px，避免误触 |

## 5. CSS 媒体查询写法

```css
/* Mobile First 写法（推荐用于子组件） */
.component {
  /* 默认: 最小尺寸样式 */
  padding: var(--space-4);
}

@media (min-width: 768px) {
  .component { padding: var(--space-6); }
}

@media (min-width: 1024px) {
  .component { padding: var(--space-8); }
}

/* Desktop First 写法（推荐用于页面级布局） */
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
}

@media (max-width: 1023px) {
  .layout {
    grid-template-columns: 56px 1fr;
  }
}

@media (max-width: 767px) {
  .layout {
    grid-template-columns: 1fr;
  }
}
```

## 6. 安全区域处理

### 6.1 Electron 窗口装饰

```
┌─ Title Bar (28~34px, 由 OS 控制) ─────────────┐
│  [icon] AI Digital Life    [—][□][✕]         │
├────────────────────────────────────────────────┤
│                                                  │
│              App Content Area                   │
│          (height: calc(100vh - titleBar))       │
│                                                  │
├────────────────────────────────────────────────┤
│  Status Bar (24~28px)                           │
│  workspace-name │ branch │ index │ memory       │
└────────────────────────────────────────────────┘
```

### 6.2 CSS 处理

```css
.app-container {
  height: 100vh;           /* 或 100dvh（移动端安全） */
  display: flex;
  flex-direction: column;
  overflow: hidden;
}

.content-area {
  flex: 1;
  overflow-y: auto;
  /* 为标题栏和状态栏预留空间 */
}
```
