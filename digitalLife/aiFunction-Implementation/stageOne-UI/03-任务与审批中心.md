# 任务与审批中心 UI 元素

> 对应模块: [09-任务与审批中心](../stageOne/09-任务与审批中心.md)
>
> IPC 通道: `task.list` / `task.getDetail` / `approval.listPending` / `approval.decide`

## 1. 任务中心布局

### 1.1 页面结构

```
┌──────────────────────────────────────────────────────┐
│  任务中心                          [筛选] [搜索]      │
├──────────┬───────────────────────────────────────────┤
│          │                                           │
│ 状态过滤  │           任务列表 / 任务详情              │
│ 侧边栏   │           (Task List / Detail)            │
│          │                                           │
├──────────┴───────────────────────────────────────────┤
│  审批队列提示 (有待审批时显示)                         │
└──────────────────────────────────────────────────────┘
```

## 2. 任务列表

### 2.1 列表过滤与搜索

| 元素 | 类型 | 说明 |
|------|------|------|
| 搜索输入框 | Input | 按任务描述关键词搜索 |
| 状态过滤标签组 | TabGroup | 全部 / 待处理 / 审批中 / 执行中 / 已完成 / 失败 / 已拒绝 |
| 优先级过滤 | MultiSelect | Critical / High / Medium / Low |
| 风险等级过滤 | MultiSelect | High / Medium / Low |
| 时间范围选择 | DateRangePicker | 按创建时间筛选 |
| **[清除筛选]** 按钮 | Button (Ghost) | 重置所有筛选条件 |

### 2.2 任务列表项

每个任务卡片/行包含:

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 任务类型图标 | Icon | 根据任务类型显示不同图标 | `Task.type` |
| 任务描述 | Text (Ellipsis) | 任务简要描述（最多2行） | `Task.description` |
| 状态标签 | Badge | 当前状态，颜色编码 | `Task.status` |
| 优先级标签 | Badge | critical(红) / high(橙) / medium(黄) / low(灰) | `Task.priority` |
| 风险等级指示 | RiskIndicator | 高/中/低风险视觉标识 | 操作中最高风险等级 |
| 创建时间 | Text (Relative) | "5分钟前" / "2小时前" | `Task.createdAt` |
| 操作按钮组 | ButtonGroup | 查看 / 取消（根据状态显示不同按钮） | - |

**状态 Badge 颜色映射:**

| Status | 颜色 | 文案 |
|--------|------|------|
| pending | 灰色 | 待处理 |
| waiting-approval | 黄色 | 待审批 |
| approved | 蓝色 | 已批准 |
| running | 蓝色(脉冲) | 执行中 |
| completed | 绿色 |已完成 |
| failed | 红色 | 失败 |
| rejected | 红色 | 已拒绝 |
| rolled-back | 橙色 | 已回滚 |

### 2.3 列表空态

| 元素 | 类型 | 说明 |
|------|------|------|
| 空状态插图 | Image | 无任务时的插画 |
| 空状态标题 | Text | "暂无任务" |
| 空状态描述 | Text | "任务将在 AI 操作执行时自动创建" |

### 2.4 列表分页

| 元素 | 类型 | 说明 |
|------|------|------|
| 每页条数选择 | Select | 10 / 20 / 50 |
| 分页控件 | Pagination | 上一页 / 页码 / 下一页 |
| 总数文本 | Text | "共 N 条任务记录" |

## 3. 任务详情面板

### 3.1 基本信息

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 任务 ID | Text (Monospace, Small) | 唯一标识（可复制） | `Task.id` |
| 任务描述 | Text (Full) | 完整任务描述 | `Task.description` |
| 任务类型 | Badge | 操作类型分类 | `Task.type` |
| 当前状态 | StatusBadge | 大尺寸状态展示 | `Task.status` |
| 优先级 | PriorityBadge | 可点击修改优先级（预留） | `Task.priority` |
| 关联工作区 | Text (Link) | 工作区名称（可跳转） | `Task.workspaceId` |
| 关联会话 | Text (Link) | 会话 ID（可跳转） | `Task.sessionId` |
| 父任务 | Text (Link) | 如为子任务则显示父任务 | `Task.parentId` |

### 3.2 时间线信息

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 创建时间 | DateTimeText | 完整日期时间 | `Task.createdAt` |
| 开始时间 | DateTimeText | 任务开始执行的时间 | `Task.startedAt` |
| 完成时间 | DateTimeText | 任务完成的时间 | `Task.completedAt` |
| 总耗时 | DurationText | completedAt - startedAt | 计算值 |
| 更新时间 | DateTimeText | 最后状态变更时间 | `Task.updatedAt` |

### 3.3 操作列表

**核心区域**: 展示此任务关联的所有操作步骤

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 操作步骤列表 | StepList | 按顺序排列的操作项 | `Task.operations[]` |
| └ 操作类型 | Text | 操作种类名称 | `TaskOperation.kind` |
| └ 目标路径 | Text (Monospace) | 操作目标文件/目录 | `TaskOperation.target` |
| └ 操作参数 | JSONView (Collapsible) | 操作参数详情（可展开） | `TaskOperation.params` |
| └ 风险等级 | RiskBadge | low / medium / high | `TaskOperation.riskLevel` |
| └ 是否可逆 | ReversibilityBadge | ✅ 可逆 / ❌ 不可逆 | `TaskOperation.reversible` |

### 3.4 结果与错误信息

**条件展示**: 仅在任务完成或失败时显示

#### 成功结果

| 元素 | 类型 | 说明 |
|------|------|------|
| 结果标签 | Badge (Success) | "执行成功" |
| 结果数据 | JSONView (Collapsible) | 结构化结果数据（可展开查看） |

#### 失败信息

| 元素 | 类型 | 说明 |
|------|------|------|
| 错误标签 | Badge (Error) | "执行失败" |
| 错误消息 | Text (Pre) | 错误详情文本 |
| 错误堆栈 | CodeBlock (Collapsible) | 可展开的错误堆栈跟踪 |
| **[重试任务]** 按钮 | Button (Primary) | 重新执行失败的任务 |
| **[回滚]** 按钮 | Button (Danger) | 回滚到检查点状态（如有关联） |

## 4. 审批中心

### 4.1 待审批队列入口

**位置**: 任务页面顶部固定横幅 或 侧边导航徽章

| 元素 | 类型 | 说明 | 条件 |
|------|------|------|------|
| 待审批计数角标 | Badge (Red) + 数字 | 显示待审批数量 | count > 0 时显示 |
| **[前往审批]** 按钮 | Button (Primary) | 跳转到审批队列视图 | 有待审批项时 |
| 审批队列快捷入口 | NavItem | 在侧边栏突出显示 | 有待审批项时高亮 |

### 4.2 审批请求列表

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 审批请求卡片 | Card | 每个待审批项一张卡片 | `ApprovalRequest` |
| └ 风险等级大标签 | RiskBadge (Large) | 高风险红色 / 中风险黄色 / 低风险绿色 | `ApprovalRequest.riskLevel` |
| └ 审批标题 | Text (Heading) | 简短操作标题 | `ApprovalRequest.title` |
| └ 审批描述 | Text | 详细说明要执行的操作 | `ApprovalRequest.description` |
| └ 关联任务 | Text (Link) | 关联任务 ID 和描述 | `ApprovalRequest.taskId` |
| └ 影响范围列表 | TagList | 受影响的文件/资源列表 | `ApprovalRequest.impact` |
| └ 可逆性标识 | Badge | ✅ 可逆 / ❌ 不可逆 | `ApprovalRequest.reversible` |
| └ 创建时间 | Text (Relative) | 请求发起时间 | `ApprovalRequest.createdAt` |
| └ 超时倒计时 | Countdown | 距离超时的剩余时间 | `ApprovalRequest.expiresAt` |
| └ 操作预览折叠面板 | Accordion | 展开查看具体操作步骤 | `ApprovalRequest.operations[]` |

#### 操作预览子元素

| 元素 | 类型 | 说明 |
|------|------|------|
| 操作序号 | Number | 步骤编号 |
| 操作类型 | Text | 文件写入 / 删除 / 命令执行 等 |
| 目标路径 | Text (Monospace) | 操作对象路径 |
| 参数摘要 | Text | 关键参数的简述 |
| 单项风险等级 | MiniRiskBadge | 该步骤的风险等级 |

### 4.3 审批操作按钮组

每个审批卡片底部的操作按钮:

| 元素 | 类型 | 图标 | 说明 | 条件 | 行为 |
|------|------|------|------|------|------|
| **[批准]** 按钮 | Button (Primary, Success) | ✅ | 同意执行所有操作 | 非超时状态 | 弹出确认后调用 `approval.decide(approved)` |
| **[拒绝]** 按钮 | Button (Danger) | ❌ | 拒绝执行操作 | 非超时状态 | 弹出原因输入框后调用 `approval.decide(rejected)` |
| **[稍后处理]** 按钮 | Button (Ghost) | ⏰ | 暂时不做决定 | - | 关闭通知但保留在队列 |
| **[查看详情]** 按钮 | Button (Ghost) | 👁️ | 展开完整操作列表 | - | 展开 accordion |

### 4.4 审批决定对话框

**触发**: 点击 [批准] 或 [拒绝] 后弹出

| 元素 | 类型 | 说明 |
|------|------|------|
| 对话框标题 | Text | "确认审批决定" |
| 决策摘要 | Alert | "你即将 **批准** / **拒绝** 以下操作:" |
| 影响范围重述 | Text | 再次列出受影响的文件和资源 |
| 拒绝原因输入框 | TextArea | 拒绝时必须填写拒绝理由（必填） |
| 危险操作二次确认 | Checkbox | 高风险操作需勾选确认 | "我理解此操作可能影响以下 N 个文件" |
| **[取消]** 按钮 | Button (Secondary) | 返回不做决定 |
| **[确认批准]** 按钮 | Button (Success) | 最终确认批准 |
| **[确认拒绝]** 按钮 | Button (Danger) | 最终确认拒绝 |

### 4.5 已完成审批历史

**Tab 切换**: 待审批 / 已处理

| 元素 | 类型 | 说明 | 数据来源 |
|------|------|------|----------|
| 历史记录项 | HistoryItem | 已处理的审批记录 | `ApprovalDecision` |
| └ 决定结果 | Badge | 🟢 批准 / 🔴 拒绝 / ⏱️ 超时 | `ApprovalDecision.decision` |
| └ 关联任务 | Text (Link) | 关联任务信息 | `ApprovalDecision.taskId` |
| └ 决定理由 | Text | 拒绝理由或备注 | `ApprovalDecision.reason` |
| └ 决定时间 | DateTimeText | 做出决定的时间 | `ApprovalDecision.decidedAt` |
| └ 决定者 | Text | 审批人标识 | `ApprovalDecision.approvedBy` |

## 5. 审计日志（最小视图）

### 5.1 任务审计时间线

**位置**: 任务详情页底部 Tab

| 元素 | 类型 | 说明 |
|------|------|------|
| 时间线容器 | Timeline | 垂直时间线布局 |
| 审计事件节点 | TimelineEvent | 每个状态变更一个节点 |
| └ 事件时间 | DateTimeText | 事件发生时间 |
| └ 事件类型 | Badge | created / status-changed / approval-requested / approval-decided / completed / failed |
| └ 事件描述 | Text | 人可读的事件描述 |
| └ 变更详情 | CollapsiblePanel | 可展开的前后对比（如有） |

## 6. 全局审批模式切换

### 6.1 模式选择器

**位置**: 设置页 或 工作区页会话信息区

| 元素 | 类型 | 说明 |
|------|------|------|
| 模式标题 | Text | "审批模式" |
| 模式选项组 | RadioGroup / SegmentedControl | 三选一 |
| └ 自动模式 | RadioOption | 低风险自动通过，高风险需审批 |
| └ 半自动模式 | RadioOption | 所有操作均弹窗提示，用户可一键批准 |
| └ 手动模式 | RadioOption | 所有操作必须用户逐一确认 |
| 当前模式指示 | DescriptionText | 对当前模式的简短解释 |
| **[应用]** 按钮 | Button (Primary) | 保存模式设置变更 |
