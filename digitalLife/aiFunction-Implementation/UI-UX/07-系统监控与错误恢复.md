# 系统监控与错误恢复

> 日志查看器、健康仪表盘、错误展示、崩溃恢复、断路器状态与通知中心

## 1. 日志查看器

### 1.1 日志级别

| 级别 | 颜色 | 图标 | 说明 |
|------|------|------|------|
| DEBUG | muted | `icon-bug` | 调试信息（仅开发模式） |
| INFO | primary | `icon-info` | 一般信息 |
| WARN | warning | `icon-alert-triangle` | 警告 |
| ERROR | danger | `icon-x-circle` | 错误 |
| FATAL | danger (闪烁) | `icon-alert-octagon` | 致命错误 |

### 1.2 日志操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 暂停/恢复 | `Space` | 暂停自动滚动，手动查看 |
| 清空 | — | 清空当前日志（需确认） |
| 搜索 | `Ctrl+F` | 在日志中搜索关键词 |
| 复制选中 | `Ctrl+C` | 复制选中日志行 |
| 导出 | — | 导出为文件 |
| 跳转到错误 | `Ctrl+Shift+E` | 跳转到下一条 ERROR 日志 |

### 1.3 筛选

| 筛选项 | 选项 |
|--------|------|
| 级别 | 全部 / DEBUG / INFO / WARN / ERROR / FATAL |
| 来源 | 全部 / indexer / gateway / task / ipc / worker / system |
| 搜索 | 关键词实时过滤 |

## 2. 健康仪表盘

### 2.1 状态卡片

| 卡片 | 指标 | 状态色 |
|------|------|--------|
| 索引服务 | 就绪/索引中/错误 | success/warning/danger |
| 模型网关 | 在线/离线/限速 | success/muted/warning |
| Worker 进程 | 运行中/已停止/崩溃 | success/muted/danger |
| 磁盘空间 | 可用百分比 | success/warning/danger |

### 2.2 性能指标

| 指标 | 说明 |
|------|------|
| IPC 延迟 | 平均/最大响应时间 |
| 内存占用 | 应用内存使用量 |
| 索引大小 | 索引文件数量与大小 |
| 模型延迟 | 最近请求的响应时间 |

## 3. 错误展示

### 3.1 错误分类

| 类型 | 图标 | 展示方式 | 示例 |
|------|------|----------|------|
| 网络错误 | `icon-wifi-off` | Toast + 重试按钮 | 模型连接失败 |
| 文件错误 | `icon-file-x` | Toast + 详情链接 | 文件读取失败 |
| 权限错误 | `icon-shield-off` | Toast + 设置链接 | 操作被安全策略拒绝 |
| 数据错误 | `icon-database` | Toast + 修复建议 | 数据库损坏 |
| 系统错误 | `icon-alert-octagon` | Dialog + 操作指引 | Worker 崩溃 |

### 3.2 错误详情

点击错误通知展开详情面板：

| 元素 | 说明 |
|------|------|
| 错误类型 | 分类标签 |
| 错误消息 | 完整错误描述 |
| 堆栈追踪 | 可折叠的调用栈（开发模式） |
| 发生时间 | 精确时间戳 |
| 建议操作 | 修复建议 + 操作按钮 |
| 复制错误 | [复制错误信息] 按钮 |

## 4. 崩溃恢复

### 4.1 Worker 崩溃

| 场景 | UI 反馈 |
|------|----------|
| 首次崩溃 | Toast: "后台服务异常，正在自动重启..." |
| 重启成功 | Toast (Success): "后台服务已恢复" |
| 连续崩溃 2 次 | Banner: "后台服务反复异常，部分功能可能受限" |
| 连续崩溃 ≥ 5 次 | Dialog: "后台服务无法稳定运行，是否进入安全模式？" |

### 4.2 应用崩溃恢复

应用重启后检测到上次异常退出：

| 元素 | 说明 |
|------|------|
| 恢复对话框 | "检测到上次异常退出" |
| 选项 | [恢复上次状态] [安全启动] |
| 崩溃日志 | 可查看崩溃时的日志 |

## 5. 断路器状态

### 5.1 断路器指示

| 状态 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 关闭（正常） | `icon-shield-check` | success | 请求正常通过 |
| 开启（熔断） | `icon-shield-off` | danger | 请求被拒绝 |
| 半开（试探） | `icon-shield` | warning | 试探性放行请求 |

### 5.2 熔断通知

断路器状态变更时：
- 关闭 → 开启：Toast (Error) + Banner 提示
- 开启 → 半开：Toast (Warning)
- 半开 → 关闭：Toast (Success)

## 6. 通知中心

### 6.1 通知触发

状态栏通知铃铛 `icon-bell`，未读数角标。

### 6.2 通知面板

| 元素 | 说明 |
|------|------|
| 面板头部 | "通知" + [全部已读] |
| 通知列表 | 按时间倒序，虚拟滚动 |
| 通知项 | 图标 + 标题 + 摘要 + 时间 |
| 空状态 | "暂无新通知" |

### 6.3 通知类型

| 类型 | 图标 | 说明 |
|------|------|------|
| 系统 | `icon-info` | 系统状态变更 |
| 任务 | `icon-check-square` | 任务状态更新 |
| 安全 | `icon-shield` | 安全策略触发 |
| 错误 | `icon-x-circle` | 错误发生通知 |
