# 设置与配置

> 应用设置、外观主题、工作区配置、模型管理、安全策略、索引设置与数据管理

## 1. 通用设置

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 语言 | Select | 跟随系统 | 中文 / English |
| 启动时打开上次工作区 | Toggle | 开 | 自动恢复上次工作状态 |
| 检查更新 | Toggle | 开 | 启动时检查新版本 |
| 自动创建检查点 | Toggle | 开 | 变更应用前自动创建 |
| 检查点保留数量 | NumberInput | 50 | 超出后自动清理最旧 |
| 默认终端 Shell | Select | 系统默认 | PowerShell / Bash / Zsh |
