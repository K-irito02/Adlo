# 主窗口与应用壳层

> Electron 桌面应用的主框架、布局结构、导航体系与全局通用组件

## 1. 主窗口布局

```
┌─────────────────────────────────────────────────────┐
│  TitleBar (拖拽区 | 窗口控制)                        │
├────────┬────────────────────────────────────────────┤
│        │  Toolbar (上下文操作栏)                      │
│  Side  ├────────────────────────────────────────────┤
│  bar   │                                            │
│        │  Content Area (主内容区)                     │
│  Nav   │                                            │
│        │                                            │
│        ├────────────────────────────────────────────┤
│        │  Bottom Panel (终端/输出，可折叠)             │
├────────┴────────────────────────────────────────────┤
│  StatusBar (工作区 | 索引状态 | 模型 | 通知)          │
└─────────────────────────────────────────────────────┘
```

### 1.1 自定义标题栏

| 元素 | 说明 |
|------|------|
| 拖拽区 | 无系统标题栏时提供窗口拖拽 |
| 面包屑 | 当前页面路径，可点击导航 |
| 窗口控制 | 最小化 / 最大化 / 关闭（遵循平台惯例） |

### 1.2 侧边栏导航

| 导航项 | 图标 | 快捷键 | 说明 |
|--------|------|--------|------|
| 对话 | `icon-message-square` | `Ctrl+1` | 主交互界面 |
| 编辑器 | `icon-code` | `Ctrl+2` | 代码编辑与变更预览 |
| 任务 | `icon-check-square` | `Ctrl+3` | 任务与审批中心 |
| 搜索 | `icon-search` | `Ctrl+4` | 全局搜索 |
| 终端 | `icon-terminal` | `Ctrl+5` | 终端面板 |
| 设置 | `icon-settings` | `Ctrl+,` | 设置页面 |

侧边栏支持折叠为图标模式（`Ctrl+B` 切换），折叠后仅显示图标，悬停显示 Tooltip。

### 1.3 状态栏

| 区域 | 内容 | 说明 |
|------|------|------|
| 左侧 | 工作区名称 + Git 分支 | 点击切换工作区 |
| 中左 | 索引状态指示 | 索引中/就绪/错误 |
| 中右 | 当前模型名称 | 点击跳转模型设置 |
| 右侧 | 通知铃铛 + 未读数 | 点击展开通知面板 |

## 2. 全局组件

### 2.1 确认对话框

按风险等级分级：

| 等级 | 图标色 | 确认按钮 | 二次确认 | 场景 |
|------|--------|----------|----------|------|
| Info | primary | 普通 | 无 | 一般确认 |
| Warning | warning | 黄色 | 无 | 可逆操作 |
| Danger | danger | 红色 | 勾选确认框 | 不可逆操作 |
| Critical | danger | 红色 | 手动输入确认文字 | 极高危操作 |

### 2.2 Toast 通知

| 类型 | 图标 | 持续时间 | 用途 |
|------|------|----------|------|
| Success | `icon-check-circle` | 3s | 操作成功 |
| Error | `icon-x-circle` | 手动关闭 | 操作失败 |
| Warning | `icon-alert-triangle` | 5s | 警告提示 |
| Info | `icon-info` | 3s | 一般信息 |

### 2.3 加载状态

| 状态 | 组件 | 场景 |
|------|------|------|
| 页面加载 | Skeleton 屏 | 页面首次渲染 |
| 局部加载 | Spinner (16px) | 按钮内、行内 |
| 长耗时 | ProgressBar | 文件操作、索引构建 |
| 不确定耗时 | Indeterminate ProgressBar | 上传/处理中 |

### 2.4 空状态

| 类型 | 标题 | 引导操作 |
|------|------|----------|
| 无数据 | "暂无数据" | [新建] |
| 无搜索结果 | "未找到匹配项" | [清除筛选] |
| 无工作区 | "请先打开工作区" | [打开工作区] |
| 无权限 | "无权访问" | — |

### 2.5 Tooltip

- 触发：Hover 500ms / Focus
- 方向：自动选择最佳位置避免溢出
- 内容：单行文字或格式化富文本

## 3. 全局快捷键

| 快捷键 | 功能 | 条件 |
|--------|------|------|
| `Ctrl+1~5` | 切换侧边栏导航 | 始终可用 |
| `Ctrl+B` | 切换侧边栏折叠 | 始终可用 |
| `Ctrl+K` | 全局搜索 | 始终可用 |
| `Ctrl+,` | 打开设置 | 始终可用 |
| `Ctrl+O` | 打开工作区 | 始终可用 |
| `Ctrl+S` | 创建检查点 | 有活跃工作区 |
| `Ctrl+Shift+L` | 打开日志 | 始终可用 |
| `Escape` | 关闭弹窗/模态框 | 有打开的弹窗 |
| `?` | 显示快捷键帮助 | 始终可用 |

## 4. 右键菜单

通用菜单项：复制 / 复制路径 / 刷新 / 在文件管理器中显示 / 查看详情

各页面可追加专属菜单项。

## 5. 无障碍

| 要求 | 实现 |
|------|------|
| 键盘导航 | Focus Ring 可见、Tab 序列符合视觉顺序、模态框 Focus Trap |
| 屏幕阅读器 | ARIA 地标、`aria-live` 实时区域、`aria-label` 图标替代 |
| 颜色非唯一信息 | 图标 + 文字双重传达，不仅依赖颜色 |
