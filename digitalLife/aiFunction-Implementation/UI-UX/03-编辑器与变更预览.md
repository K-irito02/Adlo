# 编辑器与变更预览

> 代码编辑器集成、文件浏览、Diff 视图、补丁预览与应用、文件操作

## 1. 编辑器面板布局

```
┌──────────────────────────────────────────────────┐
│  文件标签页 (Tab Bar)                              │
│  [file1.ts] [file2.ts*] [+]                       │
├──────────┬───────────────────────────────────────┤
│          │  面包屑: src / components / file.ts     │
│  文件    ├───────────────────────────────────────┤
│  树      │                                       │
│          │  代码编辑区                             │
│          │  (Monaco / CodeMirror)                 │
│          │                                       │
│          │                                       │
├──────────┴───────────────────────────────────────┤
│  Minimap | 行号 | 语法高亮 | 语言模式              │
└──────────────────────────────────────────────────┘
```

## 2. 文件树

### 2.1 文件树结构

| 元素 | 说明 |
|------|------|
| 根目录 | 工作区名称 |
| 目录节点 | `icon-folder` / `icon-folder-open`，点击展开/折叠 |
| 文件节点 | 按类型显示图标（`icon-file-code` / `icon-file-text` 等） |
| Git 状态 | 文件名后颜色标记：修改(warning) / 新增(success) / 删除(danger) |
| 懒加载 | 展开目录时才加载子节点 |

### 2.2 文件树操作

| 操作 | 触发 | 说明 |
|------|------|------|
| 打开文件 | 单击 | 在编辑器中打开 |
| 预览 | 单击（未修改时） | 临时预览，点击其他文件自动替换 |
| 固定标签 | 双击 | 固定为永久标签页 |
| 右键菜单 | 右键 | 复制路径 / 重命名 / 删除 / 在文件管理器中显示 |

### 2.3 文件搜索过滤

文件树顶部搜索框，实时过滤文件名。

## 3. 代码编辑器

### 3.1 编辑器功能

| 功能 | 说明 |
|------|------|
| 语法高亮 | 根据文件语言自动切换 |
| 行号 | 左侧显示，可点击选中行 |
| Minimap | 右侧缩略图（可关闭） |
| 搜索替换 | `Ctrl+F` / `Ctrl+H` |
| 跳转定义 | `Ctrl+Click`（预留） |
| 折叠 | 代码块折叠/展开 |

### 3.2 编辑器状态

| 状态 | 说明 |
|------|------|
| 只读 | AI 建议的变更预览，不可直接编辑 |
| 可编辑 | 用户手动打开的文件 |
| 修改标记 | 标签页文件名后 `*` 标记 |

### 3.3 标签页

| 元素 | 说明 |
|------|------|
| 文件名 | 短名 + 修改标记 |
| 关闭按钮 | `icon-x`，悬停显示 |
| 右键菜单 | 关闭 / 关闭其他 / 关闭已保存 / 复制路径 |
| 拖拽排序 | 标签页可拖拽调整顺序 |

## 4. Diff 视图

### 4.1 视图模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| Unified (内联) | 修改内容在同一文件中标记 | 小范围变更 |
| Split (并排) | 左旧右新并排显示 | 大范围变更、对比审查 |

### 4.2 Diff 标记

| 类型 | 样式 | 说明 |
|------|------|------|
| 新增行 | 绿色背景 + 左侧绿色竖线 | 添加的代码 |
| 删除行 | 红色背景 + 左侧红色竖线 | 删除的代码 |
| 修改行 | 黄色背景 + 左侧黄色竖线 | 修改的代码 |
| 行内差异 | 深色高亮文字 | 行内具体变更字符 |

### 4.3 Diff 导航

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 上一处差异 | `F7` | 跳转到上一个变更块 |
| 下一处差异 | `Shift+F7` | 跳转到下一个变更块 |
| 切换视图 | — | Unified / Split 切换 |

## 5. 补丁预览与应用

### 5.1 变更预览面板

AI 生成变更后，在对话流中或编辑器中展示：

| 元素 | 说明 |
|------|------|
| 变更摘要 | "修改 3 个文件，+45/-12 行" |
| 文件列表 | 变更文件路径 + 增删行数统计 |
| 预览按钮 | [预览变更] → 打开 Diff 视图 |
| 操作按钮 | [应用全部] [逐个审查] [拒绝] |

### 5.2 逐个审查模式

```
┌─ 变更审查 (2/5) ─────────────────────────┐
│  src/utils/helper.ts  +12 -3              │
│  ┌──────────────────────────────────────┐ │
│  │  Diff 视图 (当前文件)                 │ │
│  └──────────────────────────────────────┘ │
│  [拒绝] [跳过]          [应用此文件 →]    │
└───────────────────────────────────────────┘
```

| 操作 | 说明 |
|------|------|
| 应用此文件 | 接受当前文件变更，进入下一个 |
| 跳过 | 暂不处理，进入下一个 |
| 拒绝 | 拒绝当前文件变更 |
| 应用全部 | 接受所有剩余变更（需确认） |

### 5.3 应用确认

应用变更前弹出确认（Danger 级别）：
- 列出将修改的文件数量
- 提示将自动创建检查点
- [应用] [取消]

### 5.4 回滚

| 操作 | 说明 |
|------|------|
| 撤销上次应用 | 恢复到应用前的检查点 |
| 查看历史 | 打开检查点列表选择恢复点 |

## 6. 文件操作反馈

| 操作 | 成功反馈 | 失败反馈 |
|------|----------|----------|
| 创建文件 | Toast: "文件已创建" | Toast (Error): "创建失败: {原因}" |
| 重命名 | 自动更新标签页和文件树 | Toast (Error): "重命名失败" |
| 删除 | 从标签页和文件树移除 | Toast (Error): "删除失败" |
| 保存 | 标签页 `*` 消失 | Toast (Error): "保存失败" |
