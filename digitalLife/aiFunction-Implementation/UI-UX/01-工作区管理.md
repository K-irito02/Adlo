# 工作区管理

> 工作区选择、会话管理、Git 状态、检查点与脏保护

## 1. 工作区选择器

### 1.1 无工作区状态

首次启动或未打开工作区时，内容区显示引导：

| 元素 | 说明 |
|------|------|
| 图标 | `icon-folder-open` (大尺寸) |
| 标题 | "打开工作区" |
| 描述 | "选择一个项目目录开始" |
| 主按钮 | [打开工作区] → 调起系统目录选择器 |
| 次要链接 | "最近打开的工作区" → 展开最近列表 |

### 1.2 工作区切换

状态栏点击工作区名称，弹出下拉面板：

| 元素 | 说明 |
|------|------|
| 当前工作区 | 高亮显示，带 `icon-check` 标记 |
| 最近列表 | 工作区名称 + 路径摘要 + 最后打开时间 |
| 打开新工作区 | [打开其他...] 按钮 → 目录选择器 |

### 1.3 目录选择器

使用原生系统目录选择对话框，选择后自动触发索引构建。

## 2. Git 状态

### 2.1 状态栏指示

| 状态 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 已同步 | `icon-git-branch` | muted | 分支名正常显示 |
| 有未提交 | `icon-git-branch` | warning | 分支名 + 变更数 |
| 有未推送 | `icon-arrow-up-circle` | primary | 分支名 + 待推送数 |
| 冲突 | `icon-alert-circle` | danger | 分支名 + "冲突" |
| 非 Git 仓库 | `icon-folder` | muted | 仅显示目录名 |

### 2.2 工作区头部信息

| 元素 | 说明 |
|------|------|
| 工作区名称 | 目录名，可编辑备注 |
| Git 分支 | 当前分支 + 状态标签 |
| 最后索引时间 | 相对时间显示 |
| 操作按钮 | [刷新索引] [创建检查点] |

## 3. 会话管理

### 3.1 会话列表

侧边栏对话页顶部，以紧凑列表展示：

| 元素 | 说明 |
|------|------|
| 会话标题 | 自动生成或用户自定义 |
| 状态标记 | 进行中 / 已完成 / 已归档 |
| 时间 | 创建时间或最后活跃时间 |
| 当前会话 | `icon-play` 标记 + 高亮背景 |

### 3.2 会话操作

| 操作 | 图标 | 说明 |
|------|------|------|
| 新建会话 | `icon-plus` | 创建新对话 |
| 切换会话 | 点击列表项 | 切换到历史会话 |
| 重命名 | `icon-edit` | 修改会话标题 |
| 归档 | `icon-archive` | 归档已完成会话 |
| 删除 | `icon-trash` | 删除会话（需确认） |

## 4. 检查点

### 4.1 创建检查点

| 触发方式 | 说明 |
|----------|------|
| `Ctrl+S` | 手动创建 |
| 变更应用前 | 自动创建 |
| 定时 | 按设置间隔自动创建 |

创建时弹出简短输入框，可添加备注（可选）。

### 4.2 检查点列表

| 元素 | 说明 |
|------|------|
| 时间戳 | 创建时间 |
| 备注 | 用户备注或自动描述 |
| 类型标记 | 手动 / 自动 / 变更前 |
| 操作 | [恢复] [查看差异] |

### 4.3 恢复检查点

恢复前弹出确认对话框（Warning 级别）：
- 显示检查点时间与备注
- 列出恢复后将被撤销的变更数量
- [恢复] [取消]

## 5. 脏保护

### 5.1 未保存变更提示

| 场景 | UI 反馈 |
|------|----------|
| 切换工作区 | Dialog: "当前有 N 项未保存变更，是否先创建检查点？" |
| 关闭应用 | Dialog: "有未保存变更，是否保存后再退出？" |
| 切换会话 | Toast: "当前会话有未保存变更" |

### 5.2 脏状态指示

| 元素 | 说明 |
|------|------|
| 标题栏标记 | 工作区名后显示 `●` 圆点（warning 色） |
| 状态栏标记 | "N 项未保存" 文字 |
| 关闭按钮 | 红点标记提示有未保存内容 |
