# 任务与审批

> 任务中心、审批队列、风险分级、审计日志与安全模式

## 1. 任务列表

### 1.1 列表视图

| 列 | 说明 |
|------|------|
| 风险等级 | 色块标记（低/中/高/极高） |
| 任务标题 | 简要描述 |
| 类型 | 文件操作 / 命令执行 / 配置变更 |
| 状态 | 待审批 / 已批准 / 已拒绝 / 已执行 / 已回滚 |
| 创建时间 | 相对时间 |
| 操作 | [查看] [审批] |

### 1.2 筛选与排序

| 筛选项 | 选项 |
|--------|------|
| 状态 | 全部 / 待审批 / 已完成 / 已拒绝 |
| 风险等级 | 全部 / 低 / 中 / 高 / 极高 |
| 类型 | 全部 / 文件操作 / 命令执行 / 配置变更 |
| 排序 | 按时间 / 按风险等级 |

### 1.3 批量操作

选中多个任务后，底部浮动工具栏：

| 操作 | 条件 |
|------|------|
| 批量批准 | 仅低/中风险可批量 |
| 批量拒绝 | 任意风险等级 |
| 批量导出 | 任意状态 |

## 2. 任务详情

点击任务展开详情面板（右侧抽屉）：

| 元素 | 说明 |
|------|------|
| 风险等级标签 | 颜色 + 文字 + 图标 |

## 3. 审批操作

### 3.1 风险等级与审批要求

| 风险等级 | 颜色 | 审批方式 | 适用场景 |
|----------|------|----------|----------|
| 低 | success | 自动批准或一键批准 | 读取操作、查看文件 |
| 中 | warning | 一键批准 | 修改非核心文件 |
| 高 | danger | 确认对话框 + 勾选确认 | 修改核心配置、执行命令 |
| 极高 | danger (闪烁) | 手动输入确认文字 | 删除文件、系统级操作 |

### 3.2 审批流程

```
任务创建 → 风险评估 → 等待审批 → 批准/拒绝 → 执行/取消
                                    ↓
                              执行结果反馈
                                    ↓
                              审计记录写入
```

### 3.3 安全模式

| 模式 | 说明 | 触发条件 |
|------|------|----------|
| 正常模式 | 按风险等级分级审批 | 默认 |
| 严格模式 | 所有操作均需手动审批 | 用户手动开启 |
| 锁定模式 | 拒绝所有变更操作 | 连续高危操作触发 |

模式切换时全局横幅提示当前模式。

## 4. 审计日志

### 4.1 日志条目

| 字段 | 说明 |
|------|------|
| 时间 | 精确到毫秒 |
| 操作类型 | 批准 / 拒绝 / 执行 / 回滚 |
| 操作者 | 用户 / 系统 / 自动 |
| 任务摘要 | 简要描述 |
| 风险等级 | 对应颜色标记 |

### 4.2 日志筛选

| 筛选项 | 选项 |
|--------|------|
| 时间范围 | 今天 / 最近7天 / 最近30天 / 自定义 |
| 操作类型 | 全部 / 批准 / 拒绝 / 执行 / 回滚 |
| 风险等级 | 全部 / 低 / 中 / 高 / 极高 |

### 4.3 日志导出

[导出] 按钮 → 选择格式（JSON / CSV）→ 保存到文件

## 5. 命令治理

### 5.1 命令白名单

设置页可配置允许自动执行的命令列表，白名单内命令跳过审批。

### 5.2 命令拦截

非白名单命令执行前，弹出审批对话框：

| 元素 | 说明 |
|------|------|
| 命令内容 | 完整命令文本（等宽字体） |
| 风险评估 | 系统评估的风险等级 |
| 影响说明 | 命令可能产生的影响 |
| 操作 | [批准执行] [拒绝] [加入白名单] |
