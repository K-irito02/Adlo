# 终端与命令执行

> 终端面板、命令执行流程、输出流式展示、模型网关状态

## 1. 终端面板

### 1.1 面板控制

| 操作 | 说明 |
|------|------|
| 折叠/展开 | 点击面板标题栏或 `Ctrl+`` ` |
| 调整高度 | 拖拽面板顶部边缘 |
| 最大化 | 双击标题栏，面板占满内容区 |
| 关闭 | 关闭按钮，面板折叠到最小 |

### 1.2 终端标签页

| 元素 | 说明 |
|------|------|
| 标签名 | "终端 N" 或自定义名称 |
| 关闭按钮 | `icon-x`，悬停显示 |
| 新建 | `+` 按钮创建新终端实例 |

## 2. 命令执行流程

### 2.1 用户直接输入

用户在终端中输入命令，直接执行（受命令治理约束）。

### 2.2 Agent 发起命令

Agent 执行需要运行命令时，弹出审批对话框：

| 元素 | 说明 |
|------|------|
| 命令文本 | 等宽字体完整展示 |
| 风险等级 | 颜色标记 + 评估理由 |
| 工作目录 | 命令执行路径 |
| 操作 | [批准执行] [拒绝] [加入白名单] |

### 2.3 命令白名单

白名单内命令自动执行，跳过审批：
- 在设置页配置白名单规则
- 支持通配符匹配（如 `git status*`）
- 白名单变更需确认（Warning 级别）

## 3. 输出流式展示

### 3.1 输出渲染

| 类型 | 样式 | 说明 |
|------|------|------|
| 标准输出 | 默认文字色 | 正常输出 |
| 标准错误 | danger 色 | 错误信息 |
| 命令提示符 | muted 色 | `$` 或自定义 PS1 |
| 进度信息 | primary 色 | 构建进度、下载进度等 |

### 3.2 长时间运行命令

| 状态 | 指示 |
|------|------|
| 运行中 | 标签页显示 Spinner + 命令名 |
| 退出码 0 | 标签页恢复正常 |
| 退出码非 0 | 标签页 danger 色标记 + Toast 通知 |

### 3.3 输出操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 中断 | `Ctrl+C` | 发送 SIGINT |
| 清屏 | — | 清空当前终端输出 |
| 滚动到底 | `Ctrl+End` | 跳转到最新输出 |
| 搜索输出 | `Ctrl+F` | 在终端输出中搜索 |
| 复制选中 | `Ctrl+Shift+C` | 复制选中文本 |

## 4. 模型网关状态

### 4.1 状态栏指示

| 状态 | 图标 | 颜色 | 说明 |
|------|------|------|------|
| 已连接 | `icon-zap` | success | 模型可用 |
| 连接中 | `icon-loader` | primary | 正在建立连接 |
| 限速 | `icon-zap` | warning | 速率受限 |
| 离线 | `icon-zap-off` | muted | 无法连接 |
| 错误 | `icon-zap-off` | danger | 连接异常 |

### 4.2 模型信息面板

点击状态栏模型名称，弹出面板：

| 元素 | 说明 |
|------|------|
| 当前模型 | 模型名 + 提供商 |
| 连接状态 | 在线/离线 + 延迟 |
| Token 用量 | 本次会话累计 |
| 速率限制 | 剩余请求数 / 重置时间 |
| 切换模型 | 下拉选择其他可用模型 |

### 4.3 流式输出状态

AI 回复流式输出时：

| 状态 | 指示 |
|------|------|
| 生成中 | 消息末尾光标闪烁 + "生成中..." 文字 |
| 已完成 | 光标消失，显示完整回复 |
| 中断 | 显示 "[已中断]" 标记 |
| 错误 | danger 色错误信息 + [重试] 按钮 |
