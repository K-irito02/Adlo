# AI Digital Life - UI 设计系统

> 版本: v0.1.0 (Phase 0)
>
> 桌面应用专属 UI 风格系统 | Electron + React + TypeScript

## 核心设计原则

### 1. 桌面优先 (Desktop First)

- 针对 Electron 桌面应用场景优化
- 屏幕空间，信息密度适中（非必要显示的内容请隐藏或最小化，只有当用户点击或触发时才显示）
- 支持窗口缩放自适应（768px ~ 1920px+）
- 遵循平台原生体验（Windows/macOS/Linux）

### 2. 简约设计（极简风格）

- 组件数量有限，保持界面简洁
- 避免使用复杂的布局和动画
- 保持一致的视觉风格，避免使用不同的字体、颜色、图标等
- 参考 Cursor 新出的桌面端 UI/UX 设计

### 3. 安全边界可视化

- 权限等级通过颜色和图标直观区分
- 高风险操作有明确的视觉警示层级
- 审批流程的每一步都有清晰的 UI 反馈
- 安全模式/受限模式有醒目的视觉标识

### 4. 语义化配色

- 所有颜色使用语义化命名（primary / danger / success / warning）
- 禁止在组件中直接使用硬编码色值
- 支持浅色/深色两种主题模式，主题跟随系统或用户手动切换
- 每套主题均通过 WCAG AA 对比度验证

### 5. SVG 图标唯一性

- **严禁使用 emoji 作为 UI 图标**
- 统一使用 SVG 格式矢量图标
- 图标支持 `currentColor` 自适应主题色
- 图标尺寸标准化：12px / 16px / 20px / 24px / 32px / 48px

### 6. 渐进增强的无障碍

- 键盘可完全操作所有 UI 元素
- 屏幕阅读器友好的语义化结构
- 颜色不是唯一的信息传达方式

## 技术栈约束


| 决策项   | 选型                           | 说明              |
| ----- | ---------------------------- | --------------- |
| UI 框架 | React 18+                    | 组件化开发           |
| 样式方案  | CSS Variables + Tailwind CSS | 运行时主题切换能力       |
| 状态管理  | Zustand                      | 轻量级全局状态         |
| 图标方案  | 自建 SVG Icon System           | Lucide 风格，自定义扩展 |
| 字体渲染  | 系统字体栈 + 编程字体                 | 跨平台一致性          |
| 构建工具  | Vite                         | 快速 HMR 与构建      |


## 主题模式

支持 **Light（浅色）/ Dark（深色）/ System（跟随系统）** 三种主题模式。
