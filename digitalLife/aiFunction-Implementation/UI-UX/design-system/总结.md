# UI/UX 设计系统总结

> 现代化AI编程桌面应用完整 UI 规范精要，覆盖目前的全部功能模块

## 设计原则

- **桌面优先**：Electron 原生体验，768px~1920px+ 自适应
- **简约设计**：组件有限、布局简洁、风格统一
- **安全边界可视化**：风险等级通过颜色/图标直观区分
- **语义化配色**：primary / danger / success / warning / muted
- **SVG 图标唯一性**：`icon-*` 命名，支持 currentColor 自适应主题
- **渐进增强无障碍**：键盘完全可操作 + 屏幕阅读器友好

## 一、主窗口与应用壳层

### 侧边栏导航

| 导航项 | 快捷键 |
|--------|--------|
| 对话 `Ctrl+1` | 编辑器 `Ctrl+2` | 任务 `Ctrl+3` | 搜索 `Ctrl+4` | 终端 `Ctrl+5` | 设置 `Ctrl+,` |

侧边栏支持 `Ctrl+B` 折叠为图标模式。

### 全局组件

- **确认对话框**：Info(普通) → Warning(黄色) → Danger(勾选确认) → Critical(手动输入文字)
- **Toast 通知**：Success(3s) / Error(手动关闭) / Warning(5s) / Info(3s)
- **加载状态**：Skeleton 屏 / Spinner(16px) / ProgressBar / Indeterminate ProgressBar
- **空状态**：无数据 / 无搜索结果 / 无工作区 / 无权限 — 各有引导操作

### 全局快捷键

`Ctrl+B`(折叠) `Ctrl+K`(搜索) `Ctrl+O`(打开工作区) `Ctrl+S`(检查点) `Ctrl+Shift+L`(日志) `Escape`(关闭弹窗)

## 二、工作区管理

### 工作区选择

- 无工作区时显示引导页（图标 + [打开工作区] 按钮）
- 状态栏点击切换工作区（最近列表 + 打开其他）
- 选择后自动触发索引构建

### Git 状态

| 状态 | 颜色 | 说明 |
|------|------|------|
| 已同步 | muted | 分支名正常 |
| 有未提交 | warning | 分支名 + 变更数 |
| 冲突 | danger | "冲突" 标记 |

### 会话管理

紧凑列表展示：标题 / 状态(进行中·已完成·已归档) / 时间 / 当前会话标记。操作：新建 / 切换 / 重命名 / 归档 / 删除。

### 检查点

触发方式：`Ctrl+S` 手动 / 变更应用前自动 / 定时自动。恢复前 Warning 确认。

### 脏保护

未保存变更时：标题栏 `●` 圆点(warning) + 状态栏 "N项未保存"。切换工作区/关闭应用时弹出确认 Dialog。

## 三、对话交互 (Phase 1 核心)

### 消息类型

- **用户消息**：纯文本 + [编辑] [重新发送]
- **Assistant 消息**：Markdown 渲染(标题/列表/代码块/链接) + 流式逐字输出 + [复制] [重新生成]
- **代码块**：语言标签 + 复制按钮(`icon-copy→check`) + 超过20行自动折叠
- **文件引用**：内联卡片(路径+行号) + [查看][复制路径]

### 斜杠命令 (`/` 触发)

`/file`(添加文件) `/search`(搜索代码库) `/task`(创建任务) `/checkpoint`(创建检查点) `/model`(切换模型) `/clear`(清空对话)

### 上下文 & Agent 工作流

- 上下文面板：Token 进度条(正常<70% / 接近上限70-90% / 超出>90%) + 移除/添加按钮
- Agent 执行步骤卡片：已完成(success) / 进行中(primary旋转) / 等待中(muted) / 失败(danger) / 等待审批(warning)
- 执行结果：变更摘要("修改3文件,+45/-12行") + [预览变更] [应用到工作区]

### 对话操作

`Enter` 发送 / `Shift+Enter` 换行 / `Escape` 中断生成 / `Ctrl+N` 新建对话

---

## 四、编辑器与变更预览 (Phase 1 核心)

### 编辑器功能

- 文件树：懒加载子节点 + Git 状态颜色标记 + 顶部搜索过滤
- 编辑器状态：只读(AI预览) / 可编辑(用户打开) / 修改标记(`*`)
- 标签页：拖拽排序 + 右键菜单(关闭/关闭其他/复制路径)

### Diff 视图

- **Unified**(内联)：小范围变更；**Split**(并排)：大范围变更
- 标记：新增(绿) / 删除(红) / 修改(黄) / 行内差异(深色高亮)
- 导航：`F7` 上一个差异 / `Shift+F7` 下一个差异

### 补丁预览与应用

1. AI 生成变更 → 展示摘要("+45/-12 行") + 文件列表
2. **逐个审查模式**：Diff 视图 + [拒绝] [跳过] [应用此文件]
3. 应用确认(Danger 级别)：列出修改文件数 + 自动创建检查点提示
4. 回滚：撤销上次应用 / 查看历史检查点

## 五、任务与审批

### 任务列表

列：风险等级(低·中·高·极高色块) / 标题 / 类型(文件操作·命令执行·配置变更) / 状态(待审批·已批准·已拒绝·已执行·已回滚) / 操作。支持筛选排序 + 批量操作。

### 审批体系

| 风险等级 | 审批方式 | 适用场景 |
|----------|----------|----------|
| 低(success) | 自动或一键批准 | 读取操作 |
| 中(warning) | 一键批准 | 修改非核心文件 |
| 高(danger) | 对话框+勾选确认 | 修改核心配置、执行命令 |
| 极高(danger闪烁) | 手动输入确认文字 | 删除文件、系统级操作 |

流程：任务创建 → 风险评估 → 等待审批 → 批准/拒绝 → 执行/取消 → 审计记录

### 安全模式

正常(分级审批) / 严格(全手动) / 锁定(拒绝所有变更，连续高危触发)。全局横幅提示当前模式。

### 审计日志

字段：时间(ms) / 操作类型 / 操作者 / 任务摘要 / 风险等级。支持按时间/类型/风险筛选 + JSON/CSV 导出。

### 命令治理

白名单命令跳过审批；非白名单命令弹出审批对话框(命令文本+风险评估+[批准执行][拒绝][加入白名单])。

## 六、终端与命令执行 (Phase 1 核心)

### 终端面板

底部可折叠面板，多标签页实例。控制：`Ctrl+`` 折叠展开 / 拖拽调整高度 / 双击最大化。

### 输出渲染

标准输出(默认色) / 错误输出(danger) / 提示符(muted) / 进度信息(primary)。长时间运行命令：Spinner + 退出码标记。

### 输出操作

`Ctrl+C` 中断 / `Ctrl+F` 搜索 / `Ctrl+End` 滚到底 / `Ctrl+Shift+C` 复制

### 模型网关状态

| 状态 | 颜色 | 说明 |
|------|------|------|
| 已连接 | success | 模型可用 |
| 连接中 | primary | 正在建立连接 |
| 限速 | warning | 速率受限 |
| 离线 | muted | 无法连接 |
| 错误 | danger | 连接异常 |

点击状态栏模型名弹出详情面板(连接状态/Token用量/速率限制/切换模型)。

## 七、设置与配置

修改后自动保存。

### 设置分类

| 分类 | 核心设置项 |
|------|-----------|
| **通用** | 语言 / 启动恢复工作区 / 检查更新 / 自动检查点 / 检查点保留数 / 默认Shell |
| **外观** | 主题模式(浅色/深色/跟随) / 5套配色方案 / 编辑器字体大小/Minimap/Tab宽 |
| **工作区** | 默认目录 / 忽略模式 / 最大数量 / 自动索引 |
| **模型** | 默认模型 / API Key(加密存储) / Base URL / 超时 / Token窗口 / 上下文收集策略 |
| **安全** | 安全模式(正常/严格/锁定) / 低风险自动批准 / 命令白名单 / 高危二次确认 |
| **索引** | 深度 / 文件大小上限 / 增量间隔 / 排除模式 / 重建索引 |
| **数据管理** | 存储(info) / 清理缓存/日志/检查点(Warning) / 导出(Info) / 重置(Critical) / 迁移版本 |
| **关于** | 版本号 / 构建信息 / 技术栈 / 许可证 / 检查更新 |

### 配色方案

## 八、系统监控与错误恢复

### 日志查看器

级别：DEBUG(muted) / INFO(primary) / WARN(warning) / ERROR(danger) / FATAL(danger闪烁)。操作：Space暂停 / Ctrl+F搜索 / Ctrl+Shift+E跳转错误 / 导出。筛选：级别+来源+关键词。

### 健康仪表盘

4 张状态卡片：索引服务 / 模型网关 / Worker 进程 / 磁盘空间。性能指标：IPC延迟 / 内存占用 / 索引大小 / 模型延迟。

### 错误分类与处理

| 类型 | 展示方式 |
|------|----------|
| 网络/文件/权限/数据错误 | Toast + 重试/详情/修复建议 |
| 系统错误(Worker崩溃等) | Dialog + 操作指引 |

### 崩溃恢复

- Worker 崩溃：首次→Toast重启 / 连续2次→Banner警告 / ≥5次→Dialog询问进入安全模式
- 应用崩溃：检测异常退出后提供[恢复上次状态] [安全启动]

### 断路器

关闭(success 正常通过) → 开启(danger 熔断拒绝) → 半开(warning 试探放行)。状态变更时 Toast + Banner 通知。

### 通知中心

状态栏铃铛 `icon-bell` + 未读角标。通知面板：时间倒序虚拟滚动列表。类型：系统 / 任务 / 安全 / 错误。
