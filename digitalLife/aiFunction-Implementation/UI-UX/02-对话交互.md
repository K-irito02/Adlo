# 对话交互

> AI 对话界面、消息渲染、引用展示、斜杠命令、上下文指示与 Agent 工作流可视化

## 1. 对话面板布局

```
┌──────────────────────────────────────────┐
│  会话标题 + 模型选择 + 操作菜单           │
├──────────────────────────────────────────┤
│                                          │
│  消息流 (Message Stream)                  │
│                                          │
│  ┌─ User ──────────────────────────┐    │
│  │ 用户消息                         │    │
│  └──────────────────────────────────┘    │
│  ┌─ Assistant ─────────────────────┐    │
│  │ AI 回复 (Markdown 渲染)          │    │
│  │ ┌─ 代码块 ──────────────────┐   │    │
│  │ │ 代码 + 语言标签 + 复制按钮  │   │    │
│  │ └────────────────────────────┘   │    │
│  │ ┌─ 文件引用 ────────────────┐   │    │
│  │ │ file.ts:12-30 [查看]      │   │    │
│  │ └────────────────────────────┘   │    │
│  └──────────────────────────────────┘    │
│                                          │
├──────────────────────────────────────────┤
│  输入区域                                │
│  ┌──────────────────────────────┬───┐   │
│  │ 多行输入框                    │ ▶ │   │
│  │ / 斜杠命令 | 附件 | 上下文    │   │   │
│  └──────────────────────────────┴───┘   │
└──────────────────────────────────────────┘
```

## 2. 消息类型

### 2.1 用户消息

| 元素 | 说明 |
|------|------|
| 头像 | 用户图标 `icon-user` |
| 内容 | 纯文本，支持代码行内标记 |
| 时间 | 相对时间，悬停显示完整时间 |
| 操作 | [编辑] [重新发送] |

### 2.2 Assistant 消息

| 元素 | 说明 |
|------|------|
| 头像 | AI 图标 `icon-bot` |
| 内容 | Markdown 渲染（标题/列表/表格/代码块/链接） |
| 流式输出 | 逐字显示，光标闪烁 |
| 操作 | [复制] [重新生成] |

### 2.3 系统消息

| 元素 | 说明 |
|------|------|
| 图标 | `icon-info` / `icon-alert-triangle` |
| 内容 | 系统通知、错误提示、状态变更 |
| 样式 | 居中、小字、muted 色 |

## 3. 代码块渲染

| 元素 | 说明 |
|------|------|
| 语言标签 | 左上角显示语言名 |
| 复制按钮 | `icon-copy`，点击后变为 `icon-check` |
| 代码内容 | 等宽字体、语法高亮 |
| 折叠 | 超过 20 行自动折叠，[展开] 按钮 |

## 4. 文件引用

AI 回复中引用文件时，以内联卡片展示：

| 元素 | 说明 |
|------|------|
| 文件图标 | 按文件类型显示对应图标 |
| 文件路径 | 相对路径 + 行号范围 |
| 操作 | [查看] → 跳转编辑器 / [复制路径] |
| 代码预览 | 悬停时 Tooltip 显示引用片段 |

## 5. 斜杠命令

输入框键入 `/` 触发命令面板：

| 命令 | 图标 | 说明 |
|------|------|------|
| `/file` | `icon-file` | 添加文件到上下文 |
| `/search` | `icon-search` | 搜索代码库 |
| `/task` | `icon-check-square` | 创建任务 |
| `/checkpoint` | `icon-save` | 创建检查点 |
| `/model` | `icon-cpu` | 切换模型 |
| `/clear` | `icon-trash` | 清空当前对话 |

命令面板交互：
- 输入 `/` 后弹出，模糊匹配过滤
- 上下键选择，Enter 确认
- `Escape` 关闭

## 6. 上下文指示

### 6.1 上下文面板

输入区域上方，展示当前对话附带的上下文：

| 元素 | 说明 |
|------|------|
| 上下文标签 | `icon-paperclip` + 文件名/范围 |
| Token 计数 | "已用 / 最大" 进度条 |
| 移除按钮 | `icon-x` 移除单个上下文项 |
| 添加按钮 | [+] 添加文件/代码片段 |

### 6.2 Token 用量指示

| 状态 | 颜色 | 说明 |
|------|------|------|
| 正常 | primary | 用量 < 70% |
| 接近上限 | warning | 用量 70%-90% |
| 超出 | danger | 用量 > 90%，提示精简上下文 |

## 7. Agent 工作流可视化

### 7.1 执行状态

Agent 执行任务时，消息流中显示步骤卡片：

```
┌─ Agent 执行中 ──────────────────────────┐
│  [icon-loader] 分析代码结构...     ✓     │
│  [icon-loader] 检索相关文件...     ✓     │
│  [icon-loader] 生成变更方案...     ●     │  ← 当前步骤
│  [icon-circle]  等待审批                   │
└──────────────────────────────────────────┘
```

| 步骤状态 | 图标 | 颜色 |
|----------|------|------|
| 已完成 | `icon-check-circle` | success |
| 进行中 | `icon-loader` (旋转) | primary |
| 等待中 | `icon-circle` | muted |
| 失败 | `icon-x-circle` | danger |
| 等待审批 | `icon-shield` | warning |

### 7.2 执行结果

| 元素 | 说明 |
|------|------|
| 变更摘要 | "修改了 3 个文件，新增 45 行，删除 12 行" |
| 文件列表 | 变更文件路径 + 操作类型标记 |
| 操作 | [预览变更] [应用到工作区] |

## 8. 模型选择

对话面板顶部，模型切换下拉：

| 元素 | 说明 |
|------|------|
| 当前模型 | 模型名 + 提供商标签 |
| 下拉列表 | 可用模型列表 + 状态指示 |
| 状态 | 在线(绿) / 离线(灰) / 限速(黄) |

## 9. 对话操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 发送 | `Enter` | 发送消息（`Shift+Enter` 换行） |
| 停止生成 | `Escape` | 中断流式输出 |
| 新建对话 | `Ctrl+N` | 新建会话 |
| 清空对话 | — | 清空当前会话消息（需确认） |
