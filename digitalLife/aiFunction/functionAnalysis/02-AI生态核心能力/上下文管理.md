# 上下文管理

## 功能描述

上下文管理是AI编程工具管理对话上下文、代码上下文和项目上下文的核心能力，决定了AI对项目的理解深度和响应质量。通过智能化的上下文管理，AI可以在有限的Token窗口内获取最相关的信息，提供精准的代码建议和问题解决方案。

## 核心特性

### 上下文类型

#### 对话上下文

| 类型 | 描述 | 优先级 |
|------|------|--------|
| 当前指令 | 用户当前输入的指令 | 最高 |
| 最近对话 | 最近N轮对话历史 | 高 |
| 决策记录 | 重要的决策和约定 | 中 |
| 摘要历史 | 早期对话的压缩摘要 | 低 |

#### 代码上下文

| 类型 | 描述 | 优先级 |
|------|------|--------|
| 当前编辑文件 | 正在编辑的文件内容 | 最高 |
| 选中代码 | 用户选中的代码片段 | 最高 |
| 光标周围代码 | 光标前后的代码 | 高 |
| 直接依赖文件 | import/require的文件 | 中 |
| 类型定义文件 | 类型声明文件 | 中 |
| 测试文件 | 对应的测试文件 | 低 |

#### 项目上下文

| 类型 | 描述 | 优先级 |
|------|------|--------|
| 项目配置 | package.json、tsconfig等 | 高 |
| 项目规则 | .cursorrules、CLAUDE.md等 | 高 |
| 目录结构 | 项目目录树 | 中 |
| 依赖关系 | 模块依赖图 | 中 |
| Git状态 | 当前变更状态 | 低 |

### 上下文窗口策略

#### 优先级排序

```
上下文填充优先级：
1. 系统提示词 (System Prompt)
2. 项目规则文件
3. 用户当前指令
4. 当前编辑文件/选中代码
5. 最近对话历史
6. 直接依赖文件
7. 项目配置文件
8. 间接依赖文件
9. 早期对话摘要
```

#### 动态截断

- **智能保留**：保留关键信息，移除冗余
- **摘要替代**：用摘要替代完整内容
- **引用压缩**：用文件路径替代完整文件
- **分层裁剪**：从低优先级开始裁剪

#### 上下文缓存

```
缓存策略：
├── 热缓存：当前编辑文件、最近对话
├── 温缓存：项目配置、依赖文件
└── 冷缓存：历史对话、间接依赖
```

### 上下文工程

#### 自动上下文收集

- **文件关联分析**：自动关联相关文件
- **依赖链追踪**：追踪import依赖链
- **调用图分析**：分析函数调用关系
- **变更影响分析**：分析变更影响范围

#### 上下文注入策略

| 策略 | 描述 | Token消耗 |
|------|------|----------|
| 完整注入 | 注入完整文件内容 | 高 |
| 摘要注入 | 注入文件摘要 | 中 |
| 引用注入 | 仅注入文件路径和接口 | 低 |
| 按需注入 | 根据需要动态加载 | 可控 |

#### 上下文压缩

- **代码压缩**：移除注释、空行、格式化
- **语义压缩**：保留语义，压缩表达
- **结构压缩**：只保留接口和类型定义
- **历史压缩**：对话历史压缩为摘要

### 跨会话上下文

#### 项目记忆

- **约定记录**：项目编码约定
- **决策记录**：重要技术决策
- **模式记录**：常用代码模式
- **问题记录**：常见问题及解决方案

#### 用户偏好

- **编码风格**：个人编码风格偏好
- **常用模式**：常用代码模式
- **交互习惯**：对话交互习惯
- **模型偏好**：模型选择偏好

## 应用场景

### 大型项目上下文管理

在大型项目中，智能选择最相关的上下文，避免信息过载。

### 跨文件代码修改

修改一个文件时，自动加载相关依赖文件，确保修改的一致性。

### 长对话上下文保持

在长时间对话中，保持关键上下文不丢失，避免重复解释。

### 多任务上下文切换

在不同任务间切换时，快速加载对应的上下文。

## 技术要点

### Token计算

```
Token估算规则：
- 英文：约1 Token/4字符
- 中文：约1 Token/1.5字符
- 代码：约1 Token/3字符
- 空白：约1 Token/10字符
```

### 上下文窗口分配

```
典型200K Token窗口分配：
├── 系统提示词: 5K (2.5%)
├── 项目规则: 5K (2.5%)
├── 用户指令: 2K (1%)
├── 代码上下文: 100K (50%)
├── 对话历史: 50K (25%)
├── 工具输出: 30K (15%)
└── 预留空间: 8K (4%)
```

### 上下文检索

- **向量检索**：基于语义相似度检索
- **关键词检索**：基于关键词匹配
- **结构检索**：基于AST结构检索
- **混合检索**：结合多种检索策略

### 上下文更新

- **增量更新**：只更新变化部分
- **触发更新**：文件变更触发更新
- **定时更新**：定时刷新索引
- **手动更新**：用户手动触发

## 最佳实践

1. **精简上下文**：只提供必要的上下文信息
2. **优先级明确**：明确上下文优先级，确保关键信息不被截断
3. **定期清理**：清理过时的上下文，保持信息新鲜
4. **善用引用**：使用@引用精确提供上下文
5. **项目规则**：通过项目规则文件持久化关键上下文
