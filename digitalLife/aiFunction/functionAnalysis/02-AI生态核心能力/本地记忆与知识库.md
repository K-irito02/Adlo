# 本地记忆与知识库

## 功能描述

本地记忆与知识库是AI编程工具跨会话保持上下文、积累项目知识的能力，实现长期记忆和个性化服务。通过记忆系统，AI可以记住项目约定、用户偏好、历史决策，提供更连贯和个性化的服务。

## 应用场景

### 项目上下文保持

在多个开发会话之间保持项目上下文，避免重复解释项目背景。

### 团队知识共享

共享项目约定、最佳实践，加速新成员上手。

### 个人编码风格学习

学习个人编码风格，生成符合个人习惯的代码。

### 常见问题解决方案库

积累常见问题的解决方案，快速解决类似问题。

### 代码片段管理

管理常用代码片段，快速复用代码。

## 技术要点

### 记忆存储结构

```
记忆存储结构：
~/.ai-memory/
├── projects/
│   ├── project-a/
│   │   ├── conventions.json
│   │   ├── decisions.json
│   │   └── snippets/
│   └── project-b/
├── user/
│   ├── preferences.json
│   └── habits.json
└── knowledge/
    ├── patterns.json
    └── best-practices.json
```

### 向量索引构建

```
索引构建流程：
1. 文档切分
2. 文本向量化
3. 向量存储
4. 索引构建
5. 索引更新
```

### 检索增强生成

```
RAG流程：
1. 接收用户查询
2. 检索相关记忆
3. 注入上下文
4. 生成响应
5. 更新记忆
```

### 记忆更新策略

- **增量更新**：只更新变化部分
- **定期压缩**：压缩历史记忆
- **重要性排序**：保留重要记忆
- **过期清理**：清理过期记忆
