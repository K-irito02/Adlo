# 云服务集成

## 功能描述

云服务集成是AI编程工具与主流云平台深度整合的能力，简化云资源管理。通过云服务集成，AI可以帮助开发者创建、配置、管理云资源，生成基础设施代码，优化云成本。

### 资源发现

```typescript
// 资源发现流程
async function discoverResources(cloud: string): Promise<Resource[]> {
  const resources: Resource[] = [];
  
  // 获取资源列表
  const list = await cloudClient.listResources();
  
  // 解析资源详情
  for (const item of list) {
    const detail = await cloudClient.getResource(item.id);
    resources.push(detail);
  }
  
  return resources;
}
```
