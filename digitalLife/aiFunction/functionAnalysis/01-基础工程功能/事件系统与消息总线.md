# 事件系统与消息总线

## 功能描述

事件系统与消息总线是AI编程工具跨模块通信的基础设施，实现模块间的松耦合通信和事件驱动架构。通过统一的事件系统，各功能模块可以在不直接依赖的情况下进行协作，支持Hooks机制、插件系统、状态同步等核心能力。

## 核心特性

### 事件架构

```
事件驱动架构：
┌─────────────────────────────────────┐
│           消息总线 (Event Bus)        │
├─────────────────────────────────────┤
│  发布者 → 事件通道 → 订阅者          │
│                                     │
│  文件模块 ──→ file.changed ──→ 索引  │
│  终端模块 ──→ cmd.completed ──→ AI   │
│  AI模块  ──→ code.generated ──→ 格式 │
└─────────────────────────────────────┘
```

### 通信模式

#### 发布/订阅

```
发布/订阅模式：
发布者 ──→ [事件总线] ──→ 订阅者A
                       ──→ 订阅者B
                       ──→ 订阅者C
```

- **一对多**：一个事件多个订阅者
- **松耦合**：发布者不感知订阅者
- **异步处理**：订阅者异步处理事件

#### 请求/响应

```
请求/响应模式：
请求方 ──→ [消息总线] ──→ 处理方
     ←── [响应通道] ←──
```

- **一对一**：一个请求一个处理方
- **同步/异步**：支持同步和异步响应
- **超时控制**：请求超时处理

#### 广播

```
广播模式：
广播者 ──→ [事件总线] ──→ 所有模块
```

- **全局通知**：通知所有模块
- **配置变更**：配置变更广播
- **状态同步**：全局状态同步

## 应用场景

### Hooks机制底层支撑

事件系统为Hooks机制提供底层支撑，在特定事件触发时执行自定义逻辑。

### 插件间通信

插件通过事件系统进行通信，避免直接依赖，实现松耦合。

### 状态同步

多个模块间通过事件系统同步状态，保持数据一致性。

### 审计日志

通过事件系统记录所有操作，生成审计日志。

### 实时通知

文件变更、构建完成等事件通过事件系统实时通知相关模块。

## 技术要点

### 事件总线实现

```typescript
interface EventBus {
  publish(event: Event): void;
  subscribe(topic: string, handler: EventHandler): Subscription;
  unsubscribe(subscription: Subscription): void;
  request(topic: string, data: any): Promise<any>;
}

interface Event {
  id: string;
  topic: string;
  timestamp: number;
  source: string;
  data: any;
  metadata?: Record<string, any>;
}

type EventHandler = (event: Event) => void | Promise<void>;
```

### 事件优先级

```
优先级定义：
- critical: 必须立即处理（安全事件）
- high: 优先处理（用户操作）
- normal: 正常处理（文件变更）
- low: 空闲时处理（索引更新）
```

### 性能优化

- **批量处理**：批量处理同类事件
- **防抖节流**：高频事件防抖节流
- **懒加载**：按需加载事件处理器
- **异步处理**：非关键事件异步处理

### 错误处理

- **错误隔离**：处理器错误不传播
- **重试机制**：失败事件自动重试
- **降级处理**：处理器不可用时降级
- **错误通知**：错误事件通知监控

## 最佳实践

1. **事件命名规范**：使用统一的命名规范（module.entity.action）
2. **最小事件**：只发布必要的事件，避免事件风暴
3. **异步优先**：非关键事件使用异步处理
4. **错误隔离**：确保处理器错误不影响其他订阅者
5. **监控告警**：监控事件处理延迟和错误率
