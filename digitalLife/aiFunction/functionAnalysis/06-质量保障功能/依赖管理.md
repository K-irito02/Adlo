# 依赖管理

## 功能描述

依赖管理是AI编程工具管理项目依赖、检测依赖问题的能力。通过依赖管理，AI可以帮助开发者分析依赖关系、检测安全漏洞、管理依赖版本，确保项目的依赖健康。

## 应用场景

### 依赖升级决策

分析依赖升级的影响，辅助升级决策。

### 安全漏洞修复

识别依赖安全漏洞，提供修复方案。

### 许可证合规

检查依赖许可证，确保合规性。

### 项目瘦身

识别未使用依赖，减少项目体积。

## 技术要点

### 依赖解析

```
依赖解析流程：
1. 读取package.json/lock文件
2. 构建依赖树
3. 解析版本范围
4. 检测冲突
5. 生成报告
```

### 漏洞数据库

- **NPM Advisory**：NPM官方漏洞库
- **Snyk DB**：Snyk漏洞数据库
- **GitHub Advisory**：GitHub安全公告
- **CVE数据库**：CVE漏洞数据库

### 更新策略

```
版本更新策略：
- 补丁版本: 自动更新
- 次要版本: 建议更新
- 主要版本: 评估后更新
- 预发布版本: 谨慎更新
```

### 锁文件管理

- **package-lock.json**：NPM锁文件
- **yarn.lock**：Yarn锁文件
- **pnpm-lock.yaml**：pnpm锁文件
- **版本锁定**：确保版本一致性
