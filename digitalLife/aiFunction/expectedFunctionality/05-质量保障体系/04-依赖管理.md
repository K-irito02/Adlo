# 依赖管理

## 功能概述

依赖管理系统为AI数字生命提供全生命周期的第三方依赖管理能力,覆盖依赖的发现、安装、更新、审计与清理。系统支持多种包管理器与语言生态,通过依赖树分析、版本冲突检测、安全漏洞扫描与许可证合规检查,确保依赖的安全性与合规性,同时提供依赖锁定与镜像加速,保障构建的可重复性与效率。

核心价值:
- **全生命周期管理**:从发现到清理的完整依赖管理
- **安全合规**:漏洞扫描、许可证检查、恶意包检测
- **冲突解决**:自动检测与解决版本冲突
- **可重复构建**:依赖锁定与镜像加速

## 实现优先级

**P1** - 高优先级

| 阶段 | 内容 | 预计周期 |
|------|------|----------|

| M2 | 依赖树分析 + 冲突检测 + 更新检查 | 1.5 周 |

## 核心设计

### 包管理器支持

| 语言 | 包管理器 | 锁定文件 |
|------|----------|----------|
| JavaScript/TypeScript | npm、yarn、pnpm | package-lock.json、yarn.lock、pnpm-lock.yaml |
| Python | pip、poetry、conda | requirements.txt、poetry.lock、conda-lock.yml |
| Java | maven、gradle | pom.xml、build.gradle |
| Go | go modules | go.mod、go.sum |
| Rust | cargo | Cargo.lock |

### 依赖安装

安装策略:
- 生产依赖:仅安装dependencies
- 开发依赖:安装dependencies + devDependencies
- 可选依赖:根据环境决定是否安装optionalDependencies
- 对等依赖:检查peerDependencies兼容性

安装源:
- 官方源:npmjs、pypi、maven central
- 私有源:企业私有仓库
- 镜像源:国内镜像加速

### 版本解析

语义化版本(SemVer):
- 主版本.次版本.补丁版本(如1.2.3)
- ^1.2.3:兼容的次版本更新(≥1.2.3,<2.0.0)
- ~1.2.3:兼容的补丁更新(≥1.2.3,<1.3.0)
- 1.2.3:精确版本

版本范围:
- 或(||):满足任一范围
- 与:满足所有范围
- 排除:排除特定版本

### 依赖树分析

分析内容:
- 直接依赖:package.json中声明的依赖
- 传递依赖:直接依赖所依赖的依赖
- 依赖层级:依赖的嵌套深度
- 依赖路径:从根到叶的完整路径

可视化:
- 树状图:展示依赖层级关系
- 依赖图:展示依赖间的复杂关系
- 统计信息:依赖数量、层级深度、重复依赖

### 冲突检测与解决

冲突类型:
- 版本冲突:同一依赖的不同版本需求
- 对等依赖冲突:peerDependencies版本不兼容
- 循环依赖:A依赖B,B依赖A

解决策略:
- 自动升级:升级到满足所有约束的最低版本
- 手动选择:用户手动选择版本
- 别名安装:安装多个版本并使用别名区分
- 强制覆盖:忽略冲突,强制使用指定版本

### 安全漏洞扫描

扫描内容:
- 已知漏洞(CVE):匹配NVD、GitHub Advisory等漏洞库
- 恶意包:检测已知的恶意npm/PyPI包
- 敏感信息泄露:检测依赖中的硬编码密钥
- 不安全配置:检测不安全的默认配置

扫描时机:
- 安装前:安装前扫描,发现漏洞则警告或阻止
- 定期扫描:定期扫描已安装依赖,发现新漏洞
- CI/CD集成:构建时自动扫描,阻断高危漏洞

### 许可证检查

许可证类型:
- 宽松许可:MIT、Apache-2.0、BSD
- 弱传染许可:LGPL、MPL
- 强传染许可:GPL、AGPL
- 商业许可:专有许可证

检查规则:
- 黑名单:禁止使用特定许可证
- 白名单:仅允许使用特定许可证
- 兼容性检查:检查许可证与项目许可证的兼容性

### 依赖更新

更新策略:
- 补丁更新:自动更新补丁版本
- 次版本更新:提示更新次版本
- 主版本更新:手动确认更新主版本

更新检查:
- 定期检查:定期检查依赖更新
- 手动检查:用户手动触发检查
- 自动化PR:自动创建更新PR

### 依赖清理

清理内容:
- 未使用依赖:package.json中声明但未使用的依赖
- 孤立依赖:未在package.json中声明但存在的依赖
- 重复依赖:多个版本的同一依赖
- 过时依赖:已停止维护的依赖

## 依赖关系

| 依赖项 | 依赖类型 | 说明 |
|--------|----------|------|
| 代码安全扫描 | 强依赖 | 依赖漏洞扫描集成 |
| CI/CD流水线集成 | 强依赖 | 构建时自动安装与检查 |
| 配置管理系统 | 弱依赖 | 依赖配置、镜像源配置 |
| 通知系统 | 弱依赖 | 漏洞告警、更新通知 |

- [ ] 冲突检测:版本冲突、对等依赖冲突、循环依赖均可检测

- [ ] 许可证检查:许可证识别准确,兼容性检查正确
- [ ] 依赖更新:更新检查准确,自动化PR可创建
