# Hooks生命周期

## 功能概述

Hooks生命周期系统为AI数字生命提供关键节点的拦截与扩展能力,允许用户在智能体运行的关键阶段(启动、工具调用前后、任务完成、停止等)注入自定义逻辑。Hooks支持多种执行方式(Shell命令、内置函数、API调用),通过退出码、超时与错误处理机制确保执行的可控性,并与事件系统深度集成实现全局编排。

核心价值:
- **关键节点拦截**:在智能体运行的关键阶段注入前置/后置处理逻辑
- **灵活执行方式**:支持Shell、内置函数、API三种执行方式
- **安全可控**:退出码控制、超时保护、错误隔离三重保障
- **事件驱动**:与事件系统无缝集成,支持跨模块编排

## 核心设计

### 触发事件类型

| 事件类型 | 触发时机 | 用途 | 可否阻断 |
|----------|----------|------|----------|
| Setup | 智能体初始化完成 | 加载配置、初始化环境 | 否 |
| SessionStart | 用户会话开始 | 设置会话上下文、加载项目配置 | 否 |
| PreToolUse | 工具调用执行前 | 参数校验、权限检查、日志记录 | 是 |
| PostToolUse | 工具调用执行后 | 结果后处理、审计记录、通知 | 否 |
| TaskCompleted | 任务完成后 | 结果汇总、清理资源、通知 | 否 |
| Stop | 智能体停止运行时 | 资源释放、状态持久化 | 否 |

### 执行方式

支持三种执行器:
- Shell Executor:执行Shell命令(cmd.exe /bin/sh)
- Built-in Executor:执行内置JS/TS函数
- API Executor:执行HTTP POST / gRPC调用

### 控制机制

**退出码语义**:

| 退出码 | 含义 | 行为 |
|--------|------|------|
| 0 | 成功 | 继续执行后续Hook或原始流程 |
| 1 | 一般错误 | 记录警告,继续执行 |
| 2 | 阻断 | 阻止当前操作(仅PreToolUse有效) |
| 3 | 需要审批 | 暂停操作,等待用户确认 |
| 130+ | 信号中断 | 记录中断原因,执行清理 |

**超时策略**:
- 默认超时30秒,可按Hook粒度配置
- 超时后发送SIGTERM,5秒后发送SIGKILL
- 超时视为退出码1(一般错误),不阻断流程

**错误处理**:
- Shell执行错误:捕获stderr,记录到Hook日志
- 内置函数错误:捕获异常,转换为HookResult
- API调用错误:重试机制(最多2次),失败后降级处理

### 与事件系统的关系

Hooks是事件系统的消费者与生产者:

- **消费事件**:Hook的触发由事件系统驱动,事件类型即Hook类型
- **生产事件**:Hook执行完成后发布`hook.completed`事件,携带执行结果
- **编排能力**:通过事件系统实现Hook间的链式调用与条件分支

## 依赖关系

| 依赖项 | 依赖类型 | 说明 |
|--------|----------|------|
| 事件系统与消息总线 | 强依赖 | Hook触发由事件驱动,执行结果通过事件传播 |
| 配置管理系统 | 强依赖 | Hook配置持久化存储与热更新 |
| 进程管理 | 弱依赖 | Shell执行器需要子进程管理能力 |
| 日志系统 | 弱依赖 | Hook执行日志与审计记录 |
| 权限系统 | 弱依赖 | Shell/API执行器的权限校验 |

## 验收标准

- [ ] 六种触发事件类型均可正确触发已注册的Hook
- [ ] Shell/Builtin/API三种执行方式均可正常工作
- [ ] 退出码语义正确:0继续、1警告、2阻断、3需审批
- [ ] PreToolUse退出码2可成功阻断工具调用
- [ ] 超时保护:超过配置时间的Hook被强制终止
- [ ] 错误隔离:单个Hook执行失败不影响其他Hook
- [ ] 条件触发:仅满足条件的Hook被执行
- [ ] 执行顺序:同一事件的多个Hook按order字段升序执行
- [ ] 事件集成:Hook执行完成后正确发布hook.completed事件
- [ ] 载荷修改:PostToolUse Hook可修改工具调用结果
- [ ] 性能:单个Hook执行调度开销 < 5ms(不含实际执行时间)

## 扩展方向

- **可视化编排**:提供Hook链的可视化编辑与调试界面
- **Hook模板市场**:预置常用Hook模板(代码检查、安全审计等)
- **异步Hook**:支持异步执行模式,不阻塞主流程
- **Hook沙箱**:为Shell Hook提供容器级隔离
- **分布式Hook**:支持跨实例的Hook触发与执行
- **Hook版本管理**:支持Hook配置的版本回滚
- **智能推荐**:基于项目类型自动推荐适用的Hook配置
