# Skills技能系统

## 功能概述

Skills技能系统为AI数字生命提供结构化的能力描述与注入机制,通过标准化的SKILL.md格式定义技能元数据、触发条件、执行逻辑与约束规则。系统支持知识、工作流、工具、模板四种技能类型,采用渐进式披露策略按需加载技能上下文,避免上下文窗口浪费。技能之间通过优先级管理与隔离机制确保互不干扰,同时支持技能组合以完成复杂任务。

核心价值:
- **结构化能力描述**:统一格式定义技能,便于发现、理解与复用
- **按需上下文注入**:渐进式披露,仅在相关场景激活技能
- **优先级仲裁**:多技能匹配时自动选择最优方案
- **组合与隔离**:技能可组合使用,执行上下文相互隔离

## 核心设计

### 技能格式(SKILL.md)

每个技能以SKILL.md文件为核心描述载体,遵循YAML Front Matter + Markdown Body结构。

Front Matter核心字段:
- name:技能唯一标识
- version:语义化版本号
- type:技能类型(knowledge/workflow/tool/template)
- description:技能描述
- triggers:触发条件列表
- priority:优先级(0-100)
- dependencies:依赖列表
- capabilities:能力标签
- constraints:约束条件

### 技能类型

| 类型 | 说明 | 注入方式 | 示例 |
|------|------|----------|------|
| knowledge | 领域知识库 | 系统提示词注入 | API文档、最佳实践 |
| workflow | 多步骤工作流 | 指令链注入 | 代码审查流程、部署流程 |
| tool | 工具使用指南 | 工具描述注入 | Git操作指南、数据库查询模板 |
| template | 输出模板 | 输出格式约束注入 | 代码模板、文档模板 |

### 加载机制

**渐进式披露**策略,分三个阶段注入技能上下文:

阶段1: 元数据扫描
- 读取SKILL.md的Front Matter
- 仅加载name、type、triggers、priority

阶段2: 触发匹配
- 根据用户输入匹配triggers
- 按优先级排序候选技能

阶段3: 完整注入
- 仅对匹配技能加载完整Markdown Body
- 注入到上下文窗口

### 优先级管理

优先级数值范围0-100,数值越高优先级越高。多技能匹配时的仲裁策略:

1. 精确匹配优先于模糊匹配
2. 同匹配度下按优先级数值降序
3. 同优先级下按技能类型排序:workflow > tool > knowledge > template
4. 仍无法决断时按加载时间倒序(后加载优先)

### 技能组合与隔离

- **组合**:多个技能可同时激活,系统按优先级顺序合并指令
- **隔离**:每个技能的执行上下文独立,变量与状态不互相污染
- **冲突检测**:当两个技能的约束条件冲突时,优先保留高优先级技能的约束

## 依赖关系

| 依赖项 | 依赖类型 | 说明 |
|--------|----------|------|
| 配置管理系统 | 强依赖 | 技能注册信息、优先级配置持久化 |
| 工具调用协议 | 强依赖 | tool类型技能需要调用工具执行 |
| 事件系统 | 弱依赖 | 技能加载/卸载/匹配事件通知 |
| 上下文管理 | 弱依赖 | Token预算分配与上下文窗口管理 |

## 验收标准

- [ ] SKILL.md格式完整解析:Front Matter所有字段正确读取,Body内容完整加载
- [ ] 四种技能类型均可注册、发现、匹配与注入
- [ ] 渐进式披露:元数据扫描阶段不加载Body内容,Token消耗< 200/技能
- [ ] 按需注入:仅匹配技能的完整内容被注入上下文
- [ ] 优先级仲裁:多技能匹配时按规则正确排序
- [ ] 技能组合:多个技能可同时激活,指令正确合并
- [ ] 隔离机制:技能间变量与状态互不干扰
- [ ] 冲突检测:约束条件冲突时正确识别并解决
- [ ] 依赖校验:缺失依赖时给出明确提示
- [ ] 性能:100个已注册技能的匹配延迟 < 50ms

## 扩展方向

- **技能市场**:构建技能的发现、评分与分发平台
- **技能自动生成**:基于用户行为模式自动提取并生成技能
- **跨项目技能共享**:支持团队级别的技能库共享
- **技能版本自动更新**:检测技能更新并提示升级
- **技能效果评估**:跟踪技能激活后的任务完成率与用户满意度
- **嵌套技能**:支持技能内部引用其他技能,构建技能树
- **条件化技能**:基于运行时环境动态调整技能行为
