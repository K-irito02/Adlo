# 插件市场与分发

## 功能概述

插件市场与分发系统为AI数字生命提供标准化的插件格式规范、多渠道分发能力与全生命周期管理。系统支持官方市场、社区仓库与本地安装三种分发渠道,通过权限管理机制保障插件运行安全,覆盖插件安装、启用、更新、卸载的完整生命周期,并内置性能监控确保插件不会影响宿主系统稳定性。

核心价值:
- **标准化格式**:统一的插件规范,降低开发与集成成本
- **多渠道分发**:官方、社区、本地三渠道覆盖全场景
- **安全可控**:权限声明与运行时校验双重保障
- **全生命周期**:从安装到卸载的完整管理闭环

## 实现优先级

| 阶段 | 内容 | 预计周期 |
|------|------|----------|

## 核心设计

### 插件格式与规范

每个插件以独立目录形式组织,核心文件包括:
- manifest.json:插件清单(必需)
- README.md:插件说明
- icon.png:插件图标
- src/:源代码目录
- resources/:静态资源
- tests/:测试文件

manifest.json核心字段:
- 基础信息:name、version、description、author、license
- 入口声明:main、tools、hooks、skills
- 权限声明:permissions
- 依赖声明:dependencies、peerDependencies
- 兼容性:engines、platforms

### 分发渠道

| 渠道 | 特点 | 审核机制 | 更新方式 |
|------|------|----------|----------|
| 官方市场 | 质量保证、安全审核 | 人工审核 + 自动化检测 | 自动推送 |
| 社区仓库 | 开放贡献、快速迭代 | 社区投票 + 自动化扫描 | 手动检查 |
| 本地安装 | 私有插件、离线部署 | 无 | 手动更新 |

### 权限管理

插件必须在manifest.json中声明所需权限,运行时严格按声明授权。

权限类别包括:
- 文件系统:fs.read、fs.write
- 网络:net.request、net.listen
- 系统:sys.shell、sys.env
- 数据:data.clipboard、data.workspace
- UI:ui.notification、ui.panel

权限级别:
- granted:安装时用户已授权
- prompt:首次使用时弹窗询问
- denied:明确拒绝

### 生命周期管理

状态转换规则:
- Install → Disabled:安装完成后默认禁用
- Disabled → Enabled:用户手动启用,校验权限
- Enabled → Running:首次调用时激活
- Running → Enabled:空闲超时后停用
- Enabled → Disabled:用户手动禁用
- Disabled → Uninstall:用户卸载,清理数据
- 更新:Download → Install(保留配置) → 需重启生效

### 性能监控

对已启用插件进行运行时性能监控:

| 监控指标 | 阈值 | 超出行为 |
|----------|------|----------|
| CPU占用 | > 50% 持续 5s | 警告 + 降级 |
| 内存占用 | > 200MB | 警告 + 限制分配 |
| 工具调用延迟 | > 5s | 超时中断 |
| 错误率 | > 10% | 自动禁用 |
| 崩溃次数 | > 3次/小时 | 自动禁用 + 通知 |

## 依赖关系

| 依赖项 | 依赖类型 | 说明 |
|--------|----------|------|
| 配置管理系统 | 强依赖 | 插件配置、权限状态、安装信息持久化 |
| 事件系统 | 强依赖 | 插件生命周期事件、性能告警事件 |
| MCP协议实现 | 弱依赖 | 插件可通过MCP协议提供工具能力 |
| Skills技能系统 | 弱依赖 | 插件可包含技能定义 |
| Hooks生命周期 | 弱依赖 | 插件可注册Hook |
| 安全模块 | 弱依赖 | 签名校验、沙箱隔离 |

## 验收标准

- [ ] 插件格式规范完整:manifest.json所有字段可正确解析与校验
- [ ] 本地安装:支持从目录/压缩包安装插件
- [ ] 官方市场:支持搜索、浏览、安装、评分
- [ ] 社区仓库:支持开放注册、发布、投票
- [ ] 权限管理:未声明权限的操作被拒绝,prompt级别弹窗确认
- [ ] 生命周期完整:安装→禁用→启用→运行→禁用→卸载全流程
- [ ] 更新机制:检测到更新后提示用户,支持增量更新
- [ ] 性能监控:CPU/内存/延迟/错误率超出阈值时触发告警
- [ ] 自动保护:崩溃次数超限自动禁用插件
- [ ] 沙箱隔离:插件无法访问未授权的系统资源
- [ ] 签名校验:官方市场插件签名校验通过,篡改插件被拒绝
- [ ] 性能:插件加载与激活开销 < 500ms

## 扩展方向

- **插件依赖解析**:自动解析与安装插件的依赖链
- **插件冲突检测**:安装前检测与已安装插件的兼容性
- **插件推荐引擎**:基于项目类型与使用习惯推荐插件
- **付费插件支持**:集成支付与许可证验证
- **插件开发工具**:脚手架、调试器、测试框架一体化开发工具
- **联邦市场**:支持多个独立运营的插件市场互联互通
- **插件快照与回滚**:更新失败时自动回滚到上一版本
