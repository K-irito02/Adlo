### 4.2 时间窗口机制

**时间窗口配置：**

```yaml
时间窗口策略:
  默认窗口:
    低风险配置:
      窗口时长: 120分钟
      过期操作: 自动执行
      通知: 窗口结束前15分钟提醒
      
    中风险配置:
      窗口时长: 60分钟
      过期操作: 自动拒绝
      通知: 窗口结束前10分钟提醒
      
    高风险配置:
      窗口时长: 30分钟
      过期操作: 自动拒绝
      通知: 窗口结束前5分钟提醒
      
    极高风险配置:
      窗口时长: 15分钟
      过期操作: 自动拒绝并告警
      通知: 实时提醒
      
  自定义窗口:
    - 配置类型: 系统级配置
      窗口时长: 10分钟
      过期操作: 自动拒绝
      
    - 配置类型: 开发环境配置
      窗口时长: 180分钟
      过期操作: 自动执行
```

**时间窗口状态流转：**

```
配置变更申请提交
       │
       ▼
┌──────────────────┐
│ 进入时间窗口      │
│ 状态: 待审核      │
│ 剩余时间: 60分钟  │
└────────┬─────────┘
         │
    ┌────┴────┬─────────┬─────────┐
    │         │         │         │
    ▼         ▼         ▼         ▼
 用户批准   用户拒绝   用户修改   窗口过期
    │         │         │         │
    ▼         ▼         ▼         ▼
 执行配置   拒绝配置   更新配置   根据策略
    │         │         │      自动执行/拒绝
    ▼         ▼         ▼         │
 完成      完成      重新计时     │
                                ▼
                              完成/拒绝
```
