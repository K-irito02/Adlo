# 终端命令执行

## 功能概述

终端命令执行模块为AI数字生命提供安全的命令行操作能力，使AI能够运行构建工具、测试框架、包管理器等开发工具链命令。该模块在赋予AI执行能力的同时，通过白名单机制、确认模式和环境隔离等多层安全策略，确保命令执行过程可控、可审计、可回溯，防止潜在的系统破坏风险。

核心能力包括：
- 命令执行：子进程管理，支持Shell命令与直接执行
- 输出流解析：实时捕获stdout/stderr，结构化解析输出
- 安全控制：白名单/确认模式，危险命令拦截与审批
- 环境隔离：工作目录隔离、环境变量隔离、资源限制
- 长时运行命令管理：后台任务、进度追踪、超时控制

## 设计目标

1. 提供可靠的命令执行能力，支持各种开发工具链
2. 实现多层安全防护，防止危险命令执行
3. 提供结构化的输出解析，便于AI理解执行结果
4. 支持长时运行命令的管理与监控
5. 确保执行过程可审计、可追溯

## 实现优先级

**P0（MVP核心）**

终端执行是AI完成代码验证（运行测试、构建项目）的关键能力。无此模块，AI无法验证生成代码的正确性，也无法执行安装依赖等必要操作。

| 阶段 | 里程碑 | 预计工期 |
|------|--------|----------|
| M1 | 基础命令执行 + 输出捕获 | 2 周 |
| M2 | 安全控制（白名单 + 确认模式） | 3 周 |

## 核心设计

### 命令执行

| 执行方式 | 说明 | 适用场景 |
|----------|------|----------|
| Shell执行 | 通过系统Shell执行（bash/cmd/PowerShell） | 需要管道、重定向、环境变量展开 |
| 直接执行 | 直接启动子进程，不经过Shell | 简单命令，更安全 |
| 脚本执行 | 执行临时脚本文件 | 多行命令序列 |

命令执行参数：
- 工作目录（cwd）：默认为项目根目录
- 环境变量：继承系统环境 + 自定义覆盖
- 超时时间：默认60s，可配置
- 输入流：支持向stdin写入数据

### 输出流解析

实时输出捕获：
- stdout和stderr分别捕获，以不同颜色/样式展示
- 输出行级缓冲，避免字符级输出闪烁
- ANSI转义序列解析（颜色、光标移动等）
- 输出行数限制：默认保留最近10000行，防止内存溢出

结构化解析：

| 输出类型 | 解析规则 | 提取信息 |
|----------|----------|----------|
| 编译错误 | file:line:col: error: message | 文件路径、行号、错误消息 |
| 测试结果 | JUnit / TAP格式 | 通过/失败数量、失败详情 |
| 进度信息 | 百分比 / 进度条 | 完成百分比、预计剩余时间 |
| 包管理输出 | added X packages | 安装包数量、耗时 |
| 通用键值对 | KEY=VALUE / KEY: VALUE | 键值对提取 |

解析后的结构化数据可用于：
- 自动将编译错误关联至编辑器诊断
- 将测试结果汇总展示在对话中
- 触发后续自动化流程

### 安全控制

安全控制采用多层防御策略：

第一层：命令分类

| 分类 | 标识 | 示例 | 默认策略 |
|------|------|------|----------|
| 安全 | SAFE | ls, cat, git status, node -v | 自动执行 |
| 低风险 | LOW_RISK | npm install, pip install, go build | 自动执行（首次确认后） |
| 中风险 | MEDIUM_RISK | npm run *, python *, cargo run | 每次确认 |
| 高风险 | HIGH_RISK | rm -rf, sudo *, chmod 777 | 强制确认 + 警告 |
| 禁止 | BLOCKED | rm -rf /, format C:, dd if=* | 拒绝执行 |

第二层：确认模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 自动执行 | 安全命令自动执行，无需确认 | 信任环境、演示模式 |
| 智能确认 | 按命令分类决定是否需要确认 | 日常开发（推荐） |
| 全部确认 | 所有命令均需用户确认 | 安全敏感环境 |
| 只读模式 | 仅允许只读命令执行 | 代码审查 |

第三层：路径限制
- 命令仅允许操作项目目录内的文件
- 路径遍历检测：阻止 `../` 越界访问
- 敏感路径保护：禁止操作系统目录、用户主目录外的文件

第四层：审批流程
- 需确认的命令弹出审批卡片，展示命令内容、风险等级、影响范围
- 用户可选择：允许一次 / 允许本次会话 / 始终允许 / 拒绝
- 审批记录持久化，可回溯审计

### 环境隔离

| 隔离维度 | 实现方式 | 说明 |
|----------|----------|------|
| 工作目录 | chdir至项目目录 | 命令在项目根目录下执行 |
| 环境变量 | 自定义env覆盖 | 隔离PATH、HOME等 |
| 用户权限 | 降权执行（非root/管理员） | 防止权限提升 |
| 资源限制 | ulimit / Job Object | CPU/内存/文件描述符限制 |
| 网络隔离 | 可选禁用网络访问 | 防止数据泄露（高级选项） |

### 长时运行命令管理

| 功能 | 说明 |
|------|------|
| 后台执行 | 命令在后台运行，不阻塞对话 |
| 进度追踪 | 解析输出中的进度信息，展示进度条 |
| 输出尾随 | 实时展示最新输出（tail -f模式） |
| 超时控制 | 超时自动终止，可配置超时时间 |
| 手动终止 | 用户可随时终止运行中的命令 |
| 命令队列 | 多命令排队执行，可配置并发数 |
| 退出码检查 | 命令完成后检查退出码，非零时标记失败 |

## 验收标准

### 功能验收

- 可执行基础Shell命令并获取输出
- stdout和stderr分别捕获并以不同样式展示
- 命令超时后自动终止
- 可手动终止运行中的命令
- 安全命令（ls, git status）自动执行无需确认
- 高风险命令（rm -rf）弹出审批确认
- 禁止命令直接拒绝执行
- 审批结果"允许一次/本次会话/始终允许"均正确生效
- 编译错误可解析为结构化数据（文件路径+行号+消息）
- 测试结果可解析为通过/失败统计
- 后台命令不阻塞对话交互
- 命令历史可查询

### 性能验收

- 命令启动延迟 < 100ms
- 输出流延迟 < 50ms（从子进程输出到UI展示）
- 1000行输出的命令不导致内存溢出
- 命令分类耗时 < 5ms

### 安全验收

- 禁止命令无法通过任何方式执行
- 路径遍历攻击被阻止（`../../etc/passwd`）
- 确认模式下未审批命令无法执行
- 审批记录持久化，重启后可查询
- 子进程在主进程退出时全部终止

### 健壮性验收

- 命令不存在时返回明确错误信息
- 工作目录不存在时提示用户
- 子进程异常退出时正确捕获退出码
- 大量输出（> 10000行）不导致内存溢出
- 网络断开时不影响本地命令执行

## 扩展方向

1. 交互式终端：完整终端模拟器，支持交互式命令（vim, top等）
2. 远程执行：通过SSH在远程服务器执行命令
3. Docker集成：在容器中执行命令，完全隔离
4. 命令编排：多命令DAG编排，条件执行与错误处理
5. 智能命令建议：基于项目类型与上下文，AI推荐常用命令
6. 输出差异对比：命令输出与预期输出对比，自动检测回归
7. 性能分析：命令执行性能分析，CPU/内存/IO监控
8. CI/CD集成：与CI/CD管道集成，本地触发与结果查看
