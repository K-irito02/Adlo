# 文件系统操作

## 功能概述

文件系统操作模块为AI数字生命提供对项目文件的完整读写能力，是代码理解、编辑与生成的核心支撑。该模块封装了文件读写编辑、内容搜索、符号索引、跨文件理解、变更预览与回滚等关键能力，同时针对大文件处理与并发操作进行专项优化，确保在高频文件操作场景下的稳定性与性能。

核心能力包括：
- 文件读写编辑：支持读取、创建、修改、删除文件，提供行级精确编辑
- Grep/Glob搜索：正则表达式内容搜索与文件模式匹配
- AST符号索引：基于语法树构建符号表，支持定义跳转与引用查找
- 跨文件理解：追踪import/依赖关系，构建项目级文件关联图
- 变更预览与回滚：所有文件修改可预览diff，支持一键回滚
- 大文件处理：流式读取、分片加载、懒索引，避免内存溢出
- 并发控制：文件操作队列化，读写锁保护，防止数据竞争

## 设计目标

1. 提供完整可靠的文件操作能力，支持各种文件类型
2. 实现高性能的文件搜索与索引，支持大型项目
3. 提供精确的行级编辑能力，支持代码修改场景
4. 确保文件操作安全，支持变更预览与回滚
5. 优化大文件处理，避免内存溢出

## 实现优先级

**P0（MVP核心）**

文件操作是AI修改代码的基础能力，必须在项目初期完成。无此模块，AI无法读取项目代码，也无法将生成的代码写入文件。

| 阶段 | 里程碑 | 预计工期 |

## 核心设计

### 文件读写编辑

| 操作 | 说明 | 约束 |
|------|------|------|
| readFile | 读取文件全部内容 | 大文件走流式读取 |
| readFileLines | 读取指定行范围 | 行号从1开始 |
| writeFile | 写入/创建文件 | 自动创建中间目录 |
| editFile | 行级精确编辑 | 支持 insert/delete/replace |
| deleteFile | 删除文件 | 移至回收站而非永久删除 |
| moveFile | 移动/重命名文件 | 自动更新引用（可选） |
| copyFile | 复制文件 | 保留原始权限 |
| fileExists | 检查文件是否存在 | 支持批量检查 |
| getFileInfo | 获取文件元信息 | 大小、修改时间、权限等 |

行级编辑操作类型：
- insert：在指定行前插入新内容
- delete：删除指定行范围
- replace：替换指定行范围内容

### Grep/Glob搜索

Grep搜索：
- 支持正则表达式与字面量模式
- 支持文件类型过滤（按扩展名/语言）
- 支持目录排除（node_modules、.git等）
- 返回匹配行及上下文行（可配置上下文行数）
- 大文件流式匹配，避免全量加载

Glob匹配：
- 支持标准glob模式（`**/*.ts`、`src/**/index.{ts,js}`）
- 支持排除模式（`!node_modules/**`）
- 返回匹配文件路径列表
- 结果按修改时间或路径排序

### AST符号索引

| 功能 | 说明 |
|------|------|
| 符号定义索引 | 类、函数、变量、接口、类型定义 |
| 符号引用查找 | 查找符号在项目中的所有引用位置 |
| 定义跳转 | 从引用位置跳转至定义位置 |
| 符号重命名 | 批量重命名符号及其所有引用 |
| 依赖图 | 模块间import/require依赖关系 |
| 继承关系 | 类继承与接口实现关系 |

支持的编程语言（MVP阶段）：
- TypeScript / JavaScript（tree-sitter-typescript）
- Python（tree-sitter-python）
- 其他语言后续扩展

索引策略：
- 项目打开时后台增量构建
- 文件修改时局部更新（增量索引）
- 索引持久化至本地缓存

### 跨文件理解

- 依赖追踪：从入口文件出发，递归解析import/require链
- 影响分析：修改某文件/符号时，分析受影响的下游文件
- 项目结构概览：生成项目目录树 + 模块依赖图
- 上下文收集：根据当前编辑位置，自动收集相关文件上下文

### 变更预览与回滚

- 所有文件修改生成unified diff格式预览
- 修改前自动创建快照（Snapshot）
- 快照栈支持多级回滚（类似undo栈）
- 快照自动过期清理（默认保留最近50个）
- 批量修改支持原子性：全部应用或全部回滚

### 大文件处理

| 策略 | 阈值 | 处理方式 |
|------|------|----------|
| 小文件 | < 100KB | 全量加载至内存 |
| 中文件 | 100KB - 1MB | 分片加载，按需读取 |
| 大文件 | 1MB - 10MB | 流式读取，虚拟行号映射 |
| 超大文件 | > 10MB | 仅读取首尾 + 索引，禁止全量加载 |

AST索引对大文件采用增量解析，仅解析可见区域与符号定义。

### 并发控制

- 文件操作通过队列序列化，同一文件不并发写入
- 读写锁策略：多读单写
- 操作超时控制：单次操作最长30s
- 外部修改检测：监听文件变更事件，提示用户处理冲突
- 操作取消：支持取消排队中的操作

## 依赖关系

| 依赖模块 | 依赖方式 | 说明 |
|----------|----------|------|
| 配置管理系统 | 强依赖 | 读取项目路径、排除规则、索引配置等 |
| 事件系统 | 强依赖 | 发布文件变更事件，通知其他模块 |

被依赖关系：

| 上游模块 | 依赖方式 | 说明 |
|----------|----------|------|
| 代码编辑器集成 | 强依赖 | 编辑器文件内容加载与保存 |
| 上下文管理 | 强依赖 | 读取文件内容构建上下文 |
| 终端命令执行 | 弱依赖 | 命令执行后可能触发文件变更检测 |

## 验收标准

### 功能验收

- 可读取/写入/删除项目中的任意文件
- 行级编辑（insert/delete/replace）精确无误，行号偏移自动修正
- Grep搜索支持正则表达式，结果包含行号与上下文
- Glob匹配支持 `**` 递归模式，结果按路径排序
- TypeScript/Python文件可正确构建AST符号索引
- 符号定义查找返回正确的文件位置
- 修改文件前自动创建快照
- 快照回滚可恢复文件至修改前状态
- 大文件（>1MB）可正常读取，不导致内存溢出
- 并发写入同一文件时序列化处理，无数据损坏

### 性能验收

- 单文件读取（< 100KB）耗时 < 10ms
- Grep搜索（1000文件项目）耗时 < 500ms
- Glob匹配（1000文件项目）耗时 < 100ms
- AST索引构建（中型项目500文件）耗时 < 30s
- 增量索引更新（单文件修改）耗时 < 500ms
- 快照创建耗时 < 50ms

### 健壮性验收

- 文件不存在时返回明确错误，不抛出未捕获异常
- 文件权限不足时提示用户，不静默失败
- 外部程序修改文件后，文件监听正确触发变更事件
- 磁盘空间不足时写入操作优雅失败
- 符号索引解析失败时不影响其他文件索引

## 扩展方向

1. 语义搜索：基于嵌入向量的代码语义搜索，超越关键词匹配
2. 实时协作：支持多人同时编辑，CRDT冲突解决
3. 版本控制集成：深度集成Git，支持分支对比、stash操作
4. 远程文件系统：支持SSH/WSL远程文件操作
5. 代码格式化：集成Prettier/Black等格式化工具，编辑后自动格式化
6. 安全沙箱：限制AI可操作的文件范围，防止误操作
7. 智能重命名：跨文件符号重命名，自动更新所有引用
8. 文件模板：预置项目/文件模板，一键创建标准项目结构
