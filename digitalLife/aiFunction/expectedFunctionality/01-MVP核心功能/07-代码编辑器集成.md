# 代码编辑器集成

## 功能概述

代码编辑器集成模块将Monaco Editor嵌入AI数字生命，提供专业级代码编辑体验，并实现编辑器与对话系统的深度联动。该模块不仅提供语法高亮、智能补全等基础编辑能力，更通过行内建议、diff预览、编辑器-对话联动等特色功能，将AI能力无缝融入编码工作流，实现"对话即编码"的交互范式。

核心能力包括：
- 编辑器嵌入：基于Monaco Editor的完整代码编辑环境
- 语法高亮：多语言语法支持，与对话渲染共享语法定义
- 智能补全：AI驱动的上下文感知代码补全
- 行内建议：Ghost Text形式的AI代码建议，Tab接受
- diff预览：AI修改代码时的inline/side-by-side diff视图
- 多文件编辑：标签页管理，跨文件编辑状态保存
- 编辑器-对话联动：选中代码发送至对话、对话建议应用至编辑器

## 设计目标

1. 提供专业级的代码编辑体验，媲美VS Code
2. 实现AI能力与编辑器的无缝集成
3. 支持多种编程语言的语法高亮与智能补全
4. 提供直观的代码变更预览与接受机制
5. 实现编辑器与对话的双向联动

## 核心设计

### 编辑器嵌入

基于Monaco Editor构建，提供以下基础能力：

| 能力 | 说明 |
|------|------|
| 代码编辑 | 输入、删除、复制、粘贴、撤销、重做 |
| 光标与选区 | 多光标、列选择、选区扩展 |
| 查找替换 | Ctrl+F / Ctrl+H，支持正则表达式 |
| 代码折叠 | 按缩进/区域折叠 |
| 缩进控制 | 自动缩进、Tab/空格切换 |
| 行号显示 | 行号栏，支持断点标记区域 |
| 小地图 | 代码缩略图，快速导航 |
| 字体与主题 | 可配置字体大小、行高、主题 |

Monaco Editor实例配置要点：
- 使用Web Worker运行语法分析，避免阻塞主线程
- 按需加载语言包，减少初始加载时间
- 自定义主题与AI数字生命整体UI风格一致

### 智能补全

AI驱动补全：
- 触发方式：输入停顿300ms后自动触发（可配置）
- 补全来源：AI模型基于当前文件上下文生成
- 补全内容：单行补全 + 多行补全 + 函数体补全
- 上下文窗口：当前文件 + 打开的标签页 + 项目索引
- 补全长度：单行5-20 Token，多行50-200 Token

传统补全：
- 关键字补全：语言关键字与内置函数
- 代码片段：常用代码模板（for循环、函数定义等）
- 路径补全：import路径自动补全

补全项优先级：AI补全 > 代码片段 > 关键字 > 路径补全

### 行内建议

行内建议（Ghost Text）是AI代码建议的核心交互形式：

| 特性 | 说明 |
|------|------|
| 显示方式 | 灰色半透明文本，跟随光标位置 |
| 接受方式 | Tab接受全部 / Ctrl+→逐词接受 |
| 拒绝方式 | Esc拒绝 / 继续输入自动拒绝 |
| 部分接受 | Ctrl+→逐词接受，精细控制 |
| 多候选 | Alt+] / Alt+[切换候选建议 |
| 触发方式 | 自动触发 + 手动触发（Alt+\） |

行内建议生命周期：触发条件满足 → 请求AI模型 → 渲染Ghost Text → 用户操作（接受/拒绝/修改）→ 反馈学习

### diff预览

AI修改代码时提供diff预览，支持两种视图模式：

Inline Diff：
- 在原文件中直接标注修改区域
- 删除行红色背景 + 删除线
- 新增行绿色背景
- 修改行黄色背景 + 行内diff
- 适用于小幅修改

Side-by-Side Diff：
- 左右双栏对比
- 左侧原始内容，右侧修改后内容
- 差异行高亮标注
- 同步滚动
- 适用于大幅重构

diff操作按钮：
- 接受（Apply）：应用全部修改
- 拒绝（Reject）：放弃全部修改
- 部分接受：逐块（hunk）接受/拒绝
- 编辑：在diff视图中直接微调

### 编辑器-对话联动

| 联动方向 | 触发方式 | 行为 |
|----------|----------|------|
| 编辑器 → 对话 | 选中代码 + 右键"发送至对话" | 将选中代码作为引用发送 |
| 编辑器 → 对话 | Ctrl+I（行内对话） | 在编辑器中打开行内对话浮层 |
| 编辑器 → 对话 | 代码报错 + "求助AI" | 将错误信息与代码发送至对话 |
| 对话 → 编辑器 | AI生成代码 + "应用至文件" | 打开diff预览，确认后应用 |
| 对话 → 编辑器 | AI生成代码 + "插入至光标" | 直接在光标位置插入代码 |
| 对话 → 编辑器 | AI生成代码 + "创建新文件" | 创建新文件并打开编辑器 |

行内对话（Ctrl+I）：
- 在编辑器上方弹出对话浮层
- 上下文自动包含当前文件 + 选区
- AI响应以行内建议形式展示
- 接受后直接修改文件，拒绝则关闭浮层

## 验收标准

### 功能验收

- Monaco Editor可正常嵌入并显示代码内容
- 语法高亮正确（至少支持TypeScript/JavaScript/Python）
- 代码编辑（输入/删除/撤销/重做）正常工作
- 多文件标签页可打开/关闭/切换
- 未保存修改标记正确显示
- AI行内建议以Ghost Text形式显示
- Tab可接受行内建议，Esc可拒绝
- diff预览可正确显示inline和side-by-side两种模式
- diff预览中可逐块接受/拒绝修改
- 选中代码可发送至对话
- 行内对话（Ctrl+I）可正常打开与关闭
- 对话建议可应用至编辑器（通过diff预览确认）

### 性能验收

- 编辑器打开文件（< 100KB）耗时 < 200ms
- 输入延迟 < 50ms（无补全时）
- 行内建议首Token延迟 < 500ms
- diff预览渲染耗时 < 300ms
- 10个标签页同时打开时切换流畅

### 健壮性验收

- 大文件（> 1MB）编辑器不崩溃，提供降级体验
- 编辑器失焦时自动保存草稿
- 文件外部修改时提示用户处理冲突
- 行内建议请求失败时不影响正常编辑
- diff预览关闭时正确清理资源

## 扩展方向

1. 协作编辑：多人实时协作编辑，CRDT冲突解决
2. 可视化调试：集成调试器，断点、变量查看、调用栈
3. 代码诊断：集成LSP诊断，实时显示错误与警告
4. 代码重构：AI驱动的智能重构（提取函数、内联变量等）
5. 多光标AI编辑：AI同时在多个位置进行编辑
6. 编辑器宏：录制与回放编辑操作序列
7. 3-way Merge：三方合并视图，解决Git冲突
8. Live Share：实时共享编辑器会话，远程结对编程
