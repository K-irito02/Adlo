# 对话交互引擎

## 功能概述

对话交互引擎是用户与AI数字生命之间的核心交互层，负责管理多轮对话生命周期、渲染流式输出、识别用户意图、处理特殊交互语法（@引用、斜杠命令），并协调上下文窗口分配。该引擎将原始模型响应转化为结构化、可交互的对话内容，同时提供对话历史的持久化与检索能力。

核心能力包括：
- 多轮对话管理：维护对话状态、消息序列与轮次追踪
- 流式输出渲染：增量渲染Markdown/代码块，支持实时预览
- 意图识别：解析用户输入意图，触发对应处理管线
- @引用系统：引用文件、符号、对话历史等上下文对象
- 斜杠命令：快捷操作入口，支持命令发现与参数补全
- 对话历史管理：持久化存储、搜索、导出、分支对话
- 上下文窗口分配：与上下文管理模块协作，优化Token分配

## 设计目标

1. 提供流畅的多轮对话体验，支持上下文连贯传递
2. 实现毫秒级流式渲染，首Token到达即开始显示
3. 提供丰富的交互语法，降低用户操作成本
4. 支持对话分支与回溯，方便探索不同方案
5. 确保对话历史可靠持久化，支持跨会话恢复

## 实现优先级

对话交互是AI数字生命最核心的用户界面，必须在项目初期完成。无此模块，用户无法与AI进行有效交互。

## 核心设计

### 多轮对话管理

- 每个对话会话维护独立的消息序列
- 支持System Prompt注入（按场景动态配置）
- 消息角色区分：system / user / assistant / tool
- 对话轮次追踪，支持基于轮次的上下文窗口裁剪
- 对话分支：从任意历史消息分叉出新对话

### 流式输出渲染

- 逐Token增量渲染，首Token到达即开始显示
- Markdown实时解析与渲染（代码块、表格、列表等）
- 代码块语法高亮（与编辑器共享语法定义）
- 流式输出中的工具调用标记与结果内联展示
- 渲染中断与重试：流式错误时显示错误提示并提供重试按钮

### 意图识别

| 意图类型 | 触发模式 | 处理管线 |
|----------|----------|----------|
| 代码生成 | "写一个..." / "实现..." | 代码生成管线 |
| 代码修改 | "修改..." / "重构..." | 代码编辑管线 |
| 代码解释 | "解释..." / "这段代码..." | 代码分析管线 |
| 问题搜索 | "如何..." / "什么是..." | 知识检索管线 |
| 命令执行 | "运行..." / "执行..." | 终端执行管线 |
| 闲聊 | 其他 | 通用对话管线 |

意图识别优先级：斜杠命令 > @引用触发 > 模式匹配 > 模型分类

### @引用系统

| 引用目标 | 语法 | 解析行为 |
|----------|------|----------|
| 文件 | @file:path/to/file.ts | 读取文件内容注入上下文 |
| 符号 | @symbol:ClassName.method | 查找符号定义注入上下文 |
| 对话 | @chat:session-id | 引用历史对话内容 |
| 终端 | @terminal | 引用最近终端输出 |
| 网页 | @url:https://... | 抓取网页内容注入上下文 |
| Git | @git:diff / @git:log | 引用Git变更信息 |

引用解析流程：输入检测 → 引用提取 → 内容获取 → 上下文注入 → 发送请求

### 斜杠命令

| 命令 | 说明 | 参数 |
|------|------|------|
| /help | 显示可用命令列表 | 无 |
| /model | 切换模型 | 模型名称 |
| /clear | 清空当前对话 | 无 |
| /edit | 进入编辑模式 | 文件路径 |
| /search | 搜索代码 | 搜索词 |
| /run | 执行命令 | 命令字符串 |
| /context | 查看/管理上下文 | 子命令 |
| /export | 导出对话 | 格式（md/json） |
| /branch | 从当前消息分叉对话 | 无 |

命令注册机制：支持插件注册自定义斜杠命令，统一通过命令注册表管理。

### 对话历史管理

- 对话自动保存（按时间戳 + 首条消息摘要命名）
- 历史对话列表：按时间倒序排列，支持搜索
- 对话导出：Markdown / JSON格式
- 对话删除与恢复
- 对话标签与分类
- 存储位置：本地文件系统（JSON格式），可选同步至云端

### 上下文窗口分配

- 与上下文管理模块协作，动态计算可用Token空间
- 分配策略：System Prompt（固定）> 当前消息（必须）> @引用内容（高优）> 近期对话（中优）> 项目上下文（低优）
- 超出窗口时自动截断低优先级内容
- 上下文使用量实时展示（Token计数器）

## 依赖关系

## 验收标准

### 功能验收

- 可创建/删除/切换对话会话
- 多轮对话上下文正确传递，模型能引用前文内容
- 流式输出逐Token渲染，首Token延迟 < 200ms（不含模型延迟）
- Markdown渲染正确（代码块、表格、列表、链接）
- 代码块语法高亮正确
- @file引用可正确读取文件内容并注入上下文
- @symbol引用可正确查找符号定义
- 斜杠命令/help /clear /model正常工作
- 对话历史自动保存，重启后可恢复
- 对话搜索可按关键词匹配历史消息
- 对话导出为Markdown格式内容完整
- 分支对话可从指定消息创建新会话

### 性能验收

- 单条消息渲染耗时 < 16ms（60fps）
- 100条消息的会话滚动流畅，无明显卡顿
- 意图识别耗时 < 10ms（规则匹配模式）
- @引用解析耗时 < 100ms（本地文件）

### 健壮性验收

- 模型返回空响应时显示提示信息而非空白
- 流式中断后可重试，不丢失已有内容
- 并发发送消息时序列化处理，不产生消息错乱
- 超长对话（200条消息）不导致内存溢出

## 扩展方向

1. 多模态对话：支持图片、截图输入，结合视觉模型进行UI分析与代码生成
2. 协作对话：多人共享对话会话，支持评论与批注
3. 对话模板：预置常用对话模板（代码审查、Bug分析等），一键启动
4. 智能摘要：自动生成长对话摘要，减少上下文占用
5. 对话回放：支持对话过程回放，便于演示与教学
6. 语音输入：集成语音识别，支持语音转文字输入
7. 插件命令市场：开放斜杠命令注册API，支持第三方命令插件
8. 对话质量评分：基于用户反馈自动评估对话质量，优化提示词
