# 基础工具类库

## 功能概述

基础工具类库提供跨模块共享的通用工具函数、类型定义和常量，是整个应用的基础设施层。该模块不包含业务逻辑，只提供纯工具能力。

## 设计目标

- **零业务依赖**：不依赖任何业务模块
- **高复用性**：提供通用的工具函数
- **类型安全**：所有接口都有完整的类型定义
- **性能优先**：核心工具函数经过性能优化

## 实现优先级

**P0** - 基础工具类库是其他所有模块的基础。

## 核心能力

### 类型定义

- 结果类型（Result/Option）
- 错误类型基类
- 事件类型定义
- 通用数据结构

### 工具函数

| 类别 | 功能 |
|------|------|
| 字符串处理 | 格式化、截断、编码转换 |
| 路径处理 | 路径拼接、规范化、相对路径计算 |
| 对象操作 | 深拷贝、合并、路径访问 |
| 数组处理 | 去重、分组、排序、查找 |
| 异步工具 | 防抖、节流、重试、并发控制 |
| 时间处理 | 格式化、解析、计算 |

### 常量定义

- 应用常量（版本号、默认值）
- 错误代码
- 配置键名
- 事件名称

## 设计原则

### 结果类型

使用Result类型替代异常抛出，使错误处理更加显式：

| 类型 | 说明 |
|------|------|
| Success<T> | 成功结果，包含返回值 |
| Failure<E> | 失败结果，包含错误信息 |
| Option<T> | 可选值，Some或None |

### 防抖与节流

| 工具 | 说明 | 适用场景 |
|------|------|----------|
| debounce | 延迟执行，重复调用重置计时 | 搜索输入、窗口调整 |
| throttle | 固定频率执行 | 滚动事件、鼠标移动 |
| retry | 失败重试，支持退避策略 | 网络请求、文件操作 |

### 并发控制

| 工具 | 说明 |
|------|------|
| p-limit | 限制并发数量 |
| p-queue | 任务队列 |
| p-timeout | 超时控制 |

## 依赖关系

**外部依赖：** 最小化，仅引入必要的工具库

**内部依赖：** 无

**被依赖关系：** 所有模块均依赖基础工具类库

## 验收标准

- 所有工具函数有完整的单元测试
- 核心工具函数性能符合预期
- 类型定义完整且准确
- 无循环依赖
