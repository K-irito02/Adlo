## 市场推广调研（Adlo 桌面应用对外宣传）
- 用户计划在抖音 / B站 / 视频号（国内）与 YouTube / X（海外）宣传 Adlo（Windows 桌面应用）。
- 完成技能市场调研，可用技能按链路分为四段：选题排期 → 脚本/文案 → 素材生产 → 分发发布 → 数据复盘。
- 关键结论：真正带「发布」能力的技能共 4 个 —— `matrixmedia-publish`（矩媒，8 平台）、`self-media-distribution`（抖音/视频号/快手多账号）、`human-like-batch-publisher`（拟人节奏送草稿箱、人工点发布）、`multi-platform-publish`（公众号/头条/知乎/微博等图文类）。其余均为内容生产。
- 内容适配首选 `media-content-matrix`（9 平台一稿多发 + 广告法违禁词自查）与 `video-script`（7-60s 到 1-30min 全时长脚本）。
- 平台红线已确认：抖音/B站 禁止站外导流（链接、二维码、微信及谐音变体），抖音对「诱导安装第三方软件」高风险；YouTube 外链仅频道横幅/About/描述/置顶评论，卡片与片尾外链需 YPP（1000 订阅 + 4000 小时），Shorts 描述链接不可点击。
