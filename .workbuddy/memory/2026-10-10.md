### 已确认根因（源码级）
- **缺陷 A（图片粘贴荧光色层，颜色随重复次数变化）**：`image` 0.25.10 对 RGBA 输出 BITMAPV4HEADER + `BI_BITFIELDS` 的 BMP；`clipboard-win` 5.4.1 `raw::set_bitmap_inner` 只拷贝 40 字节 BITMAPINFOHEADER → `CreateDIBitmap` 把**未初始化栈内存**当颜色掩码读。修复：图片改 **24 位 BI_RGB BMP**（`to_rgb8`）。
- **缺陷 B（文本+图片追加式粘贴）**：`clipboard-win` 的 `raw::set_bitmap` 用 `NoClear::EMPTY_FN`，**不调 `EmptyClipboard`** → 旧格式残留。修复：统一写回前先 `EmptyClipboard`。
- **刷新延迟**：剪贴板历史**无推送**，仅 `ClipboardHistoryList.tsx` 固定 2000ms 轮询；失焦时 WebView2 后台节流更慢。`ClipboardMonitor` 的 broadcast **无订阅者**，`AppEvent::ClipboardChanged` **定义未 emit**。修复：补全 `监听 → ClipboardChanged → /ws/workspace {kind:"clipboard-changed"} → 前端即时重拉`，轮询降级 10s 兜底。

### 关键决策
- 类型扩为 text/image/html/rtf（排除文件/文件夹）；富文本存 sidecar（`clipboard/html|rtf/`），纯文本内联 `content`。
- 写回统一走后端 `clipboard.write(id)`（方案 A）；`writeImage` 移除。
- 弹窗：字符统计 / 缩放 / 自动换行 / 复制 / 编辑 / 保存为文件；文本默认字号 12px → 14px。
- 编辑模式（仅 text）：自建撤销栈 Ctrl+Z / Ctrl+Y，Ctrl+S 保存，Esc 取消更改，关闭/遮罩 = 保存并关闭；落库为原地更新（保持 createdAt 排序位置）。
- 新增 IPC：`clipboard.write` / `clipboard.update` / `clipboard.export` / `getHtmlUrl` / `getRtfUrl` / `onChanged`。
