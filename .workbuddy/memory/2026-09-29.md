### 工程经验

- **拆分 refactor 的连带清单**：改类名/模块位置后，除源码外还要同步：`editor-surface.css` 的 `:not()` 选择器、`revealOverlayWiring.test.ts` / `revealSourceLine.test.ts` / `cmPreviewStyling.test.ts` 等「源码字符串守卫测试」、以及 `.tsx`/`.ts` 后缀（含 JSX 的测试必须是 `.tsx`，否则 prettier 直接 SyntaxError）。
- **逐帧 rAF 循环的收尾**：覆盖层里的 `requestAnimationFrame` 跟踪循环若只在时长定时器里取消，宿主卸载后会空转到时长结束；jsdom 环境拆解后会抛 `HTMLElement is not defined`（vitest 报 Uncaught Exception，而非测试失败）。两条根因：① 判定用 `instanceof HTMLElement`（引用浏览器全局）→ 改 `offsetParent === null`；② React 卸载时 ref 已置空 → 清理所需宿主必须随高亮记录一起留存；另在循环内对「覆盖层已脱离文档」早退。
- **React 卸载顺序**：host 组件删除时 ref 在 mutation 阶段被置空，早于 passive effect 清理 → 清理函数里不能依赖 ref 取元素。

### 工程经验（本轮新增）

- **守卫用例会当场抓到真实缺陷**：新加的「行标记守卫」（索引每条行文案的 `locate` 必须能在 DOM 命中）立刻抓出 `downloads_default` —— 它并不在分类列表渲染（已并入「浏览器下载路径」块），索引却为它登记了行。修法不是删断言，而是把这条排除口径收成单一真源 `CATEGORY_KEYS_WITHOUT_OWN_ROW`（渲染侧原先硬编码 `!== 'downloads_default'`，与索引共用）。
- **条件渲染的 DOM 契约**：守卫对「只在特定编辑态才渲染」的行必须走**显式白名单 + 原因注释**，再加「白名单不得滞留」断言（避免删行后残留），否则守卫要么假失败、要么被随手放水。
- **用属性值等值比较而非 CSS 选择器定位**：定位值是 i18n 文案（可能含引号/反斜杠），`querySelector([data-x="..."])` 要转义；改为遍历 `[data-x]` 比 `getAttribute(...) === text` 更稳。
- **a11y 副作用可当断言**：跳转会把焦点交给落点元素，jsdom 无布局算不出高亮条几何，于是「焦点落在哪个元素」成为「落到哪一行」的可测观测点。
- 提醒：用 Python 脚本批量改源码时，`open(..., 'w', newline='')` 会把 CRLF 转成 LF；改完必须 `git diff --numstat` 确认没有整文件重写。
