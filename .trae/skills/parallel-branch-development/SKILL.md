# 并行分支开发

仓库根 [parallel-branch-development.md](../../../parallel-branch-development.md) 是并行开发流程的**唯一真源**。本技能只负责触发与路由，不重复条文；冲突时以手册为准。

## 使用步骤

1. 读取手册，至少覆盖 §1 概念、§2 开工自检、§3 模式选择。
2. 执行手册 §2 的 ENV PROBE 命令，向用户输出 `[ENV]` 一行快照；未输出快照不得开始改代码。
3. 按 §3 选路径：无任何槽位 → §3.1 建槽位；需多分支同时在线 → §3.2 新建工作树；串行换分支 → §3.3 复用改造（先过 G1–G4 门槛）。
4. 按 §4 遵守契约文件与构建运行约束，按 §5 提交与合并。
5. 收尾按 §9 更新 `.sessions/<session>.json`；工作树默认保留。

## 硬性边界

- 一分支 = 一工作树 = 一会话；两个会话禁止共用同一目录。
- 禁止跨工作树直接编辑文件，协作只走提交与合并。
- 禁止共享 `CARGO_TARGET_DIR`；同一时刻只允许一个 Tauri debug 实例。
- 分支工作树内禁止写 `.workbuddy/memory/**`。
- 清理工作树须用户明确要求。
