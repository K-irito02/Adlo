
# 浏览器标签功能重构计划

## 一、项目分析和需求理解

### 1.1 现状分析
- 当前浏览器标签管理在 `ui-store.ts` 中，使用简单的扁平数组
- 终端标签管理已经实现了完整的工作区分组、树形结构、右键菜单等功能
- 浏览器面板的当前实现仅在导航栏展示书签和历史，标签页面展示在主区域

### 1.2 需求总结
根据用户要求，需要实现：
1. 采用与终端功能完全相同的效果（布局、样式、动画、工作区头部、文件树层级等）
2. 工作区头部悬停时显示新建标签按钮
3. 空工作区展开时显示新建标签子节点
4. 工作区头部菜单/右键菜单：全部在新标签打开、重命名、删除、剪切、从该区域移除不显示
5. 标签节点右键菜单：在当前标签打开、在新标签打开、重命名、删除、剪切、编辑、复制链接
6. 支持手动创建与真实工作区无关的新工作区头部

## 二、架构设计

### 2.1 状态管理
- **浏览器标签切片**：创建与 `terminalSlice.ts` 类似的 `browserSlice.ts` 来管理浏览器标签状态
- **标签数据结构**：扩展 `BrowserTabState`，添加 `workspaceId`、`isPinned`、`sortOrder`、`pinnedAt` 字段
- **独立工作区标识**：使用 `__independent__` 作为独立（非关联真实工作区）标签的标识
- **工作区展开状态**：存储在 store 中

### 2.2 组件结构
```
features/
├── browser/
│   ├── BrowserTabBar.tsx          # 标签栏组件
│   ├── BrowserContextMenu.tsx     # 标签右键菜单
│   ├── BrowserMenuDropdown.tsx    # 更多操作菜单
│   ├── useBrowserPanel.ts         # 主面板逻辑hook
│   ├── useBrowserMenus.ts         # 菜单逻辑hook
│   ├── useBrowserContextMenu.ts   # 右键菜单hook
│   └── index.ts
└── workspace-browser/
    ├── MultiWorkspaceBrowser.tsx  # 多工作区浏览器容器
    ├── WorkspaceBrowserEntry.tsx  # 单工作区浏览器条目
    └── index.ts
```

## 三、详细实施计划

**文件：** `frontend/src/app/stores/slices/browserSlice.ts`

2. 实现状态操作
   - 标签创建、选择、关闭
   - 标签置顶、排序
   - 标签重命名、编辑

   - 从当前工作区移除功能

## 四、技术要点

### 4.1 类型设计
```typescript
export interface BrowserTabState {
  id: string;
  title: string;
  url: string;
  workspaceId: string;
  isPinned: boolean;
  pinnedAt?: number;
  sortOrder: number;
}
```

### 4.2 关键功能实现
1. 工作区头部菜单（更多操作按钮/右键）
2. 标签右键菜单
3. 新建标签在悬停/空状态时的显示
4. 独立工作区的创建和管理
